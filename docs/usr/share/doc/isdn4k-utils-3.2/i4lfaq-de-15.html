15. rawip: Raw IP

15.1 rawip_whatis: Was ist Raw IP, wann sollte ich es benutzen?

Raw IP kommt ohne Protokolle wie X.75, HDLC (für Modememulation, usw.) oder PPP aus. Die TCP/IP-Pakete werden direkt ausgetauscht. Raw IP hat sowohl Vor- als auch Nachteile. Vorteile:

  • Kein handshaking (= schnellerer Verbindungsaufbau)
  • Autorisierung durch Caller ID (= schnell, sicher, kein Password)
  • Feste IP-Addresse (= eine abgebbrochene Verbindung kann durch Wahlwiederholung fortgesetzt werden)
  • Höhere Datentransferraten
  • Bessere Stabilität (kleinerer Treiber = fast ohne Fehler)
Nachteile:
  • Kein handshaking => Die Konfiguration muss vorher stattfinden (IP-Addressen,...) => sollte nicht mit mehreren Providern gleichzeitig genutzt werden
  • Autorisierung nur durch Caller ID => Einwahl nur von einer vorher bekannten Telefonnummer möglich
  • Feste IP-Addresse => muss im Voraus bekannt sein, es werden mehr IP-Addressen benötigt, kein dynamisches Zuteilen von Addressen möglich.
Aufgrund dieser Zusammenstellung sollte klar sein, unter welchen Voraussetzungen die Verwendung von raw IP sinnvoll ist.
