15.2 Local Documentation

See (with S.u.S.E.) /usr/doc/packages/i4l und /usr/doc/packages/i4ldoc (the FAQ, package i4ldoc).

Help system (Start with help), in particular the support databank under the URL http://localhost/support-db/sdb

If the kernel sources are installed, much useful information can be found in the directory /usr/src/linux/Documentation/isdn.
