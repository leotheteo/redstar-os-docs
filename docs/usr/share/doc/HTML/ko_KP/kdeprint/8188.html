첫 페지

인쇄그룹선택항목을 미리설정으로 보관하기

문서를 인쇄할 때 자주 사용하는 선택항목의 조합이 있다면 <미리설정>으로 보관할수 있습니다. 례를 들어 두페지를 두줄의 가는 선의 테두리로 매개의 용지에 자주 인쇄한다면 하나의 미리설정으로 그 선택항목을 조합하여 각 선택항목을 개별적으로 선택하지 않고 빠르게 적용할수 있습니다.

미리설정을 보관하려면

문서를 열 때 <파일/인쇄>를 선택합니다.

인쇄대화창문에 두개의 내리펼침차림표와 아래에 일부 단추만 보인다면 <인쇄기>내리펼침차림표옆에 펼침삼각형을 찰칵합니다.

사용할 선택항목을 선택합니다.

<미리설정>내리펼침차림표에서 다른 이름으로 보관을 선택하고 선택항목모임의 이름을 입력합니다.

문서를 인쇄할 때 이 선택항목모임을 사용하려면 보관된 <미리설정>내리펼침차림표에서 이름을 선택합니다.

일부 선택항목은 미리설정값으로 보관할수 없습니다. 인쇄선택항목모임을 미리설정으로 보관한 다음 원하는 방법으로 문서가 인쇄되는가를 확인하기 위해서는 미리보기를 사용합니다.

<미리설정>을 변경하려면 <미리설정>내리펼침차림표에서 해당 이름을 선택하고 선택항목을 변경한 다음 미리설정내리펼침차림표에서 보관을 선택합니다. <이름변경>을 선택하여 보관된 미리설정의 이름을 변경할수 있으며 <삭제>를 선택하여 보관된 설정값을 삭제할수 있습니다.

특정 미리설정에 포함된 모든 선택항목목록을 보려면 <미리설정>내리펼침차림표에서 해당 이름을 선택한 다음 인쇄선택항목에서 개괄을 선택합니다.
