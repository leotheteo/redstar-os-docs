인쇄기관리에 대하여

인쇄기체계설정은 사용하는 인쇄기를 관리하도록 합니다. 인쇄기체계설정을 보기 위하여 <붉은별차림표/체계환경설정/인쇄기>를 선택합니다.


인쇄기 추가와 삭제

인쇄기를 리용하자면 인쇄기가 인쇄기목록에 있어야 합니다. 만일 인쇄기가 콤퓨터에 련결되여있다면 <추가(+)>를 찰칵하여 추가할수 있습니다. 인쇄기를 삭제하려면 삭제하려는 인쇄기를 선택하고 <삭제(-)>를 누릅니다.

■ 인쇄기 삭제

인쇄일감의 관리

인쇄일감의 관리는 인쇄기를 선택하고 인쇄대기렬의 열기를 찰칵할 때 표시되는 창문에서 진행합니다. 사용자는 여기에서 인쇄기 일시 정지, 인쇄일감지우기, 인쇄일감유지, 인쇄일감다시재개를 진행할수 있습니다.

■ 인쇄일감

인쇄기의 공유

다른 《붉은별》사용자와 인쇄기를 공유하기 위하여 <인쇄기의 공유>를 선택합니다. Windows, Unix, Mac OS X사용자와 공유를 진행하기 위하여 다음과 같이 진행할수 있습니다.

■ 인쇄기를 공유하기

인쇄기설정항목들의 선택

인쇄기의 설정항목들을 변경하여 인쇄대화창문에 그 항목들이 반영되도록 할수 있습니다. 인쇄기설정항목들을 선택하기 위하여 <설정항목···>을 찰칵하고 <구동프로그람>을 찰칵합니다.
