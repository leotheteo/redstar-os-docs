페지설정대화창문의 사용

새로운 문서를 생성할 때 용지크기, 방향을 포함하는 기본페지설정을 적용할수 있습니다. 문서를 인쇄하기 전에 페지설정대화창문에서 용지의 선택이나 인쇄페지방향의 변경을 할수 있습니다.

페지설정대화창문을 사용하려면

인쇄하려는 문서를 엽니다.

<파일/페지설정>을 선택합니다.

사용하려는 종이의 크기가 일반적인 크기라면(A3 또는 A4) <인쇄기>내리펼침차림표에서 모든 인쇄기를 선택합니다. 이렇게 하면 선택한 종이크기를 지원하는 어떤 인쇄기에서나 문서를 출력할수 있습니다.

종이의 크기가 특정한 인쇄기용이라면 <인쇄기>내리펼침차림표에서 해당 인쇄기의 이름을 선택합니다.

<용지>내리펼침차림표에서 종이를 선택합니다. 사용자설정종이를 생성하려면 <용지>내리펼침차림표에서 <사용자정의용지 설정···>을 선택합니다.

<세로(수직)>나 <가로(수평)>방향을 찰칵하여 페지방향을 선택합니다.

<확인>단추를 찰칵합니다.

참고: 여기서 설정하는 인쇄기는 용지설정만을 위한것입니다.
