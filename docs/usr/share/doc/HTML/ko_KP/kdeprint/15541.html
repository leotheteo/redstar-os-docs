첫 페지

사용자설정용지 생성하기

비표준크기의 봉투나 카드와 같이 특이한 크기의 용지에 인쇄하려면 <용지>내리펼침차림표에서 용지크기를 선택할수 있습니다. <용지>내리펼침차림표를 찾으려면 <파일/페지설정>을 선택합니다. 그렇지 않으면 <파일/인쇄>를 선택합니다.

필요한 크기를 찾을수 없다면 사용자설정용지를 생성할수 있습니다.

사용자설정용지를 생성하려면

인쇄하려고 하는 문서를 엽니다.

<파일/페지설정>을 선택합니다.

<용지>내리펼침차림표에서 <사용자정의용지 설정···>을 선택합니다.

사용자정의용지설정대화창에서 <추가(+)>단추를 찰칵합니다.

용지크기와 인쇄기여백마당에 값을 입력합니다.

인쇄선택항목의 설정
