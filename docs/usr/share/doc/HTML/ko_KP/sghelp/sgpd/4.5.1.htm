연시반복실행의 설정

모두 표시

전시회 등에서 연시물을 반복실행하려면 다음과 같은 방법으로 진행합니다.

  1. <투영편연시>차림표에서 <투영편연시 설정>을 찰칵합니다.
  2. <투영편연시 설정>대화창의 <류형>령역에서 <자동>단일선택단추를 선택하고 증감단추에 림시정지시간을 입력합니다.
  3. <투영편연시>차림표에서 <투영편 이행>을 찰칵하면 <과제>창의 <투영편 이행>표쪽이 펼쳐집니다.
  4. <투영편 이행>표쪽의 <선택된 투영편에 적용>목록칸에서 사용하려는 이행효과를 선택합니다.
  5. <화면 전환>령역의 <다음의 시간후 자동적으로> 단일선택단추를 찰칵하여 증감단추에 연시물실행시간을 입력합니다.
  6. 투영편연시를 시작하면 반복하기 전에 설정한 림시정지시간만큼 중지되였다가 자동적으로 반복실행됩니다.
