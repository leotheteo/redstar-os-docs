기호 또는 특수문자의 삽입

모두 표시

연시프로그람의 <특수문자>대화창을 사용하여 기호 또는 특수문자를 삽입하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편의 본문에서 기호 또는 특수문자를 삽입하려는 위치로 유표를 가져갑니다.
  2. <삽입>차림표에서 <특수문자>를 찰칵합니다.
  3. <특수문자>대화창의 <서체>복합칸에서 삽입하려는 기호 또는 특수문자의 서체를 선택합니다.

    4. 참고: <문자령역>복합칸의 내용은 선택한 서체에 따라서 달라집니다.

  4. <문자령역>복합칸에서 요구하는 항목을 선택합니다.
  5. 삽입하려는 기호 또는 문자를 선택합니다.
  6. <확인>단추를 찰칵합니다.

참고: <본문 서식설정>도구띠의 <특수문자>를 사용할수도 있습니다.
