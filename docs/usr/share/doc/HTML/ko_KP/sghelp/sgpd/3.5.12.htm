가로 및 세로방향 투영편의 결합

모두 표시

연시프로그람에서 투영편지면배치는 기본적으로 가로방향으로 설정되여있습니다.

때때로 가로 및 세로방향의 투영편이 결합된 연시물을 만들어야 할 필요가 있을수 있습니다.

연시프로그람은 가로 및 세로방향의 투영편이 결합된 연시물을 만들수 있는 편리한 기능을 제공합니다. 가로 및 세로방향의 투영편을 결합하여 연시물을 만들려면 다음과 같은 방법으로 진행합니다.

  1. 세로방향으로 지정하려는 투영편을 새로운 연시파일로 이동합니다.

    2. 방법

    1. <투영편>창에서 세로방향으로 지정하려는 투영편을 선택합니다.
    2. <편집>차림표에서 <자르기>를 찰칵합니다.
    3. 새로운 연시물을 엽니다.
    4. <편집>차림표에서 <붙이기>를 찰칵합니다.
  2. 연시물에서 투영편의 방향을 변경합니다.

    3. 방법

    1. <서식>차림표에서 <페지>를 찰칵합니다.
    2. <페지 설정>대화창에서 <페지>표쪽을 찰칵합니다.
    3. <용지형식>령역의 <방향>에서 <세로>단일선택단추를 찰칵합니다.
    4. <확인>단추를 찰칵하고 새로운 연시물을 보관합니다.
  3. 원래의 연시물에서 새로운 연시물로 이동하는 하이퍼련결을 만듭니다.

    4. 방법

    1. 세로방향의 투영편이 있는 연시물로 이동시키려는 본문이나 객체를 선택합니다.
    2. <표준>도구띠에서 <하이퍼련결>을 찰칵합니다.
    3. <하이퍼련결>대화창의 왼쪽창에서 <문서>를 선택합니다.
    4. <문서>령역의 <경로>본문칸에 이동하려는 새로운 연시물의 경로를 찾아 입력합니다.
    5. <적용>단추를 찰칵합니다.
    6. <닫기>단추를 찰칵합니다.
  4. 새로운 연시물에서 원래의 연시물로 이동하는 하이퍼련결을 만듭니다.

    5. 방법

    1. 가로방향의 투영편이 있는 본래의 연시물로 이동시키려는 본문이나 객체를 선택합니다.
    2. <표준>도구띠에서 <하이퍼련결>을 찰칵합니다.
    3. <하이퍼련결>대화창의 왼쪽창에서 <문서>를 선택합니다.
    4. <문서>령역의 <경로>본문칸에 이동하려는 원래의 연시물의 경로를 찾아 입력합니다.
    5. <적용>단추를 찰칵합니다.
    6. <닫기>단추를 찰칵합니다.
  5. 두개의 연시물파일을 모두 보관합니다.

참고: 이 투영편연시를 나타내려면 두개의 연시물파일이 모두 있어야 하며 이 파일들은 하이퍼련결을 설정할 때 찾았던 서류철에 그대로 있어야 합니다.
