인쇄의 추가선택

모두 표시

이 지령을 사용하려면 <서광사무처리>차림표의 <환경설정>을 찰칵합니다.

<환경설정>대화창에서 <서광사무처리 연시프로그람>의 <인쇄>를 선택합니다.

즉시도움말

이 령역에서 지정된 인쇄설정은 현재연시물뿐만이 아니라 뒤따르는 모든 문서에 적용됩니다. 현재연시물의 설정만 변경하려면 <서광사무처리>/<환경설정>/<서광사무처리>/<일반>에서 <인쇄대화창>령역에 있는 <서광사무처리 대화창 사용>확인칸을 선택하고 인쇄를 진행합니다.

출력품질령역

인쇄물의 출력품질을 지정하는 령역입니다.

항목 설명
기정 연시물의 화질을 기정으로 하여 인쇄하겠는가를 지정합니다.
회색계조 연시물을 회색계조로 인쇄하겠는가를 지정합니다.
흑백 연시물을 흑백으로 인쇄하겠는가를 지정합니다.

인쇄령역

인쇄추가선택을 지정하는 령역입니다.

항목 설명
페지이름 연시물의 페지이름을 인쇄하겠는가를 지정합니다.
날자 날자를 인쇄하겠는가를 지정합니다.
시간 시간을 인쇄하겠는가를 지정합니다.
숨겨진 페지 연시물에서 숨겨진 투영편을 인쇄하겠는가를 지정합니다.

페지 추가선택령역

연시프로그람인쇄물의 페지속성을 지정하는 령역입니다.

항목 설명
기정 연시물을 기정으로 인쇄하겠는가를 지정합니다.
페지에 맞추기 연시물을 페지크기에 맞추어 인쇄하겠는가를 지정합니다.
페지의 타일식배렬 연시물을 페지에 타일식으로 배렬하여 인쇄하겠는가를 지정합니다.
소책자

연시물을 소책자형식으로 인쇄하려면 <소책자>추가선택을 진행합니다.

연시프로그람의 소책자형식은 다음과 같습니다.

가로페지에서 세로문서를 인쇄하면 소책자의 마주 보고있는 두면은 서로 나란히 인쇄됩니다. 량면인쇄기능이 있는 인쇄기가 있는 경우 이후에 페지를 한부씩 인쇄하지 않고 문서에서 전체 소책자를 만들수 있습니다. 단면인쇄기능이 있는 인쇄기가 있는 경우 <정면>확인칸을 선택하여 먼저 앞페지를 인쇄하고 전체 용지를 인쇄기에 다시 넣은 다음 <뒤면>확인칸을 선택하여 뒤페지를 모두 인쇄하면 이 효과를 낼수 있습니다.
인쇄기설정에 따르는 용지공급법 용지함이 여러개인 인쇄기의 경우 인쇄기체계설정에서 지정한 용지법을 사용하도록 지정합니다.
