투영편찾기를 사용하여 투영편의 삽입

모두 표시

연시프로그람에서는 현재 작업하는 연시물에 다른 연시물의 일부 투영편이나 모든 투영편을 삽입할수 있습니다. 투영편찾기를 사용하여 투영편을 삽입하려면 다음과 같은 방법으로 진행합니다.

  1. <투영편>창에서 투영편을 삽입할 위치의 앞투영편의 축소판그림을 찰칵합니다.
  2. <삽입>차림표에서 <파일>을 찰칵합니다.
  3. <파일 삽입>대화창에서 파일을 선택한 다음 <열기>단추를 찰칵합니다.
  4. 다음의 방법들중에서 하나를 실행합니다.
    • 하나의 투영편을 삽입하려면 <투영편/객체 삽입>대화창에서 파일이름앞의 기호를 눌러 나타나는 투영편들가운데서 삽입하려는 투영편을 선택합니다.
    • 모든 투영편을 삽입하려면 <투영편/객체 삽입>대화창에서 연시물을 선택합니다.
  5. <확인>단추를 찰칵합니다.
