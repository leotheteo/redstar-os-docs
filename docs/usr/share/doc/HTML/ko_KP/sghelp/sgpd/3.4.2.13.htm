본문의 편집, 서식설정 및 이동에서 발생하는 문제의 해결

모두 표시

본문이 포함된 객체를 이동할수 없는 경우
  • 본문이 포함된 객체의 테두리를 찰칵하여 선택하고 마우스유표가 손모양으로 변경되면 객체를 끌어줍니다.
  • 본문이 포함된 객체를 투영편배경에서 만든 경우 투영편배경에서 해당 객체를 이동하려면 <보기>차림표에서 <배경페지>를 선택하고 <투영편배경페지>를 찰칵합니다. 투영편배경에서 객체를 찰칵하여 선택하고 끌어줍니다.
선택한 본문을 끌기하는 방법으로 편집할수 없는 경우

선택한 본문을 끌기할 때 마우스유표가 본문우에 있는가를 확인합니다. 본문을 끌기할 때 마우스유표의 오른쪽아래에 작은 빈 4각형이 표시됩니다.

본문에서 한행의 서식을 변경하려고 하는데 전체 단락의 서식이 변경되는 경우
  • 서식을 변경하려는 한행의 본문을 선택할 때 마우스유표를 현재행의 약간 아래까지 이동하면 다음행도 선택됩니다. 선택하는 도중에 마우스유표를 우로 이동하면 행이 잘못 선택되지 않습니다.
  • 행간격, 맞추기, 항목기호, 태브와 같은 일부 서식변경은 한행씩 적용되지 않으며 전체 단락의 서식이 변경됩니다.
  • 문자서식을 변경하려는 경우에는 변경하려는 본문만 선택합니다. 전체 단락을 선택하고 문자서식을 변경하면 전체 단락의 문자서식이 변경됩니다.
일부 투영편본문이 항목륜곽표쪽에 나타나지 않는 경우
  • <본문>을 사용하여 추가한 본문, 도형객체에 포함된 본문, 장식문자본문과 같은 일부 본문류형은 <항목륜곽>표쪽에 나타나지 않으며 편집할수 없습니다.
  • <항목륜곽>도구띠에서 <첫 준위>를 찰칵하면 투영편제목만 <항목륜곽>표쪽에 나타납니다. 본문을 모두 현시하려면 <모든 준위>를 다시 찰칵합니다.
