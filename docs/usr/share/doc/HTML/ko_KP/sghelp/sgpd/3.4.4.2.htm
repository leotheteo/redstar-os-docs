서체효과

모두 표시

문자의 서체효과를 설정하려면 서체효과를 설정하려는 문자렬을 선택하고 다음과 같은 방법으로 진행합니다.

  1. <서식>차림표에서 <문자>를 찰칵합니다.
  2. <문자>대화창에서 <서체효과>표쪽을 찰칵합니다.
  3. 다음의 방법들중에서 하나이상을 실행합니다.
    • 본문에 밑줄을 긋기하려면 <밑줄>복합칸에서 요구하는 밑줄형태를 선택합니다. 밑줄의 색을 변경하기 위해서는 <색>복합칸에서 해당한 색을 선택합니다.
    • 본문에 삭제선을 설정하기 위해서는 <삭제선>복합칸에서 삭제선의 형식을 선택합니다.
    • 본문의 웃쪽 또는 아래쪽에 강조표식을 하기 위해서는 <강조표식>복합칸에서 강조표식형식을 지정하고 <위치>복합칸에서 <본문우에> 또는 <본문밑에>를 선택합니다.
    • 서체의 색을 지정하기 위해서는 <서체색>복합칸에서 요구하는 색을 선택합니다.
    • 서체를 부각하려면 <부각>복합칸에서 <돌출> 또는 <오목>을 선택합니다.
    • 서체에 륜곽효과를 설정하려면 <륜곽>확인칸을 선택합니다.
    • 서체에 그림자효과를 설정하려면 <그림자>확인칸을 선택합니다.
