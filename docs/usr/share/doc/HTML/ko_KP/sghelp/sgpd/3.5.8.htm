개요투영편의 만들기

모두 표시

연시물을 만들 때 여러 투영편들의 내용을 요약하여 연시하는 투영편을 만들어야 할 필요가 있을수 있습니다. 즉 여러 투영편들의 제목을 항목륜곽으로 하는 새로운 투영편을 만들어야 할 필요가 있을수 있습니다.

연시프로그람에서는 여러 투영편들에 대하여 개요투영편을 만들수 있는 완벽한 기능을 제공합니다. 개요투영편을 만들려면 <표준>표쪽, <항목륜곽>표쪽 또는 <투영편정렬>표쪽을 찰칵하고 다음과 같은 방법으로 진행합니다.

  1. 새로 만들어지는 개요투영편의 아래준위 투영편으로 만들려는 투영편을 선택합니다.

    2. 즉시도움말

    여러 투영편을 선택하려면 [Ctrl]건을 누르면서 매 투영편들을 찰칵합니다.

  2. <삽입>차림표에서 <개요투영편>을 찰칵합니다.

    3. 참고: 개요투영편은 <투영편>창의 맨 마지막위치에 만들어집니다. 선택한 투영편으로부터 맨 마지막투영편까지의 투영편들의 제목들로 개요투영편의 개요가 이루어지며 개요투영편의 제목은 만들어지지 않습니다.
