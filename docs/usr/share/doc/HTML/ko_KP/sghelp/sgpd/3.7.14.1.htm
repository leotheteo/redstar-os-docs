사용자전용 투영편연시의 새로 만들기

연시프로그람에서 사용자전용 투영편연시를 새로 만들려면 다음과 같은 방법으로 진행합니다.

  1. <투영편연시>차림표에서 <사용자전용 투영편연시>를 찰칵합니다.
  2. <사용자전용 투영편연시>대화창에서 <새로 만들기>단추를 찰칵합니다.
  3. <사용자전용 투영편연시 정의>대화창에서 다음의 방법들중에서 하나를 실행합니다.

    4. 사용자전용 투영편연시의 만들기

    1. <이름>본문칸에 새로운 이름을 입력합니다.
    2. <기존투영편>목록칸에서 사용자전용 투영편연시에 포함시키려는 투영편을 선택합니다.

      3. 여러 투영편을 선택하려면 [Ctrl]건을 누른 상태에서 요구하는 투영편을 찰칵합니다.

    3. 단추를 찰칵합니다.
    4. <확인>단추를 찰칵합니다.
    5. 연시물에 있는 투영편으로 사용자전용 투영편연시를 더 많이 만들려면 1단계에서 4단계까지를 반복합니다.

    참고: 투영편을 <선택된 투영편>목록칸에서 <기존투영편>목록칸으로 다시 넘기려면 해당 투영편을 선택하고 단추를 찰칵합니다.

    하이퍼련결로 련결된 사용자전용 투영편연시의 만들기

    1. <이름>본문칸에 새로운 이름을 입력합니다.
    2. <기존투영편>목록칸에서 사용자전용 투영편연시에 포함시키려는 투영편을 선택합니다.

      3. 여러 투영편을 선택하려면 [Ctrl]건을 누른 상태에서 요구하는 투영편을 찰칵합니다.

    3. 단추를 찰칵합니다.
    4. <확인>단추를 찰칵합니다.
    5. 연시물에 있는 투영편으로 사용자전용 투영편연시를 더 많이 만들려면 1단계에서 4단계까지를 반복합니다.
  4. <확인>단추를 찰칵합니다.
  5. 하이퍼련결을 만듭니다.

    6. 방법

    1. 하이퍼련결로 사용하려는 본문이나 객체를 선택합니다.
    2. <표준>도구띠에서 <하이퍼련결>을 찰칵합니다.
    3. <하이퍼련결>대화창의 왼쪽령역에서 <문서>를 찰칵합니다.
    4. 오른쪽령역에서 이동하려는 사용자전용 투영편연시에 하이퍼련결을 진행합니다.
    5. <적용>단추를 찰칵합니다.
  6. <사용자전용 투영편연시 정의>대화창에서 사용자가 정의한 투영편연시를 선택하고 <시작>단추를 찰칵하여 투영편의 연시를 시작합니다.

사용자전용 투영편연시에 투영편의 추가 및 제거

사용자전용 투영편연시에 새로운 투영편을 추가하거나 이미 만든 사용자전용 투영편연시에서 투영편을 제거하려면 다음과 같은 방법으로 진행합니다.

  1. <투영편연시>차림표에서 <사용자전용 투영편연시>를 찰칵합니다.
  2. <사용자전용 투영편연시>대화창의 목록칸에서 투영편을 추가하거나 제거하려는 사용자전용 투영편연시를 선택합니다.
  3. <편집>단추를 찰칵합니다.
  4. <사용자전용 투영편연시 정의>대화창에서 다음의 방법들중에서 하나를 실행합니다.
    • 새로운 투영편을 추가하려면 <기존투영편>목록칸에서 추가하려는 투영편을 선택한 다음 단추를 찰칵합니다.
    • 투영편을 삭제하려면 <선택된 투영편>목록칸에서 삭제하려는 투영편을 선택한 다음 단추를 찰칵합니다.
  5. <확인>단추를 찰칵합니다.
  6. <시작>단추를 찰칵하여 투영편의 연시를 시작합니다.
