차림표, 차림표지령, 도구띠단추의 이동

모두 표시

이미 정의되여있는 차림표와 차림표지령, 도구띠의 단추를 사용자가 필요한 위치로 이동하여 그 배치순서를 임의로 바꿀수 있습니다.

다음과 같은 방법으로 진행합니다.

  1. <도구>차림표에서 <사용자전용화>를 찰칵합니다.
  2. <사용자전용화>대화창이 화면에 현시됩니다. 여기서 차림표와 차림표지령, 도구띠의 단추배치를 이동시킬수 있습니다.

    3. 차림표의 이동

    1. <사용자전용화>대화창에서 <차림표>표쪽을 찰칵합니다.
    2. <차림표>목록칸에서 이동할 차림표를 선택합니다. 이때 부분차림표는 이동할수 없으므로 선택하지 말아야 합니다.
    3. <차림표>단추를 찰칵하면 튀여나오기차림표가 현시되는데 여기서 <이동>을 선택합니다.
    4. 이때 현시되는 <차림표 이동>대화창에서 와 를 리용하여 차림표의 순서를 바꿉니다.
    5. <차림표 이동>대화창의 <확인>단추를 찰칵합니다.
    6. <사용자전용화>대화창의 <확인>단추를 찰칵합니다.

    차림표지령의 이동

    1. <사용자전용화>대화창에서 <차림표>표쪽을 찰칵합니다.
    2. <차림표>목록칸에서 이동하려는 차림표지령이 포함되여있는 차림표를 선택합니다. <차림표내용>부분의 <지령>목록칸에 우에서 선택한 차림표에 포함되여있는 차림표지령들이 렬거됩니다.
    3. <지령>목록칸에서 이동하려는 차림표지령을 선택하고 와 를 리용하여 차림표지령의 순서를 바꿉니다.
    4. <사용자전용화>대화창의 <확인>단추를 찰칵합니다.

    도구띠단추의 이동

    1. <사용자전용화>대화창에서 <도구띠>표쪽을 찰칵합니다.
    2. <도구띠>목록칸에서 이동하려는 단추가 포함되여있는 도구띠를 선택합니다. <도구띠내용>부분의 <지령>목록칸에 우에서 선택한 도구띠에 포함되여있는 단추들이 렬거됩니다.
    3. <지령>목록칸에서 이동하려는 단추를 선택하고 와 를 리용하여 단추의 순서를 바꿉니다.
    4. <사용자전용화>대화창의 <확인>단추를 찰칵합니다.
