암호의 제거 또는 변경

모두 표시

암호의 제거

암호를 제거하려면 다음과 같은 방법으로 진행합니다.

  1. 암호로 보호되여있는 연시물을 엽니다.
  2. <암호 입력>대화창이 나타나면 암호를 입력하고 <확인>단추를 찰칵하여 대화창을 닫습니다

    3. 참고: 틀린 암호를 입력하면 《암호가 정확하지 않습니다. 파일을 열수 없습니다.》라는 통보문이 현시됩니다. <확인>단추를 찰칵하면 <암호 입력>대화창이 다시 현시되여 정확한 암호를 다시 입력하던가 열기를 취소할수 있습니다.

  3. <파일>차림표에서 <다른 이름으로 보관>을 찰칵하여 대화창을 엽니다.
  4. 대화창에서 <암호를 사용하여 보관>확인칸의 선택을 해제합니다.
  5. <보관>단추를 찰칵하여 대화창을 닫습니다.
  6. 《파일이 이미 있습니다. 덧쓰겠습니까?》라는 통보문이 나타나면 <예>를 찰칵합니다.

암호의 변경

암호를 변경하려면 다음과 같은 방법으로 진행합니다.

  1. 암호로 보호되여있는 연시물을 엽니다.
  2. 우의 방법으로 암호를 제거합니다.
  3. <파일>차림표의 <다른 이름으로 보관>을 찰칵하여 대화창을 엽니다.
  4. 대화창에서 <암호를 사용하여 보관>확인칸을 선택합니다.
  5. 문서의 이름을 변경하지 않고 <보관>단추를 찰칵하여 대화창을 닫습니다.
  6. 《파일이 이미 있습니다. 덧쓰겠습니까?》라는 통보문이 나타나면 <예>를 찰칵합니다.
  7. <암호 설정>대화창에서 <암호>본문칸과 <확인>본문칸에 변경하려는 암호를 입력합니다. 이때 암호는 한문자이상 입력하여야 <확인>단추가 사용가능하게 됩니다.
  8. <확인>단추를 찰칵하여 대화창을 닫습니다.
