OLE 객체의 삽입

모두 표시

객체삽입지령을 사용하여 표처리프로그람의 자료표와 같은 OLE 객체를 삽입할수 있습니다.

OLE 객체를 새로 만들기

  1. <삽입>차림표의 <객체>에서 <OLE 객체>를 찰칵합니다.
  2. <OLE 객체 삽입>대화창에서 <새로 만들기>단일선택단추를 찰칵합니다.
  3. <객체류형>목록칸에서 객체류형을 선택합니다.
  4. <확인>단추를 찰칵합니다.

파일로부터 OLE 객체의 삽입

  1. <삽입>차림표의 <객체>에서 <OLE 객체>를 찰칵합니다.
  2. <OLE 객체 삽입>대화창에서 <파일로부터 만들기>단일선택단추를 찰칵합니다.
  3. <탐색>단추를 찰칵하여 <열기>대화창을 엽니다.
  4. <열기>대화창에서 OLE 객체가 포함되여있는 파일을 선택하고 <열기>단추를 찰칵하면 <OLE 객체 삽입>대화창의 <파일>본문칸에 OLE 객체가 포함되여있는 파일경로가 입력됩니다.
  5. OLE 객체를 파일과 련결하려면 <파일에 련결>확인칸를 선택합니다.
  6. <확인>단추를 찰칵합니다.
