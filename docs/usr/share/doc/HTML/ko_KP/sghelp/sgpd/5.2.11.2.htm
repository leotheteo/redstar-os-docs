도형객체의 대칭이동

모두 표시

도형객체를 대칭이동하려면 다음과 같은 방법으로 진행합니다.

  1. 대칭이동하려는 도형객체나 그림을 선택합니다.
  2. <도형>도구띠에서 <반전>을 찰칵합니다.
  3. 도형객체나 그림의 중심에 대칭축이 현시됩니다.
  4. 마우스유표를 대칭축우에 가져갑니다.
  5. 마우스유표가 손모양으로 변경되면 마우스의 왼쪽단추를 누른채로 대칭축을 임의의 위치에 끌어서 놓습니다.
  6. 마우스유표를 도형객체나 그림의 크기조종꼭지에 가져갑니다.
  7. 마우스유표가 대칭이동상태로 변경되면 마우스의 왼쪽단추를 누른 상태에서 대칭축의 반대쪽으로 끌기하면 도형객체나 그림이 대칭반전이동됩니다.
