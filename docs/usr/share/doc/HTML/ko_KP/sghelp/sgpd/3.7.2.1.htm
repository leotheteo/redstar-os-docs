형판의 만들기

모두 표시

형판은 특정한 서식, 격식, 그림, 표, 객체 및 기타 정보를 포함하고있는 문서입니다. 형판은 다른 문서를 만드는 기초로 사용됩니다.

연시프로그람에서는 연시물을 완전하고 전문적으로 보이도록 해주는 형판을 제공합니다.

새 문서를 만들 때 기초로 사용할수 있는 형판을 작성합니다.

다음의 방법들가운데서 하나를 리용하십시오.

구성항목으로 등록되는 형판의 새로 만들기

  1. 빈 문서를 새로 만들고 거기에 필요한 내용과 격식을 추가합니다.
  2. <파일>차림표에서 <형판>의 <보관>을 찰칵합니다.
  3. <형판>대화창에서 <새 형판>본문칸에 새로 작성하려는 형판의 이름을 입력합니다.
  4. <종류>목록칸에서 새로 작성하는 형판이 포함될 종류를 선택합니다.
  5. <확인>단추를 찰칵합니다.

파일보관방법을 리용한 형판의 새로 작성

  1. 빈 문서를 새로 만들고 거기에 필요한 내용과 격식을 추가합니다.
  2. <파일>차림표에서 <보관>을 찰칵합니다. 만일 이미 작성중에 있는 문서인 경우에는 <다른 이름으로 보관>을 찰칵합니다.
  3. 대화창이 펼쳐지면 파일목록칸에서 보관경로를 지정합니다.
  4. <파일형식>복합칸에서 <ODF 연시물형판( .otp)>을 선택합니다.
  5. <새로 보관>본문칸에 새로 작성하려는 형판의 이름을 입력합니다.
  6. <보관>단추를 찰칵합니다.
