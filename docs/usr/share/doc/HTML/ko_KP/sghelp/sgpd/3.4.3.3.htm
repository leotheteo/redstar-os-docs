복사 및 붙여넣기를 할 때 발생하는 문제의 해결

모두 표시

원래의 서식을 유지하도록 선택했는데도 문서처리프로그람으로부터 붙여넣은 본문의 서체크기 또는 서체격식이 제대로 현시되지 않는 경우

문서처리프로그람 또는 《내나라》열람기 등 다른 응용프로그람으로부터 본문을 붙여넣기 할 때 원래의 서식을 유지하도록 선택하면 연시프로그람에서는 대상연시물의 기본서체크기에 따라 서체크기를 조정합니다. 례를 들어 문서처리프로그람에서 12pt의 본문을 기본포인트가 32인 연시프로그람의 부제목객체틀에로 붙여넣으면 본문의 크기는 32pt가 됩니다. 또한 서체종류도 변경됩니다.
