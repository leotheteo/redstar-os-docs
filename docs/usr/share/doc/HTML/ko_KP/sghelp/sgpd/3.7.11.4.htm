호상작용의 삽입

모두 표시

다음의 방법들중에서 하나를 실행합니다.

단일 투영편에 호상작용객체를 삽입

  1. 호상작용객체를 삽입하려는 투영편을 선택합니다.
  2. 호상작용을 할수있는 객체를 만들고 <투영편연시>차림표에서 <호상작용>을 찰칵합니다.
  3. <마우스로 찰칵할 때 동작>복합칸에서 해당한 항목을 선택합니다.
  4. <확인>단추를 찰칵합니다.
모든 투영편에 호상작용객체를 삽입

하나의 투영편배경을 사용하는 경우 배경에 호상작용객체를 삽입하면 전체 연시물에서 해당 호상작용객체를 사용할수 있습니다. 둘이상의 형판을 연시물에 적용한것처럼 여러개의 투영편배경을 사용하는 경우에는 매 배경마다 호상작용객체를 삽입해야 합니다.

  1. <보기>차림표에서 <배경페지>를 가리킨 다음 <투영편배경페지>를 찰칵합니다.
  2. 호상작용할수 있는 객체를 만듭니다.
  3. <투영편연시>차림표에서 <호상작용>을 찰칵합니다.
  4. <마우스로 찰칵할 때 동작>복합칸에서 해당한 항목을 선택합니다.
  5. <확인>단추를 찰칵합니다.
  6. <배경페지보기>도구띠에서 <배경페지보기 닫기>를 찰칵합니다.
