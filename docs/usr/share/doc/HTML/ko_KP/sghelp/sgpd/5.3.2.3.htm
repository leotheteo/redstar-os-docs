도표에서 행과 렬

모두 표시

연시프로그람에서 작성한 도표의 행과 렬을 삽입, 이동, 삭제할수 있습니다.

도표의 행 또는 렬의 삽입

도표에 행 또는 렬을 삽입하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 행 또는 렬을 삽입하려는 도표를 두번 찰칵합니다.
  2. <서식 설정>도구띠에서 <도표자료의 표>를 찰칵합니다. <자료표>대화창이 현시됩니다.
  3. 다음의 방법들중에서 하나이상을 실행합니다.
    • 행을 삽입하려면 해당 행의 임의의 세포를 찰칵하고 <자료표>대화창의 <행 삽입>그림기호를 찰칵합니다.
    • 렬을 삽입하려면 해당 렬의 임의의 세포를 찰칵하고 <자료표>대화창의 <렬 삽입>그림기호를 찰칵합니다.
  4. 투영편으로 돌아가려면 도표바깥쪽을 찰칵합니다.

도표의 행 또는 렬자료의 이동

도표의 행 또는 렬자료를 이동하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 행 또는 렬의 자료를 이동하려는 도표를 두번 찰칵합니다.
  2. <서식 설정>도구띠에서 <도표자료의 표>를 찰칵합니다. <자료표>대화창이 현시됩니다.
  3. 다음의 방법들중에서 하나이상을 실행합니다.
    • 행자료를 이동하려면 해당 행의 임의의 세포를 찰칵하고 <자료표>대화창의 <행 아래쪽으로 이동>을 찰칵합니다.
    • 렬자료를 이동하려면 해당 렬의 임의의 세포를 찰칵하고 <자료표>대화창의 <렬 오른쪽으로 이동>을 찰칵합니다.
  4. <자료표>대화창을 닫고 투영편으로 돌아가려면 도표바깥쪽을 찰칵합니다.

도표의 행 또는 렬의 삭제

도표의 행 또는 렬을 삭제하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 행 또는 렬을 삭제하려는 도표를 두번 찰칵합니다.
  2. <서식 설정>도구띠에서 <도표자료의 표>를 찰칵합니다. <자료표>대화창이 현시됩니다.
  3. 다음의 방법들중에서 하나이상을 실행합니다.
    • 행을 삭제하려면 해당 행의 임의의 세포를 찰칵하고 <자료표>대화창의 <행 삭제>를 찰칵합니다.
    • 렬을 삭제하려면 해당 렬의 임의의 세포를 찰칵하고 <자료표>대화창의 <렬 삭제>를 찰칵합니다.
  4. <자료표>대화창을 닫습니다.
  5. 투영편으로 돌아가려면 도표바깥쪽을 찰칵합니다.
