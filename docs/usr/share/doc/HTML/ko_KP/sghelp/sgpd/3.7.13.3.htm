객체나 본문에 동화추가

모두 표시

객체에 동화추가

객체에 사용자전용동화를 적용하려면 다음과 같은 방법으로 진행합니다.

  1. <투영편>창에서 동화를 적용하려는 객체가 들어있는 투영편을 선택합니다.
  2. 동화를 적용할 객체를 선택합니다.
  3. 다음의 방법들중에서 하나를 실행합니다.
    • <투영편연시>차림표에서 <사용자전용 동화>를 찰칵합니다.
    • <과제>창이 현시되여있지 않은 경우 <보기>차림표에서 <과제창>을 찰칵합니다. <과제>창에서 <사용자전용 동화>표쪽을 찰칵합니다.
  4. <과제>창의 <사용자전용 동화>표쪽에서 <추가>단추를 찰칵하고 <사용자전용 동화>대화창에서 다음의 방법들중에서 하나이상을 실행합니다.
    • 투영편에 효과와 함께 객체가 나타나게 하려면 <입장>표쪽을 찰칵하고 목록칸에서 요구하는 효과를 찰칵합니다.
    • 투영편에 있는 객체에 효과를 추가하려면 <강조>표쪽을 찰칵하고 목록칸에서 요구하는 효과를 찰칵합니다.
    • 특정한 시점에서 객체가 투영편에서 사라지는 효과를 추가하려면 <퇴장>표쪽을 찰칵하고 목록칸에서 요구하는 효과를 찰칵합니다.
    • 지정된 문양으로 객체가 이동하는 효과를 추가하려면 <이동경로>표쪽을 찰칵하고 목록칸에서 요구하는 효과를 찰칵합니다.
  5. 추가된 효과에 대하여 미리보기하려면 <자동미리보기>확인칸을 선택합니다.
  6. <확인>단추를 찰칵합니다.

즉시도움말

과제창의 <사용자전용 동화>표쪽에서 <재생>단추를 사용하여 선택된 투영편의 동화를 미리보기할수 있습니다. 연시물에 적용된 동화를 미리 보려면 <투영편연시>단추를 찰칵합니다.

본문에 동화추가

연시프로그람에서는 본문에 동화를 두가지 방법으로 적용할수 있습니다.

본문대화창을 사용하여 본문에 동화추가

<본문>대화창을 사용하여 본문에 동화를 추가하려면 다음과 같은 방법으로 진행합니다.

  1. 동화를 적용하려는 본문을 선택합니다.
  2. <서식>차림표에서 <본문>을 찰칵합니다.
  3. <본문>대화창에서 <본문동화>표쪽을 찰칵합니다.

  4. <본문동화효과>령역의 <효과>복합칸에서 요구하는 효과를 선택합니다.

    본문동화효과에는 <깜박이기>, <통과흘림>, <앞뒤로 흘림>, <안으로 흘림> 등이 있습니다.

  5. <속성>령역에서 요구하는 확인칸을 선택합니다.
  6. <확인>단추를 찰칵합니다.

과제창의 사용자전용 동화표쪽을 사용하여 본문에 동화추가

<과체창>의 <사용자전용 동화>표쪽을 사용하여 본문에 동화를 추가하려면 다음과 같은 방법으로 진행합니다.

  1. <투영편>창에서 동화를 적용하려는 본문이 들어있는 본문객체를 선택합니다.

  3. <과제>창의 <사용자전용 동화>표쪽에서 <추가>단추를 찰칵하고 <사용자전용 동화>대화창에서 다음의 방법들중에서 하나이상을 실행합니다.
    • 투영편에 효과와 함께 본문이 나타나게 하려면 <입장>표쪽을 찰칵하고 목록칸에서 요구하는 효과를 찰칵합니다.
