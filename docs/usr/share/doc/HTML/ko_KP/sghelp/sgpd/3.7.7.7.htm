머리부 및 바닥부에서 발생하는 문제의 해결

모두 표시

하나의 연시물에서 여러 위치에 새 페지번호를 사용하려는 경우

연시프로그람에서는 불가능합니다. 연시물내에서 일련의 새 페지번호를 시작하려면 해당 투영편을 다른 연시물로 만들고 하이퍼련결을 사용하여 련결합니다.

숨긴 투영편에도 투영편번호가 생기는 경우

다음의 방법들중에서 하나를 실행합니다.

  • 숨긴 투영편을 모두 연시물의 끝으로 이동합니다. 현시되는 모든 투영편에 련속된 번호가 생깁니다.
  • 숨긴 투영편을 사용하는 경우 투영편번호나 페지번호를 투영편이나 투영편주해에 적용하지 마십시오.
연시물의 네트워크경로나 파일이름을 자동으로 현시하는 머리부나 바닥부를 만들려는 경우

연시프로그람에서 마당을 리용하여 삽입할수 있습니다.

  1. <보기>차림표의 <배경페지>의 <투영편배경페지>나 <주해배경페지>를 찰칵합니다.
  2. 바닥부 또는 머리부령역을 마우스로 찰칵하여 객체안의 본문을 선택합니다.
  3. <삽입>차림표의 <마당>에서 <파일이름>을 찰칵합니다.
