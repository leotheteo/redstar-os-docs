형판의 구성관리

모두 표시

연시프로그람에서는 파일을 형판으로 보관할수 있으며 형판의 구성 및 편집을 진행할수 있습니다.

<파일>차림표의 <형판>에서 <관리>를 찰칵하여 형판을 구성관리할수 있는 <형판 관리>대화창을 엽니다.

<형판 관리>대화창에서는 형판에 포함되여있는 격식들을 볼수 있으며 한 문서의 격식을 다른 문서에 복사할수 있습니다. 또한 <새로 만들기>, <삭제>, <편집>, <형판 반입>, <형판 반출> 등 여러 지령을 통하여 형판의 구성을 진행할수 있습니다.

형판의 종류를 새로 만들기

형판종류를 새로 만들수 있습니다. 새로운 형판종류를 만들려면 다음과 같은 방법으로 진행합니다.

  1. <형판 관리>대화창의 왼쪽목록칸에서 기정으로 현시되는 임의의 형판종류를 선택합니다.
  2. 다음의 방법들중에서 하나를 실행합니다.
    • 마우스의 오른쪽단추를 찰칵한 다음 상황차림표에서 <새로 만들기>를 찰칵합니다.
    • <지령>단추를 찰칵한 다음 튀여나오기차림표에서 <새로 만들기>를 찰칵합니다.
  3. <형판 관리>대화창의 왼쪽목록칸에 새로운 형판종류가 만들어집니다. 새로운 형판종류의 이름을 입력합니다.

형판의 삭제

형판을 삭제하려면 다음과 같은 방법으로 진행합니다.

  1. <형판 관리>대화창의 왼쪽목록칸에서 삭제하려는 형판을 선택합니다.
  2. 다음의 방법들중에서 하나를 실행합니다.
    • 마우스의 오른쪽단추를 찰칵한 다음 상황차림표에서 <삭제>를 찰칵합니다.
    • <지령>단추를 찰칵한 다음 튀여나오기차림표에서 <삭제>를 찰칵합니다.
  3. 확인창에서 <예>단추를 찰칵합니다.

형판의 편집

형판을 편집하려면 다음의 방법들중에서 하나를 실행합니다.

구성항목으로 등록된 형판의 편집
  1. <형판 관리>대화창의 왼쪽목록칸에서 편집하려는 형판을 선택합니다.
  2. 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표나 <지령>단추를 찰칵하여 펼쳐지는 튀여나오기차림표에서 <편집>을 찰칵합니다.
  3. 등록된 형판이 열려지면 필요한 편집조작을 진행하여 보관합니다.
열기대화창을 리용한 형판의 편집
  1. <파일>차림표의 <형판>에서 <편집>을 찰칵합니다.
  2. <열기>대화창의 파일목록칸에 《서광사무처리》 3.0프로그람이 형판의 저장고로 리용하는 서류철이 기정으로 펼쳐집니다. 파일목록칸에서 편집하려는 형판을 찾아 선택합니다.
  3. <열기>단추를 찰칵합니다.
  4. 형판이 열려지면 필요한 편집조작을 진행하여 보관합니다.

형판의 반입

<형판 반입>지령을 사용하여 형판을 반입할수 있습니다. 형판을 반입하려면 다음과 같은 방법으로 진행합니다.

  1. <형판 관리>대화창의 왼쪽목록칸에서 반입하려는 형판의 종류나 형판을 선택합니다.
  2. 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표나 <지령>단추를 찰칵하여 펼쳐지는 튀여나오기차림표에서 <형판 반입>을 찰칵합니다.
  3. <열기>대화창의 파일목록칸에서 반입하려는 파일을 선택합니다.
  4. <열기>단추를 찰칵합니다.

형판의 반출

<형판 반출>지령을 사용하여 형판을 반출할수 있습니다. 형판을 반출하려면 다음과 같은 방법으로 진행합니다.

  1. <형판 관리>대화창의 왼쪽목록칸에서 반출하려는 형판을 선택합니다.
  2. 마우스의 오른쪽단추를 찰칵하거나 <지령>단추를 찰칵하여 펼쳐지는 튀여나오기차림표에서 <형판 반출>을 찰칵합니다.
  3. <보관>대화창의 <새로 보관>본문칸에 반출하려는 파일이름을 입력합니다.
  4. <보관>단추를 찰칵합니다

격식복사

다른 문서의 격식을 이미 등록된 형판에 복사할수 있습니다. 격식을 복사하려면 다음과 같은 방법으로 진행합니다.

  1. <형판 관리>대화창의 오른쪽목록칸에서 문서를 찰칵하여 <파일>단추를 사용가능하게 합니다.
  2. <파일>단추를 찰칵합니다.
  3. <열기>대화창의 파일목록칸에서 복사하려는 격식을 포함하고있는 원본파일을 선택합니다.
  4. <열기>단추를 찰칵합니다.
  5. <형판 관리>대화창의 오른쪽목록칸에 원본파일의 이름이 현시됩니다. 원본파일을 두번 찰칵하면 파일에 포함되여있는 격식이 현시됩니다.
  6. 요구하는 격식을 복사하려면 [Ctrl]건을 누른 상태에서 격식을 끌어줍니다.

    7. 참고: 격식복사를 진행하는 두 문서는 현재 열려 있어야 합니다.

  7. <닫기>단추를 찰칵합니다.

참고: 체계가 지원하는 기정형판에 대해서는 형판을 편집하거나 삭제를 진행할수 없습니다.
