모두 표시

객체련결에 사용되는 접속기에는 접속기, 직선접속기, 선접속기, 곡선접속기의 네개 류형이 있습니다.

접속기와 결합된 객체를 다시 정렬하면 접속기가 객체에 련결된 상태에서 객체와 함께 이동합니다. 접속기의 한 끝을 이동하면 해당 끝의 련결이 해제되거나 객체에서 분리됩니다. 이때 해당 끝을 같은 객체의 다른 접착점에 련결하거나 다른 객체에 련결할수 있습니다. 일단 접착점에 련결이 설정된 접속기는 객체를 이동하더라도 객체에 계속 련결되여있습니다.

접속기의 그리기

  1. <도형>도구띠에서 <접속기>옆의 화살표를 찰칵합니다.
  2. 펼쳐지는 <접속기>도구띠에서 요구하는 접속기류형을 찰칵합니다.
  3. 련결하려는 객체의 접착점우에서 마우스의 왼쪽단추를 찰칵한 다음 마우스유표를 다른 접착점으로 이동하여 마우스의 왼쪽단추를 찰칵합니다.
