눈금자, 안내선의 현시와 숨기기

모두 표시

문서작성에서 많이 사용되는 눈금자와 안내선을 현시하거나 숨길수 있습니다.

다음과 같은 방법으로 진행합니다.

  1. <서광사무처리>차림표에서 <환경설정>을 찰칵합니다.
  2. <환경설정>대화창이 화면에 현시됩니다.
  3. 목록칸에서 <서광사무처리 연시프로그람>의 <보기>를 선택합니다.
  4. <현시>부분의 <눈금자 보이기>확인칸을 선택 및 해제하는 방법으로 눈금자를 현시하거나 숨길수 있습니다.
  5. <현시>부분의 <이동시 안내선>확인칸을 선택 및 해제하여 안내선을 현시하거나 숨길수 있습니다.

참고: 눈금자는 도형객체의 크기와 위치를 정확히 선택할수 있게 하여주며 안내선은 눈금자를 정확히 가리킬수 있도록 하여줍니다. 안내선은 객체를 이동할 때 보여지게 됩니다.

눈금자와 안내선에 의하여 가리키는 크기와 위치는 상태띠의 해당 마당에 수값으로 표현됩니다.
