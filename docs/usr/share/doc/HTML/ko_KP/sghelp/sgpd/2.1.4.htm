삽입

모두 표시

지령명 설명
투영편 현재 선택한 투영편의 다음에 투영편을 삽입합니다.
투영편 복제 현재투영편의 다음에 현재투영편의 복사본을 삽입합니다.
투영편 확장 선택한 투영편의 모든 맨 웃준위 개요항목(개요층구조에서 제목본문보다 한 준위만큼 아래에 있는 본문)에서 새 투영편을 만듭니다. 개요본문은 새 투영편의 제목으로 됩니다.
개요투영편 선택한 투영편의 다음에 오는 투영편제목의 항목기호목록을 포함한 새 투영편을 만듭니다. 마지막투영편의 다음에 개요투영편이 삽입됩니다.
머리부 및 바닥부 투영편과 주해 및 배포물의 머리부와 바닥부에 본문을 추가하거나 변경하는 대화창을 엽니다.
마당 투영편에 삽입가능한 마당을 추가합니다.
특수문자 특수문자를 삽입합니다.
서식설정 표식 객체에 삽입된 문서에 각종 서식을 적용합니다．
하이퍼련결 하이퍼련결을 만들고 편집할수 있는 대화창을 엽니다.
그림 삽입할 그림의 원본을 선택합니다.
표 현재투영편에 표를 삽입하기 위한 <표 삽입>대화창을 엽니다.
객체 문서에 객체를 삽입합니다. 수학식을 삽입하려면 <삽입>/<객체>/<수학식>을 사용합니다.
파일 현재투영편에 파일을 삽입합니다.
흡착점/흡착선 삽입 현재투영편의 지정한 위치에 흡착을 위한 점이나 선을 삽입하는 대화창을 엽니다.

마당

지령명 설명
날자(고정) 투영편에 현재날자를 고정마당으로 삽입합니다. 날자가 자동적으로 갱신되지 않습니다.
날자(가변) 투영편에 현재날자를 가변마당으로 삽입합니다. 파일을 다시 적재하면 날자가 자동적으로 갱신됩니다.
시간(고정) 투영편에 현재시간을 고정마당으로 삽입합니다. 시간은 자동적으로 갱신되지 않습니다.
시간(가변) 투영편에 현재시간을 가변마당으로 삽입합니다. 파일을 다시 적재하면 시간이 자동적으로 갱신됩니다.
작성자 《서광사무처리》 3.0 사용자자료에 입력된 성과 이름을 현재투영편에 삽입합니다.
페지번호 현재투영편 또는 페지에 페지번호를 삽입합니다.
파일이름 파일의 이름을 삽입합니다.

서식설정 표식

지령명 설명 지름건
행바꾸기 하지 않는 공백 공백을 삽입하여 공백 앞뒤의 문자를 함께 행바꾸어 현시합니다. Ctrl+Shift+Space
행바꾸기 하지 않는 이음표 이음표를 삽입하여 이음표 앞뒤의 문자를 함께 행바꾸어 현시합니다.  
임의의 이음표 단어에 보이지 않는 이음표를 삽입하여 단어가 행에서 마지막단어가 되면 이음표가 표시되고 행바꾸기되도록 합니다.  

그림

지령명 설명
파일로부터 현재문서에 그림을 삽입합니다.
주사 주사한 화상을 문서에 삽입합니다.

객체

지령명 설명
OLE 객체 현재문서에 OLE 객체를 삽입합니다. OLE 객체는 련결된 객체나 포함된 객체로 삽입됩니다.
수학식 현재문서에 수학식을 삽입합니다.
도표 현재문서에 도표를 삽입합니다.
