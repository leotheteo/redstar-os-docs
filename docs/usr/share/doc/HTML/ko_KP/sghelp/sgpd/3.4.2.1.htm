본문을 틀에 맞추기

모두 표시

연시프로그람에서는 입력하는 본문의 크기를 본문틀에 맞게 설정할수 있습니다.

본문대화창에서의 틀에 맞추기설정

본문대화창에서 틀에 맞추기를 설정하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 맞추기하려는 본문틀을 선택합니다.
  2. <서식>차림표에서 <본문>을 찰칵합니다.
  3. <본문>대화창의 <본문>표쪽에서 <틀에 맞추기>확인칸이 선택되여있지 않으면 이 확인칸을 선택합니다.
  4. <확인>단추를 찰칵합니다.

본문도구띠의 그림기호를 사용하여 틀에 맞추기설정

<본문>도구띠의 그림기호를 사용하여 틀에 맞추기를 설정하려면 다음과 같은 방법으로 진행합니다.

  1. <본문>도구띠가 현시되여있지 않으면 <보기>차림표의 <도구띠>에서 <본문>을 찰칵합니다.
  2. <본문>도구띠에서 <본문을 틀에 맞추기> 또는 <세로쓰기 본문을 틀에 맞추기>를 찰칵합니다.
  3. 투영편에서 본문을 입력하려는 위치에 마우스를 찰칵하고 끌기하여 본문칸의 크기를 지정한 다음 마우스를 놓습니다.
  4. 본문칸에 본문을 입력합니다.
