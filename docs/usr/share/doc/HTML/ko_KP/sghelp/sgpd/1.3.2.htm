기본작업서류철의 변경

모두 표시

기본작업서류철의 변경은 다음과 같은 방법으로 진행합니다.

  1. <서광사무처리>차림표에서 <환경설정>을 찰칵합니다.
  2. <환경설정>대화창이 화면에 현시됩니다.
  3. 목록칸에서 <서광사무처리>의 <경로>를 선택합니다.
  4. 오른쪽에 <서광사무처리에서 사용하는 경로>목록칸이 펼쳐집니다.
  5. 여기서 해당한 항목을 선택합니다.
  6. 경로를 변경할 항목을 선택하면 <서광사무처리에서 사용하는 경로>목록칸의 아래에 <기정>단추와 <편집>단추가 활성상태로 됩니다.
  7. <편집>단추를 찰칵하면 <경로 선택>대화창이 펼쳐집니다. 변경하려는 위치를 지정하고 <확인>단추를 찰칵합니다.
  8. 만일 변경된 후 원래값으로 복귀하려면 <기정>단추를 찰칵합니다.
  9. <환경설정>대화창의 <확인>단추를 찰칵하여 대화창을 닫습니다.
