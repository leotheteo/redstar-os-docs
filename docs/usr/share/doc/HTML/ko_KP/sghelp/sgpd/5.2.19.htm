도형객체의 테두리제거

도형객체의 테두리를 제거하려면 다음과 같은 방법으로 진행합니다.

  1. 테두리를 제거하려는 도형객체를 선택합니다.
  2. 객체안에서 마우스의 오른쪽단추를 찰칵하고 상황차림표에서 <선>을 찰칵합니다.
  3. <선>대화창에서 <선>표쪽을 찰칵하고 <선속성>령역의 <격식>복합칸에서 <보이지 않게>를 선택합니다.
  4. <확인>단추를 찰칵합니다.

칠하기추가, 변경 및 제거

도형객체의 칠하기를 추가, 변경 또는 제거하려면 다음과 같은 방법으로 진행합니다.

  1. 변경하려는 도형객체나 본문령역, 장식문자를 선택합니다.
  2. <서식>차림표에서 <령역>을 찰칵합니다.
  3. 다음의 방법들중에서 하나를 실행합니다.

    4. 칠하기색의 추가 또는 변경

    다음의 방법들중에서 하나를 실행합니다.

    • 색구성표에 있는 색으로 변경하려면 <령역>표쪽의 <색>목록칸에 현시현시된 색중에서 하나를 찰칵합니다.
    • 색구성표에 없는 색으로 변경하려면 <색>표쪽에서 요구하는 색을 찰칵합니다.

    칠하기색의 제거

    <령역>표쪽에서 <칠하기>복합칸의 <없음>을 찰칵합니다.
