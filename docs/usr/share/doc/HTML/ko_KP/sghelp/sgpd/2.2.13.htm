3D 객체

모두 표시

그림기호 지령명 기능
정6면체 투영편에서 마우스로 끌기한 위치에 채운 정6면체를 그립니다. 직6면체를 그리려면 [Shift]건을 누른 상태에서 마우스를 끕니다.
구형 투영편에서 마우스로 끌기한 위치에 채운 구형을 그립니다. 타원체를 그리려면 [Shift]건을 누른 상태에서 끕니다.
원기둥 투영편에서 마우스로 끌기한 위치에 원을 기초로 원기둥을 그립니다. 타원을 기초로 원기둥을 그리려면 [Shift]건을 누른 상태에서 끕니다.
원추형 투영편에서 마우스로 끌기한 위치에 원을 기초로 하여 원추형을 그립니다. 타원을 기초로 원추형을 그리려면 [Shift]건을 누른 상태에서 끕니다.
각추 투영편에서 마우스로 끌기한 위치에 밑면이 정4각형인 각추를 그립니다. 밑면이 직4각형인 각추를 그리려면 [Shift]건을 누른 상태에서 끕니다. 각추의 밑면을 다른 다각형으로 정의하려면 <3D 효과>대화창을 열고 <기하학>단추를 누릅니다. <토막>령역에서 <가로>증감단추에 다각형의 변수를 입력한 다음 <할당>단추를 누릅니다.
고리면 투영편에서 마우스로 끌기한 위치에 원을 기초로 반지모양의 객체를 그립니다. 타원을 기초로 고리면을 그리려면 [Shift]건을 누른 상태에서 끕니다.
쉘 투영편에서 마우스로 끌기한 위치에 원을 기초로 사발모양의 객체를 그립니다. 타원을 기초로 쉘형을 그리려면 [Shift]건을 누른 상태에서 끕니다.
반구형 투영편에서 마우스로 끌기한 위치에 반구형을 그립니다. 반타원체를 그리려면 [Shift]건을 누른 상태에서 끕니다.
