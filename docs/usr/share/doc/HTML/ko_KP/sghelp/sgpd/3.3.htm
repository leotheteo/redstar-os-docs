형판을 사용하여 새로 만들기

모두 표시

연시프로그람이 기본적으로 제공하는 형판이나 사용자가 만든 형판을 사용하여 연시물을 만들려면 다음과 같은 방법으로 진행합니다.

  1. 다음의 방법들중에서 하나를 실행하여 <형판 및 문서>대화창을 엽니다.
    • <파일>차림표의 <새로 만들기>에서 <형판 및 문서>를 찰칵합니다.
    • <표준>도구띠에서 <새로 만들기>그림기호를 찰칵하고 <형판 및 문서>를 찰칵합니다.
    • [Ctrl+Shift+N]건을 누릅니다.
  2. <형판 및 문서>대화창의 왼쪽령역에서 <형판>을 찰칵하고 형판이 있는 위치를 찾습니다.
  3. 요구하는 형판을 선택하고 <열기>단추를 찰칵하여 대화창을 닫습니다. 파일이름이 《제목 없음》으로 되여있는 새 파일이 펼쳐집니다.
  4. 문서편집을 진행합니다.
  5. 다음의 방법들중에서 하나를 실행하여 작업한 파일을 보관합니다.
    • <파일>차림표의 <보관>을 찰칵합니다.
    • <표준>도구띠에서 <보관>그림기호 를 찰칵합니다.
    • [Ctrl+S]건을 누릅니다.
  6. <보관>대화창이 펼쳐집니다.
  7. <새로 보관>본문칸에 요구하는 파일이름을 입력하고 <보관>단추를 찰칵하여 대화창을 닫습니다.
