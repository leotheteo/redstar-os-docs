색구성표의 추가

모두 표시

색구성표를 추가하여 연시물을 만드는데 사용할수 있습니다.

  1. <서광사무처리>차림표에서 <환경설정>을 찰칵합니다.

  2. <환경설정>대화창에서 <서광사무처리>의 <겉모양>을 선택합니다.

  3. <사용자전용색>부분에서 매 항목을 요구하는 색으로 선택합니다.

    4. 참고: <사용자전용색>의 모든 항목들을 재설정하려면 <재설정>단추를 찰칵합니다.

  4. <색구성표>부분에서 <보관>단추를 찰칵합니다.
  5. <구성표 보관>대화창의 <색구성표이름>본문칸에 요구하는 색구성표이름을 입력합니다.
  6. <확인>단추를 찰칵합니다.
