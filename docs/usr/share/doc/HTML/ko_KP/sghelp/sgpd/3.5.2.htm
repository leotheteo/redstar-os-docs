투영편을 복사하여 붙여넣기

모두 표시

연시프로그람에서 두 연시물사이에 투영편을 복사하여 붙여넣기하려면 다음과 같은 방법으로 진행합니다.

  1. 연시물사이에 투영편을 복사하려면 두 연시물을 엽니다.
  2. <투영편>창에서 복사할 투영편을 선택하려면 다음의 방법들중에서 하나를 실행합니다.
    • 하나의 투영편을 선택하려면 요구하는 투영편을 찰칵합니다.
    • 서로 린접하지 않은 여러 투영편을 선택하려면 한 투영편을 선택한 후 [Ctrl]건을 누른 상태에서 나머지투영편을 각각 선택합니다.
    • 린접한 여러 투영편을 선택하려면 첫번째 투영편을 선택한 후 [Shift]건을 누른 상태에서 마지막투영편을 선택합니다.
  3. 선택한 투영편에서 마우스의 오른쪽단추를 찰칵합니다.
  4. 상황차림표에서 <복사>를 찰칵합니다.
  5. 붙이려는 연시물문서로 절환한 다음 <투영편>창에서 복사한 투영편을 붙이려는 위치를 선택합니다. <투영편>창에서 임의의 투영편을 찰칵하거나 련속된 두 투영편사이의 빈 공간을 찰칵합니다.
  6. 마우스의 오른쪽단추를 찰칵한 다음 상황차림표에서 <붙이기>를 찰칵합니다.

    7. 참고: <투영편>창에서 투영편을 선택하고 붙이기하면 선택한 투영편의 아래에 삽입되며 련속된 두 투영편사이의 빈 공간을 선택하고 붙이기하면 두 투영편사이에 삽입됩니다.

참고: 투영편을 복사하지 않고 이동하려면 <복사>대신 <자르기>를 찰칵합니다. <투영편>창에서 모든 투영편들을 선택하고 마우스의 오른쪽단추를 찰칵하면 상황차림표에 <복사>항목만이 현시됩니다.

즉시도움말

[Ctrl+C]를 눌러서 복사하거나 [Ctrl+X]를 눌러서 자르기할수 있습니다. [Ctrl+V]를 누르면 붙이기할수 있습니다.
