주해의 배경

모두 표시

연시물의 모든 주해에 적용하여야 할 내용이 있다면 주해배경를 변경합니다. 례를 들어 모든 주해에 기업소상표나 다른 그림을 넣으려면 상표나 그림을 주해배경에 추가합니다. 주해에 사용하는 서체격식을 변경하려면 주해배경에서 서체격식을 변경합니다. 투영편령역, 주해령역, 머리부, 바닥부, 페지번호, 날자의 모양과 위치도 변경할수 있습니다.

투영편의 주해배경을 만들려면 다음과 같은 방법으로 진행합니다.

  1. 주해배경을 만들려는 투영편을 선택합니다.
  2. <보기>차림표에서 <배경페지>를 가리킨 다음 <주해배경페지>를 찰칵합니다.
  3. 주해창에 현재투영편에 대한 주해서식을 편집합니다.
  4. 투영편으로 이동하려면 <배경페지보기>도구띠에서 <배경페지보기 닫기>를 찰칵합니다.
