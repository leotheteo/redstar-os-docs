투영편의 이행효과 추가

연시프로그람에서는 투영편들사이에 이행효과를 적용할수 있습니다. 다음과 같은 방법으로 진행합니다.

  1. <과제>창이 현시되여있지 않으면 <보기>차림표에서 <과제창>을 찰칵합니다. <과제>창이 이미 열려있고 <배치> 또는 <사용자전용 동화>, <배경페지>표쪽이 현시되여있는 경우 <투영편 이행>표쪽을 찰칵합니다.
  2. <선택된 투영편에 적용>의 목록칸에서 요구하는 투영편이행효과를 선택합니다.
  3. 모든 투영편들에 같은 이행효과를 적용하려면 <모든 투영편에 적용>단추를 찰칵합니다.

투영편의 연시시간 설정

투영편에 이행효과를 추가하는 경우 매 투영편이 자연스럽게 련결되고 전문적으로 보이도록 연시시간을 다양하게 설정할수 있습니다.

다음의 방법들중에서 하나를 실행합니다.

수동으로 시간설정

시간을 설정하려는 모든 투영편에 대해 다음의 과정을 반복합니다.

  1. <투영편>창에서 시간을 설정하려는 투영편을 선택합니다.
  2. <투영편연시>차림표에서 <투영편 이행>을 찰칵합니다. 그러면 과제창의 <투영편 이행>표쪽이 펼쳐집니다.
  3. <화면 전환>령역의 <다음의 시간후 자동적으로>단일선택단추를 찰칵하고 투영편을 화면에 현시하려는 시간을 입력합니다.

연시시간 기록

연시시간을 측정하려면 다음과 같은 방법으로 진행합니다.

  1. <투영편연시>차림표에서 <시간맞추기 련습>을 찰칵하여 연시를 시작합니다. 연시화면의 왼쪽아래에 시간기록기가 현시됩니다.
  2. 다음투영편으로 이행하려는 시간이 되면 시간기록기를 찰칵합니다. 연시시간을 기록하지 않으려면 투영편의 임의의 곳을 찰칵합니다.
