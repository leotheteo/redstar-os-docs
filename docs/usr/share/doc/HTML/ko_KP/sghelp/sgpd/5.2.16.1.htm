선

모두 표시

선의 그리기

선을 그리려면 다음과 같은 방법으로 진행합니다.

  1. <도형>도구띠에서 <선>을 찰칵합니다.
  2. 선을 삽입하려는 위치를 찰칵하고 마우스로 요구하는 크기가 될 때까지 끌어줍니다.

    3. 참고: 선을 시작점에서 45°각도로 그리도록 제한하려면 [Shift]건을 누른 상태에서 마우스를 끌어줍니다.

  3. 투영편의 임의의 위치에서 마우스를 찰칵하여 선그리기상태를 해제합니다.

선의 변경

선을 추가한 후 선의 모양을 여러가지로 변경할수 있습니다. 선의 정점의 위치를 변경하여 선의 크기를 변경할수도 있고 선에 정점을 추가하거나 삭제하는 방법으로 선의 모양을 변경할수도 있습니다. 또한 직선을 곡선으로도 변경할수 있습니다. 선을 변경하려면 다음과 같은 방법으로 진행합니다.

  1. 변경하려는 선을 선택합니다.
  2. <도형>도구띠의 <점>을 찰칵하여 <점 편집>도구띠를 현시합니다.
  3. 다음의 방법들중에서 하나를 선택합니다.

    4. 정점의 위치를 변경하여 선의 모양변경

    선을 선택하고 정점을 찰칵하여 요구하는 크기가 될 때까지 마우스끌기를 합니다.

    정점을 추가 또는 삭제하여 선의 모양변경

    다음의 방법들중에서 하나를 실행합니다.

    • 선택한 선에 정점을 추가하여 모양을 변경하려면 <점 편집>도구띠에서 <점 삽입>을 찰칵합니다. 선우의 정점을 추가하려는 위치를 찰칵하고 마우스를 요구하는 방향으로 끌어줍니다.

      • 참고: <점 삽입>을 찰칵한 조건에서 요구하는 개수만큼의 정점을 추가할수 있습니다.

    • 선택된 선에서 정점을 삭제하여 모양을 변경하려면 삭제하려는 정점을 찰칵하고 <점 편집>도구띠에서 <점 삭제>를 찰칵합니다.

    직선을 곡선으로 변경

    다음과 같은 방법으로 진행합니다.

    1. 선에서 임의의 정점을 선택합니다.

    2. <점 편집>도구띠의 <곡선으로 변환>그림기호을 찰칵합니다.

      선에 파란색의 원형조종꼭지가 나타납니다.

    3. 마우스의 왼쪽단추로 조종꼭지를 찰칵하여 선택한 상태에서 선의 모양이 요구하는 곡선이 될 때까지 끌어줍니다.
    4. 마우스의 왼쪽단추를 놓아 곡선에로의 변환상태를 해제합니다.

선에 본문삽입

선에 본문을 삽입할수 있습니다. 선에 본문을 삽입하려면 다음과 같은 방법으로 진행합니다.

  1. <도형>도구띠에서 <선>을 찰칵합니다.
  2. 요구하는 위치에서 마우스를 찰칵하고 요구하는 크기가 될 때까지 끌어줍니다.
  3. 선우에서 [Enter]건을 누르기하여 본문편집상태로 절환합니다.
  4. 본문을 삽입하고 페지의 임의의 곳을 찰칵합니다.

선의 삭제

선을 삭제하려면 다음과 같은 방법으로 진행합니다.

  1. 삭제하려는 선을 선택합니다.
  2. [Delete]건을 누릅니다.
