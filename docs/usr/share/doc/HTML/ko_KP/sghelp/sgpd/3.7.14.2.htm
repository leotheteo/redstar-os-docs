사용자전용 투영편연시의 발표

모두 표시

연시프로그람에서 사용자전용 투영편연시를 발표하려면 다음과 같은 방법으로 진행합니다.

  1. <투영편연시>차림표에서 <사용자전용 투영편연시>를 찰칵합니다.
  2. <사용자전용 투영편연시>대화창의 목록칸에서 발표하려는 사용자전용 투영편연시를 선택합니다.
  3. <시작>단추를 찰칵합니다.
즉시도움말

<사용자전용 투영편연시>대화창의 목록칸에 여러개의 사용자전용 투영편연시가 있는 경우 고정적으로 연시하려는 항목을 선택하고 대화창의 <사용자전용 투영편연시 사용>확인칸을 선택하고 <닫기>단추를 찰칵하면 아무때나 연시를 실행하여도 사용자가 정의한 투영편연시가 실행됩니다.
