작성자이름의 변경

모두 표시

작성자의 이름은 문서속성, 변경내용추적, 주해 등의 기능에 사용됩니다. 작성자의 이름을 다음과 같이 변경할수 있습니다.

  1. <서광사무처리>차림표에서 <환경설정>을 찰칵합니다.
  2. <환경설정>대화창에서 <서광사무처리>의 <사용자자료>를 찰칵합니다.
  3. <성/이름/략명> 본문칸에 이름을 입력하고 <확인>단추를 찰칵합니다.
  4. <파일>차림표의 <속성>을 찰칵하여 <속성>대화창을 펼칩니다.
  5. <일반>표쪽에서 <사용자자료 적용>확인칸을 선택하고 <재설정>단추를 찰칵하면 작성자의 이름이 변경되는것을 볼수 있습니다.
  6. <속성>대화창의 아래에 있는 <확인>단추를 찰칵한 다음 <파일>차림표의 <보관>을 찰칵합니다.

참고: 이후에는 새 파일을 만들 때마다 <속성>대화창의 <작성날자>옆에 작성자이름이 나타납니다.
