파일열기에서 발생하는 문제의 해결

모두 표시

정상완료를 하지 못하여 파일이 손상된 경우

정전이나 기타 원인으로 정상완료를 하지 못한 경우에 열려는 파일이 손상되였을수 있습니다.

손상된 파일이 있으면 《서광사무처리》 3.0프로그람이 기동할 때 복구자동안내처리가 동작합니다.

복구자동안내처리프로그람이 기동하면 <복구된 문서의 상태>목록칸에 복구할 문서들의 이름이 렬거됩니다.

<복구 시작>단추를 찰칵하면 복구를 시작합니다.

복구가 완료되면 목록칸의 <상태>렬에 《성공적으로 복구되였습니다.》라는 문자렬이 현시됩니다.

<완료>단추를 찰칵하면 복구된 문서가 펼쳐집니다.

파일이름이 너무 긴 경우

파일이름이나 경로이름은 256문자를 초과할수 없습니다.

다음의 방법들중에서 어느 하나를 실행합니다.

  • 파일이름을 줄입니다.
  • 서류철구조의 맨 우에 있는 서류철이나 그와 가까운 서류철로 파일을 옮깁니다.
  • 파일을 다시 열어봅니다.

파일이 있는 디스크가 꽉 찬 경우

파일을 다른 디스크로 옮겨 디스크공간을 확보합니다.

찾고있는 파일이 열기대화창에 나타나지 않는 경우

<파일형식>복합칸에서 정확한 파일형식을 선택하였는가를 확인합니다.

암호로 보호된 파일을 열수 없는 경우

암호는 대소문자를 구분합니다. [Caps Lock]건의 등이 켜져있는지 확인하거나 암호를 다시 입력하십시오.
