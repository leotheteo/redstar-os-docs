모두 표시

투영편의 배경교체

투영편의 배경을 교체하려면 다음과 같은 방법으로 진행합니다.

  1. <보기>차림표에서 <배경페지>를 선택하고 <투영편배경페지>를 찰칵합니다.
  2. <보기>차림표에서 <과제창>을 선택합니다.
  3. 연시물에서 전체 배경이 아니라 선택한 배경만 교체하려면 왼쪽에 있는 축소판그림에서 배경을 선택합니다.
  4. <과제>창의 <배경페지>표쪽에서 요구하는 형판을 선택하고 마우스오른쪽단추를 찰칵하고 다음의 방법들중에서 하나를 실행합니다.
    • 선택한 배경을 새 형판의 배경으로 바꾸려면 <선택된 투영편에 적용>을 찰칵합니다.
    • 현재배경을 모두 새 형판의 배경으로 바꾸려면 <모든 투영편에 적용>을 찰칵합니다.

참고: 현재 사용중인 모든 형판은 모두 <과제>창의 <배경페지>표쪽에 있는 <이 연시에서 사용>에 현시됩니다. <표준>표쪽에서 작업하는 경우 이 형판을 투영편에 적용할수 있습니다.

투영편에 배경색추가

투영편에 배경색을 추가하려면 다음과 같은 방법으로 진행합니다.

  1. <서식>차림표에서 <페지>를 찰칵합니다.
  2. <페지 설정>대화창에서 <배경>표쪽을 찰칵합니다.
  3. <칠하기>령역에서 해당한 설정을 진행합니다.
    • 투영편배경의 채우기를 없애려면 <없음>을 선택합니다.
    • 투영편배경에 색을 추가하려면 <색>을 선택하고 현시된 목록칸에서 요구하는 색을 선택합니다.
    • 투영편배경에 계조를 추가하려면 <계조>를 선택하고 현시된 목록칸에서 요구하는 계조를 선택합니다.

    • 투영편배경에 평행선을 추가하려면 <평행선>을 선택하고 현시된 목록칸에서 요구하는 평행선을 선택합니다.

      평행선의 색을 선택하려면 <배경색>확인칸을 선택하고 그 아래에 있는 목록칸에서 요구하는 색을 선택합니다.

    • 투영편배경에 문양을 추가하려면 <문양>을 선택하고 현시된 목록칸에서 요구하는 문양을 선택합니다.
