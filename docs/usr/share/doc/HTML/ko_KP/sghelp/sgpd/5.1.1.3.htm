입력장치로부터 그림삽입

모두 표시

이 기능을 사용하려면 콤퓨터에 입력장치(례를 들어 수자식사진기, 화상입력기)가 련결되여야 하며 장치구동기가 설치되여있어야 합니다. 입력장치는 TWIN표준을 지원하여야 합니다.

  1. 입력장치에 그림을 놓습니다.
  2. <삽입>차림표에서 <그림>의 <주사>를 찰칵한 다음 <원본 선택>을 찰칵합니다.
  3. <주사장치>대화창에서 요구하는 추가선택을 진행합니다.
  4. 입력장치의 조작법대로 조작을 진행합니다.
  5. <삽입>차림표에서 <그림>의 <주사>를 찰칵한 다음 <요구>를 찰칵하여 입력한 화상을 연시물에 삽입합니다.
