접착점의 삽입과 변경

모두 표시

접착점을 삽입하거나 변경합니다.

접착점은 접속기를 련결할수 있는 사용자정의련결점입니다. 연시프로그람에서는 표준으로 사용자가 만든 모든 객체에 대하여 경계직4각형의 매 면의 가운데에 자동적으로 접착점을 만듭니다.

접착점의 삽입

객체에 접착점을 삽입하려면 다음과 같은 방법으로 진행합니다.

  1. <도형>도구띠에서 <접착점>을 찰칵하거나 <편집>차림표에서 <접착점>을 찰칵합니다.
  2. <접착점>도구띠에서 <접착점 삽입>을 찰칵합니다.
  3. 투영편에서 접착점을 삽입하려는 객체를 선택하고 임의의 위치를 찰칵합니다.

접착점의 변경

객체에 삽입된 접착점을 변경하려면 다음과 같은 방법으로 진행합니다.

  1. <도형>도구띠에서 <접착점>을 찰칵하거나 <편집>차림표에서 <접착점>을 찰칵합니다.
  2. 접착점이 삽입된 객체를 선택하고 변경하려는 접착점을 찰칵합니다.
  3. <접착점>도구띠에서 해당 그림기호를 찰칵하여 접착점의 속성을 변경합니다.
