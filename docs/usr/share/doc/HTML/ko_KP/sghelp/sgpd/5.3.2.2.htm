도표의 자료작업

모두 표시

도표의 자료변경

연시프로그람에서 작성한 도표의 자료를 변경하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 변경하려는 도표를 두번 찰칵합니다.
  2. <서식 설정>도구띠에서 <도표자료의 표>를 찰칵합니다. <자료표>대화창이 현시됩니다.
  3. 요구하는 세포를 찰칵하고 새로운 값을 입력합니다.
  4. 투영편으로 돌아가려면 도표바깥쪽을 찰칵합니다.

참고: 도표자료의 첫 렬에는 해당 행이나 렬에 대한 정보를 표시하는 본문이 들어가게 됩니다.

도표의 자료추가

연시프로그람에서 작성한 도표에 자료를 추가하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 자료를 추가하려는 도표를 두번 찰칵합니다.
  2. <서식 설정>도구띠에서 <도표자료의 표>를 찰칵합니다. <자료표>대화창이 현시됩니다.
  3. 다음의 방법들중에서 하나이상을 실행합니다.
    • 행자료를 추가하려면 해당 행의 임의의 세포를 찰칵하고 <자료표>대화창의 <행 삽입>을 찰칵합니다.
    • 렬자료를 추가하려면 해당 렬의 임의의 세포를 찰칵하고 <자료표>대화창의 <렬 삽입>을 찰칵합니다.
  4. 새로 삽입한 세포들에 새로운 자료를 입력합니다.
  5. 투영편으로 돌아가려면 도표바깥쪽을 찰칵합니다.

도표의 자료삭제

연시프로그람에서 작성한 도표의 자료를 삭제하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 자료를 삭제하려는 도표를 두번 찰칵합니다.
  2. <서식 설정>도구띠에서 <도표자료의 표>를 찰칵합니다. <자료표>대화창이 현시됩니다.
  3. 삭제하려는 세포의 내용을 선택하고 [Delete]건을 누릅니다.
  4. 투영편으로 돌아가려면 도표바깥쪽을 찰칵합니다.
