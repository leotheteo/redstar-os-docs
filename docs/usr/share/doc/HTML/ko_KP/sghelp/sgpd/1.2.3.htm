연시프로그람의 기동방법

모두 표시

연시프로그람은 실행지령으로 기동할수 있습니다.

지령실행으로 기동

  1. 지령실행을 [Alt+F2]건을 눌러 실행합니다.
  2. <지령>본문칸에 sgoffice를 입력합니다.
  3. <실행>단추를 찰칵하면 《서광사무처리》 3.0프로그람이 기동합니다.
  4. <연시물>을 선택하면 연시프로그람이 기동합니다.

도크에서 《서광사무처리》 3.0프로그람 기동

  1. 《붉은별》사용자용체계3.0의 <도크>에서 <응용프로그람>을 찰칵합니다.
  2. <서광사무처리>를 찰칵하면 《서광사무처리》 3.0프로그람이 기동합니다.
  3. <연시물>을 찰칵하면 연시프로그람이 기동합니다.
