단락맞추기

모두 표시

단락맞추기를 하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 단락맞추기를 하려는 단락을 선택합니다.

    2. 방법

    • 하나의 단락만 선택하려면 해당 단락을 찰칵합니다.
    • 여러 단락을 선택하려면 마우스의 왼쪽단추를 누른 상태에서 끌기하여 본문을 선택합니다.
  2. 다음의 방법들중에서 하나를 실행합니다.
    • 그림기호를 리용하여 단락맞추기를 하려면 <본문 서식설정>도구띠에서 <왼쪽 맞추기>, <오른쪽 맞추기> 또는 <가운데 맞추기>, <량쪽 맞추기>를 찰칵합니다.
    • <서식>차림표에서 <단락>을 찰칵합니다. <단락>대화창에서 <맞추기>표쪽을 찰칵합니다. <추가선택>령역의 <왼쪽/웃쪽>, <오른쪽/아래쪽>, <가운데>, <량쪽>단일선택단추들중에서 요구하는 단일선택단추를 찰칵하고 <확인>단추를 찰칵합니다.
