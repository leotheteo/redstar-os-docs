객체나 본문에 추가된 동화의 변경

모두 표시

동화의 변경

객체나 본문에 추가된 동화를 변경하려면 다음과 같은 방법으로 진행합니다.

  1. <투영편>창에서 동화를 변경하려는 본문이나 객체가 들어있는 투영편을 선택합니다.
  2. 동화를 변경하려는 본문이나 객체를 선택합니다.
  3. 다음의 방법들중에서 하나를 실행합니다.
    • <과제>창의 <사용자전용 동화>표쪽이 현시되지 않은 경우 <투영편연시>차림표에서 <사용자전용 동화>를 찰칵합니다.
    • <과제>창이 현시되여있지 않으면 <보기>차림표에서 <과제창>을 찰칵합니다. <과제>창에서 <사용자전용 동화>표쪽을 찰칵합니다.
  4. <과제>창의 <사용자전용 동화>표쪽에서 <변경>단추을 찰칵하고 <사용자전용 동화>대화창에서 다음의 방법들중에서 하나이상을 실행합니다.
    • 투영편에 효과와 함께 객체가 나타나게 하려면 <입장>표쪽을 찰칵하고 목록칸에서 변경하려는 효과를 찰칵합니다.
    • 투영편에 있는 객체에 강조효과를 변경하려면 <강조>표쪽을 찰칵하고 목록칸에서 변경하려는 효과를 찰칵합니다.
    • 특정한 시점에서 객체가 투영편에서 사라지는 효과를 변경하려면 <퇴장>표쪽을 찰칵하고 목록칸에서 변경하려는 효과를 찰칵합니다.
    • 지정된 문양으로 객체가 이동하는 효과를 변경하려면 <이동경로>표쪽을 찰칵하고 목록칸에서 변경하려는 효과를 찰칵합니다.
  5. <확인>단추를 찰칵합니다.

동화순서변경

동화순서를 변경하려면 다음과 같은 방법으로 진행합니다.

  1. <투영편>창에서 순서를 변경할 동화가 들어있는 투영편을 선택합니다.
  2. <투영편연시>차림표에서 <사용자전용 동화>를 찰칵합니다.
  3. <과제>창의 <사용자전용 동화>표쪽에 있는 목록칸에서 이동할 동화를 선택합니다.
  4. <변경순서>단추를 찰칵하여 동화를 웃쪽 또는 아래쪽으로 이동합니다.

동화에 효과추가

연시프로그람에서는 본문이나 객체에 추가한 동화에 효과도 추가할수 있습니다.

동화에 효과를 추가하려면 다음과 같은 방법으로 진행합니다.

  1. <투영편>창에서 동화에 효과를 추가하려는 본문이나 객체가 있는 투영편을 선택합니다.
  2. <투영편연시>차림표에서 <사용자전용 동화>를 찰칵합니다.
  3. <과제>창의 <사용자전용 동화>표쪽에 있는 목록칸에서 효과를 추가하려는 동화를 선택한 다음 마우스의 오른쪽단추를 찰칵합니다.
  4. 상황차림표에서 <효과 추가선택>을 찰칵합니다.
  5. <효과 추가선택>대화창에서 <효과>표쪽을 찰칵합니다.
  6. 요구하는 효과를 선택합니다.
  7. <확인>단추를 찰칵합니다.

즉시도움말

효과를 추가하려면 본문이나 객체에 이미 동화가 추가되여있어야 합니다.

객체의 동화시간을 변경

사용자지정동화를 설정하는 경우 매 동화들이 자연스럽게 련결되도록 연시시간을 조정할수 있습니다. 객체동화의 연시시간을 조정하려면 다음과 같은 방법으로 진행합니다.

  1. <과제>창의 <사용자전용 동화>표쪽이 현시되지 않은 경우 <투영편연시>차림표에서 <사용자전용 동화>를 찰칵합니다.
  2. <과제>창의 <사용자전용 동화>표쪽에 있는 목록칸에서 시간을 변경할 동화를 찰칵합니다.
  3. 마우스의 오른쪽단추를 찰칵하여 상황차림표에서 <시간조절>을 찰칵합니다.
  4. <효과 추가선택>대화창에서 <시간조절>표쪽을 찰칵합니다.
  5. 다음의 방법들중에서 하나를 실행합니다.

    6. 동화의 지연시간을 변경

    1. 한 동화의 끝과 다음동화의 시작사이에 시간을 지연시키려면 <지연>증감단추에 해당한 수값을 입력합니다.
    2. <시작>복합칸에서 다음의 방법들중에서 하나를 실행합니다.
      • 투영편을 찰칵하여 동화를 시작하려면 <찰칵할 때>를 찰칵합니다.
      • 이전 동화와 동시에 동화를 시작하려면 <이전의 효과와 함께>를 찰칵합니다.
      • 이전 동화가 끝난 다음 동화를 시작하려면 <이전의 효과 다음에>를 찰칵합니다.

        • 투영편의 첫번째 동화인 경우 투영편연시에 투영편이 현시되자마자 시작됩니다.

    동화의 속도나 재생시간을 변경

    <속도>복합칸에서 추가선택을 찰칵합니다.

    참고: 이 추가선택은 선택한 동화에 따라 다릅니다.

본문의 동화시간을 변경

사용자지정동화를 설정하는 경우 매 동화들이 자연스럽게 련결되도록 연시시간을 조절할수 있습니다. 본문동화의 연시시간을 조절하려면 다음과 같은 방법으로 진행합니다.

  1. <과제>창의 <사용자전용 동화>표쪽이 현시되지 않은 경우 <투영편연시>차림표에서 <사용자전용 동화>를 찰칵합니다.
  2. <과제>창의 <사용자전용 동화>표쪽에 있는 목록칸에서 시간을 변경할 동화를 찰칵합니다.
  3. 마우스의 오른쪽단추를 찰칵하여 상황차림표에서 <시간조절>을 찰칵합니다.
  4. <효과 추가선택>대화창에서 <본문동화>표쪽을 찰칵합니다.
  5. 다음의 방법들중에서 하나를 실행합니다.
    • 투영편에서 찰칵할 때마다 단락이 재생되도록 하려면 <그룹본문>복합칸에서 <1준위 단락별로>를 선택한 다음 <다음의 시간후 자동적으로>확인칸의 선택을 취소합니다.
    • 투영편을 한번 찰칵할 때마다 단락을 계속 재생하려면 <그룹본문>복합칸에서 <1준위 단락별로>를 선택한 다음 <다음의 시간후 자동적으로>확인칸을 선택하고 단락사이에서 동화시작을 지연시키려면 증감단추에 수값을 입력합니다.
    • 모든 단락을 동시에 동화하려면 <그룹본문>복합칸에서 <모든 단락을 한번에>를 선택합니다.

동화후 다시 감기

동화후 자동으로 다시 감으려면 다음과 같은 방법으로 진행합니다.

  1. <과제>창의 <사용자전용 동화>표쪽이 현시되지 않은 경우 <투영편연시>차림표에서 <사용자전용 동화>를 찰칵합니다.
  2. <과제>창의 <사용자전용 동화>표쪽에 있는 목록칸에서 시간을 조절하려는 동화를 선택한 다음 마우스의 오른쪽단추를 찰칵합니다.
  3. 상황차림표에서 <시간조절>을 찰칵합니다.
  4. <효과 추가선택>대화창에서 <시간조절>표쪽을 찰칵합니다.
  5. 동화후 자동으로 다시 감으려면 <재생이 끝나면 되감기>확인칸을 선택합니다.
  6. <확인>단추를 찰칵합니다.

참고: 이 방법을 사용하면 동화재생후에 동화항목이 원래상태로 돌아갑니다. 례를 들어 날아가기효과를 적용한 경우 이 항목은 날아가지만 그 후에 투영편의 원래위치에 다시 현시됩니다.
