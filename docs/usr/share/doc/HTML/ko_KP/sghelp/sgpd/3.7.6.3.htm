문서처리프로그람의 표를 연시물에로 복사

모두 표시

연시프로그람에 문서처리프로그람에서 작성한 표를 복사하려는 경우 다음과 같은 방법으로 진행합니다.

  1. 문서처리프로그람에서 복사하려는 세포범위를 선택하고 <복사>를 찰칵합니다.
  2. 연시프로그람으로 절환한 다음 세포를 삽입할 투영편이나 주해를 찰칵합니다.
  3. 연시프로그람의 <편집>차림표에서 <형식을 선택하여 붙이기>를 찰칵합니다.
  4. <형식을 선택하여 붙이기>대화창의 <선택>목록칸에서 <서광사무처리 문서처리프로그람>을 선택합니다.
  5. <확인>단추를 찰칵합니다. 붙이기 된 표는 OLE 객체로 삽입됩니다.

참고: <편집>차림표의 <붙이기>를 찰칵하거나 [Ctrl+V]건을 누르기하여 문서처리프로그람에서 복사한 표를 붙이기할수도 있는데 이때에는 일반표로 삽입됩니다.
