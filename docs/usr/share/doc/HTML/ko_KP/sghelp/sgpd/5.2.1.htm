도형객체의 추가

모두 표시

도형객체를 추가하려면 다음의 방법들중에서 하나를 실행합니다.

도형객체를 하나 추가

  1. <도형>도구띠에서 요구하는 도형객체형태를 찰칵합니다.
  2. 도형객체를 삽입하려는 위치를 찰칵하고 마우스로 요구하는 크기가 될 때까지 끌어줍니다.
  3. 투영편의 임의의 위치에서 마우스를 찰칵하여 객체그리기상태를 해제합니다.

참고: [Esc]건을 누르기하여 객체그리기상태를 해제할수도 있습니다.

도형객체를 여러개 추가

  1. <도형>도구띠에서 요구하는 도형객체형태를 찰칵합니다.
  2. 도형객체를 삽입할 위치를 찰칵하고 마우스로 요구하는 크기가 될 때까지 끕니다. 이와 같은 동작을 추가할 개수만큼 반복합니다.
  3. 문서의 임의의 위치에서 마우스를 찰칵하여 객체그리기상태를 해제합니다.

참고: [Esc]건을 누르기하여 객체그리기상태를 해제할수도 있습니다.

즉시도움말

<도형>도구띠에서 해당 도형객체그림기호의 오른쪽에 있는 화살표를 선택한 다음 펼쳐지는 도구띠의 맨 웃쪽의 가름선을 마우스로 끌기하여 도구띠를 분리할수 있습니다.
