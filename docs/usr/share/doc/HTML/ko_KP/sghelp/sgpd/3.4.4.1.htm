서체

모두 표시

연시프로그람에서 사용할수 있는 서체

연시프로그람에는 《붉은별》사용자용체계3.0에서 제공하는 TrueType서체는 모두 사용할수 있습니다. 사용권제한이 없는 다른 TrueType서체도 사용할수 있습니다.

자동서체전환

일부 서체는 특정한 언어에서 지원되지 않습니다. 설정된 건반언어를 사용하여 해당 언어를 지원하지 않는 서체로 본문을 입력하면 해당 언어를 지원하는 다른 비슷한 서체로 자동적으로 변경됩니다.

투영편의 서체변경

투영편의 서체를 변경하려면 다음과 같은 방법으로 진행합니다.

  1. 변경하려는 본문을 선택합니다.

    2. 방법

    • 하나의 단락이나 문장의 서체를 변경하려면 마우스를 끌기하여 본문을 선택합니다.
    • 객체틀에 있는 본문서체를 모두 변경하려면 마우스를 끌기하여 모든 본문을 선택합니다.
  2. <본문 서식설정>도구띠의 <서체이름>에서 요구하는 서체를 선택합니다.

    3. 서양문자와 동양문자를 동시에 변경하려면 다음과 같은 방법으로 진행합니다.

    1. 변경하려는 본문이나 본문이 있는 객체틀을 선택합니다.
    2. <서식>차림표에서 <문자>를 찰칵합니다.
    3. <문자>대화창에서 <서체>표쪽을 찰칵합니다.
    4. <서양문자>와 <동양문자>령역에서 <서체>, <격식>, <크기>, <언어>복합칸의 값을 변경합니다.
    5. <확인>단추를 찰칵합니다.

    배경의 서체변경

    1. 배경의 서체를 변경하려면 <보기>차림표에서 <배경페지>의 <투영편배경페지>를 찰칵합니다.
    2. 서체를 변경하려는 배경페지에서 본문틀안의 본문을 선택하고 <본문 서식설정>도구띠의 <서체이름>목록칸에서 요구하는 서체이름을 선택합니다.

    즉시도움말

    <서식>차림표의 <문자>대화창에서 본문의 서체를 변경할수 있으며 서체크기, 굵기, 경사, 본문색과 같은 다른 류형의 서식도 적용할수 있습니다.

전체 연시물의 서체변경

하나의 투영편배경을 사용하는 경우 배경에서 서체격식을 변경하면 변경내용이 전체 연시물에 반영됩니다. 여러개의 투영편배경을 사용하는 경우(연시물에 두개이상의 형판을 적용한 경우) 매 배경에서 서체격식을 변경해야 합니다.

  1. <보기>차림표에서 <배경페지>를 선택하고 <투영편배경페지>를 찰칵합니다.
  2. 여러개의 배경을 사용하는 경우 <투영편>창에서 서체격식을 변경할 투영편배경의 축소판그림을 선택합니다.
  3. 투영편에서 새 서체격식을 적용하려는 본문의 준위나 제목을 찰칵합니다.

    4. 배경페지에서는 본문을 변경하지 않고 서식만 변경합니다.

  4. <본문 서식설정>도구띠의 <서체이름>에서 요구하는 서체를 선택합니다.
  5. 서체를 변경할 다른 본문에도 이러한 단계를 반복합니다.
  6. 투영편을 다시 편집하려면 <배경페지보기>도구띠에서 <배경페지보기 닫기>를 찰칵합니다.

서체에서 발생하는 문제의 해결

연시물에 일부 서체가 없는 경우

연시물을 만들 때 사용한 콤퓨터가 아닌 다른 콤퓨터에서 연시물을 현시하면 일부 TrupType 서체를 사용하지 못할수도 있습니다. 이 경우에는 필요한 TrupType서체를 《붉은별》사용자용체계3.0이 설치되여있는 구동기의 체계/서고/fonts/korean/TrueType서류철안에 설치하면 됩니다.
