주해의 만들기

모두 표시

투영편의 주해를 만들려면 다음과 같은 방법으로 진행합니다.

  1. 주해를 만들려는 투영편을 선택합니다.
  2. 다음의 방법들중에서 하나를 실행합니다.
    • <주해>표쪽을 찰칵합니다.
    • <보기>차림표에서 <주해페지>를 찰칵합니다.
  3. 주해창에 현재투영편에 대한 주해를 입력합니다.
  4. 주해를 <주해>창에 입력하고 다른 투영편으로 이동하려면 <투영편>창에서 투영편축소판그림을 찰칵합니다.

    5. 참고: 본문이 주해창에 있는 객체틀의 크기보다 크면 연시프로그람은 입력하는 본문의 서체크기와 행간격의 크기에 맞게 객체틀을 조금씩 늘입니다.
