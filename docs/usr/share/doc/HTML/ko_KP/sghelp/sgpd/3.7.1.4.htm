페지설정

모두 표시

페지크기의 설정

  1. <서식>차림표에서 <페지>를 찰칵합니다.
  2. <페지 설정>대화창에서 <페지>표쪽을 찰칵합니다.
  3. 다음의 방법들중에서 하나를 실행합니다.
    • 용지의 표준규격으로 설정하려면 <용지형식>령역의 <형식>복합칸에서 요구하는 항목을 선택합니다.
    • 용지의 규격을 사용자정의하려면 <용지형식>령역에서 <너비>와 <높이>증감단추에 요구하는 수값을 입력합니다.
  4. <확인>단추를 찰칵합니다

페지의 방향을 설정하려면 <용지형식>령역의 <방향>에서 <가로> 또는 <세로>단일선택단추를 찰칵합니다.

페지여백의 설정

연시프로그람에서는 페지여백을 요구하는대로 설정할수 있습니다. 페지여백을 설정하려면 다음과 같은 방법으로 진행합니다.

  1. <서식>차림표에서 <페지>를 찰칵합니다.
  2. <페지 설정>대화창에서 <페지>표쪽을 찰칵합니다.
  3. <여백>령역에서 <왼쪽>, <오른쪽>, <웃쪽>, <아래쪽>증감단추에 요구하는 수값을 입력합니다.
  4. <확인>단추를 찰칵합니다

참고: 용지형식에 객체크기를 맞추려면 <배치 설정>령역의 <객체를 용지형식에 맞추기>확인칸을 선택합니다.
