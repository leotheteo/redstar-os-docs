암호의 사용

모두 표시

암호는 여러가지 용도로 사용됩니다. 권한없는 사용자가 문서를 열수 없도록 하기 위하여 파일에 암호를 설정할수 있습니다.

암호를 만들면 이 암호를 기록하여 안전한 곳에 보관하십시오. 암호를 잊어버린 경우 암호로 보호된 파일을 열거나 사용할수 없습니다.

암호는 대소문자를 구분하기때문에 암호를 설정하는 경우 대소문자를 함께 사용하면 암호를 입력할 때에도 동일한 대소문자를 입력하여야 합니다.

암호에는 문자, 수자, 공백, 기호의 모든 조합이 포함될수 있습니다.

대소문자로 구성된 문자, 수자 및 기호가 조합된 복잡한 암호를 사용하십시오(례: Y6dh!et5). 이러한 요소가 혼합되지 않은 암호는 강력하지 않은 암호입니다(례: House27). 기록해두지 않아도 쉽게 기억할수 있는 복잡한 암호를 사용하는것이 좋습니다.
