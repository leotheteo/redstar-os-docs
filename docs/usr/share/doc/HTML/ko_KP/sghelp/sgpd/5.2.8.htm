도형객체의 선택

모두 표시

도형객체를 선택하려면 다음의 방법들중에서 하나를 실행합니다.

하나의 도형객체를 선택

다음의 방법들중에서 하나를 실행합니다.

  • 선택하려는 도형객체를 찰칵합니다.
  • 그룹의 일부인 객체를 선택하려면 먼저 해당한 그룹을 선택합니다. 다음그룹우에서 마우스의 왼쪽단추를 두번 찰칵한 다음 요구하는 도형객체를 찰칵합니다.

참고: 다른 객체의 아래에 있는 객체를 선택하려면 먼저 맨 우의 객체를 선택한 다음 [Tab]건을 눌러 차례로 내려가면서 선택합니다. [Shift+Tab]건을 누르면 반대순서로 선택됩니다.

여러 도형객체를 선택

여러 도형객체를 선택하려면 [Shift]건을 누르면서 매 도형객체를 찰칵합니다.

참고:

  • 여러 도형객체의 선택을 취소하려면 도형객체밖의 임의의 곳에서 찰칵합니다.
  • 한번에 하나의 도형객체만 선택상태를 취소하려면 [Shift]건을 누른 상태에서 해당 도형객체를 찰칵합니다.

즉시도움말

특정한 도형객체나 도형객체그룹을 선택하기 어려우면 <표준>도구띠의 <확대/축소>옆의 화살표를 찰칵하여 보기를 확대합니다.
