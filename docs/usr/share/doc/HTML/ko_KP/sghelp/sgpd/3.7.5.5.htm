항목기호나 항목번호목록의 들여쓰기조정

모두 표시

항목기호나 항목번호목록의 들여쓰기를 조정하려면 다음과 같은 방법으로 진행합니다.

  1. 눈금자가 나타나지 않으면 <보기>차림표에서 <눈금자>를 찰칵합니다.
  2. 투영편에서 변경하려는 항목기호나 항목번호본문을 찰칵합니다.

    3. 본문에 준위가 두개이상인 항목기호나 항목번호항목이 있으면 눈금자에 매 준위에 대한 들여쓰기표식이 나타납니다.

    항목기호나 번호의 들여쓰기위치를 나타내는 첫행 들여쓰기표식

    목록에서 본문들여쓰기위치를 나타내는 왼쪽 들여쓰기표식

  3. 다음의 방법들중에서 하나를 실행합니다.
    • 항목기호나 번호의 위치를 변경하려면 첫행 들여쓰기표식을 끌어줍니다.
    • 본문의 위치를 변경하려면 왼쪽들여쓰기표식을 끌어줍니다.
  4. 매 항목기호 및 번호준위와 변경할 매 본문준위에 대해 3단계를 반복합니다.

참고: 연시물의 모든 투영편에 대하여 이러한 설정을 변경하려면 투영편배경에서 설정을 변경합니다. 투영편배경을 현시하려면 <보기>차림표에서 <배경페지>를 선택하고 <투영편배경페지>를 찰칵합니다.
