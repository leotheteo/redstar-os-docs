형판의 삭제

모두 표시

연시프로그람에 구성항목으로 등록되여있는 형판을 삭제할수 있습니다.

다음과 같은 방법으로 진행합니다.

  1. <파일>차림표에서 <형판>의 <관리>를 찰칵하여 <형판 관리>대화창을 현시합니다.
  2. 왼쪽목록칸의 해당한 종류를 두번 찰칵하면 구성항목으로 등록되여있는 형판들이 계층구조형태로 현시됩니다.
  3. 삭제하려는 형판을 선택하고 마우스의 오른쪽단추를 찰칵하거나 <형판 관리>대화창의 <지령>단추를 찰칵하여 펼쳐지는 튀여나오기차림표에서 <삭제>를 찰칵합니다.

참고: 체계가 지원하는 기정형판에 대해서는 삭제를 진행할수 없습니다.
