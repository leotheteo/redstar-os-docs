모두 표시

그림기호 지령명 기능
회전 선택한 객체를 회전시킵니다.
반전 선택한 객체를 대칭선을 중심으로 반전합니다. 대칭선은 투영편의 아무 위치로나 끌수 있습니다. 객체를 반전하려면 객체의 꼭지를 대칭선너머로 끕니다. 대칭선의 방향을 변경하려면 끝점중 하나를 새 위치로 끕니다.
3D 회전체로 대칭선을 중심으로 회전시켜 선택한 2차원객체를 3D 회전체로 변환합니다.
원형으로 설정(원근감있게) 선택한 객체를 가상원을 중심으로 회전한 다음 원근감을 추가하여 비틉니다. 선택한 객체의 꼭지를 끌어서 비틉니다.
원형으로 설정(기울이기) 선택한 객체를 가상원을 중심으로 회전하여 비틉니다. 선택한 객체의 꼭지를 끌어서 비틉니다.
이그러뜨리기 선택한 객체의 꼭지를 끌어서 모양을 변경할수 있습니다.
투명도 선택한 객체에 투명도를 적용합니다.
계조 선택한 객체의 색계조를 수정합니다. 이 지령은 <서식>/<령역>에서 선택한 객체에 계조를 적용한 경우에만 사용할수 있습니다.
