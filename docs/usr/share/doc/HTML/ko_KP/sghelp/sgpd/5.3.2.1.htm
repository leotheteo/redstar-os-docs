모두 표시

도표에 제목을 추가

연시프로그람에서 작성한 도표에 제목을 추가하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 제목을 추가하려는 도표를 두번 찰칵합니다.
  2. <삽입>차림표에서 <제목>을 찰칵합니다.
  3. <제목>대화창에서 <제목>본문칸에 제목을 입력하고 <확인>단추를 찰칵합니다.
  4. 투영편에로 돌아가려면 도표바깥쪽을 찰칵합니다.

도표의 제목을 변경

연시프로그람에서 작성한 도표의 제목을 변경하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 제목을 추가하려는 도표를 두번 찰칵합니다.
  2. 기본제목칸을 두번 찰칵하고 새로운 제목을 입력합니다.
  3. 투영편에로 돌아가려면 도표바깥쪽을 찰칵합니다.
