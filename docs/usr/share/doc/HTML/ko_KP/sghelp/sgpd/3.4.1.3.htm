다른 파일로부터 본문삽입

모두 표시

연시프로그람에서는 다른 파일 (.rtf, .txt, .html 등)의 본문을 삽입할수 있습니다. 다른 파일로부터 본문을 삽입하려면 다음과 같은 방법으로 진행합니다.

  1. 연시프로그람에서 <항목륜곽>표쪽을 찰칵합니다.
  2. 개요본문을 삽입하려는 투영편그림기호를 찰칵합니다.
  3. <삽입>차림표에서 <파일>을 찰칵합니다.
  4. <파일 삽입>대화창의 <파일형식>목록칸에서 삽입하려는 본문의 파일형식을 선택합니다.
  5. <파일 삽입>대화창의 파일목록칸에서 사용하려는 본문이 있는 파일의 경로를 찾아들어갑니다.
  6. 파일을 선택하고 <열기>단추를 찰칵합니다.
  7. <본문 삽입>대화창에 삽입하려는 본문이 있는 파일의 경로와 이름이 현시됩니다.
  8. <확인>단추를 찰칵합니다.
