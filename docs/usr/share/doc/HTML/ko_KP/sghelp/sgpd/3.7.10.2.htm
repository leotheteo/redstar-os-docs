객체를 복사본으로 삽입

모두 표시

객체를 복사본으로 삽입하려면 다음과 같은 방법으로 진행합니다.

  1. <편집>차림표에서 <항행기>를 찰칵합니다.
  2. <항행기>창에서 <끌기방식>그림기호옆의 화살표를 찰칵하여 <복사본으로 삽입>을 선택합니다.
  3. 투영편목록칸에서 삽입하려는 객체를 선택하고 마우스로 끌기하여 투영편의 임의의 위치에 놓습니다.
  4. <객체이름 지정>대화창의 <이름>본문칸에 이름을 입력하고 <확인>단추를 찰칵합니다. 복사본으로 삽입된 객체는 <객체이름 지정>대화창에서 입력한 이름으로 <항행기>창의 투영편목록칸에 현시됩니다.

참고: 투영편에 OLE객체를 삽입하면 투영편목록칸에 현시됩니다.
