투영기의 련결과 설정

모두 표시

콤퓨터의 연시물을 외부영상표시장치나 투영기를 통하여 연시를 실행하려면 다음과 같은 방법으로 진행합니다.

  1. 콤퓨터의 외부표시장치포구를 영상표시장치나 투영기에 련결합니다.
  2. 투영기를 켭니다.
  3. 콤퓨터의 표시장치해상도를 투영기의 해상도와 일치하도록 하려면 다음과 같은 방법으로 진행합니다.

    4. 방법

    1. 도크에 있는 <체계환경설정>을 찰칵하여 <체계환경설정>대화창에서 <영상표시장치>를 찰칵합니다.
    2. <해상도>목록칸에 있는 값들가운데서 알맞는 값을 선택합니다. 선택하려는 해상도가 명확치 않으면 800x600해상도로 설정합니다. 대부분의 투영기체계에서 이 해상도를 많이 사용합니다.
    3. 연시물에 음성을 사용하려면 콤퓨터와 투영기를 케블로 련결하고 음성파일이나 연시물의 일부를 재생하여 음량을 시험합니다.
