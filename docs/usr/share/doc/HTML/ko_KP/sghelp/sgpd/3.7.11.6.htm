하이퍼련결에서 발생하는 문제의 해결

모두 표시

하이퍼련결을 찰칵하면 통보문이 나타나는 경우

  • 하이퍼련결의 대상이 삭제 또는 이동되였거나 이름이 변경되였을수 있습니다. 대상이 인터네트에 있으면 웨브열람기에서 해당 대상이 옳은지 확인합니다.
  • 하이퍼련결의 대상이 잘못 입력되였을수 있습니다.
  • 대상을 호출할수 없는 경우일것입니다. 대상이 인터네트에 있으면 네트워크관리자에게 대상을 호출할수 있는가를 문의합니다. 대상이 인터네트에 있으면 인터네트에 접근할수 있어야 하며 웨브열람기도 설치되여있어야 합니다. 웨브싸이트에 련결하여 인터네트련결이 되는가를 확인합니다.
  • 웨브열람기의 보안설정으로 인하여 파일을 내리적재하거나 여는것이 허용되지 않을수 있습니다. 웨브열람기의 보안추가선택을 확인합니다.
  • 대상싸이트의 리용자가 너무 많을수 있습니다.

련결된 정보를 내리적재하거나 하이퍼련결대상으로 이동하는데 시간이 많이 걸리는 경우

봉사기나 대상싸이트의 리용자가 많은 경우 정보를 내리적재하거나 하이퍼련결대상으로 이동하는데 시간이 많이 걸립니다. 이러한 경우에는 다시 시도하십시오. 봉사기에 대한 내용은 네트워크관리자에게 문의하십시오.
