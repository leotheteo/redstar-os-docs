항행기를 사용하여 다른 투영편으로 이동

모두 표시

항행기를 사용하여 다른 투영편으로 이동하려면 다음의 방법을 실행합니다.

  1. 연시물에서 임의의 투영편을 선택합니다.
  2. <편집>차림표에서 <항행기>를 찰칵합니다. 이때 <항행기>창의 투영편목록칸에는 선택된 투영편이 선택되여있습니다.
  3. 다음의 방법들중에서 하나를 실행합니다.
    • 투영편목록칸에서 이동하려는 투영편을 선택하고 마우스의 왼쪽단추를 두번 찰칵합니다.
    • <항행기>창의 <첫 투영편>, <이전 투영편>, <다음 투영편>, <마지막 투영편>을 찰칵하여 다른 투영편으로 이동할수 있습니다.
