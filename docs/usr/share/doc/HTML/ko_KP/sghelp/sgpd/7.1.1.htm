전체 투영편 또는 일부 투영편을 인쇄

모두 표시

페지범위의 인쇄

  1. <파일>차림표에서 <인쇄>를 찰칵하여 <인쇄>대화창을 엽니다.
  2. <페지범위>령역에서 다음의 단일선택단추중에서 하나를 찰칵합니다.
    • 모두: 현재 연시물전체를 인쇄하려고 하는 경우 이 단일선택단추를 찰칵합니다.
    • 시작페지, 끝페지: 연시물의 특정한 투영편이나 범위를 인쇄하려고 하는 경우 이 단일선택단추를 찰칵합니다. 단추옆의 목록칸에서 인쇄할 페지번호나 페지범위를 입력합니다.
  3. <인쇄>단추를 찰칵하여 대화창을 닫습니다. 인쇄가 진행되는것을 확인합니다.

특정한 페지와 령역의 인쇄

특정한 페지, 여러 령역에 걸쳐있는 페지범위를 인쇄할수 있습니다.

  1. <서광사무처리>차림표에서 <환경설정>을 찰칵하여 <환경설정>대화창을 현시합니다.
  2. 왼쪽목록칸에서 <서광사무처리>의 <일반>을 찰칵합니다.
  3. <인쇄대화창>령역에서 <서광사무처리 대화창 사용>확인칸을 선택하고 <확인>단추를 찰칵합니다.
  4. <파일>차림표에서 <인쇄>를 찰칵합니다
  5. <인쇄>대화창에서 <일반>표쪽을 찰칵합니다.
  6. <범위와 부수>령역의 <투영편>단일선택단추를 찰칵합니다.

    7. 린접하지 않은 특정한 페지의 인쇄

    페지번호를 반점으로 구분하여 입력합니다. 례를 들어 2, 4, 5, 8, 10페지를 인쇄하려면 《2,4,5,8,10》을 입력합니다.

    린접하여있는 특정한 페지범위의 인쇄

    페지범위를 지정하려면 시작번호와 끝번호사이에 련결부호(-)를 사용합니다. 례를 들어 3페지부터 10페지까지만 인쇄하려면 《3-10》을 입력합니다. 특정한 페지와 페지범위를 조합하여 인쇄할수 있습니다. 례를 들어 3, 5, 7페지와 10페지부터 15페지까지만 인쇄하려 한다면 페지본문칸에 《3,5,7,10-15》와 같이 입력하면 됩니다.

  7. <인쇄>단추를 찰칵하여 대화창을 닫습니다. 인쇄가 진행되는것을 확인합니다.
