그림의 다듬기

모두 표시

그림을 다듬기할수 있습니다. 그림을 다듬으려면 다음과 같은 방법으로 진행합니다.

  1. 자르려는 그림을 선택합니다.
  2. 마우스의 오른쪽단추를 찰칵하여 펼쳐지는 상황차림표에서 <그림 다듬기>를 찰칵합니다.
  3. <다듬기>대화창에서 다음의 방법들중에서 하나를 실행합니다.

    4. 그림의 화상도배률을 유지하면서 요구하는 령역만큼 잘라내기

    1. <다듬기>령역의 <배률 유지>단일선택단추를 찰칵합니다.
    2. <왼쪽>, <웃쪽>, <오른쪽>, <아래쪽>증감단추에서 요구하는 크기만큼 잘라내려는 수값을 입력합니다. 미리보기에 잘라내려는 령역이 현시됩니다.

      3. 참고: 잘라낸 그림은 화상도를 그대로 유지하면서 크기가 변경됩니다.

    그림의 원래크기를 유지하면서 요구하는 령역만큼 잘라내기

    1. <다듬기>령역의 <화상크기 유지>단일선택단추를 찰칵합니다.
    2. <왼쪽>, <웃쪽>, <오른쪽>, <아래쪽>증감단추에서 요구하는 크기만큼 잘라내려는 수값을 입력합니다. 미리보기에 잘라내려는 령역이 현시됩니다.

      3. 참고: 잘라낸 그림은 원래그림의 크기와 일치하지만 그림의 화상도는 변경됩니다.

    그림의 크기변경

    다음의 방법들중에서 하나를 실행합니다.

    • <배률>령역의 <너비>와 <높이>증감단추에서 그림의 확대축소배률을 지정합니다.
    • <화상크기>령역의 <너비>와 <높이>증감단추에서 그림의 너비와 높이값을 변경합니다.
  4. <확인>단추를 찰칵합니다.
