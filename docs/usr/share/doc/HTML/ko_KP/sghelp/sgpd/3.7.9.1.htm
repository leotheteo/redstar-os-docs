객체의 복제

모두 표시

연시프로그람에서는 객체를 여러개로 복제할수 있습니다. 객체를 복제하려면 다음과 같은 방법으로 진행합니다.

  1. 복제하려는 객체를 선택합니다.
  2. <편집>차림표에서 <복제>를 찰칵합니다.
  3. <복제>대화창에서 해당한 항목의 값을 설정합니다.

    4. 객체를 여러개 복제하려는 경우

    <복제수량>증감단추에 요구하는 복제수량을 입력합니다.

    복제물의 이동 및 회전

    <이동배치>령역의 <X축>, <Y축>, <회전각>증감단추에 수값을 설정하여 복제물의 좌표를 설정합니다.

    복제물의 크기설정

    <확대>령역의 <너비>, <높이>값을 설정하여 복제물의 크기를 설정합니다.

    복제물의 색선택

    복제수량이 하나이상인 경우 첫번째 복제물의 색을 설정하려면 <색>령역의 <시작>복합칸에서 요구하는 색을 선택하고 마지막복제물의 색을 설정하려면 <끝>복합칸에서 요구하는 색을 선택합니다.

  4. <확인>단추를 찰칵합니다.

참고: 설정된 값을 표준값으로 다시 설정하려면 <기정>단추를 찰칵합니다.
