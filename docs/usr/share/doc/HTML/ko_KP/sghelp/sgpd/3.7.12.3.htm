개요의 본문이동

모두 표시

  1. 이동하려는 본문을 선택합니다.

    방법

    • 전체 단어를 선택하려면 [Ctrl+Shift+오른쪽] 또는 [왼쪽]이동건을 누릅니다.
    • 문자를 선택하려면 [Shift+오른쪽] 또는 [왼쪽]이동건을 누릅니다.
  2. 다음의 방법들중에서 하나를 실행합니다.

    3. 본문끌기

    항목기호나 투영편그림기호옆에 있는 선택한 단락을 끌기하려면 항목기호나 그림기호를 가리킨 다음 마우스를 끌어줍니다. 끌기할 때 본문의 대상을 표시하는 선이 나타납니다.

    건반을 사용하여 본문이동

    • 선택한 대상의 준위를 높이려면 [Shift+Tab]건을 찰칵합니다.
    • 선택한 대상의 준위를 낮추려면 [Tab]건을 찰칵합니다.
