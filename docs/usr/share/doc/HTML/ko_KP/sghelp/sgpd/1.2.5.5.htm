상태띠에 현시되는 항목

모두 표시

상태띠는 연시프로그람에서 문서창문의 아래에 나타나며 현재 선택된 객체를 포함하여 문서에 대한 정보를 현시합니다. 상태띠항목을 두번 찰칵하면 관련대화창이 열립니다.

상태띠를 나타내려면 <보기>차림표에서 <상태띠>를 선택합니다. 상태띠에는 다음과 같은 내용들이 현시됩니다.

  • 편집상태

    • 본문의 편집과 도형객체의 선택 및 이동상태를 현시합니다.

  • 현재 위치 및 크기

    • 선택한 도형객체의 X축 및 Y축 위치와 선택한 객체의 크기를 현시합니다.

  • 확대/축소

    • 현재페지의 척도가 현시되도록 지정합니다.

  • 문서수정

    • 문서가 변경되면 상태띠의 이 마당에 《*》가 현시됩니다. 이것은 아직 보관하지 않은 새 문서에도 꼭같이 적용됩니다. 문서를 보관하면 《*》이 현시되지 않습니다.

  • 현재 투영편 / 준위

    • 현재 투영편번호와 전체 투영편개수를 현시합니다.

  • 현재페지격식

    • 현재페지격식을 현시합니다. 편집하려면 두번 찰칵합니다. 마우스의 오른쪽단추를 찰칵하여 다른 격식으로 절환합니다. (여러개의 격식이 적용되여있는 경우)
