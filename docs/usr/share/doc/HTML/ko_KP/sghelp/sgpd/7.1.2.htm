다른 형식으로 투영편을 인쇄

모두 표시

파일로 인쇄

인쇄기대신 파일로 문서를 인쇄하면 문서가 일반 인쇄기에서 사용할수 있는 서식과 다르게 보관됩니다.

례를 들어 고해상도 인쇄기를 사용하는 상업용인쇄봉사를 통해 문서를 인쇄하려면 문서를 파일로 인쇄한 다음 상업용인쇄기로 인쇄해야 합니다.

참고: 파일로 인쇄할 때에는 먼저 파일을 최종적으로 인쇄할 인쇄기가 어떤 종류(례: PostScript 인쇄기)인가를 결정해야 합니다.

  1. <파일>차림표에서 <인쇄>를 찰칵하여 <인쇄>대화창을 엽니다.
  2. <인쇄기>복합칸에서 파일을 인쇄할 인쇄기를 선택합니다.
  3. <파일로 보관>단추를 찰칵하여 현시되는 튀여나오기차림표에서 <PostScript파일로 보관>을 찰칵합니다.
  4. 현시되는 대화창의 <새로 보관>본문칸에 이름을 입력합니다.
  5. <위치>복합칸에서 파일을 보관하려는 등록부를 선택합니다.
  6. <보관>단추를 찰칵하여 대화창을 닫습니다.

파일로 인쇄하면 페지격식과 서체간격 등의 정보가 모두 유지됩니다.

참고: 인쇄설정을 보다 상세하게 하려면 <서광사무처리>/<환경설정>/<서광사무처리>/<일반>에서 <인쇄대화창>령역에 있는 <서광사무처리 대화창 사용>확인칸을 선택합니다.
