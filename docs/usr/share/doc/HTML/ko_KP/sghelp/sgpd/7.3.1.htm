인쇄기의 설정

모두 표시

현재연시물의 기정인쇄기설정을 진행합니다.

이 기능을 사용하려면 <파일>차림표에서 <인쇄기설정>을 찰칵하여 <인쇄기설정>대화창을 엽니다.

항목 설명
인쇄기 선택한 인쇄기에 적용되는 정보들이 라렬되여있는 령역입니다. 목록칸이 비여있으면 조작체계에 맞는 기정인쇄기를 설치해야 합니다.
이름 조작체계에 설치된 인쇄기를 라렬합니다. 기정인쇄기를 변경하려면 목록칸에서 요구하는 인쇄기이름을 선택합니다.
상태 선택한 인쇄기의 현재상태를 현시합니다.
류형 선택한 인쇄기의 류형을 현시합니다.
장소 선택한 인쇄기의 포구를 현시합니다.
설명 인쇄기에 대한 추가정보를 현시합니다.
속성 선택된 인쇄기의 속성대화창을 엽니다. 인쇄기의 속성은 선택한 인쇄기에 따라 다릅니다.
