연시물을 열거나 보관할 때 발생하는 문제해결

모두 표시

연시물을 보관할 때 읽기전용이라는 통보문이 현시되는 경우

읽기전용파일은 변경할수 없습니다. 변경한 내용을 보관하려면 <파일>차림표의 <다른 이름으로 보관>지령을 사용하여 파일을 새로운 이름으로 보관하십시오. 이 파일을 새로운 서류철이나 다른 서류철에 보관할 때에는 같은 이름을 사용해도 됩니다.

보관한 연시물의 파일이름에 두개의 끝점이 포함된 경우

파일이름에 반점이나 끝점과 같은 일부 문장기호가 포함될수 있습니다. 문건.과 같이 끝점으로 끝나는 이름으로 파일을 보관하려는 경우 또 다른 끝점과 기본확장자가 파일이름에 추가됩니다. 따라서 연시물의 파일이름을 문건.으로 입력하면 문건..odp로 보관됩니다. 파일을 보관하려는 경우에는 파일이름 다음에 끝점을 입력할 필요가 없습니다.

사용자이름과 암호를 입력했으나 네트워크구동기에 접근할수 없는 경우

사용자이름과 암호를 정확히 입력하였는지 확인하고 [Caps Lock]건이 눌러지지 않았는지 확인합니다. 여전히 네트워크봉사기에 접근할수 없으면 네트워크관리자에게 문의하십시오.
