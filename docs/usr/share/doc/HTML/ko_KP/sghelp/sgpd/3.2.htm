기존연시물을 사용하여 새로 만들기

모두 표시

다음의 방법을 실행하여 연시물파일의 복사본을 만들어 원본을 변경하지 않고도 새 연시물에 맞게 설계와 내용을 변경할수 있습니다.

  1. 연시프로그람의 <파일>차림표에서 <열기>를 찰칵합니다
  2. <열기>대화창의 파일목록에서 요구하는 연시물을 선택합니다.

    3. 여러 파일의 선택

    다음의 방법들중에서 하나를 실행합니다.
    • <열기>대화창에서 린접하지 않은 파일들을 선택하려면 한 파일을 찰칵한 다음 [Ctrl]건을 누르면서 나머지파일들을 각각 찰칵합니다.
    • <열기>대화창에서 린접한 파일들을 선택하려면 첫번째 파일을 찰칵한 다음 [Shift]건을 누르면서 마지막파일을 찰칵합니다.

    참고: 요구하지 않는 파일이 선택되였다면 [Ctrl]건을 누르면서 그 파일을 다시 한번 찰칵하여 선택을 취소합니다.

  3. <열기>단추를 찰칵합니다.
  4. 연시물을 요구하는대로 변경하고 <파일>차림표에서 <다른 이름으로 보관>을 찰칵합니다.
  5. <보관>대화창의 <새로 보관>본문칸에 새 연시물의 이름을 입력합니다.
  6. <보관>단추를 찰칵합니다.

즉시도움말

다른 연시물에 있는 투영편을 새 연시물에 삽입하려면 다음과 같은 방법으로 진행합니다.

  1. 연시물을 열고 투영편을 선택합니다.
  2. <삽입>차림표에서 <파일>을 찰칵합니다.
  3. <파일 삽입>대화창의 파일목록칸에서 요구하는 연시물을 찾아 선택합니다.
  4. <열기>단추를 찰칵합니다.
  5. <투영편/객체 삽입>대화창의 목록칸에서 요구하는 투영편을 선택합니다.
  6. <확인>단추를 찰칵합니다.
