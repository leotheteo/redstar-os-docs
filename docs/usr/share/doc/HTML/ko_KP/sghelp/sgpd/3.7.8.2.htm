투영편에서 마당편집

모두 표시

투영편에 있는 마당을 편집하려면 해당 마당을 선택하고 <편집>차림표에서 <마당>을 찰칵합니다.

투영편에 삽입가능한 일반마당에는 <날자(고정)>, <날자(가변)>, <시간(고정)>, <시간(가변)>, <작성자>, <페지번호>, <파일이름> 등이 있습니다.

날자(고정)

투영편에 현재날자를 고정마당으로 삽입합니다. 날자가 자동적으로 갱신되지 않습니다.

날자(가변)

투영편에 현재날자를 가변마당으로 삽입합니다. 파일을 다시 적재하면 날자가 자동적으로 갱신됩니다.

시간(고정)

투영편에 현재시간을 고정마당으로 삽입합니다. 시간은 자동적으로 갱신되지 않습니다.

시간(가변)

투영편에 현재시간을 가변마당으로 삽입합니다. 파일을 다시 적재하면 시간이 자동적으로 갱신됩니다.

작성자

연시프로그람사용자자료에 라렬된 성과 이름을 투영편에 삽입합니다.

페지번호

현재 투영편 또는 페지에 페지번호를 삽입합니다.

파일이름

현재문서의 파일이름을 삽입합니다. 해당 이름은 파일을 보관한 다음에 나타납니다.
