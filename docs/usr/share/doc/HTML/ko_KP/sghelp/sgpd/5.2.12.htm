도형객체의 그룹 및 배렬

모두 표시

여러 도형객체를 그룹하면 그룹된 도형객체를 하나의 도형객체인것처럼 작업할수 있습니다. 그룹에 속한 모든 도형객체는 하나의 단위로 대칭이동하거나 회전, 크기조정, 확대/축소할수 있습니다. 그룹에 속한 모든 도형객체의 서식을 한번에 바꿀수도 있습니다. 례를 들어 그룹에 속한 모든 도형객체의 칠하기색을 바꾸거나 그림자를 추가합니다. 또한 그룹을 해제하지 않은 상태에서 그룹안의 특정한 도형객체를 선택하여 특성을 적용하거나 그룹안에 새 그룹을 만들어 복잡한 그림을 작성할수도 있습니다.

도형객체의 그룹 또는 그룹해제

다음의 방법들중에서 하나를 실행합니다.

도형객체의 그룹

  1. 그룹하려는 도형객체들을 선택합니다.
  2. <서식>차림표에서 <그룹>의 <그룹>을 찰칵합니다.

도형객체의 그룹해제

  1. 그룹을 해제하려는 도형객체그룹을 선택합니다.
  2. <서식>차림표에서 <그룹>의 <그룹 해제>를 찰칵합니다.

도형객체의 재배치

도형객체를 재배치하려면 다음과 같은 방법으로 진행합니다.

  1. 재배치하려는 도형객체를 선택합니다.

    2. 참고: 숨겨진 도형객체인 경우 임의의 도형객체를 선택한 다음 요구하는 도형객체가 선택될 때까지 [Tab]건이나 [Shift+Tab]건을 누릅니다.

  2. 다음의 방법들중에서 하나를 실행합니다.

    3. 객체를 한 단계 앞면에로 이동

    <도형>도구띠에서 <배렬>을 찰칵하고 <앞면에로 이동>을 찰칵합니다.

    객체를 맨 앞면에로 이동

    <도형>도구띠에서 <배렬>을 찰칵하고 <맨 앞면에로 이동>을 찰칵합니다.

    객체를 한 단계 뒤면에로 이동

    <도형>도구띠에서 <배렬>을 찰칵하고 <뒤면에로 이동>을 찰칵합니다.

    객체를 맨 뒤면에로 이동

    <도형>도구띠에서 <배렬>을 찰칵하고 <맨 뒤면에로 이동>을 찰칵합니다.

    객체 앞면에로 이동

    <도형>도구띠에서 <배렬>을 찰칵하고 <객체 앞면에로>를 찰칵하고 선택한 객체의 뒤에 놓이게 하려는 객체를 찰칵합니다. 그러면 먼저 선택되였던 객체가 후에 선택한 객체의 앞면으로 이동합니다.

    객체 뒤면에로 이동

    <도형>도구띠에서 <배렬>을 찰칵하고 <객체 뒤면에로>를 찰칵하고 선택한 객체의 앞에 놓이게 하려는 객체를 찰칵합니다. 그러면 먼저 선택하였던 객체가 후에 선택한 객체의 뒤면으로 이동합니다.

    순서 바꾸기

    <도형>도구띠에서 <배렬>을 찰칵하고 <바꾸기>를 찰칵하고 선택한 객체와 순서를 바꾸려는 객체를 찰칵합니다.
