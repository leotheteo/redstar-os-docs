표세포에 배경색을 추가, 변경 또는 제거

모두 표시

표를 수정하려면 다음과 같은 방법으로 진행합니다.

  1. 칠하기를 추가, 변경 또는 제거하려는 세포를 선택합니다.

    2. 방법

    다음의 방법들중에서 하나를 실행합니다.

    • 다음세포를 선택하려면 [Tab]건을 누릅니다.
    • 이전 세포를 선택하려면 [Shift+Tab]건을 누릅니다.
    • 행을 선택하려면 <표>도구띠의 <행 선택>을 찰칵합니다.
    • 렬을 선택하려면 <표>도구띠의 <렬 선택>을 찰칵합니다.
    • 세포를 선택하려면 세포내부를 찰칵합니다.
    • 전체 표를 선택하려면 <표>도구띠의 <표 선택>을 찰칵하거나 표의 테두리를 찰칵합니다.
  2. <표>도구띠에서 <령역격식/색칠> 복합칸을 찰칵합니다.
  3. 다음의 방법들중에서 하나이상을 실행합니다.

    4. 배경색의 추가 또는 변경

    색구성표의 색으로 변경하려면 <보이지 않게>아래에 있는 <색>을 선택하고 나타나는 색들중에서 하나를 선택합니다.

    칠하기제거

    <보이지 않게>를 선택합니다.
