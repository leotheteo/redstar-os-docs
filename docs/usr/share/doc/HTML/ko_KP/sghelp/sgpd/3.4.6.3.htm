철자법 검사

모두 표시

연시프로그람은 도표와 같은 포함객체, 장식문자와 같은 특수한 본문효과, 본문문서와 같은 삽입된 객체에 대해서는 철자법 검사를 수행하지 않습니다.

철자법을 검사하여 틀린 단어를 후보단어로 치환

투영편에서 철자법을 검사하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 철자법을 검사하려는 본문을 선택합니다.
  2. <도구>차림표에서 <철자법 검사>를 찰칵합니다.
  3. <철자법 검사>대화창의 <사전에 없음>본문칸에 사전에 없는 단어가 빨간색으로 현시됩니다.
  4. <후보단어>목록칸에서 정확한 단어를 선택하고 <변경>단추를 찰칵합니다.

철자법 검사에서 건너뛰기

철자법을 검사할 때 건너뛰기하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 철자법을 검사하려는 본문을 선택합니다.
  2. <도구>차림표에서 <철자법 검사>를 찰칵합니다.
  3. <철자법 검사>대화창의 <사전에 없음>본문칸에 사전에 없는 단어가 빨간색으로 현시됩니다.
  4. 빨간색으로 현시된 단어를 후보단어로 변경하지 않고 다음단어를 검사하려면 <한번 무시>단추를 찰칵합니다.

다른 언어로 된 본문의 자동철자법 검사

투영편에서 다른 언어로 된 본문의 철자법을 검사하려면 다음과 같은 방법으로 진행합니다.

  1. 철자법을 검사하려는 본문을 선택합니다.
  2. <도구>차림표에서 <철자법 검사>를 찰칵합니다.
  3. <철자법 검사>대화창의 <본문언어>복합칸에서 요구하는 언어를 선택합니다.
  4. <닫기>단추를 찰칵합니다.
  5. <표준>도구띠에서 <철자법 자동검사>를 찰칵합니다.
