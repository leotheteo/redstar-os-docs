투영편의 순서변경

모두 표시

투영편의 순서를 변경하려면 다음의 방법들중에서 하나를 실행합니다.

  • <항목륜곽>표쪽에서 투영편그림기호 를 선택하고 새로운 위치로 끌어줍니다.
  • <투영편>창에서 투영편축소판그림을 하나이상 선택하고 새로운 위치로 끌어줍니다.
  • <투영편정렬>에서 투영편축소판그림을 하나이상 선택하고 새로운 위치로 끌어줍니다.

참고:

  • 서로 린접하지 않은 여러 투영편을 선택하려면 한 투영편을 선택한 후 [Ctrl]건을 누른 상태에서 나머지투영편을 각각 선택합니다.
  • 린접한 여러 투영편을 선택하려면 첫번째 투영편을 선택한 후 [Shift]건을 누른 상태에서 마지막투영편을 선택합니다.
