목록에서 항목기호격식의 변경

모두 표시

목록에서 항목기호격식을 변경하려면 다음과 같은 방법으로 진행합니다.

  1. 항목기호격식을 변경할 본문이나 목록을 선택합니다.
  2. <서식>차림표에서 <항목기호 및 항목번호>를 찰칵합니다.
  3. <항목기호 및 항목번호>대화창에서 <항목기호>표쪽을 찰칵합니다.
  4. 다음의 방법들중에서 하나이상을 실행합니다.

    5. 항목기호의 변경

    다음의 방법들중에서 하나를 실행합니다.

    • 항목기호격식들중에서 요구하는 격식을 선택합니다.
    • <추가선택>표쪽을 찰칵하여 <항목번호>복합칸에서 임의의 항목기호를 선택합니다. <그림>을 찰칵하면 <선택>단추가 현시됩니다. 그림을 추가하려면 <선택>단추를 찰칵하고 튀여나오기차림표에서 <파일로부터>를 찰칵하여 펼쳐지는 대화창에서 요구하는 파일을 선택한 다음 <열기>를 찰칵합니다.

    항목기호의 크기변경

    항목기호의 크기를 변경하려면 <추가선택>표쪽의 <상대적크기>증감단추에 요구하는 수값을 입력합니다.

    항목기호의 색변경

    항목기호의 색을 변경하려면 <추가선택>표쪽의 <색>복합칸에서 요구하는 색을 선택합니다.

    특수문자로 항목기호현시

    • <문자>단추를 찰칵하여 <특수문자>대화창을 엽니다.
    • <특수문자>대화창에서 요구하는 서체와 특수문자를 선택합니다.
    • <확인>단추를 찰칵합니다.
