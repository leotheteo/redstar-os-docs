모두 표시

그림기호 지령명 기능
기록편 탐색 양식에 련결되여있는 자료기지에서 기록편자료의 탐색을 진행합니다.
절대기록편 현재 기록편번호를 현시합니다. 번호를 입력하면 해당 기록편으로 이동합니다.
첫 기록편 첫번째 기록편으로 이동합니다.
이전 기록편 이전 기록편으로 이동합니다.
다음 기록편 다음기록편으로 이동합니다.
마지막 기록편 마지막기록편으로 이동합니다.
새 기록편 새 기록편을 만듭니다.
기록편 보관 자료항목을 새로 보관합니다. 변경사항이 자료기지에 등록됩니다.
실행 취소: 자료입력 자료입력을 취소할수 있습니다.
기록편 삭제 기록편을 삭제합니다. 삭제하기 전에 질문을 확인해야 합니다.
갱신 현시된 자료를 갱신합니다.
정렬 자료현시를 위한 정렬기준을 지정하는 <정렬순서>대화창을 현시합니다.
올리순서로 정렬 자료를 자모처음부터 시작하여 올리순서로 정렬합니다.
내리순서로 정렬 자료를 자모마지막부터 시작하여 내리순서로 정렬합니다.
자동려과기 현재 선택한 자료마당의 내용을 기반으로 기록편을 려과합니다.
려과기 적용 려과된 자료보기와 려과되지 않은 자료보기를 절환합니다.
양식에 기초한 려과기 자료기지봉사기에서 지정한 기준에 따라 현시된 자료를 려과합니다.
려과기/정렬 제거 려과기설정을 취소하고 현재표의 모든 기록편을 현시합니다.
자료원본을 표로 선택한 조종체에 련결되여있는 자료원본을 표로 보여줍니다.
