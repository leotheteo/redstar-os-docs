도표류형의 변경

모두 표시

같은 자료를 가진 도표라고 하여도 도표의 류형에 따라 자료를 쉽게 살펴보고 비교할수 있습니다. 연시프로그람의 도표에서는 여러가지 도표류형을 제공합니다. 도표의 류형을 변경하려면 다음과 같은 방법으로 진행합니다.

  1. 투영편에서 류형을 변경하려는 도표를 두번 찰칵합니다.
  2. <서식 설정>도구띠에서 <도표류형>을 찰칵합니다. <도표류형>대화창이 현시됩니다.
  3. 3D 도표로 변경하려면 <도표류형>에서 <3D 모양>확인칸을 찰칵합니다.
  4. <도표류형>목록칸에서 요구하는 항목을 선택합니다.
  5. <도형>목록칸에서 요구하는 항목을 찰칵합니다.
  6. 투영편바깥쪽을 찰칵하여 투영편으로 돌아갑니다.
