BETAINV

모두 표시

참고항목  통계함수목록, BETADIST

역β분포값을 구합니다.

문법:   BETAINV(수값,α,β,하한값,상한값)

인수명 설명
수값 역β분포를 계산할 확률값입니다.
α β분포의 α파라메터입니다.
β β분포의 β파라메터입니다.
하한값 분포값구간에 대한 하한값입니다. 추가선택인수입니다.
상한값 분포값구간에 대한 상한값입니다. 추가선택인수입니다. 하한값과 상한값인수는 반드시 함께 설정하여야 합니다.

주의

  • 인수가 수자가 아니면 오유:[오유번호]가 반환됩니다.
  • α ≦ 0 또는 β ≦ 0이면 오유:[오유번호]가 반환됩니다.
  • 수값 ≤ 0 또는 수값 > 1이면 오유:[오유번호]가 반환됩니다.
  • 하한값과 상한값을 생략하면 BETAINV 함수는 하한값 = 0, 상한값 = 1인 표준루적베타분포를 사용합니다.

    수값이 주어지면 BETADIST(x, α, β, 하한값, 상한값) = 수값에 해당하는 x 값을 구합니다. 따라서 BETAINV의 정밀도는 BETADIST 정밀도에 따라 달라집니다. BETAINV 함수는 반복적인 탐색기법을 사용하며 100번 반복한 후에도 값이 수렴하지 않으면 #N/A 오유값이 반환됩니다.
