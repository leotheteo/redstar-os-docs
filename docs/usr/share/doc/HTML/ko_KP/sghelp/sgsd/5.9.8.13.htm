문법:   COMBIN(원소의 총개수,원소에서 선택한 개수)

인수명 설명
원소의 총개수 원소의 총개수입니다.
원소에서 선택한 개수 원소에서 선택한 개수입니다.

주의

  • 수값인수는 소수점이하를 잘라서 옹근수로 변환됩니다.
  • 인수가 어느 하나라도 수자가 아니면 오유:[오유번호]가 반환됩니다.
  • 원소의 총개수 < 0 이거나 원소에서 선택한 개수 < 0 또는 원소의 총개수 < 원소에서 선택한 개수이면 오유:[오유번호]가 반환됩니다.
  • 조합은 내부순서에 관계없이 항목의 집합 또는 부분집합이 됩니다. 순렬에서는 순서가 고려된다는점이 조합과 다른 점입니다.
  • 조합수를 구하는 식은 다음과 같습니다. 여기서 원소의 총개수 = n, 원소에서 선택한 개수 = k입니다.
