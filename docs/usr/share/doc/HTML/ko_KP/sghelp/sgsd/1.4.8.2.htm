형판의 수정

모두 표시

표처리프로그람에 이미 만들어진 형판을 수정할수 있습니다.

형판을 수정하면 형판을 기준으로 만드는 새 문서에 영향을 줍니다. 형판을 변경해도 기존의 문서내용은 영향을 받지 않습니다.

다음의 방법들중에서 하나를 실행합니다.

구성항목으로 등록된 형판의 편집

  1. <파일>차림표에서 <형판>의 <관리>를 찰칵하여 <형판 관리>대화창을 현시합니다.
  2. 왼쪽목록칸의 해당한 종류를 두번 찰칵하면 구성항목으로 등록되여있는 형판들이 계층구조형태로 현시됩니다.
  3. 편집하려는 형판을 선택하고 마우스의 오른쪽단추를 찰칵하거나 <형판 관리>대화창의 <지령>단추를 찰칵하여 펼쳐지는 튀여나오기차림표에서 <편집>을 찰칵합니다.
  4. 등록된 형판이 펼쳐지면 필요한 편집조작을 진행하여 보관합니다.

파일열기대화창을 리용한 형판의 편집

  1. <파일>차림표에서 <형판>의 <편집>을 찰칵하면 <열기>대화창이 현시됩니다.
  2. 표처리프로그람이 형판의 저장고로 리용하는 서류철이 기정으로 펼쳐집니다.
  3. 파일목록칸에서 이미 보관되여있는 형판들을 찾아 선택합니다.
  4. <열기>단추를 찰칵하면 이 형판이 펼쳐집니다.
  5. 필요한 편집조작을 진행하여 보관합니다.
