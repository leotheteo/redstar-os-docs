다중연산

모두 표시

변수값이 다른 동일한 수식을 다른 세포에도 적용하여 변수값에 따르는 세포의 결과값을 구합니다. 다중연산을 진행하려면 변수값과 수식이 입력되여야 합니다.

다중연산을 진행하려면 다음과 같은 방법으로 진행합니다.

  1. 변수값과 결과값세포범위를 선택합니다.
  2. <자료>차림표의 <다중연산>을 찰칵하여 <다중연산>대화창을 엽니다.
  3. <수식>본문칸에서 결과값을 구하기 위한 수식세포를 선택합니다.
  4. 행의 자료를 변수값으로 리용하는 경우 <행입력세포>본문칸에서 수식의 변수세포를 선택하고 렬의 자료를 변수값으로 리용하는 경우 <렬입력세포>본문칸에서 수식의 변수세포를 선택합니다.
  5. <확인>단추를 찰칵합니다.
