흐름도의 그리기

모두 표시

  1. <도형>도구띠의 <흐름도>를 찰칵하고 요구하는 도형객체를 선택합니다.
  2. 흐름도도형객체를 삽입할 위치를 찰칵하고 요구하는 크기가 될 때까지 마우스를 끌어줍니다.
  3. 흐름도에 다른 도형객체를 추가하려면 1단계와 2단계를 반복하여 실행합니다.
  4. 매 도형객체사이를 선으로 련결하고 선의 격식을 지정합니다.
  5. 매 도형객체에 본문을 삽입합니다.

    방법

    1. 본문을 추가할 도형객체를 선택하고 [Enter]건을 누르거나 도형객체를 두번 찰칵합니다.
    2. 본문을 입력합니다.
  6. 매 도형객체에 색칠하기를 진행합니다.

    7. 방법

    1. 변경하려는 도형객체를 선택합니다.
    2. <도형객체속성>도구띠의 <령역>을 찰칵하여 <령역>대화창을 엽니다.
    3. 해당한 표쪽에서 요구하는 설정을 합니다.
    4. <확인>단추를 찰칵합니다.
