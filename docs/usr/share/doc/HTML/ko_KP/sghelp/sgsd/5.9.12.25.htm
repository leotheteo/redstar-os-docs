T

모두 표시

참고항목  본문함수목록, CELL, N, VALUE

본문인 경우 값을 구하고 그렇지 않으면 빈 문자렬을 구합니다.

문법:   T(값)

인수명 설명
값 변환할 값입니다.

주의

  • 값이 본문이거나 본문을 참조하면 값이 반환됩니다. 값이 본문을 참조하지 않으면 ""(빈 본문)이 반환됩니다.
  • 표처리프로그람에서는 필요에 따라 값이 자동으로 변환되므로 수식에서 T함수를 사용하지 않아도 됩니다. 이 함수는 다른 표계산프로그람과의 호환을 위하여 사용하는 함수입니다.
