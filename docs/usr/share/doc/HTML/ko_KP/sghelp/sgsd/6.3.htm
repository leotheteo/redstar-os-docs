보안에서 발생하는 문제의 해결

모두 표시

암호를 입력했는데 자료표문서가 열리지 않는 경우

암호는 대소문자를 구분합니다. 처음에 암호를 만들 때 입력한것과 똑같이 대소문자를 정확히 입력하여야 합니다. 암호가 있는 자료표문서를 펼치기 전에 먼저 [Caps Lock]건이 설정되여있는가를 확인하십시오.

암호를 잊어버린 경우

암호를 설정한 후 그 암호를 잊어버리면 자료표문서를 열수 없으며 련결된 다른 자료표문서에서 그 자료에 접근할수 없게 됩니다.

자료표문서에 암호를 설정할수 없는 경우

파일을 표처리프로그람의 파일형식이 아닌 다른 형식으로 보관하려고 하면 암호를 설정할수 없습니다. 암호를 설정할수 없는 파일형식은 다음과 같습니다.

OpenDocument 자료표(Flat XML) (.fods)
Unified Office Format 자료표 (.uos)
Microsoft Excel 2007/2010 XML (.xlsx)
Microsoft Excel 2003 XML (.xml)
Microsoft Excel 95 (.xls)
Microsoft Excel 95 형판(.xlt)
HTML 문서(OpenOffice.org Calc) (.html)
본문 CSV (.csv)
