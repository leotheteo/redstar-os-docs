문서를 PDF 첨부파일로 보내기

모두 표시

자료표를 PDF 문서로 변환하여 전자우편의 첨부파일로 보내려면 다음과 같은 방법으로 진행합니다.

  1. 전자우편으로 보내려는 자료표를 엽니다.
  2. 자료표를 PDF 문서로 변환하고 전자우편의뢰기를 사용하여 첨부파일로 보냅니다.

    3. 방법

    1. <파일>차림표의 <송신>에서 <PDF 파일로 전자우편에 첨부>를 찰칵합니다.
    2. <PDF 추가선택>대화창에서 <송신>단추를 찰칵합니다.
    3. 대화창의 <받을 사람>본문칸에 받을 사람의 전자우편주소를 입력합니다.
    4. <통보문>차림표에서 <우편송신>을 찰칵합니다.
