3D 효과의 변경

모두 표시

3D 효과를 변경하려면 다른 3D 격식을 선택합니다. 현재의 3D 효과에 대한 설정을 수정하려면 다음의 방법들중에서 하나를 실행합니다.

3D 효과의 수정

  1. 변경할 3D 도형객체를 선택합니다.
  2. 현재 3D 효과의 회전, 깊이, 조명, 표면질감을 변경하려면 <3D 설정>도구띠에서 요구하는 추가선택을 찰칵합니다.

3D 효과의 색변경

  1. 색을 변경할 도형객체를 선택합니다.
  2. <도형>도구띠에서 <립체면 설정/해제>를 찰칵합니다.
  3. <3D 설정>도구띠에서 <3D 색>옆의 화살표를 찰칵합니다.
  4. 요구하는 색을 찰칵합니다.

즉시도움말

색상 등의 동일한 3D 효과를 한번에 여러 객체에 추가하려면 효과를 추가할 객체를 모두 선택하거나 그룹으로 만든 다음 요구하는 효과를 추가합니다.
