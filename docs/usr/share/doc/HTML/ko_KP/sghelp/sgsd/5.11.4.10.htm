장식문자

모두 표시

<도형>도구띠의 <장식문자 화첩>을 사용하면 장식된 본문을 삽입할수 있습니다. 본문에 그림자를 만들거나 기울이거나 회전시키거나 늘일수 있으며 미리 정의된 도형객체에 맞출수 있습니다.

특수본문효과는 도형객체에 해당되므로 <도형>도구띠의 다른 단추를 사용하여 그림으로 본문효과를 채우는 등의 효과를 변경할수 있습니다. 례를 들어 장식문자의 색을 변경할수 있으며 문자테두리선의 굵기도 변경할수 있습니다.

장식문자의 추가
  1. <도형>도구띠에서 <장식문자 화첩>을 찰칵합니다.
  2. 요구하는 장식문자격식을 선택한 다음 <확인>단추를 찰칵합니다.
  3. 장식문자객체를 두번 찰칵하여 요구하는 본문을 입력합니다.
  4. 다음의 방법들중에서 하나를 실행합니다.
    • 장식문자형태를 변경하려면 <장식문자>도구띠에서 <장식문자 형태>를 찰칵하여 요구하는 형태를 선택합니다.
    • 문자사이의 간격을 조절하려면 <장식문자>도구띠에서 <장식문자 간격>을 찰칵하여 본문문자들사이 간격을 조절합니다.

참고:  <장식문자>도구띠는 장식문자를 선택하였을 때 나타납니다.

장식문자본문의 변경
  1. 변경할 장식문자객체를 두번 찰칵합니다.
  2. 장식문자객체가 편집상태로 되였을 때 본문을 변경합니다.
장식문자본문의 칠하기, 투명도 및 그림자지정

장식문자도 도형객체의 한 종류이므로 여러가지 형식의 칠하기를 지정하고 그림자를 지정할수 있으며 투명도를 변경할수 있습니다.

장식문자의 칠하기격식 변경

  1. 칠하기격식을 변경할 장식문자객체를 선택합니다.
  2. <서식>차림표에서 <객체>의 <령역>을 찰칵하여 <령역>대화창을 엽니다. 또는 마우스의 오른쪽단추를 찰칵하여 나오는 상황차림표에서 <령역>을 찰칵할수도 있습니다.
  3. <령역>표쪽을 찰칵하고 <칠하기>복합칸에서 요구하는 칠하기격식을 지정합니다. 례를 들어 <색>, <계조>, <평행선>, <문양> 등을 선택하여 해당한 설정을 진행합니다.

    4. 참고:  <색>, <계조>, <평행선>, <문양> 등은 <령역>대화창의 해당 표쪽들을 찰칵하여 설정할수도 있습니다.

  4. <확인>단추를 찰칵합니다.

장식문자의 투명도변경

  1. 투명도를 변경할 장식문자객체를 선택합니다.
  2. <서식>차림표에서 <객체>의 <령역>을 찰칵하여 <령역>대화창을 엽니다. 또는 마우스의 오른쪽단추를 찰칵하여 나오는 상황차림표에서 <령역>을 찰칵할수도 있습니다.
  3. <투명도>표쪽을 찰칵하고 <투명방식>부분에서 요구하는 설정을 진행합니다.
  4. <확인>단추를 찰칵합니다.

장식문자의 그림자설정

  1. 그림자를 설정할 장식문자객체를 선택합니다.
  2. <서식>차림표의 <객체>의 <령역>을 찰칵하여 <령역>대화창을 엽니다. 또는 마우스의 오른쪽단추를 찰칵하여 나오는 상황차림표에서 <령역>을 찰칵할수도 있습니다.
  3. <그림자>표쪽을 찰칵하고 <속성>부분에서 요구하는 설정을 진행합니다.
  4. <확인>단추를 찰칵합니다.

참고:  <령역>대화창은 <도형객체속성>도구띠의 <령역>을 찰칵하여 열수도 있습니다.
