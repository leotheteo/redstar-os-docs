선형계획법 해석

모두 표시

주어진 조건을 만족하는 변수의 최대값, 최소값, 목표값을 구합니다.

다음과 같은 방법으로 진행합니다.

  1. 최량화문제를 풀기 위한 자료를 입력합니다.
  2. <도구>차림표에서 <선형계획법 해석>을 찰칵하여 <선형계획법 해석>대화창을 엽니다.
  3. <대상세포>본문칸에 목적함수식을 포함하는 세포를 입력합니다.
  4. <결과 최적화>부분에서 대상세포에 입력된 값을 최대값으로 하겠는가 또는 최소값으로 하겠는가를 설정합니다.
  5. <세포의 변경에 의하여>본문칸에서 변수세포범위를 선택합니다.
  6. <제한조건>부분에서 목적함수식의 제한조건들을 설정합니다. 제한조건이 한개이상인 경우 반복하여 제한조건들을 입력합니다.
  7. <해석>단추를 찰칵합니다.
  8. <해석결과>통보문에서 결과값을 그대로 표시하려면 <결과 유지>단추를 찰칵합니다.
