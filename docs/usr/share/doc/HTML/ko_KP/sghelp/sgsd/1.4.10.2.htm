문서의 여러 판본을 보관하기

모두 표시

다음의 방법들중에서 하나를 실행합니다.

파일을 닫을 때 판본정보를 자동으로 보관

  1. <파일>차림표에서 <판본>을 찰칵합니다.
  2. <닫을 때 항상 판본 보관>확인칸을 선택합니다.
  3. <닫기>를 찰칵합니다.

문서에 여러 판본 보관

  1. <파일>차림표에서 <판본>을 찰칵합니다.
  2. <새 판본 보관>단추를 찰칵합니다.
  3. <판본설명문>대화창에서 현재 보관하려는 판본에 대한 설명을 입력합니다.

참고: 문서가 처음으로 작성되여 아직 한번도 보관되지 않았을 때에는 <파일>차림표의 <판본>이 사용불가능으로 되여 리용할수 없습니다. 다시말하여 파일이름을 가지고있는 문서에 대해서만 판본을 보관할수 있습니다.
