추적

지령명 설명 지름건
참조대상 추적 수식을 포함하는 현재세포와 수식에 사용된 세포사이의 관계를 표시합니다. Shift+F7
참조대상 제거 참조대상 추적지령으로 삽입한 한 준위의 추적화살표를 삭제합니다. 같은 세포범위에 대하여 여러개의 참조대상 추적을 적용했을 경우 이것들중 하나를 제거하면 나머지 참조대상 추적들에 대해서는 화살표만 나타납니다.  
의존대상 추적 활성상태로 만든 세포의 값에 의존하는 수식에서 해당 활성상태로 만든 세포까지의 추적련결선을 그립니다. Shift+F5
의존대상 제거 의존대상 추적을 사용하여 만든 추적련결선을 삭제합니다.  
모든 추적 제거 자료표에서 모든 추적련결선을 제거합니다.  
오유 추적 선택한 세포에서 오유값을 발생시키는 모든 참조대상세포에 대한 련결선을 표시합니다.  
무효자료 표식 유효성검사규칙을 벗어나는 값이 포함된 표용지의 모든 세포에 표시합니다.  
추적 갱신 표용지의 모든 추적을 다시 그립니다. 추적을 다시 그릴 때 변경된 수식이 적용됩니다.  
자동갱신 수식을 수정할 때마다 표용지의 모든 추적을 자동적으로 새롭게 갱신합니다.  
참조대상 추적방식 추적의 참조대상 추적방식을 활성상태로 만듭니다. 마우스유표가 특수한 기호로 바뀌며 임의의 세포를 찰칵하여 참조대상세포에 대한 추적을 표시할수 있습니다.

지령명 설명 지름건

자동계산 문서의 모든 수식을 자동적으로 다시 계산합니다.  
자동입력 같은 렬의 세포인 경우 입력시 이미 있는 세포의 내용을 탐색하여 자동적으로 입력을 완료하는 자동입력기능을 절환합니다.
