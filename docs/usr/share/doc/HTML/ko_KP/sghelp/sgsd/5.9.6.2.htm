참고항목  정보함수목록

세포의 주소, 서식 또는 내용에 대한 정보를 결정합니다.

문법:   CELL(정보류형,참조)

인수명 설명
정보류형 원하는 세포정보의 류형을 지정하는 본문값으로 정보류형과 해당 결과값은 다음표와 같습니다.
참조 시험하려는 세포의 위치입니다. 추가선택인수입니다. 생략된 경우 정보류형에 지정된 정보는 변경된 마지막세포에 대한것입니다. 다음목록은 정보류형이 "format"이고 참조가 제공된 수자서식으로 지정된 세포인 경우 CELL수식에 의해 반환되는 본문값을 설명합니다.
정보류형 의미
COL 참조된 렬의 번호로 됩니다. 세포("COL", D2)는 4로 됩니다.
ROW 참조된 행의 번호로 됩니다. 세포("ROW", D2)는 2로 됩니다.
SHEET 참조된 표용지의 번호로 됩니다. Cell("Sheet", 표용지3.D2)의 결과는 3입니다.
ADDRESS 참조된 세포의 절대주소로 됩니다.

CELL("ADDRESS", D2)은 $D$2로 됩니다.

CELL("ADDRESS",표용지3.D2)은 $표용지3.$D$2로 됩니다.

CELL("ADDRESS", '/test/1.ods'#$표용지2.D2)은 'file:///test/1.ods'#$표용지2.$D$2로 됩니다.
FILENAME 참조된 세포의 표용지이름과 파일이름으로 됩니다.

수식이 현재문서/test/1.ods 표용지1에 위치하고있는 경우 CELL("FILENAME", D2)은 'file:///test/1.ods'#$표용지1로 됩니다.

CELL("FILENAME",'/test/1.ods'#$표용지1.D2)은 'file:///test/1.ods'#$표용지1로 됩니다.
COORD 결과로 Lotus(TM)-Notation의 적당한 세포주소가 산출됩니다.

CELL("COORD", D2)은 $A:$D$2로 됩니다.

CELL("COORD", 표용지3.D2)은 $C:$D$2로 됩니다.
CONTENTS 결과로 서식지정없이 참조된 세포의 내용이 산출됩니다.
TYPE 결과로 세포내용의 류형이 산출됩니다.

b = blank. 빈 세포

l = label. 본문, 수식결과를 본문으로

v = value. 값, 수식결과를 수자로
WIDTH 결과로 참조된 렬의 너비가 산출됩니다. 측정단위는 기정크기의 기정서체인 렬에 맞는 령(0)의 개수입니다.
PREFIX 참조된 세포의 맞추기상태를 제공합니다.

' = 왼쪽 또는 량쪽맞추기

" = 오른쪽맞추기

^ = 중심맞추기

\ = 반복(현재 대화식)
PROTECT 결과로 세포보호상태를 제공합니다.

1 = 세포가 보호됨

0 = 세포가 보호되지 않음
FORMAT 결과로 수자서식을 지정하는 문자렬이 산출됩니다.

= 천단위구분기호가 있는 수자(공백)

F = 천단위구분기호가 없는 수자

C = 통화형식

S = 지수표시 례를 들면 1.234+E56

P = 백분률값(%)

우의 서식에서 소수구분기호뒤의 소수자리수는 수자로 주어집니다. 례를 들어 수자서식 #.##0.0은 1을 구하며 수자서식 00.000%은 P3을 구합니다.

D1 = YY-MMM-D, YY-MM-D 그리고 류사한 서식

D2 = MM-DD

D3 = YY-MM

D4 = YYYY-MM-DD HH:MM:SS

D5 = MM-DD

D6 = 오전/오후 HH:MM:SS

D7 = 오전/오후 HH:MM

D8 = HH:MM:SS

D9 = HH:MM

G = 다른 모든 서식

끝에 - (미누스) = 부수는 색갈로 서식지정됩니다.

끝에 () (괄호) = 서식코드에 열려있는 괄호가 있습니다
COLOR 부수값이 색갈로 서식지정되여있으면 결과는 1이 되고 그렇지 않은 경우 0으로 됩니다.
PARENTHESES 서식코드에 열려있는 괄호 (가 포함되여있으면 결과는 1이 되고 그렇지 않으면 0으로 됩니다.

CELL 수식의 정보류형인수가 "format"이고 나중에 사용자지정서식으로 세포의 서식을 지정하면 자료표를 다시 계산하여 CELL 수식을 갱신해야 합니다.

주의

CELL함수는 다른 표처리프로그람과의 호환성을 위하여 제공됩니다.
