련결된 객체나 포함된 객체로 정보의 삽입

모두 표시

객체를 표처리프로그람에 삽입하여 《서광사무처리》 3.0프로그람이나 련결된 객체 및 포함된 객체를 지원하는 다른 프로그람에서 작성한 파일의 정보를 포함시킬수 있습니다.

포함된 객체

련결된 객체

원본파일

련결된 객체와 포함된 객체의 차이점

련결된 객체와 포함된 객체의 주요 차이점은 대상파일에 자료를 넣은후 자료를 보관하는 위치와 자료를 갱신하는 방법입니다.

련결된 객체

객체를 련결하면 원본파일을 수정하는 경우에만 정보가 갱신됩니다. 련결된 자료는 원본파일에 보관됩니다. 대상파일은 원본파일의 위치만 보관하고 련결된 자료를 표시합니다. 파일크기를 고려하여야 할 경우에는 련결된 객체를 사용합니다.

또한 다른 부서에서 수집한 자료와 같이 따로 관리되는 정보를 포함하거나 표처리프로그람에서 최신정보를 유지하여야 할 때 련결기능을 사용하는것이 좋습니다.

문서처리프로그람객체에 련결할 때 문서처리프로그람의 본문 및 수자격식을 사용하거나 표처리프로그람에서 제공하는 격식을 적용할수 있습니다. 표처리프로그람격식을 사용하는 경우 자료를 갱신하더라도 격식을 유지할수 있습니다. 례를 들어 련결된 객체의 표, 지면배치, 서체크기, 서체색 등을 변경한 경우 원본파일의 객체가 갱신되더라도 이러한 변경내용은 그대로 유지됩니다.

포함된 객체

객체를 포함한 경우에는 원본파일을 수정해도 대상파일의 정보는 변경되지 않습니다. 포함된 객체는 대상파일의 일부가 되며 일단 대상파일에 삽입한 후에는 더이상 원본파일의 일부가 아닙니다.

련결된 객체의 편집 및 갱신

표용지에 있는 련결된 객체를 편집하려면 <편집>차림표의 <련결>지령을 사용합니다.

기본적으로 련결된 객체는 자동적으로 갱신됩니다. 즉 표처리프로그람에서 대상파일을 열 때마다 련결된 정보가 갱신됩니다.

련결된 객체와 원본파일사이의 련결을 해제할수도 있습니다.

포함된 객체의 편집

포함된 객체를 편집하려면 객체를 두번 찰칵한 다음 원본프로그람에서 객체를 변경합니다.
