문법:   HYPGEOMDIST(X,표본크기,성공회수,모집단크기)

인수명 설명
X 표본집단에서의 성공회수입니다.
표본크기 표본집단의 크기입니다
성공회수 모집단에서의 성공회수입니다.
모집단크기 모집단의 크기입니다.

주의

  • 모든 인수는 소수점이하를 잘라서 옹근수로 변환합니다.
  • 인수가 수자가 아니면 오유:[오유번호]를 반환합니다.
  • X가 부수이거나 표본크기와 성공회수중 작은 값보다 크면 오유:[오유번호]를 반환합니다.
  • X가 0과 (표본크기 - 모집단크기 + 성공회수)중에서 큰 값보다 작으면 오유:[오유번호]를 반환합니다.
  • 표본크기 < 0이거나 표본크기 > 모집단크기이면 오유:[오유번호]를 반환합니다.
  • 성공회수 < 0이거나 성공회수 > 모집단크기이면 오유:[오유번호]를 반환합니다.
  • 모집단크기 < 0이면 오유:[오유번호]를 반환합니다.
  • 초기하분포식은 다음과 같습니다.

    여기서

    x = X

    n = 표본크기

    M = 성공회수

    N = 모집단크기

    HYPGEOMDIST함수는 유한 모집단에서 표본이 비반복으로 추출될 때 사용됩니다.
