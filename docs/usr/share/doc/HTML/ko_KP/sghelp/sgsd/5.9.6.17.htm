값을 수값으로 변환합니다.

문법:   N(값)

인수명 설명
값 수값으로 해석할 값입니다. N이 변환하는 값은 다음표와 같습니다.
값이나 참조 결과값
수자 같은 수자
표처리프로그람에서 제공된 날자서식에 따르는 날자 해당 날자의 내부수값
참 1
거짓 0
오유:503과 같은 오유값 오유:503
기타 0

주의

일반적으로 표처리프로그람에서는 필요에 따라 값이 자동으로 변환되므로 수식에서 N함수를 사용할 필요가 없습니다. 이 함수는 다른 표처리프로그람과의 호환을 위하여 제공됩니다.
