세포에 본문이 들어있는가를 확인

이 작업을 수행하려면 ISTEXT함수를 사용합니다.

실례

실례의 리용방법을 참고하십시오.

 
1
2
3
A
자료
본문
123
수식 설명
=ISTEXT(A2) A2세포에 본문이 있는가를 확인합니다. (참)
=ISTEXT(A3) A3세포에 본문이 있는가를 확인합니다. (거짓)

참조함수

ISTEXT

세포내용이 특정본문과 일치하는가를 확인하여 값을 반환

이 작업을 수행하려면 IF함수를 사용합니다. IF함수는 사용자가 지정하는 결과를 반환합니다.

실례

실례의 리용방법을 참고하십시오.

 
1
2
A
자료
서광
수식 설명
=IF(A2="서광";"성공";"실패") A2가 “서광”인가를 확인합니다. (성공)
=IF(A2="정보"; “참”; “거짓”) A2가 “정보”인가를 확인합니다. (거짓)

참조함수

IF

특정한 본문이 들어있는 행에 대한 목록의 려과

  1. 목록에서 려과할 세포를 찰칵합니다.
  2. <자료>차림표에서 <려과기>를 찰칵하고 <자동려과기>를 찰칵합니다.
  3. 수자가 포함된 렬에서 화살표를 찰칵하고 <표준>을 찰칵합니다.
  4. <조건>복합칸에서 = 또는 <>을 찰칵합니다.
  5. <값>본문칸에 요구하는 본문을 입력합니다.
  6. <확인>단추를 찰칵합니다.

세포의 일부분이 특정본문과 일치하는가를 확인하여 값을 반환

이 작업을 수행하려면 IF, FIND, SEARCH, ISNUMBER 등의 함수를 사용합니다.

실례

실례의 리용방법을 참고하십시오.

 
1
2
3
A
자료
Sogwang
ABCD123
수식 설명(결과)
=IF(ISNUMBER(FIND("w";A2));"성공"; "실패") A2에 문자w가 들어있는가를 확인합니다. (성공)
=ISNUMBER(FIND("BC";A3)) A3에 BC가 들어있는가를 확인합니다. (참)

우의 수식에서 사용하는 인수는 다음과 같습니다.

본문확인을 위한 수식

검색문: 찾으려는 대상입니다.

본문: 확인하려는 본문이 들어있는 세포입니다.

참고:  FIND함수는 대소문자를 구분합니다. 대소문자를 무시하려면 FIND함수 대신 SEARCH함수를 사용하십시오.

참조함수

IF

ISNUMBER

FIND

SEARCH

본문이 들어있는 세포를 찾기

  1. 어떤 범위내에서만 찾으려면 그 세포범위를 선택합니다.
  2. <편집>차림표에서 <탐색 및 치환>을 찰칵합니다.
  3. 찾을 본문이나 수자를 <탐색대상>복합칸에 입력하거나 복합칸에서 최근에 탐색한 내용을 선택합니다.
  4. 찾을 서식을 지정하려면 <상세히>단추를 찰칵하고 <격식 탐색>확인칸을 선택하고 <탐색대상>복합칸에서 요구하는 격식을 선택합니다.
  5. <탐색> 또는 <모두 탐색>단추를 찰칵합니다.

    6. <모두 탐색>은 탐색하는 항목이 나타나는 모든 경우를 표시하며 그중 특정한 경우를 선택하여 현재세포로 만들수 있습니다.

즉시도움말

목록에서 자료를 찾으려는 경우 려과기를 사용하여 요구하는 자료가 있는 행만 표시할수 있습니다. 례를 들어 학교자료가 들어있는 목록에서 한 학급만 표시할수 있습니다.
