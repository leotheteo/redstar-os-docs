TDIST

모두 표시

참고항목  통계함수목록, TINV, TTEST

t-분포값을 구합니다.

문법:   TDIST(수값,자유도,방식)

인수명 설명
수값 t-분포를 계산할 값입니다.
자유도 t-분포의 자유도입니다.
방식 t-분포가 단측분포인가 량측분포인가를 나타내는 수자로서 방식= 1이면 단측분포를, 방식= 2이면 량측분포를 사용하여 확률값을 구합니다.

주의

  • 자유도 < 1이면 오유:[오유번호]를 표시합니다.
  • 자유도와 방식인수는 옹근수로 변환됩니다.
  • 방식이 1, 2 이외의 값을 가지면 오유:[오유번호]를 표시합니다.
  • 수값이 0보다 작으면 오유:[오유번호]를 표시합니다.
  • 방식 = 1이면 TDIST = P( X>x )와 같이 계산됩니다. 여기서 x는 수값이고 X는 t-분포에 따른 우연변량입니다. 방식= 2이면 TDIST = P(|X| > x) = P(X > x or X < -x)와 같이 계산됩니다.
  • 0보다 작은 수값은 허용되지 않으므로 수값이 0보다 작을 경우에는 TDIST함수를 TDIST(-x,df,1) = 1- TDIST(x,df,1) = P(X > -x)와 TDIST(-x,df,2) = TDIST(x, df,2) = P(|X| > x)로 사용합니다.
