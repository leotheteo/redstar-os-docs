사용자정의도구띠의 이름 바꾸기

모두 표시

사용자가 직접 만든 사용자정의도구띠의 이름은 모두 바꿀수 있지만 표처리프로그람에 포함된 표준제공도구띠의 이름은 바꿀수 없습니다.

다음과 같은 방법으로 진행합니다.

  1. <도구>차림표에서 <사용자전용화>를 찰칵합니다.
  2. <사용자전용화>대화창이 화면에 현시됩니다.
  3. <사용자전용화>대화창에서 <도구띠>표쪽을 찰칵합니다.
  4. <도구띠>목록칸에서 이름을 바꾸려는 사용자정의도구띠를 찰칵합니다.
  5. <도구띠>단추를 찰칵하면 튀여나오기차림표가 나타나는데 여기서 <이름 바꾸기>를 찰칵합니다.
  6. 본문입력창에 새로운 이름을 입력하고 <확인>단추를 찰칵합니다.
  7. <사용자전용화>대화창의 <확인>단추를 찰칵합니다.
