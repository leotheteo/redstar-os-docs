수식 설명(결과)
=EXACT(A2;A3) A2와 A3의 내용을 비교합니다. (거짓)
=EXACT(A3;A4) A3와 A4의 내용을 비교합니다. (참)

참고:  EXACT함수는 대소문자를 구분합니다.

참조함수

EXACT

한개의 값을 값목록과 비교

이 작업을 수행하려면 EXACT와 OR함수를 사용합니다.

수식 설명(결과)
=OR(EXACT(B2; A2:A4)) "포도"를 목록의 각 값과 비교합니다. (거짓)

참고: 실례의 수식은 행렬수식으로 입력하여야 합니다. 실례를 빈 표용지에 복사하고 각 수식 세포를 개별적으로 선택한 다음 [F2]건을 누르고 [Ctrl+Shift+Enter]건을 누릅니다. 수식을 행렬수식으로 입력하지 않으면 #VALUE! 오유가 반환됩니다.

우의 수식에서 사용하는 구문은 다음과 같습니다.

=OR(EXACT(본문1;본문2))

본문1은 사용자가 입력한 값을 나타내며, 본문2는 비교할 대상의 본문값목록을 나타냅니다.

참조함수

OR

EXACT
