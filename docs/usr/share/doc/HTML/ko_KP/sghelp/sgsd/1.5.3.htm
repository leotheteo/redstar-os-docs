표용지에서 세포, 행 및 렬의 선택실례

모두 표시

선택 방법
세포안의 본문 세포를 선택하고 세포의 내부를 두번 찰칵한 다음 본문을 선택합니다. 또한 세포를 선택하고 수식띠의 입력행에서 본문을 선택합니다.

하나의 세포 마우스로 세포를 찰칵하거나 방향건을 눌러 해당 세포로 이동합니다.
세포범위 마우스로 해당 범위의 첫번째 세포를 찰칵하고 마지막세포까지 마우스를 끕니다. 또는 마우스로 해당 범위의 첫번째 세포를 찰칵한 다음 [Shift]건을 누르면서 방향건을 눌러 세포의 범위를 선택할수 있습니다.
넓은 세포범위 해당 범위에서 첫번째 세포를 찰칵하고 [Shift]건을 누르면서 해당 범위의 마지막세포를 찰칵합니다.
표용지의 모든 세포 모두선택단추를 찰칵합니다.

또는 표용지의 임의의 세포를 찰칵하고 [Ctrl+A]건을 누릅니다.
린접하지 않은 세포 또는 세포범위 첫번째 세포 또는 세포범위를 선택한 다음 [Ctrl]건을 누르면서 다른 세포 또는 세포범위를 선택합니다.
전체 행 또는 렬 행머리부 또는 렬머리부를 찰칵합니다.

행머리부

렬머리부
린접한 행 또는 렬 마우스로 행머리부나 렬머리부를 끌어서 선택합니다. 또는 첫번째 행이나 렬을 선택하고 [Shift]건을 누르면서 마지막행이나 렬을 선택합니다.
린접하지 않은 행 또는 렬 첫번째 행 또는 렬을 선택하고 [Ctrl]건을 누르면서 다른 행 또는 렬을 선택합니다.
현재 선택내용의 세포개수 변경 [Shift]건을 누르면서 새로운 선택령역에 포함하려는 마지막세포를 찰칵합니다. 현재세포와 선택한 세포사이의 네모령역이 새로운 선택령역이 됩니다.
세포 선택취소 표용지에서 선택된 세포를 제외한 다른 세포를 선택합니다.
