IF함수를 사용하여 조건부수식의 만들기

모두 표시

결과가 론리값(참 또는 거짓)인 경우

이 작업을 수행하려면 AND, OR, NOT함수와 연산자를 사용합니다.

수식 설명(결과)
=AND(A2>A3; A2＜A4) 15가 9보다 크고 8보다 작습니다. (거짓)
=OR(A2>A3; A2＜A4) 15가 9보다 크거나 8보다 작습니다. (참)
=NOT(A2+A3=24) 15 더하기 9는 24와 같지 않습니다. (거짓)

결과가 론리값이 아닌 경우

이 작업을 수행하려면 IF, AND, OR함수를 사용합니다.

실례

수식 설명(결과)
=IF(A2=15; "성공"; "실패") A2 세포값이 15이면 《성공》을 반환합니다. (성공)
=IF(AND(A2>A3; A2＜A4); "성공"; "실패") 15가 9보다 크고 8보다 작으면 《성공》을 반환합니다. (실패)
=IF(OR(A2>A3; A2＜A4); "성공"; "실패") 15가 9보다 크거나 8보다 작으면 《성공》을 반환합니다. (성공)

IF 함수에 사용하는 인수는 다음과 같습니다.

IF함수를 사용한 수식

검사식  검사할 조건입니다.

참일 때 결과값  조건이 참일 때 반환할 값입니다.

거짓일 때 결과값  조건이 거짓일 때 반환할 값입니다.

참조함수

AND

OR

IF
