그림기호 지령명 기능
URL적재 URL로 지정된 문서를 적재합니다. URL을 새로 입력하거나 이미 등록된 URL을 선택할수 있습니다.
새로 만들기 《서광사무처리》 3.0문서를 새로 만듭니다.
형판으로부터 새 문서 만들기 형판으로부터 문서를 새로 만듭니다.
열기 파일을 엽니다. 휴지통에 들어간 파일에 대해서는 열수 없습니다.
보관 현재문서를 보관합니다.
다른 이름으로 보관 현재문서를 다른 위치에 보관하거나 파일이름 또는 파일형식을 다르게 지정하여 보관합니다.
문서를 전자우편으로 표준전자우편프로그람을 사용하여 현재문서를 전자우편의 첨부파일로 보냅니다.
파일 편집 읽기전용문서를 편집할수 있습니다.
PDF로 직접 반출 현재문서를 PDF로 직접 반출합니다.
파일 직접 인쇄 (일반인쇄기) 현재 표준인쇄설정을 사용하여 활성상태로 된 문서를 인쇄하려면 직접 이 그림기호를 찰칵합니다.
인쇄 미리보기 인쇄할 페지의 미리보기창을 표시하거나 닫습니다.
철자법 검사 수동으로 철자를 검사합니다. (조선어에 대하여 이 지령이 실행되려면 <서광사무처리>/<환경설정>/<언어 설정>/<언어>/<동양언어>가 <조선어>로 설정되여있어야 합니다.)
철자법 자동검사 단어를 입력할 때 자동적으로 철자법 검사를 진행하고 오유가 있으면 밑줄을 표시합니다.
자르기 선택한 내용을 잘라내여 오림판에 복사합니다.
복사 선택한 내용을 오림판에 복사합니다.
붙이기 현재유표위치에 오림판내용을 삽입합니다. 선택된 본문이나 객체는 모두 오림판의 내용으로 바뀝니다. 서식을 선택하려면 그림기호옆의 화살표를 찰칵합니다.
서식 복사 선택한 본문이나 객체의 서식을 복사하여 다른 본문선택령역이나 객체에 적용합니다.
실행 취소 마지막지령의 실행을 취소합니다. 실행 취소할 지령을 선택하려면 <표준>도구띠에서 <실행 취소>그림기호옆의 화살표를 찰칵합니다.
다시 실행 취소하였던 지령을 다시 실행합니다. 다시 실행하려는 단계를 선택하려면 <표준>도구띠에서 <다시 실행>그림기호옆에 있는 화살표를 찰칵합니다.
하이퍼련결 하이퍼련결을 만들고 편집할수 있는 대화창을 엽니다.
올리순서로 정렬 선택된 렬의 자료를 자모처음부터 시작하여 올리순서로 정렬합니다.
내리순서로 정렬 선택된 렬의 자료를 자모마지막부터 시작하여 내리순서로 정렬합니다.
도표 현재문서에 도표를 만듭니다. 세포범위를 도표의 자료원본으로 사용하려면 세포를 선택하고 이 지령을 선택합니다.
도형그리기기능 보이기 <도형>도구띠를 보이거나 숨깁니다.
탐색 및 치환 현재문서에서 본문 또는 서식을 탐색하거나 치환합니다.
항행기 문서의 다른 부분으로 빨리 이동할수 있는 항행기를 보이거나 숨깁니다.
화첩 문서에 삽입할 그림과 음성을 선택할수 있는 화첩을 엽니다.
자료원본 《서광사무처리》 3.0프로그람에 등록된 자료기지를 표시하고 자료기지내용을 관리할수 있게 해줍니다.
확대/축소 화면표시를 축소 또는 확대합니다.
서광사무처리 도움말 현재 응용프로그람에 대한 《서광사무처리》 3.0도움말의 기본페지를 엽니다.
