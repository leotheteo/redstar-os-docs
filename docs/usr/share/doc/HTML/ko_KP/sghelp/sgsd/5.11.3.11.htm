그림에 련결추가

모두 표시

화상의 정의된 령역을 찰칵하면 이 령역과 련결된 대상으로 이동할수 있습니다. 이러한 령역에 마우스유표를 가져갔을 때 표시되는 해당 본문은 <화상편집기>에서 정의할수 있습니다.

  1. 표용지에 그림을 삽입합니다.
  2. 그림을 선택하고 <편집>차림표에서 <화상>을 찰칵합니다.
  3. <화상편집기>대화창에서 다음과 같이 그림을 편집합니다.
    1. 도구띠에서 <직사각형>, <타원>, <다각형>, <자유다각형>들을 리용하여 령역을 정의합니다.
    2. 정의한 령역을 찰칵하고 <주소>본문칸에 화상에 련결하려는 대상의 주소를 입력합니다. 례를 들어 <본문>칸에 http://www.naenara.inf.kp를 입력하면 화상의 해당 령역을 찰칵할 때 《내나라》홈페지를 열람할수 있습니다.
    3. <본문>본문칸에는 이 령역에 마우스유표를 가져갔을 때 즉시도움말로 표시되는 본문을 입력합니다.
    4. 도구띠에 있는 <속성>을 찰칵하여 나타나는 <속성>대화창에서 <이름>본문칸에 령역의 이름을 입력합니다.

    참고: 도구띠의 <열기>나 <보관>을 리용하여 <화상편집기>에서 편집한 내용을 보관하거나 열수 있습니다.

  4. 도구띠의 <적용>을 찰칵합니다.
