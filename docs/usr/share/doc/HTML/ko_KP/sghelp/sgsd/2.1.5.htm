모두 표시

지령명 설명 지름건
직접 적용한 서식 삭제 선택한 대상의 서식을 초기화합니다. Ctrl+Shift+Space
세포 다양한 서식추가선택을 지정하고 선택한 세포에 속성을 적용할수 있습니다. Ctrl+1
행 행높이를 설정하고 선택한 행을 숨기거나 표시합니다.  
렬 렬너비를 설정하고 선택한 렬을 보이거나 숨깁니다.  
표용지 표용지이름을 설정하고 선택한 표용지를 보이거나 숨깁니다.  
세포 합치고 가운데 맞추기 선택한 여러 세포들을 단일세포로 합치거나 합쳐진 세포를 가릅니다.  
페지 문서의 모든 페지의 격식을 지정할수 있는 대화창을 엽니다.  
인쇄범위 인쇄범위를 지정합니다. 인쇄범위내의 세포만 인쇄됩니다.  
문자 문자서식을 지정합니다.  
단락 단락서식을 지정합니다.  
대문자/소문자 변환 영어문자에 한해서만 적용됩니다. 선택한 문자의 대문자/소문자를 변경하거나 유표가 단어안에 있으면 단어의 전체 문자의 대문자/소문자를 변경합니다.  
격식 및 서식 격식을 지정하고 관리할수 있는 <격식 및 서식>창을 보이거나 숨기겠는가를 지정합니다. Ctrl+Shift+F11
자동서식 이 지령을 사용하여 자동서식을 선택한 표용지령역에 적용하거나 고유한 자동서식을 정의합니다.  
조건부 서식설정 특정한 조건에 따라 서식을 지정하려면 조건부 서식설정을 선택합니다.  
지탱점 선택한 객체에 대하여 지탱점을 설정합니다.  
맞추기 선택한 객체의 맞추기를 변경합니다.  
배렬 선택한 객체의 배렬순서를 변경합니다.  
반전 선택한 객체를 수평 또는 수직으로 반전합니다.  
그룹 선택한 객체들을 그룹화하여 하나의 객체처럼 이동하거나 서식을 설정할수 있습니다.  
객체 선택한 객체의 속성을 편집할수 있는 부분차림표를 엽니다.  
조종체속성 선택한 조종체를 편집할수 있는 <속성>대화창을 엽니다.  
양식속성 이 대화창에서는 전체 양식에 대한 자료원본과 사건을 지정할수 있습니다.  

행

지령명 설명
높이 선택한 행의 높이를 변경합니다.
최적행높이 선택한 행에 대한 최적행높이를 결정합니다.
숨기기 선택한 행을 숨깁니다.
보이기 이전에 숨긴 행을 표시하려면 이 지령을 선택합니다.

렬

지령명 설명
너비 선택한 렬의 너비를 지정합니다.
최적렬너비 선택한 렬에 대한 최적렬너비를 지정합니다.
숨기기 선택한 렬를 숨깁니다.
보이기 이전에 숨긴 렬을 표시하려면 이 지령을 선택합니다.

표용지

지령명 설명
이름 바꾸기 이 지령은 현재표용지에 다른 이름을 할당할수 있는 대화창을 엽니다.
숨기기 선택한 표용지를 숨깁니다.
보이기 이전에 숨기기지령을 사용하여 숨긴 표용지를 표시합니다.

인쇄범위

지령명 설명
정의 활성상태로 만든 세포 또는 선택한 세포령역을 인쇄범위로 지정합니다.
추가 지정한 인쇄령역에 현재선택령역을 추가합니다.
제거 지정한 인쇄령역을 제거합니다.
편집 인쇄범위를 지정할수 있는 대화창을 엽니다.

대문자/소문자 변환

지령명 설명
대문자 선택한 영어문자를 대문자로 변경합니다.
소문자 선택한 영어문자를 소문자로 변경합니다.
반각 선택한 영어문자를 반각으로 변경합니다.
전각 선택한 영어문자를 전각으로 변경합니다.
히라가나 가따가나를 히라가나로 변경합니다.
가따가나 히라가나를 가따가나로 변경합니다.

지탱점

지령명 설명
페지에 선택한 객체를 현재페지에 고정합니다.
세포에 선택한 객체를 세포에 고정합니다.

맞추기

지령명 설명
기정 세포내용들을 기정(왼쪽)으로 맞춥니다.
왼쪽 세포내용이나 도형객체들을 왼쪽을 기준으로 맞춥니다.
가로가운데 세포내용이나 도형객체들을 가로가운데를 기준으로 맞춥니다.
오른쪽 세포내용이나 도형객체들을 오른쪽을 기준으로 맞춥니다.
량쪽 세포내용들을 왼쪽과 오른쪽을 기준으로 맞춥니다.
웃쪽 세포내용이나 도형객체들을 웃쪽을 기준으로 맞춥니다.
세로가운데 세포내용이나 도형객체들을 세로가운데를 기준으로 맞춥니다.
아래쪽 세포내용이나 도형객체들을 아래쪽을 기준으로 맞춥니다.

배렬

지령명 설명
맨 앞면에로 이동 선택한 객체를 다른 객체들의 맨 앞면에로 이동합니다.
앞면에로 이동 선택한 객체를 앞면에로 이동합니다.
뒤면에로 이동 선택한 객체를 뒤면에로 이동합니다.
맨 뒤면에로 이동 선택한 객체를 다른 객체들의 맨 뒤면에로 이동합니다.
전경에 선택한 객체를 본문의 앞면으로 이동합니다.
배경에 선택한 객체를 본문의 뒤면으로 이동합니다.

반전

지령명 설명
수직으로 반전 선택한 객체를 수직방향으로 반전합니다.
수평으로 반전 선택한 객체를 수평방향으로 반전합니다.

그룹

지령명 설명
그룹 선택한 객체를 그룹화하여 하나의 객체처럼 이동할수 있습니다.
그룹 해제 선택한 그룹을 매 객체로 분리합니다.

객체

지령명 설명
위치 및 크기 선택한 객체의 크기를 변경하거나 이동 또는 회전하거나 기울입니다.
선 선택한 선의 서식을 설정합니다.
령역 선택한 도형객체의 칠하기속성을 설정합니다.
본문 선택한 도형객체나 본문객체에 있는 본문의 배치 및 지탱점의 속성을 설정합니다.
점 도형객체의 꼭지점을 보이거나 숨깁니다.
