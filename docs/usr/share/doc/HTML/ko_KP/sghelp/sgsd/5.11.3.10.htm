모두 표시

표처리프로그람에서 사용할수 있는 그림의 파일형식

문서에 직접 또는 별도의 그림려과기를 사용하여 인기있는 많은 파일형식의 그림을 삽입할수 있습니다. 다음과 같은 파일형식을 삽입할 때에는 별도의 그림려과기를 설치할 필요가 없습니다.

  • Enhanced Metafile(.emf)
  • Graphics Interchange Format(.gif)
  • Joint Photographic Experts Group(.jpg)
  • Portable Network Graphics(.png)
  • Windows Bitmap(.bmp)
  • Windows Metafile(.wmf)
  • AutoCAD Interchange Format (.dxf)
  • Encapsulated PostScript(.eps)
  • Mac Pict (.pct)
  • Portable Bitmap (.pbm)
  • Portable Pixelmap(.ppm)
이동속도를 향상시킬수 있도록 그림을 숨기기

<서광사무처리>차림표에서 <환경설정>을 찰칵하고 <서광사무처리 표처리프로그람>의 <보기>를 찰칵하여 <객체>부분에서 <객체/그림>복합칸에서 <숨기기>를 찰칵합니다.
