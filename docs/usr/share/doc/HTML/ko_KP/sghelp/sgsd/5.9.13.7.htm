BIN2HEX

모두 표시

참고항목  추가함수목록, DEC2BIN, HEX2BIN, OCT2BIN

2진수를 16진수로 변환합니다.

문법:   BIN2HEX(2진수,자리수)

인수명 설명
2진수 변환할 2진수입니다. 10자리(10비트)까지만 사용할수 있습니다. 2진수의 최상위비트는 부호비트이고 나머지 9비트는 값을 나타내는 비트입니다. 부수는 2의 보수표기법으로 표시됩니다.
자리수 16진수의 자리수입니다. 추가선택인수입니다. 자리수를 생략하면 필요한 최소한의 자리수가 사용됩니다. 자리수는 반환값의 앞에 0을 넣어 자리수를 맞출 때 유용합니다.

주의

  • 2진수가 유효한 2진수가 아니거나 10자리(10비트)를 초과하면 오유:[오유번호]가 반환됩니다.
  • 2진수가 부수이면 오유:[오유번호]가 반환됩니다.
  • 자리수로 지정한것보다 자리수가 더 많이 필요하면 #NAME?오유가 반환됩니다.
  • 자리수가 옹근수가 아니면 소수점이하는 무시됩니다.
  • 자리수가 수자가 아니면 #NAME?오유가 반환됩니다.
  • 자리수가 부수이면 오유:[오유번호]가 반환됩니다.
