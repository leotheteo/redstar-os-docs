GAMMADIST

모두 표시

참고항목  통계함수목록, CHIDIST, EXPONDIST, GAMMAINV

γ분포에 대한 확률밀도함수나 루적분포함수의 값을 계산합니다.

문법:   GAMMADIST(수값,α,β,류형)

인수명 설명
수값 γ분포를 계산할 값입니다.
α γ분포의 α파라메터입니다
β γ분포의 β파라메터입니다. β = 1이면 표준감마분포의 확률을 구합니다.
류형 함수류형을 결정하는 론리값으로서 류형이 1이면 루적분포함수를, 0이면 확률밀도함수를 구합니다.

주의

  • 수값, α, β 등이 수자가 아니면 오유:[오유번호]를 반환합니다.
  • 수값이 부수이면 오유:[오유번호]를 반환합니다.
  • α ≤ 0이거나 β ≤ 0이면 오유:[오유번호]를 반환합니다.
  • γ확률밀도함수식은 다음과 같습니다. 다음의 식들에서 x는 수값입니다.

    표준γ확률밀도함수식은 다음과 같습니다.

  • α = 1이면 다음과 같은 지수분포의 확률을 구합니다.

  • 정의 옹근수 n에 대하여 α = n/2, β = 2, 류형 = 1이면 자유도 n인 (1 - CHIDIST(x))를 구합니다.
  • α가 정의 옹근수인 경우 GAMMADIST를 얼랭(Erlang) 확률분포라고도 합니다.
