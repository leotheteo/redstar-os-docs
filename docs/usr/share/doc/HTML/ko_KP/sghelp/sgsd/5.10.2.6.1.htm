0값의 보이기/숨기기

모두 표시

표용지의 모든 0값의 보이기/숨기기

  1. <서광사무처리>차림표에서 <환경설정>을 찰칵하고 <서광사무처리 표처리프로그람>에서 <보기>를 찰칵합니다.
  2. 다음의 방법들중에서 하나를 실행합니다.
    • 세포에 0값을 나타내려면 <0값>확인칸을 선택합니다.
    • 0값을 빈 세포로 나타내려면 이 확인칸의 선택을 취소합니다.

선택한 세포에서 0값을 숨기는 수자서식사용

주의: 이 항목은 선택한 세포의 0값을 숨기기 위한 서식을 적용합니다. 이 세포중 하나의 값이 0이 아닌 값으로 변경되면 값의 서식은 일반수자형식과 류사해집니다.

  1. 숨기려는 0값이 들어있는 세포를 선택합니다.
  2. <서식>차림표에서 <세포>를 찰칵하고 <수자>표쪽을 찰칵합니다.
  3. <종류>목록칸에서 <사용자정의>를 찰칵합니다.
  4. <서식코드>본문칸에 0;-0;;@를 입력합니다.

참고:

  • 숨겨진 값은 수식띠 또는 세포에서 편집한 경우에는 세포에만 나타나고 인쇄되지는 않습니다.
  • 숨겨진 값을 다시 나타내려면 세포를 선택하고 <서식>차림표에서 <세포>를 찰칵한 다음 <수자>표쪽을 찰칵합니다. <서식>목록칸에서 <일반>을 찰칵하여 기본적인 수자서식을 적용합니다. 날자나 시간을 다시 나타내려면 <수자>표쪽에서 해당 날자나 시간서식을 선택합니다.

수식에서 반환되는 0값 숨기기

이 작업을 수행하려면 IF함수를 사용합니다.

실례

실례의 리용방법을 참고하십시오.

수식 설명(결과)
=A2-A3 첫번째 수자에서 두번째 수자를 덥니다. (0)
=IF(A2-A3=0;"";A2-A3) 값이 0이면 빈 세포를 반환합니다. (빈 세포)
=IF(A2-A3=0;"-";A2-A3) 값이 0이면 풀이표를 반환합니다. (-)

참조함수

IF
