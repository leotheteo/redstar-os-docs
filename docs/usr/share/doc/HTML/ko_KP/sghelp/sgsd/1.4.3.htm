문서보관

모두 표시

표처리프로그람에서는 여러가지 방법으로 문서를 보관할수 있습니다. 작업진행중인 현재문서가 새 문서이건 기존 문서이건 관계없이 문서를 보관할수 있으며 열려있는 모든 문서를 동시에 보관할수도 있습니다. 또한 현재문서의 복사본을 다른 이름으로 보관하거나 다른 위치에 보관할수 있습니다.

다른 문서에서 다시 사용하려는 본문이나 서식이 있으면 표처리프로그람의 형판으로 문서를 보관합니다.

이전판본의 표처리프로그람을 사용하는 사용자와 문서를 공유할 때 이전판본에서 열어도 문서의 모양이 똑같이 유지되게 하려면 해당 판본에서 지원하지 않는 기능을 해제합니다.
