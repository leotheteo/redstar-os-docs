자료의 입력

모두 표시

수자, 본문, 날자 및 시간의 입력

  1. 자료를 입력할 세포를 찰칵합니다.
  2. 자료를 입력하고 [Enter]건이나 [Tab]건을 누릅니다.

여러 표용지에 같은 자료의 입력 및 편집

여러 표용지를 선택하고 그중 한 표용지의 자료를 변경하면 선택한 모든 표용지에 동일한 변경내용이 적용됩니다. 이 과정에 자료가 바뀔수도 있습니다.

  1. 자료를 입력할 표용지들을 선택합니다. 표용지선택의 실례를 참고하십시오.
  2. 자료를 입력할 세포나 세포범위를 선택합니다.
  3. 처음 선택한 세포에서 자료를 입력하거나 편집합니다.
  4. [Enter]건이나 [Tab]건을 누릅니다.

참고: 여러 표용지선택을 취소하려면 선택되지 않은 임의의 표용지를 찰칵합니다.

렬에 반복되는 내용을 자동적으로 입력

세포에 입력하는 글자중 처음 몇자가 해당 렬의 기존내용과 일치하면 나머지글자가 자동적으로 채워집니다. 이 경우 본문 또는 본문/수자 조합이 들어있는 내용들만 자동적으로 채워집니다. 수자나 날자, 시간만 들어있는 항목들은 자동적으로 채워지지 않습니다.

  • 자동적으로 채워진 내용을 그대로 사용하려면 [Enter]건을 누릅니다. 자동적으로 채워진 내용은 기존내용과 대소문자까지 정확히 일치합니다.
  • 자동적으로 입력된 문자들을 사용하지 않으려면 그대로 입력을 계속합니다.
  • 자동적으로 입력된 문자들을 삭제하려면 [Backspace]건을 누릅니다.
  • 렬에 이미 있는 항목들을 목록에서 선택하려면 세포를 마우스의 오른쪽단추로 눌러 나오는 상황차림표에서 <선택목록>을 누릅니다.

수자, 날자 또는 다른 항목의 련속자료채우기

  1. 채우려는 범위에서 첫번째 세포를 선택합니다.
  2. 련속자료의 시작값을 입력합니다.
  3. 다음세포에 값을 입력하여 채움방식을 만듭니다.
  4. 시작값이 들어있는 세포와 채움방식을 만들기 위하여 입력한 다른 세포를 선택합니다.
  5. 채울 범위까지 채우기손잡이를 끕니다.

    올리순서로 채우려면 아래 또는 오른쪽으로 끕니다.

    내리순서로 채우려면 우로 또는 왼쪽으로 끕니다.

다른 여러개의 표용지에 같은 자료의 입력

한 표용지에 자료를 이미 입력했으면 그 자료를 다른 표용지의 해당 세포에 신속하게 복사할수 있습니다.

  1. 자료가 들어있는 표용지와 그 자료를 복사할 용지들을 선택합니다.
  2. 복사할 자료가 들어있는 세포를 선택합니다.
  3. <편집>차림표에서 <련속자료 채우기>를 찰칵하고 <표용지>를 찰칵합니다.
  4. <표용지 채우기>대화창에서 해당한 항목들을 선택합니다.

자료의 자동채우기

선택한 세포범위에 자료의 자동채우기를 진행합니다.

  1. 자동채우기를 하려는 표용지의 세포범위를 선택합니다.
  2. <편집>차림표에서 <련속자료 채우기>를 찰칵하여 부분차림표를 펼칩니다.

  3. 다음의 방법들중에서 하나를 실행합니다.

    • 선택된 세포범위를 세포범위의 웃쪽행의 값으로 자동채우기를 하려면 <아래쪽>을 찰칵합니다.
    • 선택된 세포범위를 세포범위의 아래쪽행의 값으로 자동채우기를 하려면 <웃쪽>을 찰칵합니다.
    • 선택된 세포범위를 세포범위의 왼쪽렬의 값으로 자동채우기를 하려면 <오른쪽>을 찰칵합니다.
    • 선택된 세포범위를 세포범위의 오른쪽렬의 값으로 자동채우기를 하려면 <왼쪽>을 찰칵합니다.
