철자법 검사

모두 표시

철자를 검사할 때에는 세포값에 대해 철자법이 검사됩니다. 철자를 검사할 때 선택한 범위가 있으면 그 범위만 검사됩니다.

  1. 검사할 세포범위를 선택합니다.

    2. 전체 표용지를 검사하려면 <모두선택>단추를 찰칵합니다.

  2. <표준>도구띠에서 <철자법 검사>를 찰칵합니다.
  3. 철자법 검사기가 사전에 없는 단어를 찾으면 <철자법 검사>대화창의 <사전에 없음>목록칸에서 해당 단어를 찾아 변경하십시오.
  4. 다른 언어로 된 본문의 철자법을 검사하려면 <본문언어>복합칸에서 사용하려는 사전언어를 선택합니다.

    구체적인 설정을 하려면 <추가선택>단추를 찰칵합니다. <추가선택>목록칸에 있는 확인칸들을 리용하여 철자법 검사에 대한 설정을 할수 있습니다.

참고: 상세한 내용에 대해서는 문서처리프로그람의 철자법 검사를 참고하십시오.
