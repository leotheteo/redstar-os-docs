값채우기

선형추세에 대한 값채우기

선형련속자료에서는 증분값 즉 련속자료의 첫째값과 다음값의 차가 시작값에 더해진 다음 계속되는 값에도 각각 더해집니다.

초기 선택 확장된 선형련속자료
1, 2 3, 4, 5
1, 3 5, 7, 9
100, 95 90, 85

지수곡선에 대한 값채우기

지수련속자료에서는 시작값을 증분값과 곱하여 련속자료의 다음값을 구합니다. 계속되는 각각의 적이 증분값과 곱해집니다.

초기 선택 확장급수 련속자료
1, 2 4, 8, 16
1, 3 9, 27, 81
2, 3 4.5, 6.75, 10.125

<련속자료 채우기>지령을 사용하여 값을 채울수 있습니다.

  • 선형련속자료에서는 시작값이 최소두제곱알고리듬(y=mx+b)에 적용되여 련속자료가 만들어집니다.
  • 지수련속자료에서는 시작값이 지수곡선알고리듬(y=b*m^x)에 적용되여 련속자료가 만들어집니다.

이 경우 모두 증분값이 무시됩니다. 만들어진 련속자료는 TREND함수나 GROWTH함수로 구하는 값과 같습니다.

함수로 값 예측

FORECAST함수의 사용

FORECAST함수는 이미 알려진 자료나 x배렬과 y배렬범위에서 최소두제곱선형회귀를 기준으로 새로운 값을 예측합니다. 례를 들면 이전 5년동안 매해 생산량을 기초로 FORECAST함수는 다음2년동안의 기대되는 생산량을 계산합니다.

TREND 또는 GROWTH함수의 사용

TREND함수와 GROWTH함수는 기존자료를 가장 잘 설명하는 지수곡선이나 직선을 확장하여 미래의 y 값을 계산할수 있습니다. 최적직선이나 곡선에 대해 이미 알려진 x 값을 기준으로 y 값만을 계산할수도 있습니다. 기존자료를 설명하는 직선이나 곡선을 그리려면 TREND또는 GROWTH함수에 의해 계산된 기존 x 값이나 y 값을 사용하십시오.

LINEST 또는 LOGEST함수의 사용

LINEST 또는 LOGEST함수를 사용하여 기존자료에서 직선이나 지수곡선을 계산할수 있습니다.

LINEST함수와 LOGEST함수는 다양한 회귀통계를 진행합니다.
