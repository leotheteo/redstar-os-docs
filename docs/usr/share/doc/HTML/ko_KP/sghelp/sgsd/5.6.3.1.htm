조건부서식

모두 표시

  1. 조건부서식을 추가, 변경 또는 제거할 세포를 선택합니다.
  2. <서식>차림표에서 <조건부 서식설정>을 찰칵합니다.
  3. 다음의 방법들중에서 하나를 실행합니다.

    4. 조건부서식의 추가

    1. 다음의 방법들중 하나를 실행합니다.
      • 선택한 세포의 값을 서식조건으로 사용하려면 <세포값은>을 선택하고 비교구문을 선택한 다음 본문칸에 상수값 또는 수식을 입력하거나 세포참조를 마우스를 리용하여 선택할수 있습니다. 수식을 입력하는 경우에는 반드시 수식앞에 같기부호(=)를 입력합니다.
      • 수식을 서식조건으로 사용하여 선택한 세포값 외의 자료나 조건을 평가하려면 <수식은>을 선택하고 참 또는 거짓 론리값으로 평가되는 수식을 입력합니다.
    2. <세포격식>복합칸에서 세포값이 조건에 맞거나 수식이 참인 값을 반환할 때 적용할 격식을 선택합니다.
    3. <조건:>1단계부터 3단계까지 반복합니다.

      4. 조건을 세개까지 지정할수 있습니다. 지정한 조건가운데 참인 것이 없으면 세포에는 기존서식이 유지됩니다.

    참고: 여러 조건 사용 - 지정한 조건가운데 두개이상이 참인 경우에는 첫번째로 참인 조건의 서식만 적용됩니다.

    조건부서식의 변경 또는 제거

    다음의 방법들중에서 하나를 실행합니다.

    • 서식을 변경하려면 <서식>차림표에서 <조건부 서식설정>을 찰칵합니다.
    • 조건부서식을 변경하려면 <조건부 서식설정>대화창에서 해당한 변경을 진행합니다.
    • 조건부서식을 제거하려면 <조건부 서식설정>대화창에서 해당한 조건의 확인칸의 선택을 취소합니다.

    즉시도움말

    선택한 세포에 적용된 세포서식과 조건부서식을 모두 삭제하려면 <편집>차림표에서 <내용 삭제>를 찰칵하고 <서식>확인칸을 선택합니다.
