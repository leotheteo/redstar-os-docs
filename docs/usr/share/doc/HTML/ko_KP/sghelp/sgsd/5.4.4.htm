자료의 탐색 및 치환

모두 표시

  1. 찾을 세포범위를 선택합니다.

    전체 표용지를 찾으려면 <모두선택>단추를 찰칵합니다.

  2. <편집>차림표에서 <탐색 및 치환>을 찰칵합니다.
  3. 찾을 자료를 <탐색대상>복합칸에 입력하거나 <탐색대상>복합칸에서 최근에 탐색한 내용을 선택합니다. 자료를 치환하려면 <치환대상>복합칸에 치환할 자료를 입력합니다.
  4. 탐색조건을 더 자세히 지정하려면 <상세히>단추를 찰칵합니다.
  5. <탐색> 또는 <모두 탐색>단추를 찰칵합니다.
  6. 찾은 내용이 표시될 때마다 치환하거나 모두 한번에 치환하려면 <치환> 또는 <모두 치환>단추를 찰칵합니다.
