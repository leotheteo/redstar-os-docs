DEC2BIN

모두 표시

참고항목  추가함수목록, BIN2DEC, HEX2DEC, OCT2DEZ

10진수를 2진수로 변환합니다.

문법:   DEC2BIN(10진수,자리수)

인수명 설명
10진수 변환할 10진수 옹근수입니다. 10진수가 부수이면 자리수가 무시되며 최상위비트는 부호비트이고 나머지 9비트는 값을 나타내는 비트인 10자리(10 비트)의 2진수가 반환됩니다. 부수는 2의 보수표기법으로 표시됩니다.
자리수 2진수의 자리수입니다. 추가선택인수입니다. 자리수를 생략하면 최소한의 자리수가 사용됩니다. 자리수는 반환값의 앞에 0을 넣어 자리수를 맞출 때 유용합니다.

주의

  • 10진수 < -512 또는 10진수 > 511이면 오유:[오유번호]가 반환됩니다.
  • 10진수가 수자가 아니면 #NAME?오유가 반환됩니다.
  • 자리수가 옹근수가 아니면 소수점이하는 무시됩니다.
  • 자리수가 수자가 아니면 #NAME?오유가 반환됩니다.
  • 자리수가 부수이면 오유:[오유번호]가 반환됩니다.
