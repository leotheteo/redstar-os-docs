련결의 원본변경

모두 표시

해당 원본을 사용하는 모든 련결에 대한 원본문서를 변경

  1. 련결이 들어있는 자료표문서를 엽니다.
  2. <편집>차림표에서 <련결>을 찰칵합니다.
  3. 목록칸에서 원본을 변경할 련결의 이름을 찰칵합니다.
  4. <수정>단추를 찰칵합니다.
  5. 그림을 련결로 삽입한 경우에는 <그림 련결>대화창이 현시되며 파일을 련결로 삽입한 경우에는 <삽입>대화창이 현시됩니다.
  6. 대화창에서 참조할 원본파일의 경로를 변경합니다.

같은 원본을 사용하는 다른 련결에 영향을 주지 않고 련결의 원본을 변경

  1. 련결이 있는 세포를 선택합니다.
  2. 수식띠 에서 례를 들어 =DDE("sgoffice","/root/Desktop/Sogwang.ods","표용지1.C4")와 같은 다른 자료표문서에 대한 참조를 찾아서 새로운 자료표문서의 이름으로 변경합니다.
