사용자가 지정한 목록으로 자료입력

모두 표시

표용지의 다른 세포에서 선택내용을 가져오는 튀여나오기차림표를 만들수 있습니다.

  1. 튀여나오기차림표에 현시할 항목을 단일렬이나 행에 입력합니다. 빈 세포는 목록에 포함시키지 마십시오.

    자료입력행과는 다른 표용지에 목록을 입력하는 경우에는 목록에 대해 이름을 정의합니다.

    방법

    1. 이름을 지정하려는 세포, 세포범위를 선택합니다.

      수식띠 의 왼쪽끝에 있는 <이름칸>을 찰칵합니다.

      이름칸

    2. 세포 또는 세포범위의 이름을 입력합니다.
    3. [Enter]건을 누릅니다.
  2. 자료를 입력하려는 세포범위를 선택하고 <자료>차림표에서 <유효성>을 찰칵하고 <기준>표쪽을 찰칵합니다.
  3. <허용>복합칸에서 <세포범위>를 찰칵합니다.
    • 목록이 동일한 표용지에 있으면 목록에 대한 참조를 <원본>본문칸에 입력합니다.
    • 목록이 다른 곳에 있으면 목록에 대해 정의한 이름을 <원본>본문칸에 입력합니다.

    참조나 이름 앞에 반드시 같기부호(=)가 와야 합니다.

  4. <선택목록 현시>확인칸이 선택되였는가를 확인합니다.
  5. 세포를 비워둘수 있는가를 지정합니다. 즉 <빈 세포 허용>확인칸을 선택하거나 취소합니다.
  6. 세포를 찰칵했을 때 입력설명이 표시되게 하려면 <입력도움말>표쪽을 찰칵하고 <세포선택시 입력도움말 현시>확인칸을 선택했는가를 확인한 다음 제목과 본문을 입력합니다.
  7. 무효한 자료를 입력했을 때 표처리프로그람에서 어떻게 반응하겠는가 하는것을 지정합니다.

    방법

    1. <오유통보문>표쪽을 찰칵하고 <무효한 값을 입력할 때 오유통보문 현시>확인칸을 선택했는가를 확인합니다.
    2. <동작>복합칸에 대해 다음의 방법들중에서 하나를 실행합니다.
      • 무효한 자료입력을 방해하지 않고 정보통보문만 표시하려면 <정보>를 찰칵합니다.
      • 무효한 자료입력을 방해하지 않고 경고통보문만 표시하려면 <경고>를 찰칵합니다.
      • 무효한 자료를 입력하지 못하게 하려면 <중지>를 찰칵합니다.
    3. 오유통보문의 제목과 본문을 입력합니다.
  8. <확인>단추를 찰칵합니다.
