자료

모두 표시

지령명 설명
범위 정위 표용지에서 선택한 세포에 기초하여 자료기지범위를 지정합니다.
자료범위 선택 <자료>/<범위 정의>에서 지정한 자료기지범위를 선택합니다.
정렬 지정한 조건에 따라 선택한 행을 정렬합니다.
려과기 자료를 려과할수 있는 각종 려과기들을 포함하고있습니다.
부분합 선택한 렬에 대한 부분합을 계산합니다.
유효성 선택한 세포 또는 세포범위에 대해 유효한 자료를 지정합니다.
다중연산 인수값이 다른 동일한 수식을 다른 세포에 적용합니다.
본문을 렬로 선택한 세포의 내용을 다중세포로 확장하기 위한 설정을 진행합니다.
통합 하나이상의 독립적인 세포범위에서 자료를 결합하고 지정된 함수를 사용하여 새 범위를 계산합니다.
그룹 및 륜곽 자료범위를 그룹화할수 있습니다.
집계기준표 많은 량의 자료에 대한 륜곽을 제공합니다.
범위 갱신 외부자료기지에서 삽입된 자료범위를 갱신합니다.

려과기

지령명 설명
자동려과기 선택한 세포범위를 자동적으로 려과하고 표시할 항목을 선택할수 있는 단일행의 목록칸을 만듭니다.
표준려과기 표의 자료를 려과할 론리적조건을 지정합니다.
고급려과기 최대 8개의 다른 려과기기준을 결합할수 있는 려과기를 지정합니다.
려과기 제거 선택한 세포범위에서 려과기를 제거합니다.
자동려과기 숨기기 선택한 세포범위에서 자동려과기단추를 숨깁니다.

그룹 및 륜곽

지령명 설명 지름건
세부사항 숨기기 유표를 포함하는 그룹화된 행 또는 렬의 세부사항을 보여줍니다. 그룹화된 모든 행이나 렬을 보려면 계층이 설정된 표를 선택한 다음 이 지령을 선택합니다.  
세부사항 보이기 유표를 포함하는 그룹화된 행 또는 렬의 상세정보를 숨깁니다. 그룹화된 모든 행 또는 렬의 세부사항을 표시하려면 계층이 설정된 표를 선택한 다음 이 지령을 선택합니다.  
그룹 선택한 세포범위를 행 또는 렬그룹으로 지정합니다. F12
그룹 해제 선택령역의 그룹을 해제합니다. 중첩된 그룹의 경우 추가된 마지막행이나 렬이 그룹에서 제거됩니다. Ctrl+Shift+F12
자동륜곽 선택한 세포범위에 수식이나 참조가 포함되여있으면 《서광사무처리》 3.0은 선택령역의 계층을 자동적으로 설정합니다.  
제거 선택한 세포범위에서 계층을 제거합니다.  

집계기준표

지령명 설명
만들기 자료에 대한 륜곽을 진행합니다.
갱신 자료안내표를 갱신합니다.
삭제 선택한 자료안내표를 삭제합니다.
