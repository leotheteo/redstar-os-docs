련결된 객체나 포함된 객체의 편집

모두 표시

련결된 객체의 련결을 해제하여 포함된 객체로 만들수 있고 련결된 객체의 내용을 변경할수도 있습니다.

다음의 방법들중에서 하나를 실행합니다.

련결된 객체의 련결을 차단

  1. <편집>차림표에서 <련결>을 찰칵합니다.
  2. <련결 편집>대화창의 목록칸에서 련결을 중지할 객체를 선택합니다.
  3. <련결 차단>단추를 찰칵합니다. 련결을 제거하겠는가를 묻는 통보문에서 <예>단추를 찰칵하여 객체의 련결을 차단합니다. 련결을 차단한 객체는 포함된 객체로 됩니다.

련결된 객체의 모양을 변경

  1. 련결된 객체를 두번 찰칵합니다.
  2. 객체편집상태로 절환하면 객체를 요구하는대로 바꿉니다.

원본프로그람에서 포함된 객체의 편집

  1. 포함된 객체를 두번 찰칵하여 엽니다.
  2. 객체를 변경합니다.
  3. 다음의 방법들중에서 하나를 실행하여 표처리프로그람으로 돌아갑니다.
    • 표처리프로그람에서 객체를 편집하는 경우에는 객체 바깥쪽을 찰칵하여 대상파일로 돌아갑니다.
    • 별도의 창으로 연 원본프로그람에서 객체를 편집하는 경우에는 원본프로그람의 <파일>차림표에서 <닫기>를 찰칵하여 대상파일로 돌아갑니다.
