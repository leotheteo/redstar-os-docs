사용자정의 수자서식의 만들기 또는 삭제

모두 표시

사용자정의 수자서식의 만들기

  1. <서식>차림표에서 <세포>를 찰칵한 다음 <수자>표쪽을 찰칵합니다.
  2. <종류>목록칸에서 알맞는 종류를 찰칵한 다음 요구하는 서식과 류사한 기정서식을 선택합니다. 기정으로 제공된 서식은 변경되지 않으며 복사본이 만들어져서 사용자정의하게 됩니다.
  3. <서식코드>본문칸에서 해당한 서식을 만들 수자서식코드를 편집합니다.

    서식코드부분은 최대 네개까지 지정할수 있습니다. 반두점으로 구분된 부분은 정수, 부수, 0 및 본문순서로 서식을 정의합니다. 두부분만 지정하는 경우 첫번째 부분은 정수와 0에 사용되고 두번째 부분은 부수에 사용됩니다. 한 부분만 지정하는 경우 해당 서식이 모든 수자에 사용됩니다. 특정부분을 건너뛰려면 해당 부분에 반두점을 사용하십시오.

    수자, 날자나 시간, 통화, 백분률 또는 지수표기, 본문이나 간격의 표시방식을 설명하는 서식 코드를 사용하십시오. 구체적인것은 수자서식코드를 참고하십시오.

  4. <추가>를 찰칵합니다.

사용자정의 수자서식의 삭제

  1. <서식>차림표에서 <세포>를 찰칵한 다음 <수자>표쪽을 찰칵합니다.
  2. <종류>목록칸에서 <사용자정의>를 찰칵합니다.
  3. 삭제할 사용자정의서식을 찰칵합니다.
  4. <제거>를 찰칵합니다.
