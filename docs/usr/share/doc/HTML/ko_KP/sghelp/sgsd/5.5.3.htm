려과

모두 표시

려과는 범위에서 자료의 부분집합을 찾거나 작업할 때 사용할수 있는 빠르고 간편한 방법입니다.

려과한 범위에는 사용자가 렬에 대해 지정한 조건에 맞는 행만 표시됩니다.

정렬과 달리 려과를 사용하면 범위가 다시 배렬되지 않으며 표시할 필요가 없는 행을 잠시 숨깁니다.

자동려과기

<자동려과기>지령을 사용하면 자동려과화살표 가 려과된 목록의 렬표식자 오른쪽에 나타납니다.

려과되지 않은 범위

려과된 범위

표준려과기

지정된 추가선택을 사용하여 자료를 려과합니다.

고급려과기

<고급려과기>지령을 사용하면 <자동려과기>지령과 마찬가지로 범위를 려과할수 있지만 렬의 튀여나오기차림표가 표시되지 않습니다. 대신에 요구하는 려과조건을 범위우에 별도의 조건범위로 입력합니다. 조건범위를 사용하면 더 복잡한 조건으로 려과할수 있습니다.
