세포의 모든 값의 표시/숨기기

모두 표시

  1. 숨겨진 값이나 숨길 값이 들어있는 세포를 선택합니다.
  2. <서식>차림표에서 <세포>를 찰칵하고 <수자>표쪽을 찰칵합니다.
  3. 다음의 방법들중에서 하나를 실행합니다.

    4. 세포의 숨겨진 값의 표시

    <종류>목록에서 <모두>를 찰칵하여 <일반>서식을 적용합니다.

    특정수자서식으로 된 날자, 시간 또는 값을 다시 표시하려면 <수자>표쪽에서 해당 날자, 시간 또는 수자서식을 선택합니다.

    세포의 모든 값의 숨기기

    • <종류>목록칸에서 <사용자정의>를 찰칵합니다.
    • <서식코드>본문칸에서 기존코드를 선택하고 [Delete]건을 누릅니다.
    • ;;;(반두점 3개)를 입력합니다.
