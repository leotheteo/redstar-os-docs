값을 예측하는 방법

모두 표시

복잡한 비선형자료를 확장하기 위하여서는 함수를 사용할수 있습니다.

련속자료 채우기지령으로 선형 및 지수추세의 만들기

  1. 련속자료 채우기를 시작할 세포범위를 선택합니다.

    2. <련속자료 채우기>지령을 사용하면 원래 선택한 값이 련속자료로 바뀝니다. 원래값을 보관하려면 다른 행이나 렬로 복사하고 복사된 값을 선택하여 련속자료를 만듭니다.

  2. <편집>차림표에서 <련속자료 채우기>를 찰칵하고 <련속자료 채우기>를 찰칵합니다.
  3. 다음의 방법들중에서 하나를 실행합니다.
    • 페지에 련속자료 채우기를 아래로 채우려면 <아래쪽>, 우로 채우려면 <웃쪽>단일선택단추를 찰칵합니다.
    • 페지에 련속자료 채우기를 오른쪽으로 채우려면 <오른쪽>, 왼쪽으로 채우려면 <왼쪽>단일선택단추를 찰칵합니다.
  4. <련속자료류형>부분에서 <산수> 또는 <기하급수>단일선택단추를 찰칵합니다.
    5. 련속자료류형 증분 값 결과
    산수 증분값이 처음 시작값에 더해진 다음 계속되는 값에도 각각 더해집니다.
    기하급수 처음 시작값에 증분값이 곱해집니다. 계속되는 각각의 적이 증분값과 곱해집니다.
  5. <증분>본문칸에 련속자료 채우기의 증분값을 입력합니다.
  6. <마감값>본문칸에 련속자료 채우기가 끝나는 값을 입력합니다.

함수로 값예측

값을 예측할 때 사용할수 있는 함수는 다음과 같습니다.

함수 설명
FORECAST 값을 예측하는 방법
TREND 회귀선을 따라 위치한 점을 계산합니다.
GROWTH 지수회귀함수의 점을 계산합니다.
LINEST 선형회귀의 파라메터를 배렬형태로 계산합니다.
LOGEST 지수회귀곡선의 파라메터를 배렬형태로 계산합니다.
