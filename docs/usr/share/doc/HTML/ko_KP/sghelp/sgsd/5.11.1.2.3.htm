3D 도표보기의 변경

모두 표시

3D 도표의 3D 효과를 변경

  1. 변경하려는 3D 도표를 두번 찰칵합니다.
  2. <서식>차림표에서 <3D 보기>를 찰칵합니다.
  3. <3D 보기>대화창에서 요구하는 3D 효과를 선택합니다.
  4. 효과를 도표에 적용하기 위하여 <확인>단추를 찰칵합니다.

3D 도표의 3D 보기를 변경

  • 차림표사용
    1. 변경하려는 3D 도표를 두번 찰칵합니다.
    2. <서식>차림표에서 <3D 보기>를 찰칵합니다.
    3. X, Y, Z축의 각도를 요구하는 값으로 변경합니다.
    4. <확인>단추를 찰칵합니다.
  • 마우스사용
    1. 3D 도표를 두번 찰칵합니다.
    2. <도표옆면>을 찰칵하여 <도표옆면>테두리에 8개의 빨간색꼭지가 표시되도록 합니다.

      3. 참고: 풀색꼭지(크기조종꼭지)가 표시되였을 때에는 같은 구역을 한번 더 찰칵합니다.

      3D 보기 조종꼭지

    3. 요구하는 방향의 조종꼭지를 끌기하여 도표의 3D 보기를 변경합니다.

큰 3D 자료점이 작은 자료점을 가리우지 않도록 자료계렬의 계렬순서를 변경

  1. 도표에서 변경하려는 자료계렬을 선택합니다. 도표의 각종 요소의 선택을 참고하십시오.
  2. <서식>차림표에서 <배렬>을 찰칵하고 <앞면에로 이동>이나 <뒤면에로 이동>을 찰칵합니다.

3D 기둥의 양식을 변경

  1. 3D 도표를 두번 찰칵합니다.
  2. 3D 기둥의 양식을 변경하려는 자료계렬을 선택한 다음 마우스의 오른쪽단추를 찰칵하여 나오는 상황차림표에서 <도표류형>을 찰칵합니다.
  3. <도표류형>대화창의 류형목록칸에서 <기둥도표>를 선택하고 <도형>목록칸의 <칸>, <원기둥>, <원추>, <각추>중에서 하나를 지정할수 있습니다.
  4. <확인>단추를 찰칵합니다. 3D 도표의 해당한 자료계렬기둥이 선택한 양식으로 변경된것을 볼수 있습니다.

참고: 막대형의 3D 도표에서만 3D 기둥의 양식을 변경할수 있습니다.
