모두 표시

지령명 설명 지름건
실행 취소 마지막지령의 실행을 취소합니다. 실행 취소할 지령을 선택하려면 <표준>도구띠에서 <실행 취소>그림기호옆의 화살표를 찰칵합니다. Ctrl+Z
다시 실행 취소하였던 지령을 다시 실행합니다. 다시 실행하려는 단계를 선택하려면 <표준>도구띠에서 <다시 실행>그림기호옆에 있는 화살표를 찰칵합니다. Ctrl+Y
반복 마지막작업실행을 반복하여 실행합니다. Ctrl+Shift+Y
자르기 선택한 내용을 잘라내여 오림판에 복사합니다. Ctrl+X
복사 선택한 내용을 오림판에 복사합니다. Ctrl+C
붙이기 현재유표위치에 오림판내용을 삽입합니다. 선택된 본문이나 객체는 모두 오림판의 내용으로 바뀝니다. 서식을 선택하려면 <표준>도구띠에서 <붙이기>그림기호옆의 화살표를 찰칵합니다. Ctrl+V
형식을 선택하여 붙이기 오림판의 내용을 지정한 서식으로 현재파일에 삽입합니다. Ctrl+Shift+V
모두선택 현재문서의 전체 내용을 선택합니다. Ctrl+A
변경 파일의 변경을 추적하는데 사용할수 있는 지령을 라렬합니다  
탐색 및 치환 현재문서에서 본문 또는 서식을 탐색하거나 치환합니다. Ctrl+Shift+H
항행기 문서의 다른 부분으로 빨리 이동할수 있는 항행기를 보이거나 숨깁니다. F5
머리부 및 바닥부 머리부 및 바닥부를 정의 및 서식지정할수 있습니다.  
련속자료 채우기 세포내용을 자동적으로 채웁니다.  
내용 삭제 활성화된 세포나 선택한 세포범위에서 삭제할 내용을 지정합니다. BackSpace
세포 삭제 선택한 세포, 렬 또는 행을 삭제합니다. 삭제한 세포의 아래쪽 또는 오른쪽에 있는 세포가 공백을 채웁니다. Ctrl+-
표용지 전체 표용지에 대한 지령을 편집합니다.  
페지가르기 삭제 제거할 가르기의 류형을 선택합니다.  
련결 원본파일의 경로를 포함하여 현재문서에 있는 모든 련결의 속성을 편집할수 있습니다. 현재문서에 다른 파일에 대한 련결이 없으면 이 지령을 사용할수 없습니다.  
화상 그림을 수정하거나 그림의 하이퍼련결부에 URL을 첨부할수 있습니다. 여기서 그림은 하나이상의 하이퍼련결부로 구성된 묶음입니다.  
객체 삽입된 OLE 객체를 편집하거나 이름을 달아 보관할수 있습니다.  

변경

지령명 설명
기록 현재문서의 모든 변경을 작성자 및 날자별로 추적합니다.
기록 보호 기록보호는 사용자가 기록변경기능을 비활성상태로 만들거나 암호를 입력하지 않고 변경을 수락하거나 거부할수 없게 합니다.
현시 기록된 변경을 보이거나 숨깁니다.
수락 또는 거부 기록된 변경을 수락하거나 거부합니다.
설명 기록된 변경에 대한 설명을 입력합니다.
문서 합치기 기록된 변경을 합치기 위한 <삽입>대화창을 엽니다.

련속자료 채우기

지령명 설명
아래쪽 최소한 두개이상의 행이 선택될 때 선택한 범위의 제일 웃쪽세포의 내용으로 채웁니다.
오른쪽 최소한 두개이상의 렬이 선택될 때 선택한 범위의 제일 왼쪽세포의 내용으로 채웁니다.
웃쪽 최소한 두개이상의 행이 선택될 때 선택한 범위의 제일 아래쪽세포의 내용으로 채웁니다.
왼쪽 최소한 두개이상의 렬이 선택될 때 선택한 범위의 제일 오른쪽세포의 내용으로 채웁니다.
표용지 자료표나 특정한 자료표의 범위를 전송하기 위한 추가선택을 지정합니다.
련속자표 채우기 련속자료를 자동적으로 생성합니다. 방향, 증분, 시간단위 및 련속자료류형을 결정합니다.

표용지

지령명 설명
이동/복사 표용지를 문서의 새 위치나 다른 문서로 이동 또는 복사합니다.
선택 여러개의 표용지를 선택합니다.
삭제 질문을 확인한 후 현재표용지를 삭제합니다.

페지가르기 삭제

지령명 설명
행 가르기 활성상태로 만든 세포우의 행가르기를 삭제합니다.
렬가르기 활성상태로 만든 세포왼쪽의 렬가르기를 삭제합니다.
