WEEKNUM_ADD

모두 표시

참고항목  날자 및 시간함수목록, DAYS360, WEEKDAY

지정된 날자가 1년중 몇번째 주에 해당하는가를 구합니다.

문법:   WEEKNUM_ADD(날자,반환류형)

인수명 설명
날자 해당 주에 속하는 날자입니다.
반환류형 주의 시작요일을 결정합니다. 기본값은 1입니다. 반환류형 = 1(기본값)에서는 요일이 일요일부터 계산되고 반환류형 = 2에서는 요일이 월요일=1부터 계산되며 반환류형 = 3에서는 월요일=0부터 계산됩니다.

주의

  • 국제표준 ISO 8601은 월요일을 주의 첫날로 규정하였습니다. 두해에 걸쳐 포함되는 주에는 해당되는 날자수가 더 많은 년도의 번호가 할당됩니다. 즉 모든 년도의 주번호1은 1월 4일이 포함된 주입니다.
  • WEEKNUM_ADD함수는 Microsoft Excel과 꼭같은 반환류형으로 요일번호를 계산합니다. ISO 8601요일번호가 필요한 경우 WEEKNUM함수를 사용하거나 날자세포의 서식을 설정합니다.

수식 설명(결과)

=WEEKNUM_ADD(A2,2) 주의 시작요일이 월요일인 경우의 1년중 해당 주의 번호입니다. (10)
