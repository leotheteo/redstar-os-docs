기둥도표와 막대도표에서 자료점들사이의 간격변경

모두 표시

  1. 변경하려는 도표를 두번 찰칵합니다.
  2. 임의의 자료계렬을 찰칵합니다.
  3. <서식>차림표에서 <선택요소의 서식>을 찰칵합니다.
  4. <자료계렬>대화창에서 <추가선택>표쪽을 찰칵합니다.
  5. <설정>부분에서 <간격>과 <겹침>의 본문칸들에 요구하는 값을 입력합니다. 자료점들사이의 겹치기를 변경하려면 <겹침>본문칸에 -100과 100사이의 값을 입력합니다. 값이 클수록 자료점들사이의 겹치기가 커집니다. 자료점들사이의 간격을 변경하려면 <간격>증감단추에 0 ~ 600 범위의 값을 입력합니다. 값이 클수록 자료점들사이의 간격이 커집니다.
