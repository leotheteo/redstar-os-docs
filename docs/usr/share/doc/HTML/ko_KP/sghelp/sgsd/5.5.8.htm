범위정렬

모두 표시

올리순서(ㄱ부터 ㅇ, A부터 Z, 0부터 9) 또는 내리순서 (ㅇ부터 ㄱ, Z부터 A까지, 9부터 0)로 행 정렬

  1. 정렬기준으로 사용하려는 렬의 세포를 선택합니다.
  2. <올리순서로 정렬> 또는 <내리순서로 정렬>을 찰칵합니다.

두개 또는 세개의 렬을 기준으로 행정렬

  1. 정렬할 자료범위를 선택합니다.
  2. <자료>차림표에서 <정렬>을 찰칵합니다.
  3. <첫째 기준>복합칸과 <둘째 기준>복합칸에서 정렬할 렬을 찰칵합니다.
  4. 정렬방식을 선택하고 <확인>단추를 찰칵합니다.

네개의 렬을 기준으로 정렬

  1. 정렬할 자료범위를 선택합니다.
  2. <자료>차림표에서 <정렬>을 찰칵합니다.
  3. <첫째 기준>복합칸에서 중요하지 않은 렬을 찰칵합니다.
  4. <확인>단추를 찰칵합니다.
  5. <자료>차림표에서 <정렬>을 찰칵합니다.
  6. 가장 중요한 렬부터 시작하여 <첫째 기준>, <둘째 기준>, <셋째 기준>복합칸에서 정렬하려는 나머지 세 렬을 선택합니다.
  7. 해당한 정렬항목들을 선택하고 <확인>단추를 찰칵합니다.

요일을 기준으로 행정렬

  1. 정렬할 세포나 범위를 선택합니다.
  2. <자료>차림표에서 <정렬>을 찰칵합니다.
  3. <첫째 기준>복합칸에서 정렬할 렬을 선택합니다.
  4. <추가선택>표쪽을 찰칵합니다.
  5. <사용자전용 정렬순서>확인칸을 선택하고 복합칸에서 요일을 의미하는 정렬순서를 선택하고 <확인>단추를 찰칵합니다.

정렬순서로 사용자정의자료를 사용

  1. 세포범위에 정렬할 기준값을 해당한 순서대로 우에서 아래로 입력하고 선택합니다. 례를 들면 다음과 같습니다.
    2. 높음
    중간
    낮음
  2. 범위를 선택합니다.
  3. <서광사무처리>차림표에서 <환경설정>을 찰칵하고 <서광사무처리 표처리프로그람>의 <정렬목록>을 찰칵합니다.
  4. <복사>단추를 찰칵하고 <확인>단추를 찰칵합니다.
  5. 정렬할 자료범위를 선택합니다.
  6. <자료>차림표에서 <정렬>을 찰칵합니다.
  7. <첫째 기준>복합칸에서 정렬할 렬을 찰칵합니다.
  8. <추가선택>표쪽을 찰칵합니다.
  9. <사용자전용 정렬순서>확인칸을 선택하고 복합칸에서 만든 사용자정의목록(례: 높음, 중간, 낮음)을 찰칵합니다.
  10. <확인>단추를 찰칵합니다.

행을 기준으로 렬정렬

대부분의 경우 행을 정렬하지만 렬을 정렬하자면 다음과 같이 합니다.

  1. 정렬할 자료범위를 선택합니다.
  2. <자료>차림표에서 <정렬>을 찰칵합니다.
  3. <추가선택>표쪽을 찰칵합니다.
  4. <왼쪽에서 오른쪽으로(렬 정렬)>단일선택단추를 찰칵합니다.
  5. <정렬기준>표쪽을 찰칵하고 <첫째 기준>과 <둘째 기준>, <셋째 기준>복합칸에서 정렬할 행을 선택합니다.
  6. <확인>단추를 찰칵합니다.
