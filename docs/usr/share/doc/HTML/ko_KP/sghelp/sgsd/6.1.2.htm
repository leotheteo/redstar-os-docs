암호의 설정 및 해제

모두 표시

암호설정

  • 새로운 자료표문서에 암호를 설정

    • 이미 새로 작성하는 자료표문서가 표처리프로그람에 열려있어야 합니다.

    1. <파일>차림표에서 <보관>을 찰칵합니다.
    2. <암호를 사용하여 보관>확인칸을 선택합니다.
    3. <새로 보관>본문칸에 문서의 이름을 입력하고 <보관>단추를 찰칵합니다.
    4. 이때 나타나는 <암호 설정>대화창에서 암호를 입력하고 <확인>단추를 찰칵합니다.
  • 이미 있는 자료표문서에 암호를 설정
    1. 암호를 설정할 자료표문서를 엽니다.
    2. <파일>차림표에서 <다른 이름으로 보관>을 찰칵합니다.
    3. <암호를 사용하여 보관>확인칸을 선택합니다.
    4. <새로 보관>본문칸에 이 문서의 원래이름을 입력하고 <보관>단추를 찰칵합니다.
    5. 덧쓰기하겠는가고 묻는 통보문에서 <예>단추를 찰칵합니다.
    6. 이때 나타나는 <암호 설정>대화창에서 암호를 입력하고 <확인>단추를 찰칵합니다.

참고:

<암호를 사용하여 보관>확인칸이 항상 선택되여있게 하려면 다음과 같은 설정을 진행합니다.

  1. <서광사무처리>차림표에서 <환경설정>을 찰칵합니다.
  2. <환경설정>대화창에서 <서광사무처리>의 <보안>을 찰칵합니다.
  3. <보안 추가선택 및 경고>부분의 <추가선택>단추를 찰칵합니다.
  4. <보관시 암호보호 권고>확인칸을 선택하고 <확인>단추를 찰칵합니다.

암호해제

  1. 암호가 설정된 자료표문서를 엽니다.
  2. <암호 입력>대화창에서 암호를 입력합니다.
  3. <파일>차림표에서 <다른 이름으로 보관>을 찰칵합니다.
  4. <암호를 사용하여 보관>확인칸의 선택이 취소되여있는가를 확인합니다.
  5. <새로 보관>본문칸에 다른 이름을 입력하고 <보관>단추를 찰칵합니다.
