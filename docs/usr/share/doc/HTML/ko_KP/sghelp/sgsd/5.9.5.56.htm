XIRR

모두 표시

참고항목  재정함수목록, IRR, MIRR, NPV, RATE, XNPV

비정기적인 납입에 대한 내부수익률을 구합니다.

문법:   XIRR(값,날자,추정값)

인수명 설명
값 날자의 지불일정에 대응하는 일련의 현금지출입니다. 최초 상환금은 선택사항으로서 투자초기에 발생하는 비용이나 상환금에 해당됩니다. 최초 상환금이 비용이나 상환금인 경우는 부수가 되여야 합니다. 이후의 모든 상환금은 년간일수 365일을 기준으로 할인됩니다. 일련의 값들에는 정수와 부수가 최소한 하나씩 포함되여야 합니다.
날자 현금지출상의 상환금에 해당하는 지불일정입니다. 최초상환날자는 지불일정의 시작을 나타냅니다. 그외의 모든 상환날자는 이 날자후가 되여야 하지만 발생순서는 관계없습니다. 날자는 DATE함수를 사용하거나 다른 수식 또는 함수의 결과로 입력하여야 합니다. 례를 들어 2008년 5월 23일의 경우 DATE(2008,5,23)을 사용합니다.
추정값 XIRR함수의 결과값에 가깝다고 추측되는 수입니다. 추가선택인수입니다. 생략하면 10%(0.1)로 간주됩니다.

주의

  • 날자에 포함된 수자는 소수점이하를 잘라서 옹근수로 변환됩니다.
  • XIRR 함수에는 늘거나 줄어든 현금지출이 최소한 하나씩 필요합니다. 그렇지 않으면 오유:[오유번호]가 반환됩니다.
  • 날자의 수자중 무효한 날자가 있으면 오유:[오유번호]가 반환됩니다.
  • 날자에 포함된 날자가 시작날자보다 전 날자일 때에는 오유:[오유번호]가 반환됩니다.
  • 값과 날자에 있는 값의 개수가 서로 다를 때에는 오유:[오유번호]가 반환됩니다.
  • XIRR함수계산에서는 대부분 날자를 지정하지 않아도 됩니다. 생략하면 추정값은 0.1(10%)로 계산됩니다.
  • XIRR함수는 순현재가치를 계산하는 XNPV 함수와 밀접한 관계가 있습니다. XIRR로 계산하는 회수률은 XNPV = 0일 때의 리자률과 같습니다.
  • XIRR함수는 반복기법을 사용하여 계산됩니다. 계속 새로운 리자률을 사용하면서(추정값에서 시작하여) 결과의 오차가 0.000001%이내로 정확해질 때까지 반복합니다. XIRR함수가 100번 반복실행후에도 결과를 얻지 못하면 오유:[오유번호]가 반환됩니다. 다음식을 만족할 때까지 리자률이 변하게 됩니다.

    여기서

    di = i번째 또는 마지막상환날자입니다.

    d1 = 0번째 상환날자입니다.

    Pi = i번째 또는 마지막상환금입니다.
