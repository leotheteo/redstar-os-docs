표용지에서 인쇄하려는 부분의 정의

모두 표시

인쇄범위를 정의

  1. <보기>차림표에서 <페지 가르기 미리보기>를 찰칵합니다.
  2. 인쇄하려는 령역을 선택합니다.
  3. <서식>차림표에서 <인쇄범위>를 찰칵하고 <정의>를 찰칵합니다.

참고: 문서를 보관하면 인쇄범위의 선택상태도 보관됩니다.

인쇄범위를 추가

  1. <보기>차림표에서 <페지 가르기 미리보기>를 찰칵합니다.
  2. 인쇄범위에 추가하려는 세포나 세포범위를 선택합니다.
  3. <서식>차림표에서 <인쇄범위>를 찰칵하고 <추가>를 찰칵합니다.

인쇄범위를 제거

<서식>차림표에서 <인쇄범위>를 찰칵하고 <제거>를 찰칵합니다.
