세포범위의 자료통합

모두 표시

두개이상의 독립적인 세포범위자료를 선택된 함수로 계산하여 통합합니다.

세포범위의 자료를 통합하려면 다음과 같은 방법으로 진행합니다.

  1. <자료>차림표에서 <통합>을 찰칵하여 <통합>대화창을 엽니다.
  2. <원본자료범위>목록칸이나 본문칸에 통합하려는 세포범위를 선택하고 <추가>단추를 찰칵합니다. <통합범위>목록칸에 통합하려는 세포범위가 추가됩니다.
  3. <함수>목록칸에서 세포범위자료를 계산하려는 함수를 선택합니다.
  4. <결과를 복사하는 위치>목록칸이나 본문칸에서 통합한 세포범위의 결과를 복사하려는 세포범위의 첫 위치를 선택합니다.
  5. <확인>단추를 찰칵합니다.

참고: 통합하려는 세포범위에 표식자가 포함된 경우 표식자를 리용하여 통합된 자료를 배치하려면 <통합>대화창에서 <상세히>단추를 찰칵한 다음 <통합기준>령역에 있는 <행표식자>나 <렬표식자>확인칸을 선택합니다. <추가선택>령역의 <원본자료에 련결>확인칸을 선택하면 통합범위의 자료를 원본자료에 련결하며 원본자료가 변경되는 경우 통합 결과를 자동적으로 변경합니다.
