수식의 만들기

모두 표시

수식은 표용지에서 값을 계산하는 식이며 같기부호(=)로 시작합니다. 례를 들어 아래에 서술한 식은 2와 3을 곱하고 그 결과에 5를 더하는 수식입니다.

=5+2*3

간단한 수식의 만들기: =128+345

다음수식에는 연산자와 상수가 포함되여있습니다.

실례수식 작업 내용
=128+345 128 더하기 345
=5^2 5의 2제곱
  1. 수식을 입력할 세포를 찰칵합니다.
  2. 같기부호(=)를 입력합니다.
  3. 수식을 입력합니다.
  4. [Enter]건을 누릅니다.

참조 또는 이름이 포함된 수식의 만들기: =A1+23

다음의 실례수식에서는 다른 세포에 대한 상대참조와 이름을 리용하여 값을 계산합니다. 세포에 참조를 사용한 수식이 들어있는 경우 그 세포를 참조하는 세포라고 하며 수식에서 참조한 세포는 참조되는 세포라고 합니다. 례를 들어 B2세포에 수식 =C2이 들어있으면 B2세포는 참조하는 세포입니다.

실례수식 작업 내용
=C2 C2 세포의 값을 사용합니다.
=표용지2.B2 표용지2에 있는 B2 세포의 값을 사용합니다.
=계획-실적 《계획》이라는 이름의 세포값에서 《실적》이라는 이름의 세포값을 덥니다.
  1. 수식을 입력할 세포를 찰칵합니다.
  2. 수식띠에 혹은 세포에 직접 =(같기부호)를 입력합니다.
  3. 다음의 방법들중에서 하나를 실행합니다.
    • 참조를 만들려면 자료표문서내에서 필요한 세포나 세포범위 또는 다른 자료표문서의 세포나 세포범위를 선택합니다. 세포선택범위의 테두리를 끌어서 선택범위를 이동하거나 테두리의 가장자리를 끌어서 선택범위를 확장합니다.

    • 이름이 정의된 범위에 대한 참조를 리용하려면 그 범위의 이름을 입력합니다.
  4. [Enter]건을 누릅니다.

함수가 포함된 수식의 만들기: =AVERAGE(A1:B4)

아래의 실례수식에는 함수가 포함되여있습니다.

실례수식 작업내용
=SUM(A1:B4) 범위내에 있는 모든 수를 더합니다.
=AVERAGE(A1:B4) 범위내에 있는 모든 수의 평균을 구합니다.
  1. 수식을 입력할 세포를 찰칵합니다.
  2. 수식의 첫번째 인수로 함수를 사용하려면 수식띠에서 <함수자동안내처리>를 찰칵합니다.
  3. <종류>복합칸에서 함수의 종류를 선택하고 <함수>목록칸에서 사용할 함수를 선택합니다.
  4. 인수들을 입력하기 위한 본문칸들에 필요한 값들을 입력합니다. 세포참조를 인수로 입력하려면 <줄이기>를 찰칵하여 대화창을 림시로 숨깁니다. 표용지에서 세포 또는 세포범위를 선택한 다음 <늘이기>를 찰칵합니다.
  5. 수식입력이 끝나면 [Enter]건을 누릅니다.

중첩함수가 있는 수식의 만들기: =IF(AVERAGE(F2:F5)>50;SUM(G2:G5);0)

중첩함수는 인수로 다른 함수를 사용합니다. 다음의 수식에서는 세포범위(F2:F5)의 평균값이 50보다 큰 경우에만 세포범위(G2:G5)의 합을 구합니다. 작은 경우에는 0을 반환합니다.

  1. 수식을 입력할 세포를 찰칵합니다.
  2. 수식의 첫번째 인수로 함수를 사용하려면 수식띠에서 <함수자동안내처리>를 찰칵합니다.
  3. <종류>복합칸에서 함수의 종류를 선택하고 <함수>목록칸에서 사용할 함수를 선택합니다.
  4. 인수들을 입력하기 위한 본문칸들에 필요한 값들을 입력합니다. 다음의 방법들중에서 하나를 실행합니다.
    • 세포참조를 인수로 입력하려면 <줄이기>를 찰칵하여 대화창을 림시로 숨깁니다. 표용지에서 세포 또는 세포범위를 선택한 다음 <늘이기>를 찰칵합니다.
    • 다른 함수를 인수로 입력하려면 그림기호를 찰칵하여 요구하는 함수를 선택합니다.
