차림표와 차림표지령, 단추의 이름 바꾸기

모두 표시

이미 정의되여있는 차림표와 차림표지령, 도구띠의 그림기호에 할당되여있는 이름을 사용자의 요구에 맞게 바꿀수 있습니다.

다음과 같은 방법으로 진행합니다.

  1. <도구>차림표에서 <사용자전용화>를 찰칵합니다.
  2. <사용자전용화>대화창이 화면에 현시됩니다. 여기서 차림표와 차림표지령, 도구띠단추의 이름을 사용자의 요구에 맞게 변경할수 있습니다.

    3. 차림표의 이름 바꾸기

    1. <사용자전용화>대화창에서 <차림표>표쪽을 찰칵합니다.
    2. <차림표>목록칸에서 이름을 바꾸려는 차림표를 선택합니다. 체계에서 이미 정의하고있는 차림표의 이름은 바꿀수 없으므로 주의하여야 합니다.
    3. <차림표>단추를 찰칵하면 튀여나오기차림표가 현시되는데 여기서 <이름 바꾸기>를 찰칵합니다.
    4. <이름 바꾸기>대화창이 나타나면 거기에 차림표의 새 이름을 입력하고 <확인>단추를 찰칵합니다.
    5. <사용자전용화>대화창의 <확인>단추를 찰칵합니다.

    차림표지령의 이름 바꾸기

    1. <사용자전용화>대화창에서 <차림표>표쪽을 찰칵합니다.
    2. <차림표>목록칸에서 이름을 바꾸려는 차림표지령이 포함되여있는 차림표를 선택합니다. <차림표내용>부분의 <지령>목록칸에 우에서 선택한 차림표에 포함되여있는 차림표지령들이 렬거됩니다.
    3. <지령>목록칸에서 이름을 바꾸려는 지령을 선택합니다.
    4. <수정>단추를 찰칵하면 튀여나오기차림표가 현시되는데 여기서 <이름 바꾸기>를 찰칵합니다.
    5. <새 이름>본문칸에 새로운 이름을 입력합니다.
    6. <사용자전용화>대화창의 <확인>단추를 찰칵합니다.

    단추의 이름 바꾸기

    1. <사용자전용화>대화창에서 <도구띠>표쪽을 찰칵합니다.
    2. <도구띠>목록칸에서 이름을 바꾸려는 도구띠를 선택합니다. <도구띠내용>부분의 <지령>목록칸에 우에서 선택한 도구띠에 포함되여있는 그림기호항목들이 렬거됩니다.
    3. <지령>목록칸에서 이름을 바꾸려는 지령을 선택합니다.
    4. <수정>단추를 찰칵하면 튀여나오기차림표가 현시되는데 여기서 <이름 바꾸기>를 선택합니다.
    5. <새 이름>본문칸에 새로운 이름을 입력합니다.
    6. <사용자전용화>대화창의 <확인>단추를 찰칵합니다.
