주해의 서식지정

모두 표시

  1. 주해의 서식을 변경하려는 세포를 마우스의 오른쪽단추로 찰칵합니다.
  2. 상황차림표에서 <주해 현시>를 찰칵합니다.
  3. 주해본문칸의 테두리를 찰칵하여 크기조종꼭지를 표시합니다.

  4. 다음의 방법들중에서 하나이상을 실행합니다.

    5. 본문의 서체 또는 서체색의 변경

    주해를 두번 찰칵하여 편집방식으로 놓습니다.

    본문의 서체 또는 서체색변경은 본문서식의 변경을 참고하십시오.

    배경색의 변경

    1. <서식>차림표에서 <객체>를 찰칵하고 <령역>을 찰칵합니다.
    2. <령역>대화창에서 <색>표쪽을 찰칵합니다.
    3. <색>복합칸 또는 <표>목록에서 요구하는 색을 찰칵합니다.
    4. <확인>단추를 찰칵합니다.

    배경의 투명도, 계조, 문양, 평행선의 설정

    1. <서식>차림표에서 <객체>를 찰칵하고 <령역>을 찰칵합니다. 이때 <령역>대화창이 현시됩니다.
    2. 다음의 방법들중에서 하나를 실행합니다.
      • <투명도>표쪽을 찰칵하고 <투명도>단일선택단추를 선택한 다음 증감칸에 투명도값을 입력합니다.
      • 계조를 설정하려면 <계조>표쪽에서 요구하는 설정들을 진행합니다.
      • 평행선을 설정하려면 <평행선>표쪽에서 요구하는 설정들을 진행합니다.
      • 문양을 설정하려면 <문양>표쪽에서 요구하는 설정들을 진행합니다. <반입>단추를 리용하여 그림파일을 설정할수도 있습니다.
    3. <확인>단추를 찰칵합니다.

    테두리선의 격식이나 색, 두께, 투명도의 변경

    1. <서식>차림표에서 <객체>를 찰칵하고 <선>을 찰칵합니다.
    2. <선>대화창에서 <선>표쪽을 찰칵합니다.
    3. 다음의 방법들중에서 하나를 실행합니다.
      • <격식>복합칸에서 요구하는 격식을 찰칵합니다.
      • <색>복합칸에서 요구하는 색을 찰칵합니다.
      • <너비>증감칸에 테두리선의 너비를 입력합니다.
      • <투명도>증감칸에 테두리선의 투명도값을 입력합니다.
    4. <확인>단추를 찰칵합니다.

    그림자의 위치, 간격, 색, 투명도의 변경

    1. <서식>차림표에서 <객체>를 찰칵하고 <령역>을 찰칵합니다.
    2. <그림자>표쪽을 찰칵하고 <그림자 사용>확인칸을 선택합니다.
    3. 다음의 방법들중에서 하나를 실행합니다.
      • <위치>단일선택단추들을 선택하여 그림자의 위치를 변경합니다.
      • <간격>증감칸에 주해와 그림자사이의 간격을 입력합니다.
      • <색>복합칸에서 요구하는 색을 찰칵합니다.
      • <투명도>증감칸에 그림자의 투명도값을 입력합니다.
    4. <확인>단추를 찰칵합니다.
