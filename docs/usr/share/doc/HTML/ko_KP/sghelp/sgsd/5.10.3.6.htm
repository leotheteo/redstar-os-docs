다른 세포, 자료표문서에 대한 련결의 만들기

모두 표시

같은 표용지 또는 자료표문서의 세포에서 련결의 만들기

  1. 련결하려는 대상자료가 있는 세포를 찰칵하고 <표준>도구띠에서 <복사>를 찰칵합니다.
  2. 련결을 시작할 세포를 찰칵하고 <붙이기>옆에 있는 화살표를 찰칵합니다.
  3. <DDE 련결>을 찰칵합니다.

여러 자료표문서의 세포사이에 련결의 만들기

  1. 련결이 포함되는 자료표문서(대상자료표문서라고 함)와 련결하려는 대상자료가 들어있는 자료표문서(원본자료표문서라고 함)를 모두 엽니다.
  2. 대상자료표문서에서 <보관>을 찰칵합니다.
  3. 원본자료표문서에서 련결하려는 원본세포를 한개이상 선택하고 <표준>도구띠에서 <복사>를 찰칵합니다.
  4. 대상자료표문서에서 련결을 시작할 세포를 찰칵하고 <붙이기>옆에 있는 화살표를 찰칵합니다.
  5. <DDE 련결>을 찰칵합니다.

기존문서에 대한 련결의 만들기

  1. 련결된 객체를 넣을 표용지를 찰칵합니다.
  2. <삽입>차림표에서 <객체>를 찰칵하고 <OLE 객체>를 찰칵합니다.
  3. <파일로부터 만들기>단일선택단추를 찰칵합니다.
  4. <탐색>단추를 찰칵하여 파일을 선택하고 <열기>단추를 찰칵합니다.
  5. <파일에 련결>확인칸을 선택합니다.

참고: <삽입>차림표의 <객체>를 사용하여 그림과 특정한 류형의 파일을 삽입할수 없습니다. 그림을 삽입하려면 <삽입>차림표에서 <그림>을 찰칵하고 <파일로부터>를 찰칵합니다.

문서포함

  1. 포함된 객체를 넣을 표용지를 찰칵합니다.
  2. <삽입>차림표에서 <객체>를 찰칵하고 <OLE 객체>를 찰칵합니다.
  3. 문서가 아직 존재하지 않으면 <새로 만들기>단일선택단추를 찰칵합니다. <객체류형>목록칸에서 만들려는 객체류형을 찰칵합니다.

    4. 문서가 이미 존재하면 <파일로부터 만들기>단일선택단추를 찰칵합니다. <탐색>단추를 찰칵하여 파일을 선택하고 <열기>단추를 찰칵합니다.

  4. <파일에 련결>확인칸선택을 취소합니다.

같은 표용지나 다른 표용지의 세포사이에 참조를 만들기

아래수식에는 다른 세포에 대한 상대참조와 그 이름이 들어있습니다. 세포에 수식이 들어있는 경우 그 값을 다른 세포에서 참조하는 경우 그 세포를 참조하는 세포라고 합니다. 례를 들어 B2 세포에 수식 =C2가 들어있으면 그 세포는 참조하는 세포입니다.

실례수식 작업내용
=C2 C2 세포의 값을 사용합니다.
=표용지2.B2 표용지2에 있는 B2 세포의 값을 사용합니다.
=Asset-Liability Asset이라는 이름의 세포에서 Liability라는 이름의 세포를 덥니다.
  1. 수식을 입력할 세포를 찰칵합니다.
  2. 수식띠 에 =(같기부호)를 입력합니다.
  3. 참조를 만들려면 세포나 세포범위, 다른 표용지의 위치, 다른 자료표문서의 위치중 하나를 선택합니다. 마우스를 끌어서 세포나 세포범위를 선택합니다.

  4. [Enter]건을 누릅니다.
