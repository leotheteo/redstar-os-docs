주해의 삭제

모두 표시

  1. 삭제하려는 주해가 들어있는 세포를 선택합니다.
  2. <편집>차림표에서 <내용 삭제>를 찰칵합니다. 또는 [BackSpace]건을 누릅니다.
  3. <모두 삭제>확인칸의 선택을 취소하고 <주해>확인칸만 선택합니다.
  4. <확인>단추를 찰칵합니다.

참고: 마우스오른쪽단추의 상황차림표를 리용하여 주해를 삭제할수도 있습니다. 마우스오른쪽단추의 상황차림표를 리용하여 주해를 삭제하려면 주해가 들어있는 세포를 선택한 다음 마우스오른쪽단추를 찰칵합니다. 이때 나타나는 상황차림표에서 <주해 삭제>를 찰칵합니다.
