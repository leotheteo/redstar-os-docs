여러 파일의 선택

모두 표시

  1. <표준>도구띠에서 <열기>를 찰칵합니다.
  2. 다음의 방법들중에서 하나를 실행합니다.
    • <열기>대화창에서 서로 린접하지 않은 여러 파일을 선택하려면 한개의 파일을 선택한 후 [Ctrl]건을 누른 상태에서 나머지파일을 각각 선택합니다.
    • <열기>대화창에서 린접한 여러 파일을 선택하려면 첫번째 파일을 선택한 후 [Shift]건을 누른 상태에서 마지막파일을 선택합니다.

즉시도움말

요구하지 않는 파일이 선택되였다면 [Ctrl]건을 누른 상태에서 그 파일을 다시 한번 찰칵하여 선택을 취소합니다.
