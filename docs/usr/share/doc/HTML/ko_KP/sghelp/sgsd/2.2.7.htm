격식 및 서식 격식을 지정하고 관리할수 있는 <격식 및 서식>창을 보이거나 숨기겠는가를 지정합니다.
격식 적용 현재단락이나 선택한 단락 또는 선택한 객체에 격식을 지정할수 있습니다. <서식>/<격식 및 서식>에서 더 많은 격식을 사용할수 있습니다.
서체이름 서체이름을 목록에서 선택하거나 직접 입력할수 있습니다.
서체크기 목록의 여러 서체크기중에서 선택하거나 수동으로 크기를 입력할수 있습니다.
두껍게 선택한 본문을 굵은체로 표시합니다. 유표가 단어안에 있으면 단어전체가 굵은체로 표시됩니다. 선택령역이나 단어가 이미 굵은체로 표시되여있으면 서식이 초기화됩니다.
경사 선택한 본문을 경사체로 표시합니다. 유표가 단어안에 있으면 단어의 전체가 경사체로 표시됩니다. 선택령역이나 단어가 이미 경사체로 표시되여있으면 서식이 초기화됩니다.
밑줄 선택한 본문에 밑줄을 표시하거나 밑줄을 제거합니다.
밑줄: 이중실선 선택한 본문에 두줄로 된 밑줄을 표시합니다.
왼쪽 맞추기 세포내용을 세포의 왼쪽테두리에 맞춥니다.
가로가운데 맞추기 세포내용을 세포의 가로가운데에 맞춥니다.
오른쪽 맞추기 세포내용을 세포의 오른쪽테두리에 맞춥니다.
량쪽 맞추기 세포내용을 세포의 왼쪽 및 오른쪽테두리에 맞춥니다.
세포 합치고 가운데 맞추기 선택한 세포들을 단일세포로 결합하거나 합쳐진 세포를 가릅니다.
왼쪽에서 오른쪽으로 본문이 왼쪽에서 오른쪽으로 입력됩니다.
오른쪽에서 왼쪽으로 본문이 오른쪽에서 왼쪽으로 입력됩니다.
본문방향 왼쪽에서 오른쪽으로 본문의 가로방향을 지정합니다.
본문방향 웃쪽에서 아래쪽으로 본문의 세로방향을 지정합니다.
웃쪽 맞추기 세포내용을 세포의 웃쪽테두리에 맞춥니다.
세로가운데 맞추기 세포내용을 세포의 세로가운데에 맞춥니다.
아래쪽 맞추기 세포내용을 세포의 아래쪽테두리에 맞춥니다.
수자서식: 통화 선택한 세포에 기정통화서식을 적용합니다.
수자서식: 백분률 선택한 세포에 백분률서식을 적용합니다.
수자서식: 날자 선택한 세포에 날자서식을 적용합니다.
수자서식: 지수 선택한 세포에 지수서식을 적용합니다.
수자서식: 표준 선택한 세포에 표준수자서식을 적용합니다.
수자서식: 소수부 추가 선택한 세포가 수자인 경우 소수점의 자리수에서 하나의 아래자리수를 추가합니다.
수자서식: 소수부 삭제 선택한 세포가 수자인 경우 소수점의 자리수에서 하나의 아래자리수를 제거합니다.
들여쓰기 감소 단락의 들여쓰기를 감소합니다.
들여쓰기 증가 단락의 들여쓰기를 증가합니다.
테두리 표시할 세포 테두리의 네면을 각각 지정합니다.
배경색 배경색을 지정합니다. 이 색은 현재단락이나 선택한 단락의 배경에 적용됩니다.
서체색 선택한 문자에 서체색을 적용합니다. 그림기호를 찰칵한 후 선택범위를 끌기하여 본문색을 적용할수도 있습니다. 그림기호옆의 화살표를 찰칵하면 <서체색>도구띠가 열립니다.
선격식 테두리선격식을 지정합니다.
테두리색 테두리색을 지정합니다.
행 삽입 활성상태로 만든 세포우에 새 행을 삽입합니다.
렬 삽입 활성상태로 만든 세포의 왼쪽에 새 렬을 삽입합니다.
행 삭제 최소한 하나이상의 세포를 선택한 후 표용지에서 행전체를 삭제합니다.
렬 삭제 최소한 하나이상의 세포를 선택한 후 표용지에서 렬전체를 삭제합니다.
