CHITEST

모두 표시

참고항목  통계함수목록, CHIDIST, CHIINV

χ² 독립성검정을 구합니다.

문법:   CHITEST(관측자료,예상자료)

인수명 설명
관측자료 관측된 자료행렬입니다.
예상자료 예상된 자료행렬입니다.

주의

  • 관측자료와 예상자료의 자료수가 다르면 #N/A 오유가 나타납니다.
  • χ²검정은 먼저 다음수식을 사용하여 χ²통계량을 계산합니다.

    여기서

    Aij = i번째 행, j번째 렬의 실제빈도

    Eij = i번째 행, j번째 렬의 기대빈도

    r = 행의 개수

    c = 렬의 개수

  • 낮은 χ²값은 독립성을 나타내는 표식입니다. 수식에서 알수 있듯이 χ²는 항상 정수 또는 0이며 모든 i와 j에 대해 Aij = Eij일 때에만 0입니다.
  • CHITEST 함수는 우의 수식으로 계산한 값이상의 χ²통계량값이 독립성가정하에 우연히 발생할수 있는 확률을 구합니다. 이 확률계산에서는 적절한 자유도 df를 가지는 χ²분포를 사용합니다. r > 1이고 c > 1이면 df = (r - 1)(c - 1)입니다. r = 1, c > 1이면 df = c - 1이고 r > 1, c = 1이면 df = r - 1입니다. r = c= 1은 허용되지 않으므로 #N/A 오유가 발생합니다.
  • CHITEST 함수는 Eij가 너무 작을 때 적합한 함수입니다. 각 Eij가 5보다 크거나 같아야 한다고 주장하는 통계학자도 있습니다.
