OCT2BIN

모두 표시

참고항목  추가함수목록, BIN2OCT, DEC2OCT, HEX2OCT

8진수를 2진수로 변환합니다.

문법:   OCT2BIN(8진수,자리수)

인수명 설명
8진수 변환할 8진수입니다. 10자리까지 사용할수 있습니다. 최상위비트는 부호비트이고 나머지 29비트는 값을 나타내는 비트입니다. 부수는 2의 보수표기법으로 표시됩니다.
자리수 2진수의 자리수입니다. 추가선택인수입니다. 자리수를 생략하면 최소한으로 필요한 문자수가 사용됩니다. 자리수는 반환값의 앞에 0을 넣어 자리수를 맞출 때 유용합니다.

주의

  • 8진수가 부수이면 오유:[오유번호]가 반환됩니다.
  • 8진수가 부수이면 7777777000보다 크거나 같아야 하며 8진수가 정수이면 777보다 작거나 같아야 합니다.
  • 8진수가 유효한 8진수가 아니면 오유:[오유번호]가 반환됩니다.
  • 자리수로 지정한것보다 자리수가 더 많이 필요하면 오유:[오유번호]가 반환됩니다.
  • 자리수가 옹근수가 아니면 소수점이하는 무시됩니다.
  • 자리수가 수자가 아니면 #NAME?오유가 반환됩니다.
  • 자리수가 부수이면 오유:[오유번호]가 반환됩니다.
