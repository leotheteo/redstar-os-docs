RAND

모두 표시

참고항목  수학함수목록

0과 1사이의 란수를 구합니다.

문법:   RAND( )

주의

  • a와 b사이의 실수인 란수를 만드는 방법은 다음과 같습니다.

    RAND()*(b-a)+a

  • RAND를 사용하여 란수를 만들고 세포가 계산될 때마다 만들어진 란수가 변경되지 않도록 하려면 수식입력행에 =RAND()를 입력하고 [F9]건을 눌러 수식을 란수로 변경합니다.
