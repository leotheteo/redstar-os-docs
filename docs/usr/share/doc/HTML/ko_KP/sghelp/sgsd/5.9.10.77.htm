WEIBULL

모두 표시

참고항목  통계함수목록, EXPONDIST

웨이블분포값을 구합니다.

문법:   WEIBULL(수값,α,β,류형)

인수명 설명
수값 웨이블분포를 계산할 값입니다.
α 웨이블분포의 α파라메터입니다.
β 웨이블분포의 β파라메터입니다.
류형 적분류형입니다. 류형 = 0인 경우에는 밀도함수, 류형 = 1인 경우에는 적분함수를 계산합니다.

주의

  • 수값, α, β 등이 수자가 아니면 WEIBULL함수는 오유:[오유번호]를 반환합니다.
  • 수값 < 0이면 오유:[오유번호]를 반환합니다.
  • α나 β가 0이하이면 오유:[오유번호]를 반환합니다.
  • 웨이블루적분포함수의 식은 다음과 같습니다.

  • 웨이블확률밀도함수의 식은 다음과 같습니다.

  • α = 1이면 웨이블함수는 다음의 식과 함께 지수분포를 반환합니다.
