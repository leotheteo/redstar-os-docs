앞뒤로 객체의 이동

모두 표시

  1. 이동할 객체를 선택합니다.

    가리워진 객체의 경우 아무 객체나 선택한 후 요구하는 객체가 선택될 때까지 [Tab]건이나 [Shift+Tab]건을 누릅니다.

  2. 다음의 방법들중에서 하나를 실행합니다.
    • 객체를 한 계층의 앞으로 가져오기

      <서식>차림표에서 <배렬>을 찰칵하고 <앞면에로 이동>을 찰칵합니다.

    • 객체를 맨 앞으로 가져오기

      <서식>차림표에서 <배렬>을 찰칵하고 <맨 앞면에로 이동>을 찰칵합니다.

    • 객체를 한 계층의 뒤로 보내기

      <서식>차림표에서 <배렬>을 찰칵하고 <뒤면에로 이동>을 찰칵합니다.

    • 객체를 맨 뒤로 보내기

      <서식>차림표에서 <배렬>을 찰칵하고 <맨 뒤면에로 이동>을 찰칵합니다.

    • 객체를 전경으로 보내기

      <서식>차림표에서 <배렬>을 찰칵하고 <전경에>를 찰칵합니다
    • 객체를 배경으로 보내기

      <서식>차림표에서 <배렬>을 찰칵하고 <배경에>를 찰칵합니다
