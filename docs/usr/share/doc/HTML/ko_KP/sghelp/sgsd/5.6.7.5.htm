문자서식의 변경

모두 표시

<문자>대화창을 리용하여 선택한 문자의 서체나 서체효과를 설정할수 있습니다.

문자의 서식을 변경하려면 다음과 같은 방법으로 진행합니다.

  1. 변경하려는 문자를 선택합니다.
  2. <서식>차림표에서 <문자>를 찰칵하여 <문자>대화창을 엽니다.

  3. 다음의 방법들중에서 하나이상을 실행합니다.

    • <문자>표쪽을 찰칵합니다. <문자>표쪽에서는 서양문자와 동양문자에 대하여 서체종류와 형태, 크기 등을 지정합니다.
    • <서체효과>표쪽을 찰칵합니다. 여기서는 선택된 문자에 밑줄이나 삭제선, 강조표식, 서체색, 부각 등 서체효과를 지정합니다.
    • <서체위치>표쪽을 찰칵합니다. 여기서는 선택한 문자의 위치를 지정합니다. 례를 들어 선택한 문자를 웃첨자로 설정하려면 <위치>령역의 <웃첨자>단일선택단추를 선택합니다.
  4. <확인>단추를 찰칵합니다.
