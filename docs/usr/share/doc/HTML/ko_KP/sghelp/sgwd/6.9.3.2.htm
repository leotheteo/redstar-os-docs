사용자정의사전에서 발생하는 문제의 해결

모두 표시

편집기를 사용하여 사용자정의사전 작업을 해왔을 때

문서처리프로그람에서는 별도의 다른 본문편집기를 사용하여 사용자정의사전의 내용을 편집할 필요가 없도록 사용자정의사전 작업방법을 간소화했습니다. 즉 다른 편집기를 사용하지 않아도 됩니다.

사용자정의사전에 추가한 단어를 철자법 검사기가 인식하지 못할 때

사용자정의사전을 사용하여 철자를 검사하려면 먼저 <서광사무처리>/<환경설정>/<언어 설정>/<문장작성 지원>의 <사용자정의사전>목록칸에서 해당 이름옆에 있는 확인칸을 선택하여 사전을 사용가능하게 하여야 합니다.
