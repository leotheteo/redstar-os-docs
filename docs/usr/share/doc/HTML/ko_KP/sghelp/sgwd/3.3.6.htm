형판의 위치

모두 표시

문서형판은 하드디스크에 보관하거나 또는 문서서고에 포함하거나 작업그룹형판으로 사용할수 있습니다. 형판위치설정을 확인하려면 <서광사무처리>차림표에서 <환경설정>을 찰칵하고 <서광사무처리>의 <경로>를 찰칵합니다. <서광사무처리에서 사용하는 경로>목록칸의 <형판>옆에 있는 경로를 선택하여 형판위치를 확인합니다.

보안: 서류철의 위치를 변경하는 경우 새 서류철의 위치를 안전한 곳으로 지정해야 합니다.

위치를 변경하려면 다음과 같은 방법으로 진행합니다.

  1. <서광사무처리>차림표에서 <환경설정>을 찰칵합니다.
  2. <환경설정>대화창에서 <서광사무처리>의 <경로>를 선택합니다.
  3. <서광사무처리에서 사용하는 경로>목록칸에서 <형판>을 선택합니다.
  4. <편집>단추를 찰칵하여 <경로 편집: 형판>대화창을 현시합니다.
  5. <추가>단추를 찰칵하여 <경로 선택>대화창을 현시합니다.
  6. <경로 선택>대화창에서 변경하려는 해당한 경로에 있는 서류철을 선택하고 <선택>단추를 찰칵하여 대화창을 닫습니다.
  7. <경로 편집: 형판>대화창에서 <확인>단추를 찰칵합니다.
  8. <환경설정>대화창에서 <확인>단추를 찰칵합니다.
