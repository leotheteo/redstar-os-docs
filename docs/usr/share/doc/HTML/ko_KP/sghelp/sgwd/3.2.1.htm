다른 파일형식으로 열기 및 보관

모두 표시

파일형식은 프로그람에서 파일을 열고 보관할수 있도록 파일에 정보를 보관하는 방식입니다. 파일형식은 파일이름의 뒤에 오는 세글자 또는 네글자의 확장자로 구분됩니다. 례를 들어 문서처리프로그람에서 새 문서를 보관하면 기본적으로 확장자가 .odt인 문서처리프로그람의 문서형식으로 보관됩니다.

다른 형식사이의 변환

문서처리프로그람은 파일형식변환기를 사용하여 다른 형식으로 문서를 열고 보관합니다. 가장 자주 사용되는 파일형식변환기는 사용하지 않도록 선택하지 않는 한 기본적으로 문서처리프로그람과 함께 설치됩니다.

다른 프로그람이나 기존판본의 문서처리프로그람에서 열수 있도록 다른 형식으로 문서를 변환하려면 문서를 보관할 때 해당 파일형식을 선택합니다.

기본적으로 설치되지 않는 형식으로 열거나 보관하려면 다른 파일형식변환기를 설치해야 합니다.

문서처리프로그람에서 제공되는 파일형식변환기를 사용하면 다음의 방법들중에서 요구하는 작업을 실행할수 있습니다.

  • 다른 프로그람에서 작성한 파일의 열기
  • 다른 프로그람에서 열수 있도록 파일의 보관
  • 다른 프로그람에서 문서처리프로그람 문서를 열기

파일형식변환기를 사용하지 않고 다양한 형식의 파일을 열기 및 보관

문서처리프로그람에서는 파일형식변환기를 사용하지 않고도 기본형식(.odt)이 아닌 다른 여러가지 형식으로 파일을 열고 보관할수 있습니다.

문서처리프로그람에서 직접 열거나 보관할수 있는 형식

문서처리프로그람에서 직접 열수 있는 여러가지 파일형식들이 있습니다.

확장자 설명
.odt ODF 본문문서
.ott ODF 본문문서형판
.sxw OpenOffice.org 1.0 본문문서
.stw OpenOffice.org 1.0 본문문서형판
.fodt OpenDocument 본문(Flat XML)
.uot Unified Office Format 본문
.dot Microsoft Word 97/2000/XP/2003 형판
.doc Microsoft Word 97/2000/XP/2003
.docx Microsoft Word 2007/2010 XML
.htm, .html HTML형식의 웨브페지입니다.
.rtf 서식화된 본문(.rtf)으로서 호환되는 Microsoft프로그람을 비롯한 다른 프로그람에서 읽고 해석할수 있는 서식지령이 포함되여있습니다.
.txt 일반 본문형식으로서 본문서식이 없습니다.

기정파일형식의 변경

작성한 모든 문서를 기존판본의 문서처리프로그람을 사용하는 사람들과 공유해야 하는 등의 리유로 문서를 항상 다른 형식으로 보관하는 경우에는 문서처리프로그람에서 새 문서를 보관할 때 사용하는 기정파일형식을 변경할수 있습니다. 기정파일형식은 <서광사무처리>차림표의 <환경설정>을 찰칵하여 펼쳐지는 <환경설정>대화창에서 <적재 및 보관>의 <일반>을 찰칵하여 변경할수 있습니다. 이 설정은 새 문서를 만들 때에만 적용되며 이미 보관되였던 문서는 열 때와 같은 형식으로 보관됩니다.
