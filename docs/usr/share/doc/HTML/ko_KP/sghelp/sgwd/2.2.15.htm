표준(보기방식)

모두 표시

그림기호 지령명 기능
다른 이름으로 보관 현재문서를 다른 위치에 보관하거나 파일이름 또는 파일형식을 다르게 지정하여 보관합니다.
파일 편집 읽기전용문서를 편집합니다.
문서를 전자우편으로 표준전자우편프로그람을 사용하여 현재문서를 전자우편의 첨부파일로 보냅니다.
PDF로 직접 반출 현재문서를 PDF로 직접 반출합니다. 대화창이 현시됩니다.
파일 직접 인쇄 (기정인쇄기) 현재 표준인쇄설정을 사용하여 활성상태로 된 문서를 직접 인쇄합니다.
복사 선택한 내용을 오림판에 복사합니다.
탐색 및 치환 현재문서에서 본문 또는 서식을 탐색하거나 치환합니다.
항행기 문서의 다른 부분으로 빨리 이동할수 있는 항행기를 보이거나 숨깁니다.
확대/축소 화면을 확대 또는 축소합니다.
