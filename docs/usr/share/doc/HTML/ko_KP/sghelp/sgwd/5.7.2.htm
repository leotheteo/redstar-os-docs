각주/본문끝주의 삽입

모두 표시

문서처리프로그람에서는 문서전체에서 각주/본문끝주의 번호를 자동적으로 매깁니다.

자동적으로 번호가 매겨진 각주/본문끝주를 추가, 삭제, 이동하면 각주/본문끝주의 참조기호의 번호도 다시 매겨집니다.

각주/본문끝주의 참조기호에 사용할 서식에 따라 다음의 방법들중에서 하나를 실행합니다.

각주/본문끝주의 참조기호로 번호서식을 리용하는 경우

  1. 인쇄배치에서 각주/본문끝주의 참조기호를 삽입할 위치를 찰칵합니다.
  2. <삽입>차림표의 <각주/본문끝주>를 찰칵하여 <각주/본문끝주 삽입>대화창을 현시합니다.
  3. <항목번호>령역에서 <자동>단일선택단추를, <류형>령역에서 <각주> 또는 <본문끝주>단일선택단추를 선택합니다.
  4. <확인>단추를 찰칵합니다. 참조번호가 삽입되고 유표가 참조번호의 옆으로 이동합니다. 기본적으로 각주는 매개 페지의 아래끝에, 본문끝주는 문서의 끝에 배치됩니다.
  5. 각주 또는 본문끝주의 령역에 본문을 입력합니다.
  6. 다른 각주 또는 본문끝주를 삽입하면 해당 번호서식이 자동적으로 적용됩니다.

각주/본문끝주의 참조기호로 사용자정의서식을 리용하는 경우

사용자정의한 각주/본문끝주를 사용하면 같은 페지에 서식이 다른 각주/본문끝주를 삽입할수 있습니다. 례를 들어 별표(*)를 각주/본문끝주의 참조기호로 사용할수 있습니다. 사용자정의한 각주/본문끝주의 참조기호는 자동적으로 번호가 다시 매겨지지 않습니다.

  1. <삽입>차림표의 <각주/본문끝주>를 찰칵하여 <각주/본문끝주 삽입>대화창을 현시합니다.
  2. <항목번호>령역에서 <문자>단일선택단추를 선택하고 옆의 단추를 찰칵하여 <특수문자>대화창을 현시합니다.
  3. 요구하는 기호를 선택하고 <확인>단추를 찰칵합니다. 그러면 <각주/본문끝주 삽입>대화창의 <문자>단일선택단추옆의 본문칸에 선택한 문자가 입력됩니다.
  4. <확인>단추를 찰칵합니다.
  5. 각주 또는 본문끝주의 령역에 본문을 입력합니다.
  6. 다른 각주 또는 본문끝주를 삽입하면 사용자정의서식이 자동적으로 적용됩니다.
