형판의 수정

모두 표시

문서처리프로그람에 이미 만들어진 형판을 수정할수 있습니다.

형판을 수정하면 형판을 기준으로 만드는 새 문서에 영향을 줍니다. 형판을 변경해도 기존의 문서내용은 영향을 받지 않습니다.

  1. <파일>차림표에서 <형판>의 <편집>을 찰칵하면 <열기>대화창이 현시됩니다.
  2. 《서광사무처리》 3.0프로그람이 형판의 저장고로 리용하는 서류철이 기정으로 현시됩니다.
  3. 파일목록칸에서 이미 보관되여있는 형판들을 찾아 선택합니다.
  4. <열기>단추를 찰칵하면 선택된 형판이 현시됩니다.
  5. 필요한 편집조작을 진행하여 보관합니다.
