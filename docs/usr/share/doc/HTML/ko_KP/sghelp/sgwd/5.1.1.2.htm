페지여백의 설정

모두 표시

페지여백이란 페지가장자리주위의 빈 령역을 말합니다.

여백에는 머리부, 바닥부, 페지번호 등을 배치할수 있습니다.

페지여백의 설정

  1. 다음의 방법들중에서 하나를 실행하여 <페지격식>대화창을 현시합니다.
    • <서식>차림표에서 <페지>를 찰칵합니다.
    • 상태띠의 페지격식부분을 두번 찰칵합니다.
  2. <페지>표쪽을 찰칵합니다.
  3. <여백>령역에서 요구하는 추가선택을 진행합니다. 페지설정을 원래상태로 되돌리려면 <재설정>단추를 찰칵합니다.
  4. <확인>단추를 찰칵합니다.

제본용여백의 설정

이런 경우 왼쪽페지여백과 오른쪽페지여백은 안쪽여백끼리의 너비가 같고 외부여백끼리의 너비가 같게 됩니다.

  1. 다음의 방법들중에서 하나를 실행하여 <페지격식>대화창을 현시합니다.
    • <서식>차림표에서 <페지>를 찰칵합니다.
    • 상태띠의 페지격식부분을 두번 찰칵합니다.
  2. <페지>표쪽을 찰칵합니다.
  3. <여백>령역의 <왼쪽>(페지배치가 대칭변환으로 선택된 경우에는 <안쪽>)증감칸과 <웃쪽>증감칸을 리용하여 제본할 공간까지 계산된 값을 설정합니다.
  4. <확인>단추를 찰칵합니다.
