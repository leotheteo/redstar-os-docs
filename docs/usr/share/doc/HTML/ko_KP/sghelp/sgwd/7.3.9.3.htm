장식문자본문의 채우기, 투명도 및 그림자지정

모두 표시

장식문자도 도형객체의 한 종류이므로 여러가지 형식의 채우기를 지정하고 그림자를 지정할수 있으며 투명도를 변경할수 있습니다.

장식문자의 채우기격식 변경

  1. 채우기격식을 변경할 장식문자객체를 선택합니다.
  2. <서식>차림표의 <객체>에서 <령역>을 찰칵하여 <령역>대화창을 현시합니다. 또는 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <령역>을 찰칵할수도 있습니다.
  3. <령역>표쪽을 찰칵하고 <칠하기>복합칸에서 요구하는 채우기격식을 지정합니다. 례를 들어 <색>, <계조>, <평행선>, <문양> 등을 선택하여 해당한 설정을 진행합니다.

    4. 참고: <색>, <계조>, <평행선>, <문양> 등은 <령역>대화창의 해당 표쪽들을 찰칵하여 설정할수도 있습니다.

  4. <확인>단추를 찰칵하여 대화창을 닫습니다.

장식문자의 투명도변경

  1. 투명도를 변경할 장식문자객체를 선택합니다.
  2. <서식>차림표의 <객체>에서 <령역>을 찰칵하여 <령역>대화창을 현시합니다. 또는 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <령역>을 찰칵할수도 있습니다.
  3. <투명도>표쪽을 찰칵하고 <투명방식>령역에서 요구하는 설정을 진행합니다.
  4. <확인>단추를 찰칵하여 대화창을 닫습니다.

장식문자의 그림자설정

  1. 그림자를 설정할 장식문자객체를 선택합니다.
  2. <서식>차림표의 <객체>에서 <령역>을 찰칵하여 <령역>대화창을 현시합니다. 또는 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <령역>을 찰칵할수도 있습니다.
  3. <그림자>표쪽을 찰칵하고 <속성>령역에서 요구하는 설정을 진행합니다.
  4. <확인>단추를 찰칵하여 대화창을 닫습니다.

참고: <령역>대화창은 <도형객체속성>도구띠의 <령역>그림기호를 찰칵하여 열수도 있습니다.
