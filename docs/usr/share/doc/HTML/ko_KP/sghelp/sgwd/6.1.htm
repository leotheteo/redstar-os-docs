본문과 객체의 선택

모두 표시

마우스나 건반을 사용하여 서로 린접하거나 린접하지 않은 본문과 객체를 선택할수 있습니다. 례를 들어 1페지에 있는 단락과 3페지에 있는 문장을 선택할수 있습니다.

서로 린접한 항목의 선택

마우스를 누른채로 끌기하거나 [Shift]건을 누른채로 방향건 또는 [Home], [End], [PageUp], [PageDown]건을 눌러서 선택할수 있습니다.

서로 린접하지 않은 항목의 선택

  1. 표의 세포나 단락 등 첫번째 항목을 선택합니다.
  2. [Ctrl]건을 누른채로 요구하는 다른 항목을 선택합니다.

마우스로 본문과 객체의 선택

마우스로 본문과 객체를 선택하는 방법에는 여러가지가 있습니다.

선택대상 선택방법
본문 본문우로 마우스를 끕니다.
단어 해당 단어를 두번 찰칵합니다.
본문의 한 문장 선택할 문장의 임의의 위치에서 마우스단추를 세번 찰칵합니다. 이때 점(.)으로 구분된 한개 문장만이 선택됩니다.
단락 선택할 단락의 아무 위치에서 마우스단추를 네번 찰칵합니다. 이때 단락기호로 구분된 한개 단락이 선택됩니다. 단락에 한개 문장만 있는 경우에는 세번 찰칵하면 단락이 선택됩니다.
본문령역 선택할 령역의 시작위치를 찰칵하고 [Shift]건을 누른채로 선택할 령역의 끝위치를 찰칵합니다.
머리부 또는 바닥부의 령역 인쇄배치에서 회색의 머리부 또는 바닥부의 본문이 있는 령역을 두번 찰칵합니다. 머리부 또는 바닥부령역이 활성화됩니다.
머리부 또는 바닥부의 본문 인쇄배치에서 회색의 머리부 또는 바닥부의 본문을 세번 찰칵합니다. 머리부 또는 바닥부령역이 활성화되고 머리부 또는 바닥부의 본문이 선택됩니다.
각주 또는 본문끝주 각주 또는 본문끝주 참조기호를 찰칵합니다.
객체 객체를 찰칵합니다.
본문칸이나 틀 테두리로 마우스유표를 이동한 다음 틀이나 본문칸의 테두리를 찰칵하여 크기조종꼭지를 나타냅니다.

건반으로 본문을 선택

Shift건에 의한 선택

Shift건을 누른채로 유표이동건을 눌러 본문을 선택합니다.

선택방법 선택내용
Shift+오른쪽이동건 한 글자 오른쪽으로
Shift+왼쪽이동건 한 글자 왼쪽으로
Ctrl+Shift+오른쪽이동건 단어의 끝까지
Ctrl+Shift+왼쪽이동건 단어의 시작위치까지
Shift+End 행의 끝으로
Shift+Home 행의 시작위치로
Shift+아래쪽이동건 아래쪽으로 한행
Shift+웃쪽이동건 웃쪽으로 한행
Shift+Page Down 한 화면 아래쪽으로
Shift+Page Up 한 화면 웃쪽으로
Ctrl+Shift+Home 문서의 시작위치까지
Ctrl+Shift+End 문서의 끝까지
Ctrl+A 문서전체

확장방식설정에 의한 선택

확장방식을 설정하고 유표를 이동하는 건을 눌러 본문을 선택합니다.

[F8]건을 한번 누르면 확장방식이 설정됩니다. 확장방식이 설정된 상태는 [Shift]건을 누른 상태와 같습니다. 따라서 [Shift]건에 의한 선택방법과 같습니다.

[F8]건을 다시 한번 누르면 확장방식의 설정이 해제됩니다.

참고: 유표를 이동하는 건의 조합을 알면 일반적으로 [Shift]건을 누른채로 같은 건조합을 사용하여 본문을 선택할수 있습니다. 례를 들어 유표를 다음단어로 이동하려면 [Ctrl+오른쪽이동건]을 누르고 유표위치에서 다음단어의 시작위치까지 본문을 선택하려면 [Ctrl+Shift+오른쪽이동건]을 누릅니다.

마우스로 표의 항목을 선택

마우스로 표의 요구하는 항목들에 대한 선택을 진행할수 있습니다.

참고: 표의 일부 요소는 <표준>도구띠에서 <인쇄하지 않는 문자>그림기호를 찰칵하여 모든 서식기호를 표시한 경우에만 볼수 있습니다.

선택할 요소 선택방법
행

행의 왼쪽을 찰칵합니다.
렬

렬의 맨 우의 눈금선이나 테두리를 찰칵합니다.
다음세포의 본문 [Tab]건을 누릅니다.
이전 세포의 본문 [Shift+Tab]건을 누릅니다.

참고:   표를 찰칵하고 <표>차림표의 <선택>지령이나 건반지름건을 사용하여 행, 렬, 표의 전체를 선택할수 있습니다.

건반으로 표의 항목을 선택

지름건을 리용하여 표의 요구하는 항목들에 대한 선택을 진행할수 있습니다.

건지정방식 선택내용
Tab건 다음세포의 내용을 선택
Shift+Tab 이전 세포의 내용을 선택
[Shift]건을 누른채로 이동건을 반복해서 누릅니다. 린접한 세포로 선택범위를 확장
선택할 렬의 맨 웃쪽이나 맨 아래쪽의 세포를 찰칵합니다. [Shift]건을 누른채로 웃쪽이동건이나 아래쪽이동건을 반복해서 누릅니다. 렬을 선택

건반으로 객체를 선택

유표가 문서의 본문안에 있는 경우 다음의 방법을 수행합니다.

  1. [F6]건을 눌러 도구띠를 활성화합니다.
  2. <도형>도구띠가 활성화될 때까지 [F6]건을 누릅니다.
  3. 오른쪽이동건을 눌러 <선택>그림기호를 선택합니다.
  4. 첫번째 객체를 선택하려면 [Ctrl+Enter]건을 누릅니다.
  5. [Esc]건을 누른 다음 선택할 객체에 크기조종꼭지가 나타날 때까지 앞쪽으로 이동하려면 [Tab]건을 누르고 뒤쪽으로 이동하려면 [Shift+Tab]건을 누릅니다.
