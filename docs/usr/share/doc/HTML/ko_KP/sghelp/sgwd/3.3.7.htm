다른 문서나 형판의 설정사용정보

모두 표시

기정형판이나 <나의 형판>에 보관된 항목을 사용할수 있습니다. 또한 다른 문서에 있는 항목들을 사용할수도 있습니다.

격식의 복사

  1. <파일>차림표의 <형판>에서 <관리>를 찰칵합니다.

    <형판 관리>대화창의 왼쪽과 오른쪽선택목록은 사용가능한 형판종류나 현재 현시되여있는 《서광사무처리》 3.0파일을 현시합니다. 목록내용을 변경하려면 대화창아래의 복합칸에서 <형판> 또는 <문서>를 선택합니다.

    또는 <파일>단추를 찰칵하여 <열기>대화창에서 요구하는 문서나 형판을 추가할수 있습니다.

  2. 형판종류에 속하는 항목들은 서류철그림기호로 현시됩니다. 종류별 형판을 보려면 서류철을 두번 찰칵합니다. 그러면 그 종류에 포함된 형판들이 현시됩니다. 파일에서 사용되는 격식을 보려면 해당 파일이름을 두번 찰칵한 다음 <격식>그림기호를 두번 찰칵합니다.
  3. 문서의 매 서식을 끌기하여 형판에 복사하거나 반대로 형판의 매 서식을 끌기하여 문서에 복사합니다.

    4. 참고: 문서에 이미 동일한 이름의 서식이 있으면 기존서식을 교체하겠는가를 묻는 통보문이 현시됩니다.

  4. <닫기>를 찰칵하여 대화창을 닫습니다.

기정형판의 설정

  1. <파일>차림표의 <형판>에서 <관리>를 찰칵하여 <형판 관리>대화창을 현시합니다.
  2. 형판종류목록칸에서 기정형판으로 설정하려는 형판이 포함된 형판종류를 찰칵합니다.
  3. 기정형판으로 설정할 형판을 선택합니다.
  4. 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표 또는 <지령>단추를 찰칵하여 현시되는 차림표에서 <기정형판으로 설정>을 찰칵합니다.
  5. <닫기>를 찰칵하여 대화창을 닫습니다.

참고: 이제부터 새 문서를 만들면 사용자가 기정형판으로 설정한 형판이 열립니다.
