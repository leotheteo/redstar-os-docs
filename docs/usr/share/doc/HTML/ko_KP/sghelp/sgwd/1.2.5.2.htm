차림표의 추가, 삭제 및 수정

모두 표시

차림표를 새로 추가하거나 삭제할수 있으며 차림표지령들을 다시 정렬하고 수정할수 있습니다.

다음과 같은 방법으로 진행합니다.

  1. <도구>차림표에서 <사용자전용화>를 찰칵합니다.
  2. <사용자전용화>대화창이 화면에 현시됩니다.
  3. <사용자전용화>대화창에서 <차림표>표쪽을 찰칵합니다.

    4. 차림표의 추가

    1. 차림표를 사용자가 새롭게 정의하려면 <새로 만들기>단추를 찰칵합니다.
    2. <새 차림표>대화창에서 차림표의 이름과 순서를 정의합니다.
    3. 차림표에 지령을 새로 추가하려는 경우에는 <사용자전용화>대화창에서 <차림표내용>부분의 <추가>단추를 찰칵합니다.
    4. <지령 추가>대화창이 현시되며 해당한 지령을 선택하고 <추가>단추를 찰칵합니다.

    부분차림표의 추가

    1. <차림표>목록칸에서 부분차림표를 추가하려는 차림표를 선택합니다.
    2. <수정>단추를 찰칵하여 현시되는 튀여나오기차림표에서 <부분차림표 추가>를 찰칵하여 <부분차림표 추가>대화창을 현시합니다.
    3. 대화창의 <부분차림표이름>본문칸에 부분차림표의 이름을 입력하고 <확인>단추를 찰칵합니다. <사용자전용화>대화창의 <지령>목록칸에 부분차림표가 추가됩니다.

    차림표의 수정 및 삭제

    1. <차림표>목록칸에서 수정하려는 차림표를 선택합니다.
    2. <차림표>단추를 찰칵하면 튀여나오기차림표가 현시됩니다.
      • <이동>을 찰칵하여 차림표의 순서를 바꿀수 있습니다.
      • <이름 바꾸기>를 찰칵하여 차림표의 이름을 바꿀수 있습니다.
      • <삭제>를 찰칵하여 차림표를 삭제할수 있습니다.

    차림표지령의 수정

    1. <차림표>목록칸에서 수정하려는 차림표지령을 포함하는 차림표를 선택합니다.
    2. <차림표내용>의 <지령>목록칸에서 필요한 차림표지령을 선택합니다.
    3. 현재 정의되여있는 차림표지령을 수정하려면 <수정>단추를 찰칵하여 튀여나오기차림표를 현시합니다.
      • <이름 바꾸기>를 찰칵하여 차림표지령의 이름을 변경할수 있습니다.
      • <그룹 편집>을 찰칵하여 그룹선을 추가할수 있습니다.
      • <부분차림표 추가>를 찰칵하여 부분차림표를 새로 추가할수 있습니다.
      • <삭제>를 찰칵하여 이 차림표지령을 삭제할수 있습니다.

  4. <사용자전용화>대화창에서 <확인>단추를 찰칵합니다.
