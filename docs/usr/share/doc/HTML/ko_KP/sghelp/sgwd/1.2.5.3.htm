지름건의 할당과 삭제

모두 표시

차림표지령이나 도구띠의 기능지령에 대하여 해당한 지름건을 할당하거나 삭제할수 있습니다.

다음과 같은 방법으로 진행합니다.

  1. <도구>차림표에서 <사용자전용화>를 찰칵합니다.
  2. <사용자전용화>대화창이 화면에 현시됩니다.
  3. <사용자전용화>대화창에서 <건반>표쪽을 찰칵합니다. 여기서 지름건을 할당하거나 삭제할수 있습니다.

    4. 지름건의 할당

    1. <지름건>목록칸에서 건이 아직 할당되지 않은 항목을 선택합니다. 이때 사용불가능으로 된것은 할당할수 없는 지름건이므로 선택할수 없습니다.
    2. 다음 <기능띠>부분의 <종류>목록칸과 <기능>목록칸을 리용하여 할당하려는 기능항목을 선택합니다.
    3. <수정>단추를 찰칵합니다.
    4. 이때 <건>목록칸의 비여있던 기능부분이 채워집니다.
    5. <사용자전용화>대화창의 <확인>단추를 찰칵합니다.

    지름건의 삭제

    1. <지름건>목록칸에서 건이 이미 할당되여있는 항목을 선택합니다. 이때 사용불가능으로 된것은 삭제할수 없는 지름건이므로 선택할수 없습니다.
    2. <삭제>단추를 찰칵합니다.
    3. 이때 <건>목록칸에 할당되여있던 기능부분이 삭제됩니다.
    4. <사용자전용화>대화창의 <확인>단추를 찰칵합니다.
