파일열기

모두 표시

  1. 문서처리프로그람에서 <파일>차림표를 찰칵한 다음 <열기>를 찰칵합니다.
  2. 파일목록칸에서 열려는 파일의 경로를 찾아들어갑니다.
  3. 파일을 선택한 다음 <열기>단추를 찰칵합니다.

파일을 읽기전용으로 열기

  1. 문서처리프로그람에서 <파일>차림표의 <열기>를 찰칵합니다.
  2. 파일목록칸에서 열려는 파일의 경로를 찾아들어갑니다.
  3. 읽기전용으로 열려는 파일을 선택합니다.
  4. <열기>대화창의 맨 아래에 위치하고있는 <읽기전용>확인칸을 선택합니다.
  5. <열기>단추를 찰칵합니다.
