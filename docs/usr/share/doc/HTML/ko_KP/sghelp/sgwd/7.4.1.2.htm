그림자의 추가

모두 표시

그림에 그림자를 추가

  1. 그림자를 적용할 그림을 선택합니다.
  2. <서식>차림표에서 <그림>을 찰칵하거나 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <그림>을 찰칵하여 <그림>대화창을 현시합니다.
  3. <테두리>표쪽을 찰칵합니다.
  4. <그림자격식>령역에서 요구하는 그림자추가선택을 진행합니다.
  5. <확인>단추를 찰칵하여 대화창을 닫습니다.

표에 그림자를 추가

표나 표의 매개 세포에 테두리를 추가하고 그림자를 사용하여 표의 배경을 채울수 있습니다.

또한 표자동서식기능을 사용하면 다양한 테두리, 서체, 그림자로 구성된 표를 쉽게 만들수 있습니다.

  1. 그림자를 적용할 표를 선택합니다.
  2. <표>차림표에서 <표서식>을 찰칵하거나 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <표서식>을 찰칵하여 <표서식>대화창을 현시합니다.
  3. <테두리>표쪽을 찰칵합니다.
  4. <그림자격식>령역에서 요구하는 그림자추가선택을 진행합니다.
  5. <확인>단추를 찰칵하여 대화창을 닫습니다.

본문에 그림자를 추가

테두리를 추가하여 단락이나 선택한 본문을 문서의 나머지부분과 구분할수 있습니다. 또한 그림자를 추가하여 본문을 강조할수도 있습니다.

  1. 그림자를 적용할 본문를 선택합니다.
  2. <서식>차림표에서 <단락>을 찰칵하거나 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <단락>을 찰카하여 <단락>대화창을 현시합니다.
  3. <테두리>표쪽을 찰칵합니다.
  4. <그림자격식>령역에서 요구하는 그림자추가선택을 진행합니다.
  5. <확인>단추를 찰칵하여 대화창을 닫습니다.
