마우스유표를 리용한 표, 행 또는 렬, 세포의 선택

선택할 요소 선택방법
행

행의 왼쪽을 찰칵합니다.
렬

렬의 맨 우의 눈금선이나 테두리를 찰칵합니다.
여러 세포, 행, 렬 요구하는 세포, 행, 렬우로 마우스를 끕니다.
다음세포의 본문 [Tab]건을 누릅니다.
이전세포의 본문 [Shift+Tab]건을 누릅니다.
전체 표

인쇄배치에서 표의 왼쪽웃가장자리에서 마우스유표를 찰칵하거나 전체 표의 우로 마우스를 끕니다.

표도구띠를 리용한 표, 행 또는 렬의 선택

  1. 선택할 표, 행 또는 렬의 임의의 위치를 찰칵합니다.
  2. <표>도구띠의 <표 선택>그림기호, <행 선택>그림기호, <렬 선택>그림기호중에서 요구하는 지령을 찰칵합니다.

차림표를 리용한 표, 행 또는 렬, 세포의 선택

  1. 선택할 표, 행 또는 렬, 세포의 임의의 위치를 찰칵합니다.
  2. <표>차림표에서 <선택>을 찰칵하고 <표>, <행>, <렬>, <세포>중에서 요구하는 지령을 찰칵합니다.
