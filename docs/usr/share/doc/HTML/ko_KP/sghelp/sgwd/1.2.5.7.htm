사용자정의도구띠의 만들기

모두 표시

사용자는 자주 쓰이는 기능들을 하나로 묶어 도구띠를 새롭게 정의할수 있습니다.

다음과 같은 방법으로 진행합니다.

  1. <도구>차림표에서 <사용자전용화>를 찰칵합니다.
  2. <사용자전용화>대화창이 화면에 현시됩니다.
  3. <사용자전용화>대화창에서 <도구띠>표쪽을 찰칵합니다. 여기서 도구띠를 새로 만들고 단추를 추가할수 있습니다.

    4. 도구띠의 새로 만들기

    1. 도구띠를 사용자가 새롭게 정의하려면 <새로 만들기>단추를 찰칵합니다.
    2. <이름>대화창이 현시됩니다.
    3. 도구띠의 이름과 그 보관위치를 입력합니다.
    4. <확인>단추를 찰칵하면 <사용자전용화>대화창의 <도구띠>목록칸에 새로 만들어진 도구띠가 선택됩니다.

    도구띠에 단추추가

    1. 도구띠에 단추를 새로 추가하려는 경우에는 <도구띠내용>부분의 <추가>단추를 찰칵합니다.
    2. <지령 추가>대화창이 현시됩니다.
    3. <종류>목록칸에서 해당한 종류를 선택한 다음 그에 의하여 펼쳐지는 항목들을 <지령>목록칸에서 선택하여 <추가>단추를 찰칵합니다.
    4. 필요한 단추추가가 끝나면 <지령 추가>대화창의 <닫기>단추를 찰칵합니다.
    5. <사용자전용화>대화창에서 <확인>단추를 찰칵합니다.
