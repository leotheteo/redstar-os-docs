에워싸기

지령명 설명
에워싸지 않음 문서에서 에워싸기를 해제합니다.
사면으로 에워싸기 본문으로 객체테두리의 사면을 에워쌉니다.
최적으로 에워싸기 왼쪽으로, 오른쪽으로 또는 객체테두리의 사면에 본문을 자동적으로 배치합니다. 하지만 객체와 페지여백사이의 거리가 2cm미만이면 본문이 배치되지 않습니다.
통과하여 에워싸기 객체를 본문우에 놓습니다. 이때 객체를 배경으로 이동하지 않으면 객체크기만한 령역의 본문이 보이지 않습니다.
배경에 선택한 객체를 배경으로 이동합니다. <통과하여 에워싸기>를 선택한 경우에만 이 추가선택을 사용할수 있습니다.
륜곽 에워싸기 본문으로 객체륜곽을 따라 에워쌉니다. 이 추가선택은 <통과하여 에워싸기>서식이나 틀에서는 사용할수 없습니다.
륜곽 편집 선택한 객체의 륜곽을 변경합니다. 《서광사무처리》 3.0프로그람에서는 객체의 본문감아보내기 추가선택을 결정할 때 륜곽을 사용합니다.
첫 단락 에워싸기 [Enter]건을 누른 다음 객체아래에서 새 단락을 시작합니다.
편집... 에워싸기형식을 지정합니다.

맞추기

지령명 설명
왼쪽 선택된 단락의 본문이나 도형객체들을 왼쪽을 기준으로 맞춥니다.
가로가운데 선택된 단락의 본문이나 도형객체들을 수평가운데를 기준으로 맞춥니다.
오른쪽 선택된 단락의 본문이나 도형객체들을 오른쪽을 기준으로 맞춥니다.
량쪽 선택된 단락의 본문을 왼쪽과 오른쪽을 기준으로 맞춥니다.
웃쪽 선택된 표세포의 본문이나 도형객체들을 웃쪽을 기준으로 맞춥니다.
세로가운데 선택된 표세포의 본문이나 도형객체들을 수직가운데를 기준으로 맞춥니다.
아래쪽 선택된 표세포의 본문이나 도형객체들을 아래쪽을 기준으로 맞춥니다.

배렬

지령명 설명
맨 앞면에로 이동 선택한 객체를 다른 객체들의 맨 앞면에로 이동합니다.
앞면에로 이동 선택한 객체를 한 준위 앞면으로 이동합니다.
뒤면에로 이동 선택한 객체를 한 준위 뒤면으로 이동합니다.
맨 뒤면에로 이동 선택한 객체를 다른 객체들의 맨 뒤면에로 이동합니다.
전경에 선택한 객체를 본문의 앞으로 이동합니다.
배경에 선택한 객체를 본문의 뒤로 이동합니다.

지령명 설명
수직으로 반전 선택한 객체를 수직방향으로 반전합니다.
수평으로 반전 선택한 객체를 수평방향으로 반전합니다.

그룹

지령명 설명
그룹 선택한 객체를 그룹화하여 하나의 객체처럼 이동할수 있습니다.
그룹 해제 선택한 그룹을 매 객체로 분리합니다.

객체

지령명 설명
위치 및 크기 선택한 객체의 크기를 변경하거나 이동 또는 회전하거나 기울입니다.
선 선택한 선의 서식을 설정합니다.
령역 선택한 도형객체의 채우기속성을 설정합니다.
본문 선택한 도형객체나 본문객체에 있는 본문의 배치 및 지탱점의 속성을 설정합니다.
설명 선택한 객체에 대한 설명을 삽입합니다.
이름 선택한 객체의 이름을 입력합니다.
