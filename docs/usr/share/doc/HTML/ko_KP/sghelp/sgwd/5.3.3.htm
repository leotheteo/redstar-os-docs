표에 행 또는 렬의 추가

모두 표시

표도구띠를 리용한 행 또는 렬의 추가

  1. 표에서 추가하려는 위치를 찰칵합니다.
  2. 다음의 방법들중에서 하나를 실행합니다.
    • <표>도구띠에서 <행 삽입>그림기호를 찰칵합니다. 그러면 유표가 있는 행의 아래쪽에 빈 행이 삽입됩니다.
    • <표>도구띠에서 <렬 삽입>그림기호를 찰칵합니다. 그러면 유표가 있는 렬의 오른쪽에 빈 렬이 삽입됩니다.

차림표를 리용한 행 또는 렬의 추가

  1. 표에서 추가하려는 위치를 찰칵합니다.
  2. <표>차림표의 <삽입>에서 <행> 또는 <렬>을 찰칵하여 <행 삽입>대화창 또는 <렬 삽입>대화창을 현시합니다.
  3. <삽입>령역의 <개수>본문칸에 삽입할 행 또는 렬의 개수를 입력합니다.
  4. <위치>령역에서 다음의 방법들중에서 하나를 실행합니다.
    • 현재위치의 앞에 삽입하려면 <앞>단일선택단추를 선택합니다.
    • 현재위치의 뒤에 삽입하려면 <뒤>단일선택단추를 선택합니다.
  5. <확인>단추를 찰칵합니다.
참고: [Tab]건을 리용하여 표의 마지막행의 다음에 빈행을 삽입할수 있습니다. 표의 마지막행의 다음에 빈행을 삽입하려면 마우스유표를 표의 오른쪽아래에 놓고 [Tab]건을 누릅니다.
