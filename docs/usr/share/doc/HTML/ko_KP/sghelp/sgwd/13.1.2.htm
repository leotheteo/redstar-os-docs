문서정보마당의 류형

모두 표시

문서정보마당에는 문서를 작성한 사람과 날자, 문서작성시간 등 문서의 정보와 관련한 정보들을 포함합니다.

문서정보와 관련한 마당의 값들은 대체로 <파일>차림표의 <속성>을 찰칵하여 현시되는 <속성>대화창에 설정되여있는 정보들을 사용합니다.

다음의 마당들을 사용할수 있습니다.

마당류형 의미
개정번호 문서를 개정한 회수가 삽입됩니다. <속성>대화창의 <일반>표쪽의 개정번호표식자에 현시되는 값을 삽입합니다.
마지막인쇄 문서가 마지막으로 인쇄된 날자를 삽입합니다. 문서의 작성자와 시간, 날자 등을 현시할수 있습니다.
사용자정의 사용자가 입력한 정보들이 삽입됩니다. <속성>대화창의 <사용자전용속성>표쪽에서 입력한 정보들을 삽입합니다.
설명 문서에 포함된 설명문을 삽입합니다. <속성>대화창의 <설명>표쪽에서 삽입한 본문이 삽입됩니다.
수정됨 문서의 수정과 관련한 정보들을 삽입할수 있는 마당입니다.
실마리어 문서의 실마리어와 관련한 정보들을 삽입할수 있는 마당입니다. <속성>대화창의 <설명>표쪽에서 입력한 실마리어가 입력됩니다.
작성 문서의 작성과 관련한 정보들을 삽입합니다. 거기에는 문서의 작성자와 작성날자, 작성시간 등이 속합니다.
주제 문서의 주제와 관련한 정보를 삽입합니다. <속성>대화창의 <설명>표쪽에서 입력한 주제내용이 삽입됩니다.
제목 문서의 제목을 삽입합니다. <속성>대화창의 <설명>표쪽에서 삽입한 제목이 삽입됩니다.
총 편집시간 문서가 편집되는데 소비된 총시간을 삽입합니다. 시간현시형식을 지정할수 있습니다.
