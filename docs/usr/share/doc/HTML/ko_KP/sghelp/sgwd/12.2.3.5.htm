련결된 객체를 다시 련결

모두 표시

원본파일을 이동하거나 이름을 바꾸려면 해당 파일과 대상파일사이의 련결을 끊습니다. 대상파일의 객체를 계속 갱신하려면 련결을 다시 설정해야 합니다.

  1. <편집>차림표에서 <련결>을 찰칵하여 <련결 편집>대화창을 현시합니다.
  2. 목록칸에서 다시 련결하거나 변경할 련결된 객체를 찰칵합니다.
  3. <수정>단추를 찰칵합니다.
  4. 다음의 작업들중에서 하나를 진행합니다.
    • 련결된 객체가 기타 파일에서 련결된 객체인 경우 련결하려는 다른 파일이름을 선택합니다.
    • 련결된 객체가 그림삽입에서 련결된 객체인 경우 <그림 련결>대화창에서 요구하는 그림객체를 선택합니다.
  5. <확인>단추를 찰칵하여 <련결 편집>대화창을 닫습니다.
