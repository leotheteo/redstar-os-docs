그림기호 지령명 기능
선 선택한 선의 서식을 설정합니다.
화살표격식 현시된 기호를 사용하여 선택한 선의 끝에 적용할 격식을 정의합니다.
선격식 사용할 선격식을 선택합니다. 사용자정의 선격식을 지정하려면 문서에서 선을 선택하고 <서식>/<객체>/<선>을 선택한 다음 <선격식>표쪽을 찰칵합니다.
선너비 선너비를 선택합니다.
선색 선색을 선택합니다.
령역 선택한 도형객체의 칠하기속성을 설정합니다.
령역격식/색칠 선택한 도형객체에 적용할 칠하기류형을 선택합니다.
회전 선택한 객체를 회전시킵니다.
눈금선 현시 눈금선을 현시하겠는가를 지정합니다.
눈금선에 흡착 눈금점사이에서만 객체를 이동할수 있도록 지정합니다.
이동시 안내선 객체이동시 안내선을 표시하겠는가를 지정합니다.
에워싸지 않음 문서에서 객체를 본문과 구별되게 따로 행에 배치합니다. 문서에서 본문은 객체의 웃쪽과 아래쪽에는 배치되지만 객체의 측면에는 배치되지 않습니다.
사면으로 에워싸기 본문으로 객체테두리의 사면을 에워쌉니다.
최적으로 에워싸기 왼쪽으로, 오른쪽으로 또는 객체테두리의 사면에 본문을 자동적으로 배치합니다. 하지만 객체와 페지여백사이의 거리가 2cm미만이면 본문이 배치되지 않습니다.
왼쪽으로 에워싸기 본문으로 객체의 왼쪽으로부터 웃쪽과 아래쪽을 에워쌉니다.
오른쪽으로 에워싸기 본문으로 객체의 오른쪽으로부터 웃쪽과 아래쪽을 에워쌉니다.
통과하여 에워싸기 객체를 본문우에 놓습니다. 이때 객체를 배경으로 이동하지 않으면 객체크기만한 령역의 본문이 보이지 않습니다.
륜곽 에워싸기 본문으로 객체륜곽을 따라 에워쌉니다. 이 추가선택은 <통과하여 에워싸기>서식이나 틀에서는 사용할수 없습니다.
전경에 선택한 객체를 본문의 앞으로 이동합니다.
배경에 선택한 객체를 본문의 뒤로 이동합니다.
맨 앞면에로 이동 선택한 객체를 다른 객체들의 제일 앞으로 이동합니다.
맨 뒤면에로 이동 선택한 객체를 다른 객체들의 제일 뒤로 이동합니다.
맞추기 선택한 객체의 맞추기를 변경합니다.
지탱점 변경 지탱점을 지정합니다.
그룹 해제 선택한 그룹을 매 객체로 분리합니다.
그룹 선택한 객체를 그룹화하여 하나의 객체처럼 이동할수 있습니다.
