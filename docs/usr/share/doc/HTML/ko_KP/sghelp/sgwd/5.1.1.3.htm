페지방향의 선택

모두 표시

  1. 다음의 방법들중에서 하나를 실행하여 <페지격식>대화창을 현시합니다.
    • <서식>차림표에서 <페지>를 찰칵합니다.
    • 상태띠의 페지격식부분을 두번 찰칵합니다.
  2. <페지>표쪽을 찰칵합니다.
  3. <용지형식>령역의 <방향>에서 <세로> 또는 <가로>단일선택단추중에서 하나를 선택합니다. 이때 <너비>와 <높이>본문칸의 값은 서로 바뀌여집니다.
  4. <확인>단추를 찰칵합니다.

참고: 문서에서 사용할 본문의 방향을 설정하려면 <용지형식>령역의 <본문방향>목록칸에서 본문방향을 선택합니다. 례를 들어 문서에서 본문의 방향을 세로본문이면서 오른쪽에서 왼쪽으로 설정하려면 복합칸에서 <오른쪽에서 왼쪽으로(세로)>를 선택합니다.
