형판의 구성관리

모두 표시

<형판 관리>대화창을 사용하면 형판에 포함되여있는 격식들을 볼수 있으며 형판을 삭제하거나 한 문서의 형판을 다른 문서에 복사할수 있습니다.

다음과 같은 방법으로 진행합니다.

  1. <파일>차림표의 <형판>에서 <관리>를 찰칵하여 <형판 관리>대화창을 현시합니다.
  2. <형판 관리>대화창은 격식을 현시할수 있는 두개의 목록칸을 포함하며 개개의 목록칸밑에는 형판이나 문서를 갈라 현시시킬수 있게 하는 복합칸이 위치하고있습니다.
  3. 왼쪽목록칸은 이미 작성된 형판을 보여주며 오른쪽에는 복사하려는 격식을 포함하고있는 문서로서 <파일>단추를 리용하여 적재할수도 있습니다.

    4. 격식보기

    1. 왼쪽목록칸의 아래에 있는 복합칸에서 <형판>을 선택하면 왼쪽목록칸에는 문서처리프로그람이 포함하고있는 모든 형판들의 구성에 대하여 계층구조형태로 볼수 있습니다.
    2. 필요한 항목을 마우스로 두번 찰칵하면 거기에 포함되여있는 형판들과 형판에 포함되여있는 모든 격식들이 현시됩니다.

    격식복사

    1. <형판 관리>대화창의 <파일>단추를 리용하여 복사할 격식을 포함하고있는 원본문서를 적재합니다. 이때 오른쪽목록칸에 적재된 파일이름이 현시됩니다.
    2. 오른쪽목록칸의 문서파일을 마우스로 두번 찰칵하면 문서에 포함되여있는 격식들이 현시됩니다.
    3. 요구하는 격식을 복사하려면 [Ctrl]건을 누른 상태에서 격식을 끌어줍니다.
    4. <형판 관리>대화창의 <닫기>를 찰칵합니다.

    참고: 격식복사를 진행하려면 격식이 들어있는 문서와 격식을 복사하려는 형판이 모두 열려져 있어야 합니다.
