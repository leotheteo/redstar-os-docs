표의 가르기부분조절

모두 표시

긴 표에서 작업할 때 페지 가르기위치마다 표가 갈라집니다. 기본적으로 긴 행에서 페지가 바뀌면 페지가르기를 통해 행을 두 페지로 가를수 있습니다.

표가 여러 페지로 배치될 때 요구하는 모양으로 정보가 배치되도록 표를 조절할수 있습니다.

페지 가르기에 의해 표가 다음페지로 분리되지 않도록 방지

  1. 표를 선택합니다.
  2. 다음의 방법들중에서 하나를 실행하여 <표서식>대화창을 현시합니다.
    • <표>차림표에서 <표서식>을 찰칵합니다.
    • <표>도구띠에서 <표서식>그림기호를 찰칵합니다.
    • 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <표서식>을 찰칵합니다.
  3. <본문흐름>표쪽을 찰칵합니다.
  4. <본문흐름>령역에서 <페지와 단에 걸쳐 표가르기 허용>확인칸을 선택하고 <페지와 단에 걸쳐 행가르기 허용>확인칸선택을 해제합니다.
  5. <확인>단추를 찰칵합니다.
