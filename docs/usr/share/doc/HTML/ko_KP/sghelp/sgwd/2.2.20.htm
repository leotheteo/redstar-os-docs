모두 표시

그림기호 지령명 기능
격식 적용 현재단락, 선택한 단락 또는 선택한 객체에 격식을 지정합니다. <서식>/<격식 및 서식>에서 더 많은 격식을 사용할수 있습니다.
왼쪽 맞추기 객체를 페지의 왼쪽여백에 맞춥니다.
가로가운데 맞추기 객체를 페지의 가로가운데에 맞춥니다.
오른쪽 맞추기 객체를 페지의 오른쪽에 맞춥니다.
웃쪽 맞추기 객체를 현재지탱점을 기준으로 웃쪽에 맞춥니다. 실례로 지탱점이 페지에 설정되여있으면 페지의 웃쪽여백에 맞추고 단락에 설정되여있으면 단락의 웃쪽에 맞춥니다.
세로가운데 맞추기 객체를 현재지탱점을 기준으로 세로가운데에 맞춥니다. 실례로 지탱점이 페지에 설정되여있으면 페지의 세로가운데에 맞추고 단락에 설정되여있으면 단락의 세로가운데에 맞춥니다.
아래쪽 맞추기 객체를 현재지탱점을 기준으로 아래쪽에 맞춥니다. 실례로 지탱점이 페지에 설정되여있으면 페지의 아래쪽여백에 맞추고 단락에 설정되여있으면 단락의 아래쪽에 맞춥니다.
왼쪽으로 에워싸기 본문을 객체의 왼쪽으로부터 웃쪽과 아래쪽으로 에워쌉니다.
오른쪽으로 에워싸기 본문을 객체의 오른쪽으로부터 웃쪽과 아래쪽으로 에워쌉니다.
에워싸지 않음 문서에서 객체를 본문과 구별되게 따로 행에 배치합니다. 문서에서 본문은 객체의 웃쪽과 아래쪽에는 배치되지만 객체의 측면에는 배치되지 않습니다.
사면으로 에워싸기 본문을 객체테두리의 사면으로 에워쌉니다.
통과하여 에워싸기 객체를 본문우에 놓습니다. 이때 객체를 배경으로 이동하지 않으면 객체크기만한 령역의 본문이 보이지 않습니다.
최적으로 에워싸기 왼쪽으로, 오른쪽으로 또는 객체 테두리틀의 네면 모두에 본문을 자동으로 배치합니다.
틀속성 선택한 틀의 크기, 위치 및 기타 속성을 설정합니다.
맨 앞면에로 이동 선택한 객체를 다른 객체들의 제일 앞면에로 이동합니다.
맨 뒤면에로 이동 선택한 객체를 다른 객체들의 제일 뒤면에로 이동합니다.
지탱점 변경 지탱점을 지정합니다.
테두리 테두리의 네면을 각각 지정합니다.
선격식 선격식을 지정합니다.
테두리색 테두리색을 지정합니다.
