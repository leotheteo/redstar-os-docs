자동적으로 삽입된 빈 페지 인쇄

설정한 경우 자동적으로 삽입된 빈 페지가 인쇄됩니다. 량면인쇄를 하는 경우 이것을 사용하는것이 좋습니다. 례를 들어 책에서 장의 단락격식이 항상 홀수페지로 시작하도록 설정됩니다. 이전 장이 홀수페지로 끝나면 《서광사무처리》 3.0에서 빈 짝수페지를 삽입합니다. 이 추가선택은 삽입된 짝수페지를 인쇄하겠는가 말겠는가를 설정합니다.

인쇄기설정에 따르는 용지공급법

용지함이 여러개인 인쇄기의 경우 인쇄기체계설정에서 지정한 용지함을 사용하도록 지정합니다.

확스

콤퓨터에 확스프로그람을 설치하고 본문문서에서 직접 확스를 보내려면 요구하는 확스기를 선택합니다.
