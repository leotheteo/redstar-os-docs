표의 복사

모두 표시

  1. 다음의 방법들중에서 하나를 실행하여 복사할 표를 선택합니다.
    • 마우스유표를 표의 왼쪽웃모서리로 이동하여 표선택유표()로 바뀌면 찰칵합니다. 이때 <전체 표 선택>이라는 설명문이 현시됩니다.
    • 표의 임의의 위치에서 찰칵하고 <표>차림표의 <선택>에서 <표>를 찰칵합니다.
    • 표의 임의의 위치에서 찰칵하고 <표>도구띠에서 <표 선택>그림기호를 찰칵합니다.

      • 참고: <표>도구띠가 현시되지 않았으면 <보기>차림표의 <도구띠>에서 <표>를 찰칵합니다.

  2. 다음의 방법들중에서 하나를 실행하여 선택한 표를 복사합니다.
    • <편집>차림표에서 <복사>를 찰칵합니다.
    • <표준>도구띠에서 <복사>그림기호를 찰칵합니다.
    • [Ctrl+C]건을 누릅니다.
    • 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <복사>를 찰칵합니다.
  3. 표를 붙이기 할 위치에서 마우스유표를 찰칵합니다.
  4. 다음의 방법들중에서 하나를 실행하여 선택된 위치에 표를 붙입니다.
    • <편집>차림표에서 <붙이기>를 찰칵합니다.
    • <표준>도구띠에서 <붙이기>그림기호를 찰칵합니다.
    • [Ctrl+V]건을 누릅니다.
    • 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <붙이기>를 찰칵합니다.
