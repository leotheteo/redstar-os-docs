문서를 보관할 때 발생하는 문제의 해결

모두 표시

문서처리프로그람형식으로 문서보관

문서를 보관하면 변경내용이 사라지는 경우

자동복구기능을 사용하여 변경내용을 보관했지만 복구파일에 변경내용이 보관되지 않은 경우는 자동복구기능에 의해 문서의 변경내용이 복구파일에 보관되기 전에 문서처리프로그람이 비정상적으로 완료되였기때문입니다. 복구파일에 보관되는 새 정보의 량은 자동보관간격에 따라 달라집니다. 례를 들어 복구파일이 15분마다 보관되는 경우에는 정전이나 그와 류사한 문제가 발생했을 때 최대 15분동안의 작업이 무효로 될수 있습니다. 자동보관간격을 변경하려면 <서광사무처리>차림표의 <환경설정>지령을 찰칵한 다음 <적재 및 보관>에서 <자동복구정보 보관간격>의 <분>증감칸에서 간격을 지정합니다.

파일이 너무 커서 보관할수 없다는 통보문이 현시되는 경우

문서가 너무 커서 보관할수 없는 경우에는 문서를 여러개의 작은 문서로 나눕니다. 문서의 일부를 갈라내여 새 문서에 붙여넣고 매개 파일을 따로 보관합니다.

파일을 보관할 때 구동기용량이나 기억기가 부족하다는 내용의 통보문이 현시되는 경우

파일을 보관할 디스크가 꽉 찼거나 읽기전용일 가능성이 높습니다. 파일열람기로 해당 구동기를 확인하여 파일을 보관하는데 충분한 구동기용량이 있는지 확인하십시오.

또한 해당 서류철이나 구동기가 읽기전용으로 설정되였거나 파일을 보관할수 있는 사용권한이 사용자에게 없을수 있습니다. 이러한 경우에는 해당 관리자나 해당 서류철이나 구동기의 소유자에게 요청하십시오.

사용중인 콤퓨터의 국부구동기가 꽉 찬 경우에는 유연성디스크구동기, 쓰기가능한 CD-ROM구동기 또는 파일을 보관할수 있는 매체보관령역과 같은 그밖의 다른 사용가능한 구동기가 있는지 조작체계를 확인하십시오. 파일을 보관하기 위한 다른 장소가 없는 경우에는 구동기에서 필요없는 파일을 삭제하여 공간을 만들거나 콤퓨터에 다른 구동기를 추가하십시오.

문서이름을 지정하기

보관한 파일이름에 두개의 점이 추가되여있는 경우

문서처리프로그람에서는 파일이름에 일부 문장부호문자(례: 반점, 점)가 포함될수 있습니다. 파일에 점으로 끝나는 이름(례: Sales.)을 지정하면 문서처리프로그람에서 파일이름에 또 다른 점과 기본확장자를 추가합니다. 례를 들어 문서처리프로그람의 이름을 Sales.으로 지정하면 해당 파일의 이름은 Sales..odt로 됩니다. 기본확장자로 파일을 보관할 경우 문서처리프로그람에서 확장자를 붙일 때 자동으로 점을 추가하므로 파일이름의 뒤에 점을 입력할 필요가 없습니다.

확장자는 파일형식을 구분하고 파일을 열 때 사용할 프로그람을 식별하는데 필요합니다.
