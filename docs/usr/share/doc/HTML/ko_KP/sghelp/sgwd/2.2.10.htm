그림기호 지령명 기능
선택 현재문서에서 객체를 선택합니다.
설계방식 적용/해제 설계방식을 적용하거나 해제합니다. 이 기능은 설계방식과 사용자방식사이를 빠르게 절환하는데 사용합니다. 조종체를 편집하려면 활성상태로 만들고 조종체를 사용하려면 비활성상태로 만듭니다.
조종체속성 선택한 조종체의 일반속성과 자료원본 및 사건을 편집하는 속성대화창을 현시합니다.
양식속성 선택한 조종체의 양식에 대한 일반속성과 자료원본 및 사건을 편집하는 속성대화창을 현시합니다.
양식항행기 양식항행기를 현시합니다. 양식항행기에는 현재문서의 모든 양식과 부분양식이 해당 조종체와 함께 현시됩니다.
마당 추가 양식에 추가할 자료기지마당을 선택하는 창을 현시합니다.
활성화순서 <활성화순서>대화창에서는 사용자가 <[Tab]>건을 누를 때 조종체마당에 초점을 두는 순서를 지정합니다.
설계방식에서 열기 닫기하였던 문서를 여는 경우 문서가 양식 설계방식으로 열리도록 설정합니다.
자동조종체초점 자동조종체초점를 활성상태로 만들면 문서를 열 때 첫번째 조종체가 선택됩니다. 단추가 활성상태로 되여있지 않으면 초기에 본문이 선택됩니다. 지정한 활성화순서에 따라 첫번째 조종체가 결정됩니다.
위치 및 크기 선택한 객체의 크기를 변경하거나 이동 또는 회전하거나 기울입니다.
지탱점 변경 지탱점을 지정합니다.
맨 앞면에로 이동 선택한 객체를 다른 객체들의 제일 앞면에로 이동합니다.
맨 뒤면에로 이동 선택한 객체를 다른 객체들의 제일 뒤면에로 이동합니다.
그룹 선택한 객체를 그룹화하여 하나의 객체처럼 이동할수 있습니다.
그룹 해제 선택한 그룹을 매 객체로 분리합니다.
맞추기 선택한 객체의 맞추기를 변경합니다.
눈금선 현시 눈금선을 현시하겠는가를 지정합니다.
눈금선에 흡착 눈금점사이에서만 객체를 이동할수 있도록 지정합니다.
이동시 안내선 객체이동시 안내선을 현시하겠는가를 지정합니다.
