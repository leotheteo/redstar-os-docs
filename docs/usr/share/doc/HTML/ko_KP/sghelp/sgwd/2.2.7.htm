모두 표시

그림기호 지령명 기능
표 표를 문서에 삽입합니다. 도구띠에서 표그림기호의 옆에 있는 화살표를 찰칵하여 행과 렬개수를 선택한 다음 표를 삽입할수도 있습니다.
선격식 선격식을 지정합니다.
테두리색 테두리색을 지정합니다.
테두리 테두리의 네면을 각각 지정합니다.
배경색 배경색을 지정합니다. 이 색은 현재단락이나 선택한 단락의 배경에 적용됩니다.
세포 합치기 선택한 표세포의 내용을 한 세포로 결합합니다.
세포 가르기 입력한 세포수만큼 세포나 세포그룹을 수평이나 수직으로 가릅니다.
최적화 표에서 행과 렬을 최적화하는 기능이 포함되여있는 도구띠를 현시합니다.
웃쪽 세포내용을 세포의 웃쪽테두리에 맞춥니다.
세로가운데 세포내용을 세포의 세로가운데에 맞춥니다.
아래쪽 세포내용을 세포의 아래쪽테두리에 맞춥니다.
행 삽입 표에서 유표위치의 아래쪽에 한행을 삽입합니다.
렬 삽입 표에서 유표위치의 오른쪽에 한렬을 삽입합니다.
행 삭제 표에서 선택한 행을 삭제합니다.
렬 삭제 표에서 선택한 렬을 삭제합니다.
표 선택 현재표를 선택합니다.
렬 선택 유표를 포함하는 렬을 선택합니다.
행 선택 행유표를 포함하는 행을 선택합니다.
자동서식 표의 자동서식을 지정합니다.
표서식 이름, 맞추기, 간격, 렬너비, 테두리, 배경 등과 같이 선택한 표에 대한 서식을 지정합니다.
정렬 선택한 단락 또는 표의 행을 자모순서나 수자순서로 정렬합니다.
합계 수식본문칸에서 합계함수를 입력할수 있는 상태로 만듭니다. 합계를 계산할 세포에 유표를 놓아야 합니다.
