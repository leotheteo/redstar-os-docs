웨브페지파일

모두 표시

문서처리프로그람에서는 문서를 웨브페지파일형식으로 보관할 때 특정한 속성을 설정하여 웨브열람기에서 여러가지 효과가 현시되게 할수 있습니다.

례를 들어 문서처리프로그람에서 작성한 웨브페지를 웨브열람기에서 열 때 후에 특정한 령역의 그림은 일정한 시간이 지난후에 보여주도록 설정할수 있습니다.

다음을 실행합니다.

  1. <파일>차림표의 <속성>을 찰칵합니다.
  2. <인터네트>표쪽을 찰칵합니다.
  3. 다음의 방법들중에서 하나를 실행합니다.
    • 자동적으로 갱신하지 않음:   웨브페지문서를 문서처리프로그람에서 변경할 때 웨브열람기에서 이 웨브페지가 자동적으로 갱신되지 않습니다. 만일 수동으로 문서를 갱신하려면 웨브열람기에서 <갱신>지령을 실행합니다. 여기서 알아두어야 할것은 문서처리프로그람에서 웨브페지문서를 변경하고 반드시 <보관>지령을 실행하여야 웨브열람기에 갱신된 내용이 반영된다는것입니다.
    • 이 문서 갱신:   이 항목을 선택하면 <설정시간>증감칸이 사용가능하게 되는데 거기에 입력한 시간간격으로 웨브페지문서를 웨브열람기가 자동적으로 갱신합니다. 여기서도 <보관>지령을 실행하여야 웨브열람기에 갱신된 내용이 반영됩니다.

    • 이 문서로부터 다시 전송:   이 항목을 선택하면 <설정시간>증감칸에 입력한 시간이 지난 후에 지정한 페지를 웨브열람기에 적재합니다.

      <URL로>본문칸에 적재할 파일의 URL주소를 입력하거나 본문칸옆의 단추를 찰칵하여 현시되는 <열기>대화창에서 파일을 선택합니다.

      <틀에>목록칸에서는 파일을 적재할 목표틀의 이름을 선택합니다.

      기본값들의 의미는 다음의 표와 같습니다.

      • 기본값 의미
      _self 현재틀에 파일이 열립니다.
      _blank 빈 새 틀에 파일이 열립니다.
      _parent 웃틀에 파일이 열립니다.
      _top 계층에서 제일 웃틀에 파일이 열립니다.
