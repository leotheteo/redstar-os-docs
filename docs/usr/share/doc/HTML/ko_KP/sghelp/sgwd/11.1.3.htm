하이퍼련결의 변경

모두 표시

다음의 방법들중에서 요구하는 방법을 실행합니다.

하이퍼련결의 대상변경

  1. 변경할 하이퍼련결본문을 선택합니다.
  2. <표준>도구띠의 <하이퍼련결>그림기호를 찰칵하거나 <편집>차림표의 <하이퍼련결>을 찰칵하여 <하이퍼련결>대화창을 현시합니다.
  3. <하이퍼련결>대화창에서 련결대상의 경로와 대상을 변경합니다.
  4. <적용>단추를 찰칵한 다음 <확인>단추를 찰칵하여 대화창을 닫습니다.

하이퍼련결의 련결본문변경

  1. 변경할 하이퍼련결본문을 선택합니다.
  2. <표준>도구띠의 <하이퍼련결>그림기호를 찰칵하거나 <편집>차림표의 <하이퍼련결>을 찰칵하여 <하이퍼련결>대화창을 현시합니다.
  3. <기타 설정>령역의 <본문>본문칸에서 하이퍼련결본문을 입력합니다.
  4. <적용>단추를 찰칵한 다음 <확인>단추를 찰칵하여 대화창을 닫습니다.

참고: 하이퍼련결본문을 직접 변경할수도 있습니다.

하이퍼련결본문을 일반본문으로 변경

하이퍼련결본문을 선택하고 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <하이퍼련결 제거>를 찰칵합니다.
