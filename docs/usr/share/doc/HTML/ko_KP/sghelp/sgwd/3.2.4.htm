파일변환에서 발생하는 문제의 해결

모두 표시

파일의 열기 및 보관

<열기>대화창에 요구하는 파일형식이 없는 경우

  • <파일형식>목록칸에서 선택한 파일형식이 맞는지 확인합니다.
  • 파일이 여전히 현시되지 않으면 <열기>대화창에서 다른 서류철을 찰칵하여 찾습니다.

기존판본의 문서처리프로그람에서 만든 문서를 문서처리프로그람에서 열 때

기존판본의 문서처리프로그람 1.0에서 만든 문서를 문서처리프로그람에서 직접 열수 있습니다. 문서처리프로그람 1.0에서 작성된 모든 자료와 서식은 문서처리프로그람에서 완벽하게 지원됩니다.

서식의 설정

본문은 제대로 변환되였지만 그림이 사라졌을 때

  • 그림현시를 설정했는지 확인합니다.
    1. <서광사무처리>차림표에서 <환경설정>을 찰칵하여 <환경설정>대화창을 현시합니다.
    2. <서광사무처리 문서처리프로그람>의 <보기>를 찰칵합니다.
    3. <현시>령역의 <그림과 객체>확인칸을 선택합니다.
    4. <확인>단추를 찰칵하여 대화창을 닫습니다.
  • 필요한 그림려과기를 설치했는지 확인합니다.
    1. <삽입>차림표의 <그림>에서 <파일로부터>를 찰칵하여 <그림 삽입>대화창을 현시합니다.
    2. <파일형식>목록칸에서 려과기목록을 확인합니다.
  • 목록에 필요한 려과기가 없으면 설치하여야 합니다.

변환된 문서의 서체가 다르게 현시될 때

다른 문서편집기에서 만든 문서안에서 리용된 서체들중의 일부가 현재체계에 설치되여있지 않을수 있습니다. 문서처리프로그람에서 해당 문서를 열면 체계에 설치되여있는 서체로 대치합니다. 대치할 서체를 조절하려면 <서광사무처리>차림표에서 <환경설정>을 찰칵하고 <서광사무처리>의 <서체>를 찰칵한 다음 요구하는 추가선택을 진행합니다.

선택한 내용은 문서처리프로그람에서 작업하는동안 문서현시방법에만 영향을 주며 문서가 영구변경되지는 않습니다.
