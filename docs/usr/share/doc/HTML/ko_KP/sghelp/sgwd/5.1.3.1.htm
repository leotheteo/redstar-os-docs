행번호의 현시

모두 표시

문서처리프로그람에서는 문서의 행수를 자동적으로 계산하여 매개 본문행의 옆에 행번호를 현시할수 있습니다. 이 기능은 문서에서 특정한 행을 참조할 때 유용합니다.

행번호는 문서처리프로그람체계와 관련되는 내용입니다. 즉 문서의 내용에는 아무러한 영향도 주지 않습니다.

기본적으로 문서처리프로그람에서는 문서에서 표, 각주와 본문끝주, 본문칸, 틀, 머리부 및 바닥부를 제외한 모든 행마다 번호가 매겨집니다.

문서전체 또는 일부에 행번호를 추가하거나 특정한 간격(례: 10, 20, 30 등)에 따라 행번호가 매겨지도록 지정할수도 있습니다.

전체 문서에 행번호추가

  1. <도구>차림표의 <행번호>를 찰칵하여 <행번호>대화창을 현시합니다.
  2. <행번호 현시>확인칸을 선택합니다.
  3. 요구하는 추가선택을 진행합니다.
  4. <확인>단추를 찰칵합니다. 그러면 행번호가 현시됩니다.

페지별로 행번호추가

  1. 번호를 추가할 페지를 선택합니다.
  2. <도구>차림표의 <행번호>를 찰칵하여 <행번호>대화창을 현시합니다.
  3. <행번호 현시>확인칸을 선택합니다.
  4. <계수>령역에서 <페지마다 다시 시작>확인칸을 선택합니다.
  5. <확인>단추를 찰칵합니다.

단락에 행번호추가

  1. 번호를 추가할 단락을 찰칵합니다.
  2. <서식>차림표의 <단락>을 찰칵하여 <단락>대화창을 현시합니다.
  3. <항목번호>표쪽을 찰칵합니다.
  4. <행번호>령역에서 <이 단락에서 다시 시작>확인칸을 선택합니다.
  5. <시작번호>를 입력합니다.
  6. <확인>단추를 찰칵합니다.

참고: 단락에 행번호를 추가하려면 먼저 행번호를 적용하여야 합니다.
