전자우편으로 문서를 보낼 때 발생하는 문제의 해결

모두 표시

동작하는 전자우편구성을 찾을수 없다는 통보문이 련시되면서 우편을 보낼수 없는 경우

조작체계에 Kmail과 같은 전자우편의뢰기가 설치되여있지 않기때문에 현시되는 통보문입니다.

이때에는 전자우편의뢰기를 설치하고 해당한 전자우편구성을 설정하여야 합니다.

  1. 전자우편의뢰기를 설치합니다.
  2. <서광사무처리>차림표의 <환경설정>을 찰칵하여 <환경설정>대화창을 현시합니다.
  3. <인터네트>의 <전자우편>을 찰칵합니다.
  4. <전자우편프로그람>본문칸옆의 단추를 찰칵한 다음 알맞는 전자우편의뢰기프로그람(례: Mail)을 선택합니다.
  5. <확인>단추를 찰칵하여 대화창을 닫습니다.
