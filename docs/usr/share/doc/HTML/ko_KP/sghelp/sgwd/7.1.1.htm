본문과 도형객체의 선택

마우스나 건반을 사용하여 서로 린접하거나 린접하지 않은 본문과 객체를 선택할수 있습니다. 례를 들어 1페지에 있는 단락과 3페지에 있는 문장을 선택할수 있습니다.

문서처리프로그람에는 표의 항목, 도형객체를 선택하는 그밖의 다른 방법도 제공되여있습니다.

서로 린접하지 않은 항목의 선택

  1. 표세포나 단락 등 첫번째 항목을 선택합니다.
  2. [Ctrl]건을 누른채 요구하는 다른 항목을 선택합니다.

마우스로 본문과 도형객체를 선택

선택대상 선택방법
본문 본문의 우로 마우스를 끕니다.
단어 해당 단어를 두번 찰칵합니다.
문장 선택할 문장의 임의의 곳에서 세번 찰칵합니다.
단락 선택할 단락의 임의의 곳에서 세번 찰칵합니다.
여러 단락 시작단락의 왼쪽끝을 찰칵한 다음 우나 아래로 끕니다.
본문블로크 선택할 령역의 시작위치를 찰칵하고 [Shift]건을 누른채 선택할 령역의 끝위치를 찰칵합니다.
문서전체 <편집>차림표의 <모두선택>을 찰칵합니다.
머리부 또는 바닥부 <삽입>차림표의 <머리부> 또는 <바닥부>를 찰칵하거나 인쇄배치에서 회색의 머리부 또는 바닥부본문을 두번 찰칵합니다. 본문의 선택방법은 우와 같습니다.
각주 또는 본문끝주 각주 또는 본문끝주의 본문을 찰칵합니다. 각주 또는 본문끝주본문의 선택은 일반 본문선택과 같습니다.
도형객체 도형객체를 찰칵합니다.
본문칸이나 틀 본문우나 테두리를 찰칵하여 크기조절꼭지를 현시합니다.

건반으로 본문을 선택

[Shift]건을 누른채 유표이동건을 눌러 본문을 선택합니다.

선택령역의 확장

건반조작 실행내용
Shift+오른쪽이동건 한글자의 오른쪽으로
Shift+왼쪽이동건 한글자의 왼쪽으로
Ctrl+Shift+오른쪽이동건 단어의 끝까지
Ctrl+Shift+왼쪽이동건 단어의 시작위치까지
Shift+End 행의 끝으로
Shift+Home 행의 시작위치로
Shift+아래쪽이동건 아래쪽의 한행
Shift+웃쪽이동건 웃쪽의 한행
Shift+Page Down 한화면의 아래쪽으로
Shift+Page Up 한화면의 웃쪽으로
Ctrl+A 문서전체

참고: 유표이동건의 조합을 알면 일반적으로 [Shift]건을 누른채 같은 건조합을 사용하여 본문을 선택할수 있습니다. 례를 들어 유표위치에서 다음단어의 시작위치까지 본문을 선택하려면 [Ctrl+Shift+오른쪽이동건]을 누릅니다.

마우스로 표의 항목을 선택

선택대상

선택대상 선택방법
세포 선택하려는 세포를 찰칵하고 <표>차림표의 <선택>에서 <세포>를 찰칵합니다.
행

행의 왼쪽을 찰칵합니다.
렬

렬의 맨 우의 눈금선이나 테두리를 찰칵합니다.
여러 세포, 행, 렬 요구하는 세포, 행, 렬우로 마우스를 끕니다.
전체 표

인쇄배치에서 표의 왼쪽웃가장자리에서 마우스유표를 찰칵하거나 전체 표의 우로 마우스를 끕니다.

참고: 표를 찰칵하고 <표>차림표의 <선택>지령이나 <표>도구띠의 선택지령들, 건반지름건을 사용하여 행, 렬, 표전체를 선택할수 있습니다.

건반으로 표의 항목을 선택

조작방법 실행내용
Tab 다음세포에로 유표를 이동
Shift+Tab 이전세포에로 유표를 이동
Shift건을 누른채 이동건을 반복해서 누릅니다.

린접한 세포로 선택범위를 확장.

한 세포를 선택하고 [Tab]건을 반복해서 눌러도 린접한 세포에로 선택범위를 확장할수 있습니다.
선택할 렬의 맨 웃쪽이나 맨 아래쪽의 세포를 찰칵합니다. [Shift]건을 누른채 웃쪽이동건이나 아래쪽이동건을 반복해서 누릅니다. 렬을 선택

건반으로 도형객체를 선택

유표가 문서의 본문안에 있는 경우

  1. F6건을 눌러 도구띠를 활성화합니다.
  2. <도형>도구띠의 <선택>그림기호가 활성화될 때까지 [Tab]건을 누릅니다.
  3. 첫번째 도형객체를 선택하려면 [Ctrl+Enter건]을 누릅니다.
  4. <도형>도구띠를 비활성화하려면 [Esc]건을 누릅니다.
  5. 요구하는 객체가 선택될 때까지 앞쪽으로 이동하려면 [Tab]건을 누르고 뒤쪽으로 이동하려면 [Shift+Tab]건을 누릅니다.

유표가 도형객체의 본문안에 있는 경우

  1. [Esc]건을 눌러 본문편집을 끝냅니다.
  2. 요구하는 객체가 선택될 때까지 앞쪽으로 이동하려면 [Tab]건을 누르고 뒤쪽으로 이동하려면 [Shift+Tab]건을 누릅니다.

참고: 객체선택에서 본문편집상태로 전환하려면 [Enter]건을 누릅니다.
