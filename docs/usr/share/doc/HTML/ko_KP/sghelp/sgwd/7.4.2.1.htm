테두리의 변경

모두 표시

페지의 테두리를 변경

  1. <서식>차림표에서 <페지>를 찰칵하거나 문서의 임의곳을 마우스의 오른쪽단추로 찰칵하여 현시되는 상황차림표에서 <페지>를 찰칵하여 <페지격식>대화창을 현시합니다.
  2. <테두리>표쪽을 찰칵합니다.
  3. 요구하는 추가선택을 변경합니다.
  4. <확인>단추를 찰칵하여 대화창을 닫습니다.

참고: 인쇄배치에서 문서를 보면 화면에서 페지의 테두리를 볼수 있습니다.

그림이나 표, 본문의 테두리를 변경

  1. 테두리를 변경할 그림이나 표, 본문을 선택합니다.
  2. 그림이나 본문인 경우에는 <서식>차림표에서 <그림> 또는 <단락>을 찰칵하고 표인 경우에는 <표>차림표의 <표서식>을 찰칵하여 해당한 <표서식>대화창을 현시합니다.
  3. <테두리>표쪽을 찰칵합니다.
  4. 요구하는 추가선택을 변경합니다.
  5. <확인>단추를 찰칵하여 대화창을 닫습니다.

    6. 참고: 복잡한 표의 여러 부분의 테두리를 변경하려면 <표>도구띠를 사용합니다.
