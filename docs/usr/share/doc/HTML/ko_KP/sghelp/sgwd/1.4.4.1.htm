문서보관 방법

모두 표시

문서를 보관하려면 <표준>도구띠에서 <보관>을 찰칵합니다. 문서를 다른 위치에 보관하거나 다른 형식으로 보관하려면 다음과 같이 합니다.

파일복사본을 보관하기

  1. <파일>차림표에서 <다른 이름으로 보관>을 찰칵합니다.
  2. <새로 보관>본문칸에 새 파일이름을 입력합니다.
  3. <보관>단추를 찰칵합니다.

참고: 복사본을 다른 서류철에 보관하려면 파일목록칸에서 다른 서류철을 선택합니다.

파일을 다른 형식으로 보관

  1. <파일>차림표에서 <다른 이름으로 보관>을 찰칵합니다.
  2. <새로 보관>본문칸에 새 파일의 이름을 입력합니다.
  3. <파일형식>복합칸을 찰칵하고 파일을 보관할 파일형식을 선택합니다.
  4. <보관>단추를 찰칵합니다.

복구정보를 자동으로 보관

  1. <서광사무처리>차림표에서 <환경설정>을 찰칵한 다음 <적재 및 보관>을 찰칵합니다.
  2. <일반>을 찰칵합니다.
  3. <자동복구정보 보관간격>확인칸을 선택합니다.
  4. <분>증감칸에 파일보관간격을 입력합니다. 보관간격이 짧을수록 파일작업 진행중에 전원이 끊기거나 이와 류사한 문제가 발생하더라도 더 많은 정보를 복구할수 있습니다.

참고: 파일자동복구기능을 사용하는것과 주기적으로 보관하는것은 다릅니다. 문서처리프로그람에서 파일을 연후 복구파일을 보관하지 않으면 파일이 삭제되고 보관되지 않은 변경내용은 잃게 됩니다. 복구파일을 보관하는 경우 새로운 파일이름을 지정하지 않는 한 원래문서에 덧쓰기를 진행합니다.
