객체위치의 지탱점지정

모두 표시

기준위치를 사용하여 객체, 그림 또는 틀을 문서에 배치할수 있습니다. 문서를 수정하면 고정된 객체는 제자리에 있거나 이동됩니다. 다음 지탱점추가선택을 사용할수 있습니다.

지탱점 작용
문자로

선택한 객체를 현재본문에서 문자로 고정합니다. 선택한 객체의 높이가 현재서체크기보다 크면 객체가 있는 행의 높이는 커집니다.

HTML페지에서 그림을 가운데에 맞추려면 그림을 삽입하고 《문자로》 고정한 다음 단락을 가운데에 맞춥니다.
문자에 선택한 객체를 문자에 고정합니다.
단락에 선택한 객체를 현재단락에 고정합니다.
페지에 선택한 객체를 현재페지에 고정합니다.

도형객체, 그림 또는 틀을 삽입하면 객체가 고정된 위치에 지탱점그림기호가 현시됩니다. 객체를 다른 위치로 끌어서 고정된 객체를 배치할수 있습니다. 객체의 지탱점추가선택을 변경하려면 마우스의 오른쪽단추로 객체를 찰칵한 다음 <지탱점>을 선택하고 부분차림표에서 요구하는 지탱점형식을 선택합니다.
