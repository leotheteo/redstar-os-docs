단추의 그림기호변경

모두 표시

도구띠의 단추에 이미 할당되여있는 그림기호를 사용자의 요구에 맞게 바꿀수 있습니다.

다음과 같은 방법으로 진행합니다.

  1. <도구>차림표에서 <사용자전용화>를 찰칵합니다.

  2. <사용자전용화>대화창이 화면에 현시됩니다.

  3. <사용자전용화>대화창에서 <도구띠>표쪽을 찰칵합니다.

  4. <도구띠>목록칸에서 그림기호를 바꾸려는 단추가 포함되여있는 도구띠를 선택합니다. <도구띠내용>부분의 <지령>목록칸에 우에서 선택한 도구띠에 포함되여있는 단추들이 현시됩니다.

  5. <지령>목록칸에서 그림기호를 바꾸려는 항목을 선택합니다.

  6. <수정>단추를 찰칵하면 튀여나오기차림표가 현시되는데 여기서 <그림기호 변경>을 찰칵합니다.

  7. <그림기호 변경>대화창이 현시되며 <그림기호>목록칸에 선택가능한 그림기호들이 현시됩니다. 만일 <그림기호>목록칸에 적당한 그림기호가 없으면 <반입>단추를 찰칵하여 다른 위치의 그림기호를 반입하여 사용할수 있습니다.

  8. 필요한 그림기호를 선택한 다음 <확인>단추를 찰칵합니다.
