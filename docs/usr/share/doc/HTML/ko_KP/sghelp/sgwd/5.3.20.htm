표의 세포참조

모두 표시

표에서 계산을 수행하면 A1, A2, B1, B2 등으로 표세포를 참조하게 됩니다. 여기서 문자는 렬을 나타내고 수자는 행을 나타냅니다. 표처리프로그람의 세포참조와 달리 문서처리프로그람의 세포참조는 항상 절대참조이므로 기호《$》가 사용되지 않습니다. 례를 들어 문서처리프로그람에서 A1로 세포를 참조하면 표처리프로그람에서 $A$1로 세포를 참조하는것과 같습니다.

매개 세포의 참조

수식에서 세포를 참조하려면 지정한 범위내의 첫 세포와 마지막세포를 구분할 때에는 두점을 사용하고 합계나 평균을 계산할 때에는 더하기기호를 사용합니다. 다음례를 참고하십시오.

평균을 계산할 세포

선택형식 계산방식
=mean<B1:B3>
=mean<A1:B2>
=mean<A1:C2>
=mean<A1>+<A3>+<C2>

다른 표의 세포참조

다른 표의 세포를 참조하거나 표외부의 세포를 참조하려면 =mean<표2.B1: 표2.B3>과 같은 형식으로 입력합니다.
