형판의 만들기

모두 표시

새 문서를 만들 때 기초로 사용할수 있는 형판을 작성합니다.

다음의 방법들중에서 하나를 실행합니다.

구성항목으로 등록되는 형판의 새로 작성

  1. 빈 문서를 새로 만들고 거기에 필요한 내용과 격식을 추가합니다.
  2. <파일>차림표의 <형판>에서 <보관>을 찰칵합니다.
  3. <새 형판>본문칸에 새로 작성하려는 형판의 이름을 입력합니다.
  4. <종류>목록칸에서 새로 작성하는 형판이 포함될 종류항목을 선택합니다.
  5. <확인>단추를 찰칵합니다.

파일보관방법을 리용한 형판의 새로 작성

  1. 빈 문서를 새로 만들고 거기에 필요한 내용과 격식을 추가합니다.
  2. <파일>차림표에서 <보관>을 찰칵합니다. 만일 이미 작성된 문서인 경우에는 <다른 이름으로 보관>을 찰칵합니다.
  3. 파일목록칸에서 보관할 위치를 지정합니다.
  4. <파일형식>복합칸에서 <ODF 본문문서형판 (.ott)>을 선택합니다.
  5. <새로 보관>본문칸에 새로 작성하려는 형판의 이름을 입력합니다.
  6. <보관>단추를 찰칵합니다.

기존형판의 수정 혹은 기존문서로 형판의 만들기

  1. 다음의 방법들중에서 하나를 실행하여 기존형판이나 기존문서를 엽니다.

    2. 기존형판의 열기

    1. 다음의 방법들중에서 하나를 실행하여 <열기>대화창을 현시합니다.
      • <파일>차림표에서 <열기>를 찰칵합니다.
      • <파일>차림표의 <형판>에서 <편집>을 찰칵합니다.
      • <표준>도구띠에서 <열기>그림기호를 찰칵합니다.
      • [Ctrl+O]건을 누릅니다.
    2. 요구하는 형판을 선택합니다.
    3. <열기>단추를 찰칵하여 대화창을 닫습니다.

    참고: <열기>대화창에서 <읽기전용>확인칸을 선택하고 형판을 열면 열린 파일안에서 본문의 추가 및 삭제작업을 비롯하여 변경작업을 진행할수 없습니다.

    기존문서의 열기

    1. <파일>차림표의 <새로 만들기>를 찰칵하고 <형판 및 문서>를 찰칵하여 <형판 및 문서>대화창을 현시합니다.
    2. 대화창의 왼쪽령역에서 <형판> 또는 <나의 문서>를 찰칵합니다.
    3. <제목>목록칸에서 요구하는 파일이름을 선택하고 <열기>단추를 찰칵하여 문서를 엽니다.
  2. <파일>차림표에서 <다른 이름으로 보관>을 찰칵합니다.
  3. <파일형식>목록칸에서 <ODF 본문문서형판 (.ott)>을 선택합니다.
  4. <새로 보관>본문칸에 새 형판의 이름을 입력하고 <보관>단추를 찰칵합니다.
  5. 새 형판에서 형판을 기준으로 만든 새 문서전체에 현시된 본문과 그림 등을 추가하고 현시되지 않은 항목은 삭제합니다.
  6. 여백설정, 페지크기와 방향, 격식, 기타 서식을 바꿉니다.
  7. 다음의 방법들중에서 하나를 실행하여 파일의 보관을 진행합니다.
    • <파일>차림표에서 <보관>을 찰칵합니다.
    • <표준>도구띠에서 <보관>그림기호를 찰칵합니다.
    • [Ctrl+S]건을 누릅니다.
  8. <파일>차림표에서 <닫기>를 찰칵합니다.
