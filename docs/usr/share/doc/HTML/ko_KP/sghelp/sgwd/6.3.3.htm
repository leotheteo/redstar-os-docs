류사한 탐색

모두 표시

<탐색 및 치환>대화창에서 <류사 탐색>확인칸을 선택하면 <탐색대상>본문과 비슷한 단어를 찾을수 있습니다. 례를 들어 <탐색대상>본문과 두 문자가 다른 단어를 찾을수 있습니다.

<류사 탐색>확인칸을 선택하고 오른쪽옆의 단추를 찰칵하면 <류사 탐색>대화창이 현시됩니다.

설정항목들의 의미는 다음과 같습니다.

  • 문자 교환

    • 탐색단어에서 치환할수 있는 문자수를 입력합니다. 례를 들어 2를 입력하면 《black》와 《crack》는 비슷한 단어로 인식됩니다.

  • 문자 추가

    • 본문안의 단어가 탐색단어의 문자수를 초과할 경우 허용되는 최대문자수를 입력합니다. 례를 들어 2를 입력하면 《black》와 《blacket》는 비슷한 단어로 인식됩니다.

  • 문자 제거

    • 본문안의 단어가 탐색단어의 문자수보다 짧을 경우 허용되는 최소문자수를 입력합니다. 례를 들어 2를 입력하면 《black》와 《ack》는 비슷한 단어로 인식됩니다.

  • 조합

    • 우의 설정들의 조합으로 단어를 탐색합니다.
