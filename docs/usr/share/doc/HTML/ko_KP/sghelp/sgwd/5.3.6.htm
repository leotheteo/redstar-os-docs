표의 삭제

모두 표시

표도구띠를 리용한 표, 행 또는 렬의 삭제

  1. 삭제할 행 또는 렬의 임의의 세포를 찰칵합니다.
  2. <표>도구띠에서 다음의 방법들중에서 하나를 실행합니다.
    • 행을 삭제하려면 <표>도구띠에서 <행 삭제>그림기호를 찰칵합니다.
    • 렬을 삭제하려면 <표>도구띠에서 <렬 삭제>그림기호를 찰칵합니다.

참고: 표를 삭제하려면 표전체를 선택하고 표도구띠에서 <행 삭제>그림기호 또는 <렬 삭제>그림기호를 찰칵합니다.

차림표를 리용한 표, 행 또는 렬의 삭제

  1. 삭제할 표, 행 또는 렬을 선택합니다.
  2. <표>차림표에서 <삭제>를 찰칵하고 <표>, <행>, <렬>중에서 요구하는 지령을 찰칵합니다.
