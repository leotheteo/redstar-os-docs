문서의 변환

모두 표시

기정파일형식을 다른 파일형식으로 변환

  1. <파일>차림표에서 <열기>를 찰칵하여 <열기>대화창을 현시합니다.
  2. <파일형식>목록칸에서 열려는 파일의 형식을 찰칵합니다.
  3. 열려는 파일을 선택한 다음 <열기>단추를 찰칵하여 대화창을 닫습니다.
  4. 필요한 문서편집을 진행합니다.
  5. 변경된 파일을 보관하기 위하여 <파일>차림표에서 <다른 이름으로 보관>을 찰칵하여 <보관>대화창을 현시합니다.
  6. <파일형식>목록칸에서 변환할 파일형식을 선택하고 <보관>단추를 찰칵하여 대화창을 닫습니다.

참고:

  • 문서를 서식화된 본문(.rtf)로 보관하면 다른 여러 프로그람에서 열수 있습니다.
  • 자주 사용하는 파일형식변환기는 문서처리프로그람과 함께 표준으로 설치됩니다. 표준으로 설치되지 않은 형식으로 열거나 보관하려면 다른 파일형식변환기를 설치해야 합니다.
