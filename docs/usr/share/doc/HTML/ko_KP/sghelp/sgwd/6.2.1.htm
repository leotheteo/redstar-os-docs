본문과 객체의 이동 또는 복사

모두 표시

한 항목의 이동 또는 복사

  1. 이동하거나 복사할 항목을 선택합니다.
  2. 다음의 방법들중에서 하나를 실행하여 이동하거사 복사할 항목을 자르거나 복사합니다.
    • 항목을 이동하려면 다음의 방법들중에서 하나를 실행합니다.
      • <편집>차림표에서 <자르기>를 찰칵합니다.
      • 마우스오른쪽단추를 찰칵하여 현시되는 상황차림표에서 자르기를 찰칵합니다.
      • <표준>도구띠에서 <자르기>그림기호를 찰칵합니다.
      • [Ctrl+X]건을 누릅니다.
    • 항목을 복사하려면 다음의 방법들중에서 하나를 실행합니다.
      • <편집>차림표에서 <복사>를 찰칵합니다.
      • 마우스오른쪽단추를 찰칵하여 나오는 상황차림표에서 <복사>를 찰칵합니다.
      • <표준>도구띠에서 <복사>그림기호를 찰칵합니다.
      • [Ctrl+C]건을 누릅니다.
  3. 항목을 다른 문서로 이동하거나 복사하려면 해당 문서로 전환합니다.
  4. 항목을 나타낼 위치를 찰칵합니다.
  5. 다음의 방법들중에서 하나를 실행하여 붙이기를 진행합니다.
    • <편집>차림표에서 <붙이기>를 찰칵합니다.
    • 마우스오른쪽단추를 찰칵하여 현시되는 상황차림표에서 붙이기를 찰칵합니다.
    • <표준>도구띠에서 <붙이기>그림기호를 찰칵합니다.
    • [Ctrl+V]건을 누릅니다.

여러 항목의 이동 및 복사
