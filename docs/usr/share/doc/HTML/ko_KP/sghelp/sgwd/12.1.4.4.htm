사용자가 문서처리프로그람에서 완성하는 양식의 만들기

모두 표시

문서처리프로그람에서 사용할 양식을 만들려면 다음의 조작을 실행합니다.

  1. 형판을 만듭니다.

    2. 방법

    1. 새 문서를 시작하거나 형판의 기준문서 또는 형판을 엽니다.
    2. <파일>차림표에서 <다른 이름으로 보관>을 찰칵합니다.
    3. <파일형식>복합칸에서 <ODF 본문문서형판 (.ott)>을 선택합니다.
    4. <새로 보관>본문칸에 새 형판의 이름을 입력하고 <보관>을 찰칵합니다.

    참고: <파일>차림표의 <속성>을 찰칵하여 현시되는 <속성>대화창의 <일반>표쪽에 새 형판이 현시됩니다.

  2. 먼저 배치를 스케치하여 양식을 설계하거나 안내서로 기존양식을 사용합니다.

    3. 참고: 양식에서는 양식마당, 양식조종체, 표와 중첩된 표 및 본문칸을 사용할수 있습니다.

  3. <보기>차림표에서 <도구띠>를 찰칵한 다음 <양식 설계>와 <양식조종체>를 찰칵하여 <양식 설계>도구띠와 <양식조종체>도구띠를 현시합니다.
  4. <본문칸>, <확인칸> 및 <복합칸> 등에 대한 양식들을 추가합니다.

    5. 방법

    1. 문서에서 양식마당을 삽입할 위치를 찰칵합니다.
    2. 다음의 방법들중에서 하나를 실행합니다.

      3. 사용자가 본문을 입력할수 있는 본문칸을 삽입

      • <양식조종체>도구띠에서 <본문칸>그림기호를 찰칵합니다.

      응답을 변경하는 경우를 제외하고 사용자가 항목을 입력할 필요가 없도록 마당을 두번 찰칵하여 <조종체속성>대화창에서 기본항목을 설정합니다.

      매개 추가선택옆에 사용자가 선택하거나 선택을 취소할수 있는 확인칸을 삽입

      • <양식조종체>도구띠에서 <확인칸>그림기호를 찰칵합니다.

      또한 이 단추를 사용하면 사용자가 둘이상을 선택할수 있는 선택그룹의 매개 항목옆에 확인칸을 삽입할수 있습니다.

      사용자가 선택할수 있는 항목을 제한하는 복합칸을 삽입

      1. <양식조종체>도구띠에서 <복합칸>그림기호를 찰칵합니다.
      2. <복합칸 자동안내처리>대화창이 현시됩니다.

      3. 항목을 추가하려면 <자료원본>목록칸에서 자료원본을 선택합니다.

        만일 목록칸에 자료원본항목들이 없으면 목록칸옆의 단추를 찰칵하여 요구하는 자료항목을 찾아 선택합니다.

      4. <다음>단추를 찰칵하면서 필요한 설정을 진행합니다.
      5. 마지막에 <완료>단추를 찰칵하여 대화창을 닫습니다.
  5. 양식마당의 속성을 설정하거나 편집합니다.

    6. 방법

    1. 바꿀 양식마당을 두번 찰칵합니다. 해당한 양식의 <속성>대화창이 현시됩니다.
    2. 요구하는 추가선택을 변경한 다음 <확인>단추를 찰칵합니다.
  6. 양식에 도움말을 추가합니다.

    7. 다음의 방법들중에서 하나를 실행합니다.

    조종체에 도움말본문을 추가

    1. 도움말을 추가할 양식마당을 두번 찰칵하여 <속성>대화창을 현시합니다.
    2. <일반>표쪽을 찰칵합니다.
    3. <도움말본문>본문칸에 도움말본문을 입력합니다.

참고: <양식 설계>도구띠나 <양식조종체>도구띠에서 <설계방식 적용/해제>그림기호를 선택하여야만 조종체들이 사용가능으로 되여 양식마당들을 입력할수 있습니다.
