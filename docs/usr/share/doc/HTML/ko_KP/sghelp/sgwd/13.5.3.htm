고정시간 또는 가변시간마당의 삽입

모두 표시

현재시간을 갱신할수 있는 마당으로 삽입하거나 갱신되지 않는 마당으로 삽입할수 있습니다.

  1. <삽입>차림표의 <마당>에서 <기타>를 찰칵합니다. <마당>대화창이 현시됩니다.
  2. <문서>표쪽을 찰칵하고 <류형>목록칸에서 <시간>을 찰칵합니다.
    • 갱신시킬수 있는 마당으로 시간을 삽입하려면 <선택>목록칸에서 <시간>을 찰칵합니다.
    • 갱신되지 않는 마당으로 시간을 삽입하려면 <선택>목록칸에서 <시간(고정)>을 찰칵합니다.
  3. <서식>목록칸에서 요구하는 시간표시서식을 선택합니다. 추가적인 서식을 적용하려면 목록칸의 <추가서식>을 찰칵합니다.
  4. <삽입>단추를 찰칵하고 <닫기>를 찰칵하여 대화창을 닫습니다.

참고: <삽입>차림표의 <마당>에서 <시간>을 찰칵하여 현재의 시간을 삽입할수 있습니다. 여기서 삽입하는 시간은 고정된 시간이므로 갱신을 진행할수 없습니다.
