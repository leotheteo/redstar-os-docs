도형객체의 채우기변경

모두 표시

도형객체의 색이나 장식효과를 변경

  1. 채우기를 변경할 도형객체나 본문칸을 선택합니다.
  2. <도형객체속성>도구띠에서 <령역>그림기호옆의 <령역격식/색칠>복합칸의 화살표를 찰칵합니다.
  3. 단색을 적용하려면 <색>을, 다른 형식을 선택하려면 <계조>나 <평행선>, <문양>를 찰칵합니다.
  4. 요구하는 추가선택을 변경합니다.

도형객체의 륜곽선을 변경

  1. 변경할 도형객체나 본문칸을 선택합니다.
  2. 선색을 변경하려면 <도형객체속성>도구띠에 있는 <선>그림기호를 찰칵하고 현시되는 <선>대화창에서 <선>표쪽을 찰칵합니다. <선속성>령역의 <색>복합칸에서 요구하는 색을 선택합니다.
  3. 선을 점선이나 실선으로 변경하려면 <도형객체속성>도구띠에 있는 <선>그림기호를 찰칵하고 현시되는 <선>대화창에서 <선>표쪽을 찰칵합니다. <선속성>령역의 <격식>복합칸에서 요구하는 선격식을 선택합니다.
  4. <확인>단추를 찰칵하여 대화창을 닫습니다.

    5. 참고: 선의 격식을 편집하려면 <선>대화창의 <선격식>표쪽을 찰칵합니다. 요구하는 추가선택을 진행하여 기존의 선격식을 수정하거나 새로운 선격식을 추가합니다.
