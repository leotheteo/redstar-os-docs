도형객체나 그림의 본문에워싸기형식 변경

모두 표시

  1. 해당 도형객체나 그림을 선택합니다.
  2. <서식>차림표에서 <에워싸기>를 찰칵합니다. 또는 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <에워싸기>를 찰칵합니다.
  3. <에워싸기>부분차림표에서 요구하는 에워싸기형식을 찰칵합니다.
  4. 에워싸기에 대한 자세한 추가선택을 하려면 <서식>차림표에서 <에워싸기>를 찰칵한 다음 <편집>을 찰칵하여 <에워싸기>대화창에서 요구하는 추가선택을 진행합니다.

    5. 참고: 문서처리프로그람에서는 그림에 대하여 독특한 형식의 에워싸기형식을 지원하고있습니다. 그림에서 특정한 령역(그림의 륜곽선으로 둘러막힌 령역, 직4각형령역이나 타원령역, 임의의 형태의 다각형령역 등)만을 보여주고 이 령역을 본문으로 에워싸기할수 있습니다.

    그림의 다각형령역만을 본문으로 에워싸기

    1. 해당한 그림을 선택합니다.
    2. <서식>차림표의 <에워싸기>를 찰칵합니다. 또는 그림에서 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <에워싸기>를 찰칵합니다.
    3. <에워싸기>부분차림표에서 <륜곽 편집>을 찰칵합니다. <륜곽편집기>대화창이 현시됩니다.
    4. <다각형>도구를 찰칵하여 요구하는 령역을 선택합니다.
    5. <적용>을 찰칵하고 대화창을 닫습니다.

    6. 변경내용을 보관하겠는가를 묻는 대화창에서 <예>를 찰칵합니다.

      다음의 그림은 다각형도구로 잘라낸 도형객체를 본문으로 감아보내기한 실례입니다.

    참고: <륜곽편집기>를 사용하여 그림자르기를 진행할수도 있습니다.
