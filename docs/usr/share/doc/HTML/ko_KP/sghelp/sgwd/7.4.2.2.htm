그림자의 변경

모두 표시

그림이나 표, 본문의 그림자를 변경

  1. 그림자를 변경할 그림이나 표, 본문을 선택합니다.
  2. 그림이나 본문인 경우에는 <서식>차림표에서 <그림> 또는 <단락>을 찰칵하고 표인 경우에는 <표>차림표에서 <표서식>을 찰칵하여 해당한 <표서식>대화창을 현시합니다.
  3. <테두리>표쪽을 찰칵합니다.
  4. <그림자격식>령역에서 변경할 추가선택을 진행합니다.
  5. <확인>단추를 찰칵하여 대화창을 닫습니다.

    6. 참고: 복잡한 표의 여러 부분에서 그림자를 변경하려면 <표>도구띠를 사용합니다.
