페지령역

모두 표시

여러 페지가 있는 본문문서의 인쇄순서를 지정하는 령역입니다.

항목 설명
왼쪽 페지 문서의 모든 왼쪽페지만을 인쇄하겠는가 말겠는가를 지정합니다.
오른쪽 페지 문서의 모든 오른쪽페지만을 인쇄하겠는가 말겠는가를 지정합니다.
소책자

문서를 소책자형식으로 인쇄하려면 <소책자>추가선택을 진행합니다. 문서처리프로그람의 소책자형식은 다음과 같습니다.

가로페지에서 세로문서를 인쇄하면 소책자의 마주보고있는 두면은 서로 나란히 인쇄됩니다. 량면인쇄기능이 있는 인쇄기가 있는 경우 이후에 페지를 한부씩 인쇄하지 않고 문서에서 전체 소책자를 만들수 있습니다. 단면인쇄기능이 있는 인쇄기가 있는 경우 <오른쪽 페지>추가선택을 선택하여 먼저 앞페지를 인쇄하고 전체 용지를 인쇄기에 다시 넣은 다음 <왼쪽 페지>추가선택을 선택하여 뒤페지를 모두 인쇄하면 이 효과를 낼수 있습니다.
오른쪽에서 왼쪽으로 소책자를 인쇄할 때 오른쪽에서 왼쪽으로 펼치도록 인쇄하겠는가를 지정합니다. 이 확인칸은 <소책자>확인칸을 선택하여야 능동상태로 됩니다.
