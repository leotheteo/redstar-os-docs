특정한 기능이 지원되지 않는 파일형식으로 문서를 보관

모두 표시

파일형식은 특정프로그람에서 파일을 열고 보관할수 있도록 파일에 정보를 보관하는 방식입니다. 문서처리프로그람에서는 기본 .odt형식외에 여러가지 형식으로 문서를 보관할수 있습니다. 그러나 일부 파일형식에서는 보통 .odt파일에 보관하는 정보를 보관할수 없습니다.

례를 들어 일반 본문파일(.txt)에는 서식화되지 않은 본문만 보관할수 있습니다. 본문문서를 일반 본문형식으로 보관하면 서식, 그림, 객체, 표와 같은 본문을 제외한 모든 요소가 잃게 되는데 이러한 요소는 일반 본문파일로 보관할수 없기때문입니다.

웨브페지파일형식(.htm, .html)에도 문서보호암호나 문서판본관리와 같은 일부 문서처리프로그람기능을 보관할수 없습니다.
