모두 표시

문서처리프로그람에서 사용할수 있는 그림의 파일형식

문서에 직접 또는 별도의 그림려과기를 사용하여 인기있는 많은 파일형식의 그림을 삽입할수 있습니다. 다음과 같은 파일형식을 삽입하는 경우에는 별도의 그림려과기를 설치할 필요가 없습니다.

  • 확장 메타파일(.emf)
  • graphics interchange format(.gif)
  • Joint Photographic Experts Group(.jpg)
  • Portable Network Graphics(.png)
  • Windows Metafile Graphics(.wmf)
  • AutoCAD Interchange format (.dxf)
  • Encapsulated PostScript(.eps)
  • Mac Pict (.pct)
  • Portable Bitmap (.pbm)
  • Portable Graymap(.pgm)
  • Portable Pixelmap(.ppm)

이동속도를 향상시킬수 있도록 그림 및 도형객체의 숨기기

<서광사무처리>차림표에서 <환경설정>을 찰칵하고 <서광사무처리 문서처리프로그람>에서 <보기>를 찰칵하여 <그림과 객체>확인칸의 선택을 취소합니다. 이렇게 하면 그림이나 도형객체대신 륜곽선이 현시됩니다.

파일의 크기를 줄이는 방법

  • 그림의 압축:    그림을 축소하면 잘린 령역 등 파일에서 불필요한 정보를 삭제하고 화상의 해상도를 줄이며 가능한 경우 더 효률적인 그림파일형식으로 변경할수 있습니다.
  • 한문서에 대한 하나이상의 판본 삭제:    판본관리기능을 사용하여 여러 판본의 문서를 만들면 파일크기가 커집니다. 한문서에 다른 판본이 있는지 확인하려면 파일차림표에서 판본을 찰칵합니다. 다른 판본이 있으면 가장 오래된 판본을 삭제하여 파일의 크기를 줄입니다.
  • 그림을 삽입하지 않고 련결:    포함된 객체대신에 련결된 객체를 사용합니다. 련결된 객체를 사용하는 경우 원본파일의 내용이 바뀌면 문서처리프로그람 문서의 정보도 쉽게 갱신할수 있습니다. 련결된 자료는 원본 파일에 보관되고 대상파일에는 원본파일의 위치만 보관되며 련결된 자료가 현시됩니다.
