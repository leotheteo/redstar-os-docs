새로운 표격식의 만들기

모두 표시

문서처리프로그람에서 제공하는 기본표격식외에 직접 표격식을 만들어 표의 수자형식, 서체, 맞추기, 테두리, 문양, 그림자 등의 일관성을 유지할수 있습니다.

  1. 다음의 방법들중에서 하나를 실행하여 <자동서식>대화창을 현시합니다.
    • <표>차림표에서 <자동서식>을 찰칵합니다.
    • <표>도구띠에서 <자동서식>그림기호를 찰칵합니다.
  2. <자동서식>대화창에서 <추가>단추를 찰칵하여 <자동서식 추가>대화창을 현시합니다.
  3. <이름>본문칸에 이름을 입력하고 <확인>단추를 찰칵하여 대화창을 닫습니다.
  4. <확인>단추를 찰칵하여 <자동서식>대화창을 닫습니다.
