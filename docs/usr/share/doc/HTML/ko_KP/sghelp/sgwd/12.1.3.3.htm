암호에 의한 변경내용의 보호

모두 표시

변경기록기능을 사용불가능상태로 만들려고 하는 경우 암호를 사용하여서만 이 기능을 사용불가능으로 만들도록 설정할수 있습니다. 례를 들어 다른 사용자가 문서를 변경하면서 자기가 변경한 내용이 기록되지 않도록 변경내용기능을 취소하려고 할 때 암호를 입력하지 못하면 이 기능을 취소할수 없으므로 문서에 대한 모든 변경내용들이 기록되게 됩니다. 따라서 누가 문서를 변경하였는지 쉽게 추적할수 있습니다.

방법

  1. <서광사무처리>차림표에서 <환경설정>을 찰칵하여 <환경설정>대화창을 현시합니다.
  2. <서광사무처리>의 <보안>을 찰칵합니다.
  3. <이 문서의 파일공유 추가선택>령역의 <변경을 기록>확인칸을 찰칵하여 선택합니다.
  4. <보호>단추를 찰칵하여 현시되는 <암호 입력>대화창에서 암호를 입력하고 확인합니다. <확인>단추를 찰칵하여 <암호 입력>대화창을 닫습니다. <보호>단추의 이름이 <보호 해제>로 바뀝니다.
  5. <확인>단추를 찰칵하여 대화창을 닫습니다.

이 설정을 한 다음 <편집>차림표의 <변경>에서 <기록>이나 <기록 보호>의 선택을 취소하려고 하면 암호를 묻는 대화창이 현시되는데 정확한 암호를 입력하지 못하면 <기록>이나 <기록 보호>의 선택을 취소할수 없습니다. 그러므로 사용자가 진행하는 모든 변경내용들이 기록되게 됩니다.
