하이퍼련결의 만들기

모두 표시

하이퍼련결을 사용자정의할수 있습니다.

하이퍼련결을 사용자정의하려면 다음의 방법들중에서 하나를 실행합니다.

기존문서, 웨브페지, FTP

  1. 하이퍼련결로 련결할 본문이나 그림을 선택하고 <표준>도구띠에서 <하이퍼련결>그림기호를 찰칵하거나 <삽입>차림표에서 <하이퍼련결>을 찰칵합니다.
  2. 다음의 방법들중에서 하나를 실행합니다.

    3. 기존문서에 련결

    1. <하이퍼련결>대화창의 왼쪽마당에서 <문서>를 찰칵합니다.
    2. <경로>본문칸에 련결할 문서주소를 입력하거나 본문칸옆의 <파일 열기>그림기호를 찰칵하여 <열기>대화창을 현시합니다.
    3. 요구하는 문서를 찾아 선택하고 <열기>단추를 찰칵하여 <열기>대화창을 닫습니다.
    4. <하이퍼련결>대화창에서 <적용>단추를 찰칵한 다음 <닫기>단추를 찰칵하여 대화창을 닫습니다.

    웨브페지에 련결

    1. <하이퍼련결>대화창의 왼쪽마당에서 <인터네트>를 찰칵합니다.
    2. <하이퍼련결류형>령역에서 <웨브>단일선택단추를 선택합니다.
    3. <대상>본문칸에 련결하려고 하는 웨브페지의 주소를 입력합니다. 웨브페지의 주소입력에 대한 정보를 보기 위하여서는 본문칸옆의 <WWW 열람기>그림기호를 찰칵하여 현시되는 <웨브주소 전송>설명문을 참고하십시오.
    4. <기타 설정>령역에서 요구하는 설정을 진행합니다.
    5. <적용>단추를 찰칵한 다음 <닫기>단추를 찰칵하여 <하이퍼련결>대화창을 닫습니다.

    FTP에 련결

    1. <하이퍼련결>대화창의 왼쪽마당에서 <인터네트>를 찰칵합니다.
    2. <하이퍼련결류형>령역에서 <FTP>단일선택단추를 선택합니다.
    3. <대상>본문칸에 련결하려고 하는 FTP의 주소를 입력합니다. FTP주소입력에 대한 정보를 보기 위하여서는 본문칸옆의 <WWW 열람기>그림기호를 찰칵하여 현시되는 <웨브주소 전송>설명문을 참고하십시오.
    4. <가입이름>본문칸과 <암호>본문칸에 가입이름과 암호를 입력합니다.
    5. <기타 설정>령역에서 요구하는 설정을 진행합니다.
    6. <적용>단추를 찰칵한 다음 <닫기>단추를 찰칵하여 <하이퍼련결>대화창을 닫습니다.

현재문서나 웨브페지의 특정한 위치

문서의 특정한 위치(례: 단락, 표, 그림, 책갈피 등)에로 하이퍼련결을 만들수 있습니다.

  1. 대상문서나 웨브페지에 제목격식이나 책갈피 등 특정한 항목들을 삽입합니다.
  2. 하이퍼련결로 련결할 본문이나 객체를 선택합니다.
  3. <표준>도구띠에서 <하이퍼련결>그림기호를 찰칵하거나 <삽입>차림표에서 <하이퍼련결>을 찰칵하여 <하이퍼련결>대화창을 현시합니다.
  4. <하이퍼련결>대화창의 왼쪽마당에서 <인터네트> 또는 <문서>를 찰칵니다.
  5. <인터네트>를 선택한 경우에는 <대상>본문칸에, <문서>를 선택한 경우에는 <경로>본문칸에 현재문서의 경로를 입력하거나 본문칸옆의 <파일 열기>그림기호를 눌러서 현재문서나 웨브페지를 찾아 선택합니다.
  6. <문서안의 대상>그림기호를 눌러서 <문서안의 대상>작업창을 현시합니다.
  7. 련결하려고 하는 항목들을 선택한 다음 <적용>단추를 찰칵하고 <닫기>단추를 찰칵하여 작업창을 닫습니다.

다른 파일이나 프로그람

  1. 하이퍼련결로 련결할 본문이나 객체를 선택합니다.
  2. <표준>도구띠에서 <하이퍼련결>그림기호를 찰칵하거나 <삽입>차림표에서 <하이퍼련결>을 찰칵하여 <하이퍼련결>대화창을 현시합니다
  3. <하이퍼련결>대화창의 왼쪽마당에서 <문서>를 찰칵합니다.
  4. <경로>본문칸에 련결할 파일이나 프로그람의 정확한 경로와 이름을 지정하거나 본문칸옆의 <파일 열기>그림기호를 눌러서 파일이나 프로그람을 찾아서 선택합니다.
  5. <적용>단추를 찰칵한 다음 <닫기>단추를 찰칵하여 대화창을 닫습니다.
