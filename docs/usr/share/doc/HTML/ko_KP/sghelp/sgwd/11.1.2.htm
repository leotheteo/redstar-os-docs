하이퍼련결의 서식지정

모두 표시

본문이나 그림을 선택하고 새 서식을 적용하여 하나의 하이퍼련결에 련결되는 본문이나 그림의 서식을 지정할수 있습니다.

문서에 있는 모든 본문하이퍼련결의 모양을 변경하려면 다음을 실행합니다.

  1. 변경할 하이퍼련결이 포함된 문서를 엽니다.
  2. <서식 설정>도구띠에서 <격식 및 서식>그림기호를 찰칵하여 <격식 및 서식>작업창을 현시합니다.
  3. 다음의 방법들중에서 하나를 실행합니다.
    • 방문하지 않은 하이퍼련결의 모양을 변경하려면 <문자격식>을 찰칵한 다음 목록칸에서 <인터네트 련결>격식을 마우스의 오른쪽단추로 찰칵하고 <수정>을 찰칵합니다.
    • 방문한 하이퍼련결의 모양을 변경하려면 <문자격식>칸에서 <방문한 인터네트 련결>격식을 마우스의 오른쪽단추로 찰칵한 다음 <수정>을 찰칵합니다.

    참고: <인터네트 련결> 또는 <방문한 인터네트 련결>격식이 목록칸에 현시되지 않으면 대화창의 맨 밑의 목록칸에서 <모두>를 찰칵합니다.

  4. <문자격식>대화창에서 해당한 표쪽을 찰칵하여 하이퍼련결본문의 격식 및 서식을 수정합니다.

참고: 하이퍼련결본문의 색을 기정으로 설정합니다.

  1. <서광사무처리>차림표의 <환경설정>을 찰칵하여 <환경설정>대화창을 현시합니다.
  2. <서광사무처리>의 <겉모양>을 찰칵합니다.
  3. <사용자전용색>령역의 목록칸에서 <방문하지 않은 련결>확인칸과 <방문한 련결>확인칸을 선택하고 그옆의 <색 설정>목록칸에서 요구하는 색을 찰칵합니다. 선택한 색은 <미리보기>에 현시됩니다.
  4. <확인>단추를 찰칵하여 대화창을 닫습니다.
