목록의 항목번호를 다시 시작

모두 표시

번호가 매겨져있는 목록의 임의의 항목에서 항목번호를 다시 시작할수 있습니다.

  1. 항목번호목록에서 항목번호를 다시 시작할 항목을 찰칵합니다.
  2. 다음의 방법들중에서 하나를 실행합니다.
    • 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <항목번호 다시 시작>을 찰칵합니다.
    • 구체적으로 설정하려면 다음을 실행합니다.
      1. <서식>차림표의 <단락>을 찰칵하여 <단락>대화창을 현시합니다.
      2. <항목번호>표쪽을 찰칵합니다.
      3. <항목번호>령역에서 <이 단락에서 다시 시작>확인칸을 선택합니다.

        4. 참고: 다시 시작할 번호를 설정하려면 <시작번호>확인칸을 선택하고 <시작번호>본문칸에 번호를 입력합니다.

      4. <확인>단추를 찰칵합니다.
