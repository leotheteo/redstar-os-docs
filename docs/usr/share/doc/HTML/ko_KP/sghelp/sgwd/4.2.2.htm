문서에서 화면시야의 이동

모두 표시

화면을 시야이동한 후 입력을 시작할 위치를 찰칵하고 다음의 방법들중 하나를 실행합니다.

시야이동방향 방법
한행 웃쪽으로 시야이동 수직흘림띠의 웃쪽 시야이동화살표 를 찰칵합니다.
한행 아래쪽으로 시야이동 수직흘림띠의 아래쪽 시야이동화살표 를 찰칵합니다.
왼쪽으로 시야이동 수평흘림띠의 왼쪽 시야이동화살표 를 찰칵합니다.
오른쪽으로 시야이동 수평흘림띠의 오른쪽 시야이동화살표 를 찰칵합니다.

참고

  • 더 천천히 시야이동하려면 건반에서 이동건을 사용하거나 [PageUp] 또는 [PageDown]건을 누릅니다.
  • Microsoft IntelliMouse 등의 마우스장치나 기타 지시장치에는 기본적으로 시야이동기능과 확대/축소기능이 내장되여있습니다.
