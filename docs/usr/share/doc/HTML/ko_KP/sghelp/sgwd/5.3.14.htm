본문과 표사이의 변환

모두 표시

다음의 방법들중에서 하나를 실행합니다.

본문을 표로 변환

본문을 표로 변환하려면 반점, 태브, 기타 구분문자로 본문을 구분하여 새 렬이 시작될 위치를 지정합니다. 새 행을 시작하려면 단락기호를 사용합니다.

  1. 요구하는 구분문자를 삽입하여 본문을 여러 렬로 배치할 위치를 표식합니다.

    례를 들어 두개의 단어가 한행에 있는 목록에서 첫번째 단어의 뒤에 반점이나 태브를 삽입하여 두개의 렬로 된 표를 만듭니다.

  2. 변환할 본문을 선택합니다.
  3. <표>차림표의 <변환>에서 <본문을 표로>를 찰칵하여 <본문을 표로 변환>대화창을 현시합니다.
  4. <본문구분기호>령역에서 요구하는 구분문자를 선택합니다.
  5. <확인>단추를 찰칵합니다.

표를 본문으로 변환

  1. 단락으로 변환할 행이나 표를 선택합니다.
  2. <표>차림표의 <변환>에서 <표를 본문으로>를 찰칵하여 <표를 본문으로 변환>대화창을 현시합니다.

  3. <본문구분기호>령역에서 렬경계위치에 사용할 구분문자를 선택합니다.

    행은 단락기호로 구분됩니다.

  4. <확인>단추를 찰칵합니다.
