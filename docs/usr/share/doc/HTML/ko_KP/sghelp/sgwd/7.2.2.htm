그림의 배치

모두 표시

다음의 방법들중에서 하나를 실행합니다.

그림주위에 본문의 배치

  1. 그림을 선택합니다.
  2. 그우에서 마우스의 오른쪽단추를 찰칵한 다음 상황차림표에서 <에워싸기>를 찰칵합니다.
  3. 부분차림표에서 적용할 본문에워싸기형식을 선택합니다.

단락유지 행바꾸기의 삽입

단락유지 행바꾸기는 제목본문처럼 본문에서 웨브페지의 객체주변본문을 구분하는데 사용됩니다.

제목에서 행바꾸기

  1. 웨브페지에서 단락유지 행바꾸기를 지정할 위치를 찰칵합니다.
  2. <삽입>차림표의 <수동가르기>를 찰칵합니다.
  3. <류형>에서 <행 가르기>를 찰칵합니다.
  4. <확인>단추를 찰칵하여 <가르기 삽입>대화창을 닫습니다.

참고: [Shift+Enter]건을 누르면 단락유지 행바꾸기를 삽입할수 있습니다.

단락유지 행바꾸기는 기본적으로 문서에 현시되지 않는 서식기호입니다. 단락유지 행바꾸기를 보려면 <표준>도구띠에서 <인쇄하지 않는 문자>그림기호를 찰칵하여 서식기호를 현시합니다. 단락유지 행바꾸기 위치에는 단락유지 행바꾸기기호()가 현시됩니다.
