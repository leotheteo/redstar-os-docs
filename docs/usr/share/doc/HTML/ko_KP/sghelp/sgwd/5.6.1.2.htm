삽화제목의 추가

모두 표시

표, 그림, 수학식, 기타 객체를 삽입할 때 자동적으로 삽화제목의 추가

  1. 적당한 객체를 삽입합니다.
  2. 객체우에서 마우스의 오른쪽단추를 찰칵하고 <삽화제목>을 찰칵합니다.
  3. <삽화제목>대화창의 <삽화제목>본문칸에 표제를 입력하고 <종류>복합칸에서 요구하는 선택을 하거나 새로운 종류이름을 입력한 다음 다른 추가선택을 진행합니다.
  4. <자동삽화제목>단추를 찰칵하고 요구하는 추가선택을 진행한 다음 <확인>단추를 찰칵합니다.
  5. <삽화제목>대화창의 <확인>단추를 찰칵합니다.

  6. <삽입>차림표의 <객체>지령을 사용하여 문서에 객체를 삽입합니다.

    객체를 삽입할 때마다 해당 삽화제목과 련번호가 자동적으로 추가됩니다.

표, 그림, 수학식, 기타 객체에 직접 삽화제목을 추가

  1. 제목을 추가하려는 객체를 선택합니다.
  2. 다음의 방법들중에서 하나를 실행하여 <삽화제목>대화창을 현시합니다.
    • <삽입>차림표에서 <삽화제목>을 찰칵합니다.
    • 객체우에서 마우스의 오른쪽단추를 찰칵하고 <삽화제목>을 찰칵합니다.
  3. <삽화제목>본문칸에 삽화제목을 입력합니다.
  4. <종류>복합칸에서 요구하는 종류를 선택하거나 새로운 종류이름을 입력한 다음 <항목번호>복합칸에서 요구하는 번호서식을 선택합니다.
  5. 다음의 방법들중에서 하나를 실행합니다.
    • 다른 추가선택을 하려면 다음과 같은 방법으로 진행합니다.
      1. <추가선택>단추를 찰칵하여 <추가선택>대화창을 현시합니다.
      2. 장별로 삽화제목번호를 매기려면 <장별로 삽화제목 번호매기기>의 <준위>복합칸에서 요구하는 준위를 선택하고 <구분기호>본문칸에 구분기호를 입력합니다.
      3. <종류 및 틀형식>령역의 <문자격식>복합칸에서 요구하는 서식을 선택합니다.
      4. <확인>단추를 찰칵합니다.
    • 객체를 삽입하는 경우 자동적으로 삽화제목이 추가되게 하려면 다음과 같은 방법으로 진행합니다.
      1. <자동삽화제목>단추를 찰칵하여 <자동삽화제목>대화창을 현시합니다.
      2. <다음을 삽입할 때 자동적으로 삽화제목 추가>목록칸에서 요구하는 항목을 선택합니다.
      3. 다른 추가선택을 진행합니다.
      4. <확인>단추를 찰칵합니다.
  6. <확인>단추를 찰칵합니다.
