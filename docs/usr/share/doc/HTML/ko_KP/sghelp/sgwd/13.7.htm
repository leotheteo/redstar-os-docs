마당의 그림자배경

모두 표시

마당의 그림자배경의 현시/해제

  1. 마당의 그림자배경을 현시하려면 <보기>차림표에서 <마당그림자>를 찰칵하거나 지름건 [Shift+F8]건을 누릅니다.
  2. 마당의 그림자배경을 해제하려면 <마당그림자>를 다시 찰칵하거나 지름건 [Shift+F8]건을 누릅니다.

마당의 그림자배경색의 변경

  1. <서광사무처리>차림표에서 <환경설정>을 찰칵하여 <환경설정>대화창을 현시합니다.
  2. <서광사무처리>에서 <겉모양>을 찰칵합니다.
  3. <사용자전용색>의 <사용자대면부요소>목록에서 <마당그림자>의 <색 설정>복합칸에서 다른 색을 설정합니다.
  4. <확인>단추를 찰칵하여 대화창을 닫습니다.
