페지번호의 서식

모두 표시

다음의 방법들중에서 하나를 실행합니다.

페지번호의 번호매기기격식을 변경

  1. 회색의 머리부 또는 바닥부령역을 두번 찰칵하여 활성화합니다.
  2. 다음의 방법들중에서 하나를 실행하여 <마당 편집>대화창을 현시합니다.
    • <편집>차림표에서 <마당>을 찰칵합니다.
    • 페지번호마당을 두번 찰칵합니다.
  3. <서식>목록칸에서 요구하는 서식을 선택합니다.
  4. <확인>단추를 찰칵하거나 선택한 서식을 두번 찰칵합니다.

페지번호의 문자서식을 변경

  1. 회색의 머리부 또는 바닥부령역을 두번 찰칵하여 활성화합니다.
  2. 페지번호를 선택합니다.
  3. 다음의 방법들중에서 하나를 실행합니다.
    • <서식 설정>도구띠에서 서체를 변경하거나 서체크기 또는 서체색을 변경합니다.
    • <서식>차림표의 <문자>를 찰칵하여 현시되는 <문자>대화창에서 요구하는 추가선택을 합니다.
