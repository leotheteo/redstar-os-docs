표에서 발생하는 문제의 해결

모두 표시

표크기가 창크기에 맞게 변경되지 않는 경우

창크기를 변경했을 때 자동적으로 표의 크기도 바뀌도록 설정하려면 편집창을 웨브배치로 절환합니다. 인쇄배치에서는 표의 크기가 바뀌지 않습니다.

본문의 일부가 표세포에 숨겨져있는 경우

  • 세포안의 들여쓰기를 조절해야 합니다. 세포를 찰칵하고 <서식>차림표의 <단락>을 찰칵하고 <들여쓰기 및 간격>표쪽의 <들여쓰기>에 새 값을 지정합니다.
  • 현시할 본문보다 행높이가 작을수 있습니다. 세포를 찰칵하고 필요한만큼 행높이를 조절합니다.

표에 인쇄되지 않는 회색테두리가 현시될 때

표를 만들면 기본적으로 표에 0.5pt두께의 검은색테두리가 현시됩니다. 이 테두리를 삭제해도 회색테두리가 여전히 현시되지만 인쇄되지 않습니다. 표에 있는 선을 인쇄하려면 테두리를 설정해야 합니다. 회색테두리선을 현시되지 않게 하려면 <표>차림표에서 <표테두리>를 찰칵합니다.
