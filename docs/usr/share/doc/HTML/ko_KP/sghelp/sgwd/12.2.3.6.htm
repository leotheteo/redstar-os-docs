련결된 객체와 포함된 객체에서 발생하는 문제의 해결

모두 표시

련결된 객체나 포함된 객체를 두번 찰칵하면 편집할수 없다는 통보문이 현시될 때

이 통보문은 원본파일이나 원본프로그람을 열수 없는 경우에 현시됩니다.

  • 원본프로그람을 실행할수 있는 충분한 기억기가 있는지 확인합니다. 필요하면 다른 프로그람을 닫아 기억기를 확보합니다.
  • 원본프로그람이 실행중이면 대화창이 현시되여있지 말아야 합니다. 원본프로그람으로 전환하여 현시되여있는 모든 대화창을 닫습니다.
  • 련결된 객체의 경우에는 편집할 원본파일이 련결을 만들 때와 같은 이름으로 같은 위치에 있어야 합니다. 원본 파일이름을 확인하려면 련결된 객체를 선택하고 <편집>차림표에서 <련결>을 찰칵합니다. 원본 파일이름이 변경되였거나 위치가 바뀐 경우에는 <련결 편집>대화창에서 <수정>단추를 찰칵하여 련결을 다시 지정합니다.

문서에서 련결된 큰 객체나 포함된 객체가 잘릴 때

큰 련결된 객체나 포함된 객체를 작성할 때 페지에 전체 객체를 모두 현시할수 있을 만큼 여유가 있어도 오른쪽이나 아래쪽이 잘리는 경우가 있습니다. 이것은 련결된 객체나 포함된 객체가 최대 높이와 너비가 제한된 확장 메타파일(.emf) 형식으로 현시되기때문입니다. 객체가 이 최대 크기를 넘으면 본문문서에서 잘려서 현시됩니다.

련결된 객체나 포함된 객체가 잘리지 않게 하려면 다음의 방법들중에서 하나를 실행합니다.

  • 원본프로그람에서 서체크기와 렬크기 등을 줄여 자료의 크기를 줄입니다.
  • 문서처리프로그람에서 서식화된 본문이나 서식화되지 않은 본문으로 자료를 붙여넣거나 련결합니다. 이렇게 하려면 <편집>차림표의 <형식을 선택하여 붙이기>를 찰칵하고 <선택>목록칸에서 <서식화된 본문(RTF)>이나 <서식화되지 않은 본문>을 찰칵합니다.
