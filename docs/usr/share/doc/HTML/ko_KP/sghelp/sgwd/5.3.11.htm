표의 테두리지정

모두 표시

미리 정의된 테두리격식의 설정

  1. 테두리를 지정할 표세포를 선택합니다.
  2. <표>도구띠의 <테두리>그림기호를 찰칵하여 <테두리>창을 현시합니다.
  3. 미리 정의된 테두리격식들중에서 하나를 찰칵합니다.
  4. 그러면 선택한 격식이 표세포의 현재테두리격식에 추가됩니다. 테두리격식을 모두 선택취소하려면 <테두리>에서 왼쪽우에 있는 빈 테두리격식을 선택합니다.

사용자정의 테두리격식의 설정

  1. 테두리를 지정할 표세포를 선택합니다.
  2. 다음의 방법들중에서 하나를 실행하여 <표서식>대화창을 현시합니다.
    • <표>차림표에서 <표서식>을 찰칵합니다.
    • <표>도구띠에서 <표서식>그림기호를 찰칵합니다.
    • 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <표서식>을 찰칵합니다.
  3. <테두리>표쪽을 찰칵하고 요구하는 추가선택을 합니다.
  4. <확인>단추를 찰칵합니다.
