페지에서 표위치의 지정

모두 표시

다음의 방법들중에서 하나를 실행합니다.

표의 이동

  • 표를 다른 행으로 이동하려면 표의 바로 웃쪽에 있는 단락기호를 찰칵하고 [Enter]건을 누릅니다.
  • 표를 다음페지로 단번에 이동하려면 이동하려는 표를선택하고 [Ctrl+Enter]건을 누릅니다.

페지에 표맞추기

  1. 표를 찰칵합니다.
  2. <표>차림표에서 <표서식>을 찰칵하여 <표서식>대화창을 현시한 다음 <표>표쪽를 찰칵합니다.
  3. <맞추기>령역에서 요구하는 추가선택을 진행합니다.
  4. <확인>단추를 찰칵합니다.

참고: 표전체를 선택하고 상황차림표의 <맞추기>에서 요구하는 추가선택을 선택할수도 있습니다.
