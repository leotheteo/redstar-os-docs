배경의 추가

모두 표시

  1. <서식>차림표에서 <페지>를 찰칵하거나 문서의 임의의 곳을 마우스의 오른쪽단추로 찰칵하고 상황차림표에서 <페지>를 찰칵하여 <페지격식>대화창을 현시합니다.
  2. <배경>표쪽을 찰칵합니다.
  3. 다음의 방법들중에서 하나를 실행합니다.
    • <양식>복합칸에서 <색>을 찰칵하고 <배경색>령역의 조색판에서 요구하는 색을 찰칵합니다.
    • <양식>복합칸에서 <그림>을 찰칵하고 <찾아보기>단추를 찰칵하여 요구하는 그림을 포함 또는 련결합니다.
    • <그림>을 선택한 경우 <류형>령역에서 그림의 배치형식을 선택합니다. 례를 들어 작은 그림객체를 타일형식으로 배경에 배치하려고 하면 <타일>단일선택단추를 찰칵합니다. 또한 그림객체를 페지에 꽉차게 배치하려면 <령역>단일선택단추를 찰칵합니다.
  4. <확인>단추를 찰칵하여 대화창을 닫습니다.
