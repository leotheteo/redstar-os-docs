련결된 객체나 포함된 객체는 이 기능을 지원하는 모든 프로그람에서 만들수 있습니다.

포함된 객체를 새로 만들기

  1. 문서에서 객체를 포함할 위치를 선택합니다.
  2. <삽입>차림표의 <객체>에서 <OLE 객체>를 찰칵하여 <OLE 객체 삽입>대화창을 현시합니다.
  3. <새로 만들기>단일선택단추를 찰칵합니다.
  4. <객체류형>목록칸에서 요구하는 객체류형을 선택합니다.
  5. <확인>단추를 찰칵하여 대화창을 닫습니다.

기존 정보를 사용하여 련결된 객체나 포함된 객체의 만들기

표처리프로그람의 파일에서

  1. 련결된 객체나 포함된 객체를 만들 원본자료가 있는 자료표와 본문문서를 모두 엽니다.
  2. 표처리프로그람으로 전환하고 전체 자료표나 세포 범위를 선택합니다.
  3. <표준>도구띠에서 <복사>그림기호를 찰칵합니다.
  4. 본문문서로 전환하고 정보를 삽입할 위치를 찰칵합니다.
  5. <편집>차림표에서 <형식을 선택하여 붙이기>를 찰칵합니다. <형식을 선택하여 붙이기>대화창이 현시됩니다.
  6. 객체를 련결하거나 포함하려면 다음의 방법들중에서 하나를 실행합니다.
    • 련결된 객체를 만들려면 <선택>목록칸에서 <DDE 련결>을 찰칵합니다.
    • 포함된 객체를 만들려면 <선택>목록칸에서 <서광사무처리 표처리프로그람>을 찰칵합니다.
  7. <확인>단추를 찰칵하여 대화창을 닫습니다.

기타 프로그람파일에서

  1. <삽입>차림표의 <객체>를 선택하고 <OLE 객체>를 찰칵하여 <OLE 객체 삽입>대화창을 현시합니다.
  2. <파일로부터 만들기>단일선택단추를 찰칵하고 <파일에 련결>확인칸을 선택합니다.
  3. <파일>본문칸에 파일의 경로와 이름을 입력하거나 <탐색>단추를 찰칵하여 요구하는 파일을 찾아 선택합니다.
  4. <확인>단추를 찰칵하여 대화창을 닫습니다.

참고: 그림을 삽일할 때에도 련결된 객체로 하는가 포함된 객체로 하는가를 선택할수 있습니다. <그림 삽입>대화창의 <련결>확인칸을 선택하고 그림을 삽입하면 그림객체는 련결된 객체로 되며 련결편집이 가능합니다.
