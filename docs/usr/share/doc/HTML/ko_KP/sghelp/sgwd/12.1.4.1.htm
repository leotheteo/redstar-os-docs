《서광사무처리》 3.0으로 직결식양식 또는 인쇄된 양식의 만들기

모두 표시

  • 복잡한 서식, 그림, 련결된 객체, 포함된 객체, 확인칸, 복합칸이 포함되거나 특정한 자료형식, 서식 및 기본본문이 있는 본문령역이 포함된 양식을 만들려면 문서처리프로그람을 사용하십시오. 이 프로그람에서는 콤퓨터에서 직접 입력하는 양식과 인쇄하여 사용하는 양식을 만들수 있습니다. 또한 양식에 자료를 추가하는 조건을 설정하고 자동적으로 실행되는 마크로를 포함할수 있으며 다른 사용자가 쉽게 양식을 완성할수 있게 하는 도움말의 통보문을 제공할수도 있습니다.
  • 계산 또는 분석 작업을 수행하거나 증서, 견적서 같은 재정자료에 사용할 정보를 수집하는 양식을 만들려면 표처리프로그람을 사용하십시오. 양식에 입력된 정보를 자료기지에 추가하려면 자료추적형판 자동안내처리를 사용하여 양식형판을 만듭니다. 형판으로 만들어진 새로운 양식은 자료기지에 해당 기록을 자동적으로 만듭니다.
