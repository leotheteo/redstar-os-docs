표의 가르기

모두 표시

표의 가르기

  1. 표를 두개로 가르려면 둘째표의 첫행이 될 행을 찰칵합니다.
  2. 다음의 방법들중에서 하나를 실행하여 <표 가르기>대화창을 현시합니다.
    • <표>차림표의 <표 가르기>를 찰칵합니다.
    • 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표에서 <표 가르기>를 찰칵합니다.
  3. <표 가르기>대화창에서 필요한 추가선택을 진행합니다.
  4. <확인>단추를 찰칵합니다.

세포의 가르기

  1. 가르려는 세포를 선택합니다.
  2. 다음의 방법들중에서 하나를 실행하여 <세포 가르기>대화창을 현시합니다.
    • <표>차림표에서 <세포 가르기>를 찰칵합니다.
    • <표>도구띠에서 <세포 가르기>그림기호를 찰칵합니다.
    • 마우스의 오른쪽단추를 찰칵하여 현시되는 상황차림표의 <세포>에서 <가르기>를 찰칵합니다.
  3. <가르기>령역에서 <세포가르기수>본문칸에 가를 세포의 수를 입력합니다.
  4. <방향>령역에서 <가로> 또는 <세로>를 찰칵합니다. 세포를 가로방향으로 균등하게 가르려면 <가로>를 찰칵하고 <균등하게 분배>확인칸을 선택합니다.
  5. <확인>단추를 찰칵합니다.
