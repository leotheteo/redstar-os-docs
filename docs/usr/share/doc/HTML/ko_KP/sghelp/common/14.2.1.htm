수학식의 서체변경

모두 표시

수학식에서 변수, 함수, 수자, 본문의 서체를 요구하는대로 변경할수 있습니다. 수학식에서 변수, 함수, 수자, 본문의 서체를 변경하려면 다음과 같은 방법으로 진행합니다.

  1. 변수, 함수, 수자, 본문의 서체를 변경하려는 수학식을 선택하고 두번 찰칵합니다.
  2. <서식>차림표에서 <서체>를 찰칵합니다.
  3. <서체>대화창에서 <수정>단추를 찰칵한 다음 튀여나오기차림표에서 요구하는 지령을 찰칵합니다.
  4. 현시되는 <서체>대화창의 <서체>목록칸에서 요구하는 항목을 선택합니다.
  5. 다음의 방법들중에서 하나이상을 실행합니다.
    • 서체를 굵은체로 하려면 <두껍게>확인칸을 찰칵합니다.
    • 서체를 경사체로 하려면 <경사>확인칸을 찰칵합니다.
  6. <확인>단추를 찰칵합니다.

    7. 참고: 변경된 내용을 모든 새 수학식에 적용하려면 <기정>단추를 찰칵합니다.
