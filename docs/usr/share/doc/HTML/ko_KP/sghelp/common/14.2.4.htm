수학식에서 맞추기변경

모두 표시

수학식에서 맞추기를 요구하는대로 변경할수 있습니다. 수학식에서 맞추기를 변경하려면 다음과 같은 방법으로 진행합니다.

  1. 맞추기를 변경하려는 수학식을 선택하고 두번 찰칵합니다.
  2. <서식>차림표에서 <맞추기>를 찰칵합니다.
  3. <맞추기>대화창에서 다음의 방법들중에서 하나를 실행합니다.
    • 왼쪽에 맞추려면 <왼쪽>단일선택단추를 찰칵합니다.
    • 가운데에 맞추려면 <가운데>단일선택단추를 찰칵합니다.
    • 오른쪽에 맞추려면 <오른쪽>단일선택단추를 찰칵합니다.

    참고: 변경된 내용을 모든 새 수학식에 적용하려면 <기정>단추를 찰칵합니다.

  4. <확인>단추를 찰칵합니다.
