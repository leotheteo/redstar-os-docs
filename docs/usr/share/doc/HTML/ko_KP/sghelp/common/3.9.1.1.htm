확인칸, 단일선택단추

모두 표시

확인칸조종체와 단일선택단추조종체를 만들려면 <양식조종체>도구띠에서 <설계방식 적용/해제>를 찰칵하고 다음과 같은 방법으로 진행합니다.

확인칸의 만들기

  1. <양식조종체>도구띠에서 <확인칸>을 찰칵합니다.
  2. 해당 령역에 마우스를 끌기하여 확인칸조종체를 생성합니다.
  3. 조종체의 설계방식을 해제하려면 <양식조종체>도구띠의 <설계방식 적용/해제>를 찰칵합니다.

확인칸의 속성변경

  1. 속성을 변경하려는 확인칸조종체를 선택합니다. 확인칸조종체가 선택되지 않는 경우 <양식조종체>도구띠에서 <설계방식 적용/해제>를 찰칵합니다.
  2. <양식조종체>도구띠에서 <조종체속성>을 찰칵합니다.
  3. <속성: 확인칸>대화창에서 다음의 방법을 리용하여 확인칸조종체의 속성을 설정합니다.

    4. <일반>표쪽에서 속성변경

    • <이름>본문칸에 확인칸조종체의 이름을 입력합니다.
    • <표식자>복합칸에 화면에 현시할 확인칸조종체의 표식자를 입력합니다.
    • <사용가능상태>복합칸에서 <예> 또는 <아니>를 선택하여 확인칸조종체의 사용가능 또는 사용불가능상태를 선택합니다.
    • <인쇄가능>복합칸에서 문서를 인쇄하는 경우 이 확인칸조종체를 인쇄하겠는가 하지 않겠는가를 선택합니다.
    • <태브정지점>복합칸에서 확인칸조종체의 태브순서를 설정하겠는가 하지 않겠는가를 선택합니다.
    • <활성화순서>증감단추에서 조종체들사이의 활성화순서를 설정합니다.
    • <서체>본문칸의 옆에 있는 단추를 리용하여 서체를 설정합니다.
    • <격식>복합칸에서 확인칸조종체의 격식을 지정합니다.
    • <맞추기>복합칸에서 확인칸조종체의 표식자본문의 맞추기를 설정합니다.
    • <세로맞추기>복합칸에서 확인칸조종체의 표식자본문의 세로맞추기를 설정합니다.
    • <배경색>옆에 있는 단추를 리용하여 확인칸조종체의 배경색을 설정합니다.
    • <단어 가르기>복합칸에서 확인칸조종체본문이 조종체의 크기보다 긴 경우 단어들을 가르겠는가 가르지않겠는가를 설정합니다.
    • <기정상태>복합칸에서 확인칸조종체의 처음상태가 선택되여있는가 선택되여있지 않는가를 설정합니다.
    • <그림>복합칸의 옆에 있는 단추를 리용하여 확인칸조종체에 그림을 삽입합니다.
    • <그림 맞추기>복합칸을 리용하여 확인칸조종체에 삽입된 그림의 맞추기를 설정합니다.
    • <삼상태>복합칸을 리용하여 확인칸조종체의 삼상태를 설정합니다.
    • <도움말본문>본문칸에 이 확인칸조종체로 마우스유표를 가져갔을 때 현시되는 도움말간략해설본문을 입력합니다.

    <자료>표쪽에서 속성변경

    • <자료마당>목록칸에 조종체가 참조하는 자료원본표의 마당을 지정합니다.
    • <참조값(사용)>본문칸에 웨브 양식전송시 봉사기로 전달될 참조값을 입력할수 있습니다.
    • <참조값(사용안함)>본문칸에 자료표문서의 확인칸조종체와 단일선택단추조종체를 현재문서의 세포에 첨부할수 있는 값을 입력합니다.

단일선택단추의 만들기

  1. <양식조종체>도구띠에서 <단일선택단추>를 찰칵합니다.
  2. 해당 령역에 마우스를 끌기하여 단일선택단추조종체를 생성합니다.
  3. 조종체의 설계방식을 해제하려면 <양식조종체>도구띠의 <설계방식 적용/해제>를 찰칵합니다.

단일선택단추의 속성변경

  1. 속성을 변경하려는 단일선택단추조종체를 찰칵합니다.
  2. <양식조종체>도구띠에서 <조종체속성>을 찰칵합니다.
  3. <속성: 단일선택단추>대화창에서 단일선택단추조종체의 속성을 설정합니다. 확인칸조종체의 속성변경을 참고하십시오.
