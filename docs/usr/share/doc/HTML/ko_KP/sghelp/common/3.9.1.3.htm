누름단추

모두 표시

누름단추조종체를 만들려면 다음과 같은 방법으로 진행합니다.

누름단추의 만들기

  1. <양식조종체>도구띠에서 <누름단추>를 찰칵합니다.
  2. 해당 령역에 마우스를 끌기하여 누름단추를 생성합니다.
  3. 조종체의 설계방식을 해제하려면 <양식조종체>도구띠의 <설계방식 적용/해제>를 찰칵합니다.

누름단추의 속성변경

  1. 속성을 변경하려는 누름단추를 찰칵합니다.
  2. <양식조종체>도구띠에서 <조종체속성>을 찰칵합니다.
  3. <속성: 누름단추>대화창에서 누름단추조종체의 속성을 설정합니다.

    4. <일반>표쪽에서 속성변경

    • <이름>본문칸에 누름단추조종체의 이름을 입력합니다.
    • <표식자>복합칸에 화면에 현시할 누름단추조종체의 표식자를 입력합니다.
    • <사용가능상태>복합칸에서 누름단추조종체의 사용가능 또는 사용불가능상태를 선택합니다.
    • <인쇄가능>복합칸에서 문서를 인쇄하는 경우 이 누름단추조종체를 인쇄하겠는가 하지 않겠는가를 선택합니다.
    • <태브정지점>복합칸에서 조종체들의 표쪽순서를 설정하겠는가를 설정합니다.
    • <활성화순서>증감단추에서 조종체들사이의 활성화순서를 설정합니다.
    • <절환>복합칸에서 누름단추조종체를 찰칵하였을 때 단추모양을 절환하겠는가를 설정합니다.
    • <찰칵할 때 초점 맞추기>복합칸에서 누름단추를 찰칵하였을 때 초점을 맞추겠는가를 설정합니다.
    • <서체>본문칸의 옆에 있는 단추를 리용하여 서체를 설정합니다.
    • <맞추기>복합칸에서 누름단추조종체의 본문맞추기를 설정합니다.
    • <세로맞추기>복합칸에서 단추조종체본문의 세로맞추기를 설정합니다.
    • <배경색>복합칸에서 누름단추조종체의 배경색을 설정합니다.
    • <단어 가르기>복합칸에서 단추조종체본문을 단추크기에 맞게 가르겠는가를 설정합니다.
    • <동작>복합칸에서 누름단추조종체를 찰칵하였을 때 진행할 동작을 설정합니다.
    • <그림>목록칸의 옆에 있는 단추를 리용하여 그림을 불러들여 삽입합니다.
    • <그림 맞추기>복합칸에서 단추조종체안의 그림의 맞추기를 진행합니다.
    • <도움말본문>본문칸에 이 누름단추조종체로 마우스유표를 가져갔을 때 현시되는 본문을 입력합니다.
