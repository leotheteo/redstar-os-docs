본문칸, 서식화된 마당, 표식자마당

모두 표시

본문칸의 만들기

  1. <양식조종체>도구띠에서 <본문칸>을 찰칵합니다.
  2. 해당 령역에 마우스를 끌기하여 본문칸조종체를 생성합니다.
  3. 조종체의 설계방식을 해제하려면 <양식조종체>도구띠의 <설계방식 적용/해제>를 찰칵합니다.

본문칸의 속성변경

  1. 속성을 변경하려는 본문칸을 찰칵합니다.
  2. <양식조종체>도구띠에서 <조종체속성>을 찰칵합니다.
  3. <속성: 본문칸>대화창에서 본문칸조종체의 속성을 설정합니다.

    4. <일반>표쪽에서 속성변경

    • <이름>본문칸에 본문칸조종체의 이름을 입력합니다.
    • <최대본문길이>본문칸에 수자를 입력하여 본문칸조종체에 입력되는 본문의 길이를 제한합니다.
    • <사용가능상태>복합칸에서 <예> 또는 <아니>를 선택하여 본문칸조종체의 사용가능 또는 사용불가능상태를 설정합니다.
    • <읽기전용>복합칸에서 본문칸조종체를 편집할수 있게 하겠는가 읽기전용으로 하겠는가를 선택합니다.
    • <인쇄가능>복합칸에서 <예> 또는 <아니>를 선택하여 문서를 인쇄하는 경우 이 본문칸조종체를 인쇄하겠는가 하지 않겠는가를 설정합니다.
    • <태브정지점>증감단추에서 조종체의 활성화순서를 설정하겠는가를 설정합니다.
    • <활성화순서>증감단추에서 조종체들사이의 활성화순서를 설정합니다.
    • <기정본문>본문칸에 본문칸조종체본문을 입력합니다.
    • <서체>본문칸의 옆에 있는 단추를 리용하여 서체를 설정합니다.
    • <맞추기>복합칸에서 본문칸조종체의 본문맞추기를 설정합니다.
    • <배경색>복합칸에서 본문칸조종체의 배경색을 설정합니다.
    • <테두리>복합칸에서 본문칸조종체의 테두리형식을 설정합니다.
    • <테두리색>복합칸에서 본문칸조종체의 테두리색을 설정합니다. 이 복합칸은 <테두리>복합칸에서 <평면>을 찰칵하였을 때에만 사용가능상태로 됩니다.
    • <본문류형>복합칸에서 본문칸조종체에 본문을 입력하는 경우 한행을 입력하겠는가 혹은 여러 행을 입력하겠는가를 설정합니다.
    • <흘림띠>복합칸에서 본문칸조종체에 가로 또는 세로흘림띠를 주겠는가를 설정합니다.
    • <암호문자>본문칸에 한 문자를 입력합니다. 거기에 입력한 문자로 본문칸조종체의 모든 문자들이 현시됩니다. <암호문자>본문칸은 <본문류형>복합칸에서 <한행>을 선택하였을 때에만 사용가능상태로 됩니다.
    • <선택령역 숨기기>복합칸에서 조종체본문의 선택령역을 숨기겠는가를 설정합니다.
    • <도움말본문>본문칸에 이 본문칸조종체로 마우스유표를 가져갔을 때 현시되는 본문을 입력합니다.

서식화된 마당의 만들기

  1. <양식조종체>도구띠에서 <서식화된 마당>을 찰칵합니다.
  2. 해당 령역에 마우스를 끌기하여 서식화된 마당조종체를 생성합니다.
  3. 조종체의 설계방식을 해제하려면 <양식조종체>도구띠의 <설계방식 적용/해제>를 찰칵합니다.

서식화된 마당의 속성변경

  1. 속성을 변경하려는 서식화된 마당을 찰칵합니다.
  2. <양식조종체>도구띠에서 <조종체속성>을 찰칵합니다.
  3. <속성: 서식화된 마당>대화창에서 서식화된 마당의 속성을 설정합니다.

    4. <일반>표쪽에서 속성변경

    • <최소값>본문칸에 서식화된 마당조종체에 입력될수 있는 최소값을 입력합니다.
    • <최대값>본문칸에 서식화된 마당조종체에 입력될수 있는 최대값을 입력합니다.
    • <서식 설정>본문칸의 옆에 있는 단추를 리용하여 서식을 지정합니다. 서식설정을 어떻게 하는가에 따라 최소값과 최대값이 달라집니다.
    • <증감단추>복합칸에서 서식화된 마당조종체에 증감단추를 삽입하겠는가를 설정합니다.
    • 이외의 속성설정은 본문칸조종체의 속성변경을 참고하십시오.

표식자마당의 만들기

  1. <양식조종체>도구띠에서 <표식자마당>을 찰칵합니다.
  2. 해당 령역에 마우스를 끌기하여 표식자마당조종체를 생성합니다.
  3. 조종체의 설계방식을 해제하려면 <양식조종체>도구띠의 <설계방식 적용/해제>를 찰칵합니다.

표식자마당의 속성변경

  1. 속성을 변경하려는 표식자마당을 찰칵합니다.
  2. <양식조종체>도구띠에서 <조종체속성>을 찰칵합니다.
  3. <속성: 표식자마당>대화창에서 표식자마당의 속성을 설정합니다. 본문칸조종체의 속성변경을 참고하십시오.
