복합칸, 목록칸

모두 표시

복합칸조종체와 목록칸조종체를 만들려면 다음과 같은 방법으로 진행합니다.

복합칸의 만들기

  1. <양식조종체>도구띠에서 <복합칸>을 찰칵합니다.
  2. 해당 령역에 마우스를 끌기하면 <복합칸자동안내처리>대화창이 현시됩니다.
  3. <자료원본>복합칸에서 자료원본을 선택하고 <표/질문>목록칸에서 자료원본의 표를 선택한 다음 대화창의 <다음>단추를 찰칵합니다.
  4. <조종체>령역의 목록칸에서 목록내용의 자료로 사용될 표를 선택하고 <다음>단추를 찰칵합니다.
  5. <기존마당>목록칸에서 조종체에 현시할 마당을 선택하고 <다음>단추를 찰칵합니다.
  6. 자료기지마당의 값을 보관하기 위한 설정을 진행하고 <완료>단추를 찰칵합니다.
  7. 조종체의 설계방식을 해제하려면 <양식조종체>도구띠의 <설계방식 적용/해제>를 찰칵합니다.

복합칸의 속성변경

  1. 속성을 변경하려는 복합칸을 찰칵합니다.
  2. <양식조종체>도구띠에서 <조종체속성>을 찰칵합니다.
  3. <속성: 복합칸>대화창에서 복합칸조종체의 속성을 설정합니다.

    4. <일반>표쪽에서 속성변경

    • <이름>본문칸에 복합칸조종체의 이름을 입력합니다.
    • <표식자마당>본문칸에 복합칸의 표식자를 현시하기 위한 조종마당을 설정합니다.
    • <최대본문길이>증감단추의 본문칸에 최대문자수를 입력합니다.
    • <사용가능상태>복합칸에서 복합칸조종체의 사용가능 또는 사용불가능상태를 선택합니다.
    • <읽기전용>복합칸에서 복합칸조종체를 편집하도록 하겠는가 읽기전용으로 하겠는가를 선택합니다.
    • <인쇄>복합칸에서 문서를 인쇄하는 경우 이 복합칸조종체를 인쇄하겠는가 하지 않겠는가를 선택합니다.
    • <활성화순서>증감단추에서 조종체들사이의 활성화순서를 설정합니다.
    • <목록항목>복합칸에 복합칸조종체의 자료를 입력합니다. 복합칸조종체에 2개의 항목 《수자》 와 《문자》를 입력하려고 한다면 <목록항목>복합칸에 처음에 《수자》를 입력하고 그다음 《문자》를 입력합니다. <목록항목>복합칸에는 《수자》;《문자》 로 현시됩니다.
    • <기정본문>본문칸에 본문을 입력합니다.
    • <서체>본문칸의 옆에 있는 단추를 리용하여 서체를 설정합니다.
    • <맞추기>복합칸에서 복합칸조종체의 본문맞추기를 설정합니다.
    • <배경색>복합칸에서 복합칸조종체의 배경색을 설정합니다.
    • <테두리>복합칸에서 복합칸조종체의 테두리형식을 설정합니다.
    • <테두리색>복합칸에서 복합칸조종체의 테두리색을 설정합니다. 이 복합칸은 <테두리>복합칸에서 <평면>을 찰칵하였을 때에만 사용가능상태로 됩니다.
    • <내리떨구기>복합칸에서 복합칸조종체의 내려떨구기단추를 현시하겠는가 현시하지 않겠는가를 설정합니다.
    • <렬수>증감단추에 복합칸조종체의 항목수를 입력합니다.
    • <선택령역 숨기기>복합칸에서 조종체의 본문을 선택하였을 때 선택한 부분을 숨기겠는가를 설정합니다.
    • <도움말본문>본문칸에 이 복합칸조종체로 마우스유표를 가져갔을 때 현시되는 본문을 입력합니다.

    <자료>표쪽에서 속성변경

    • <자료마당>본문칸에 조종체가 참조하는 자료원본표의 마당을 지정합니다.
    • <빈 문자렬은 NULL>복합칸에서 빈 문자렬 입력이 처리되는 방법을 정의합니다. <예>를 선택한 경우 길이가 0인 문자렬은 NULL값과 같이 처리됩니다. <아니>를 선택한 경우 어떤 입력도 변환없이 취급됩니다.
    • <목록내용류형>복합칸에서 목록칸조종체와 복합칸조종체의 목록을 채울 자료를 결정합니다.
    • <목록내용>복합칸에서 자료기지양식을 사용하여 양식요소의 목록내용에 대한 자료원본을 지정합니다.

목록칸의 만들기

  1. <양식조종체>도구띠에서 <목록칸>을 찰칵합니다.
  2. 해당 령역에 마우스를 끌기하면 <목록칸자동안내처리>대화창이 현시됩니다.
  3. <자료원본>복합칸에서 자료원본을 선택하고 <표/질문>목록칸에서 자료원본의 표를 선택한 다음 대화창의 <다음>단추를 찰칵합니다.
  4. <조종체>령역의 목록칸에서 목록내용의 자료로 사용될 표를 선택하고 <다음>단추를 찰칵합니다.
  5. <기존마당>목록칸에서 조종체에 현시할 마당을 선택하고 <다음>단추를 찰칵합니다.
  6. <수값표로부터의 마당>목록칸과 <목록표로부터의 마당>목록칸에서 현시마당의 내용과 일치하는 마당을 선택하고 <완료>단추를 찰칵합니다.
  7. 조종체의 설계방식을 해제하려면 <양식조종체>도구띠의 <설계방식 적용/해제>를 찰칵합니다.

목록칸의 속성변경

  1. 속성을 변경하려는 목록칸을 찰칵합니다.
  2. <양식조종체>도구띠에서 <조종체속성>을 찰칵합니다.
  3. <속성: 목록칸>대화창에서 목록칸조종체의 속성을 설정합니다. 복합칸조종체의 속성변경을 참고하십시오.
