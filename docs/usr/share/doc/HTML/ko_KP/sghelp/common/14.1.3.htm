수학식의 내용편집

수학식의 내용을 편집하려면 다음과 같은 방법으로 진행합니다.

  1. 편집하려는 수학식을 선택하고 두번 찰칵합니다.

  2. <요소>창의 기호들을 사용하여 수학식을 편집합니다.

  3. 수학식편집이 다 끝나면 수학식본문칸밖의 임의의 곳을 찰칵하여 수학식입력상태를 해제합니다.

수학식에서 항목의 지우기

수학식에서 어떤 항목을 지우려면 다음의 방법들중에서 하나를 실행합니다.

삽입지시자의 왼쪽에 있는 문자나 기호를 지우려면

[Backspace]건을 누릅니다.

삽입지시자의 오른쪽에 있는 문자나 기호를 지우려면

[Delete]건을 누릅니다.

수학식안에 본문삽입

수학식안에 본문을 삽입하려면 <서식>차림표에서 <본문방식>을 찰칵하고 수학식본문칸에 본문을 입력합니다.

즉시도움말

표처리프로그람에서 수학식의 속성변경

수학식은 문서에 삽입된 객체이기때문에 그의 속성 등을 변경할수 있습니다. 례를 들어 수학식의 테두리격식이나 색, 수학식의 배경색, 그림자효과 등을 줄수 있습니다.

수학식의 속성변경은 일반객체의 속성변경과 같습니다.

수학식의 속성을 변경하려면 다음과 같은 방법으로 진행합니다.

  1. 속성을 변경하려는 수학식을 선택하고 <서식>차림표의 <객체>의 부분항목들을 찰칵합니다.
  2. 해당 선택항목들의 대화창이 펼쳐집니다.
  3. 요구하는 변경내용에 따라 해당한 표쪽을 찰칵하여 변경을 진행합니다.
  4. 속성변경을 진행한 후 <확인>단추를 찰칵하여 대화창을 닫습니다.
