수학식의 서체크기변경

모두 표시

수학식에서 변수, 함수, 수자, 본문의 서체크기를 요구하는대로 변경할수 있습니다. 수학식에서 변수, 함수, 수자, 본문의 서체크기를 변경하려면 다음과 같은 방법으로 진행합니다.

  1. 변수, 함수, 수자, 본문의 서체크기를 변경하려는 수학식을 선택하고 두번 찰칵합니다.
  2. <서식>차림표에서 <서체크기>를 찰칵합니다.
  3. <서체크기>대화창에서 다음의 방법들중에서 하나를 실행합니다.
    • 수학식전체의 서체크기를 변경하려면 <기본크기>증감단추에 요구하는 수값을 입력합니다.
    • 수학식안에서 본문, 첨자, 함수, 연산자, 극한의 서체크기를 상대적으로 조절하려면 <비례크기>령역의 해당한 증감단추에 요구하는 수값을 입력합니다.

      • 참고: 변경된 내용을 모든 새 수학식에 적용하려면 <기정>단추를 찰칵합니다.

  4. <확인>단추를 찰칵합니다.
