흘림띠, 증감단추

모두 표시

흘림띠의 만들기

  1. <기타 조종체>도구띠에서 <흘림띠>를 찰칵합니다.
  2. 해당 령역에 마우스를 끌기하여 흘림띠조종체를 생성합니다.
  3. 조종체의 설계방식을 해제하려면 <양식조종체>도구띠의 <설계방식 적용/해제>를 찰칵합니다.

흘림띠의 속성변경

  1. 속성을 변경하려는 <흘림띠>를 찰칵합니다.
  2. <양식조종체>도구띠에서 <조종체속성>을 찰칵합니다.
  3. <속성: 흘림띠>대화창에서 흘림띠조종체의 속성을 설정합니다.

    4. <일반>표쪽에서 속성변경

    • <이름>본문칸에 흘림띠조종체의 이름을 입력합니다.
    • <사용가능상태>복합칸에서 <예> 또는 <아니>를 선택하여 흘림띠조종체의 사용가능 또는 사용불가능상태를 설정합니다.
    • <인쇄가능>복합칸에서 <예> 또는 <아니>를 선택하여 문서를 인쇄하는 경우 이 흘림띠조종체를 인쇄하겠는가 하지 않겠는가를 설정합니다.
    • <태브정지점>복합칸에서 조종체들의 활성화순서를 설정하겠는가를 설정합니다.
    • <활성화순서>증감단추에서 조종체들의 활성화순서를 설정합니다.
    • <최소흘림값>본문칸에 흘림띠조종체의 최소흘림값을 입력합니다.
    • <최대흘림값>본문칸에 흘림띠조종체의 최대흘림값을 입력합니다.
    • <기정흘림값>본문칸에 흘림띠조종체의 기정흘림값을 입력합니다.
    • <작은 변경사항>본문칸에 흘림띠조종체의 왼쪽이나 오른쪽화살표를 찰칵할 때 이동할 흘림값을 입력합니다.
    • <큰 변경사항>본문칸에 흘림띠조종체를 찰칵할 때 이동할 흘림값을 입력합니다.
    • <보이는 크기>본문칸에 흘림띠조종체의 이동단추의 크기를 입력합니다.
    • <방향>복합칸에서 흘림띠조종체를 가로흘림띠로 하겠는가 세로흘림띠로 하겠는가를 설정합니다.
    • <배경색>복합칸에서 흘림띠조종체의 배경색을 설정합니다.
    • <기호색>복합칸에서 흘림띠조종체의 화살표색을 설정합니다.
    • <테두리>복합칸에서 흘림띠조종체의 테두리형식을 설정합니다.
    • <테두리색>복합칸에서 흘림띠조종체의 테두리색을 설정합니다. 이 복합칸은 <테두리>복합칸에서 <평면>을 찰칵하였을 때에만 사용가능상태로 됩니다.
    • <도움말본문>본문칸에 이 흘림띠조종체로 마우스유표를 가져갔을 때 현시되는 본문을 입력합니다.

증감단추의 만들기

  1. <기타 조종체>도구띠에서 <증감단추>를 찰칵합니다.
  2. 해당 령역에 마우스를 끌기하여 증감단추를 생성합니다.
  3. 조종체의 설계방식을 해제하려면 <양식조종체>도구띠의 <설계방식 적용/해제>를 찰칵합니다.

증감단추의 속성변경

  1. 속성을 변경하려는 <증감단추>를 찰칵합니다.
  2. <양식조종체>도구띠에서 <조종체속성>을 찰칵합니다.
  3. <속성: 증감단추>대화창에서 증감단추조종체의 속성을 설정합니다. 흘림띠조종체의 속성변경을 참고하십시오.
