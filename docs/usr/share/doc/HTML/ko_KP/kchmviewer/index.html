CHM파일열람기 

이 프로그람은 CHM파일(*.chm)들을 열람하기 위한 전용열람기입니다.

1. 기동과 완료

    기동
    - 확장자가 CHM인 파일을 두번 누르기하면 자동적으로 CHM파일열람기가 동작합니다.
    - <응용프로그람>/<CHM파일열람기>를 실행합니다.

    완료
    - 차림표에서 <CHM파일열람기>/<CHM파일열람기 끝내기>를 누릅니다.
    - 제목띠에서 <닫기>단추를 누릅니다.
    - 지름건 Ctrl+Q 를 누릅니다.

2. 차림표의 리용

- 파일

항 목

설 명

열기... CHM파일을 열기합니다.(Ctrl+O)
인쇄... 현재 펼쳐진 페지에 대한 인쇄를 진행합니다.(Ctrl+P)
CHM압축풀기 CHM파일을 압축풀기하여 압축전상태의 파일들을 생성합니다.
최근파일열기 최근에 열람하였던 파일들을 선택하여 열기합니다.

- 편집

항 목

설 명
복사 현재 열람기에 선택된 내용을 오려둠판에 복사합니다.(Ctrl+C)
전체 선택 현재 펼쳐진 페지에 대한 전체 내용선택을 진행합니다.(Ctrl+A)

- 보기

항 목

설 명
글자크기증가 / 글자크기감소 내용보기창에 펼쳐진 글자의 크기를 증가 및 감소시킵니다.(Ctrl++/Ctrl+-)
HTML원천코드보기 현재 펼쳐진 페지에 대한 HTML원천코드내용을 보여줍니다.(Ctrl+U)
전화면 CHM열람기를 전화면방식/보통화면방식으로 절환하여 보여줍니다.(Ctrl+Shift+F)
차례창문현시 화면의 왼쪽에 위치한 차례창문을 현시/감추기를 진행합니다.(F2)
차례에서 찾기 현재 펼쳐진 페지를 차례목록에서 찾아 선택하여 줍니다.(Ctrl+L)

- 책갈피

항 목

설 명
책갈피추가 현재 현시된 페지를 책갈피에 등록합니다.(Ctrl+B)
등록된 제목들은 <책갈피추가>차림표 아래에 추가됩니다. 이 항목들을 눌러 등록된 책갈피를 열람할수 있습니다.

- 창문

항 목

설 명
닫기 현재 펼쳐진 페지를 닫습니다.(Alt+Q)
아래에는 현재 열람중인 페지들의 제목들이 나타납니다. 안내창에 현시되는 제목우에서 오른쪽단추를 누르고 <새 페지에서 열기>를 누르면 새로운 태브창문이 현시됩니다.
기능건 Alt+1, Alt+2, … 을 리용하여 절환을 진행합니다.

3. 도구띠의 리용

제 목

설 명
파일열기 CHM파일을 열기합니다.(Ctrl+O)
인쇄 현재 펼쳐진 파일에 대한 인쇄를 진행합니다.(Ctrl+P)
이전리력보기/다음리력보기 리력정보에 기초하여 리력의 이전페지/다음페지를 열람합니다.(Ctrl+Left/Ctrl+Right)
첫페지로 가기 CHM파일을 처음 열기할 때 현시되는 페지에로 되돌아갑니다.(Ctrl+Home)
문자렬입력창 검색할 문자렬을 입력합니다.(Ctrl+F)
이전검색결과/다음검색결과 검색문자렬 입력창에 입력한 문자렬에 대한 앞방향/뒤방향 검색을 진행합니다.(F3/F4)
차례에서 찾기 현재 열람하는 내용의 제목을 차례에서 보여줍니다.(Ctrl+L)
전화면방식/전화면방식 끝내기 CHM열람기를 전화면방식/보통화면방식으로 절환하여 보여줍니다.(Ctrl+Shift+F)
글자크기증가/글자크기감소 현재 열람중인 페지의 문자크기를 증가/감소시킵니다.(Ctrl++/Ctrl+-)
HTML원천코드보기 현재 펼쳐진 페지에 대한 HTML원천코드내용을 보여줍니다.(Ctrl+U)
책갈피에 추가 현재 펼쳐진 페지를 책갈피에 등록합니다.(Ctrl+B)
이전제목/다음제목 현재 보기하는 페지의 이전/다음제목을 현시합니다.(Ctrl+Up/Ctrl+Down)

4. 안내창의 리용

- 차례창(Ctrl+1)

차례보기창에서 제목을 두번 누르면 해당 내용이 내용보기창에 현시됩니다.

- 색인창(Ctrl+2)

입력칸에 색인내용을 입력합니다. 목록창에 현시되는 제목을 두번 누르면 해당 내용이 내용보기창에 현시됩니다.

- 검색창(Ctrl+3)

입력칸에 검색할 내용을 입력하고 <검색>단추를 누릅니다. 검색된 페지제목들이 아래의 목록창에 현시됩니다. 제목을 두번 누르면 해당 내용이 현시됩니다.

- 책갈피창(Ctrl+4)

   추가: 책갈피를 새로 추가합니다.
   편집: 이미 등록된 책갈피의 제목을 바꿀수 있습니다.
   삭제: 선택된 항목을 책갈피에서 삭제합니다.
