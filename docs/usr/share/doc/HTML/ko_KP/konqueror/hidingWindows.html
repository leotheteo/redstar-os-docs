창문숨기기

여러 창문이 열려있을 때 작업을 보다 쉽게 하기 위하여 한개이상의 창문을 일시적으로 숨길수 있습니다.

몇가지 방법으로 창문을 숨길수 있습니다.

■

창문을 숨기려면 창문의 왼쪽 웃구석에 있는 노란색의 <최소화(-)>단추를 마우스로 누르십시오.

■

<파일열람기>에서 창문을 숨기려면 <파일열람기 / 파일열람기 숨기기> 또는 <파일열람기 / 다른 창문 숨기기>를 선택합니다. <파일열람기>차림표가 보이지 않는다면 응용프로그람이 사용중인 상태입니다.

■

응용프로그람내에서 창문을 숨기려면 해당 응용프로그람차림표를 열고 숨기기선택항목중 하나를 선택합니다. 실례로 본문편집기의 경우 <본문편집기 / 본문편집기 숨기기> 또는 <본문편집기 / 다른 창문 숨기기>를 선택합니다.

■

열려진 모든 창문을 숨기고 탁상화면을 보려면 [F11]건을 누릅니다. [F11]건을 다시 누르면 <일반보기>로 돌아갑니다. (휴대용콤퓨터에서는 [Fn-F11]건을 누릅니다.)

창문을 다시 나타나게 하려면 도크에서 응용프로그람의 그림기호를 마우스로 누르거나 응용프로그람차림표에서 <모두 표시>를 선택하십시오.
