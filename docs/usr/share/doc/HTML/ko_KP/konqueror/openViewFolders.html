서류철 열기와 보기

<파일열람기>에서 계층구조로 되여 있는 서류철안으로 이동하려면 필요한 서류철을 마우스로 두번 누르십시오.

서류철을 찾아보려면

탁상화면의 웃부분 오른쪽모서리에 있는 <하드디스크>그림기호를 마우스로 두번 눌러서 <파일열람기>창문을 엽니다.

<파일열람기>창문의 왼쪽에 있는 목록에서 문서를 마우스로 누르십시오.

왼쪽에 있는 목록을 측면띠라고 하는데 특정한 서류철에 마우스로 눌러서 접근할수 있게 해줍니다.

<파일열람기>창문의 웃부분에 있는 <보기>단추들을 마우스로 누르면 보기방식이 변경됩니다.

각각 3개의 보기로 서류철을 열고 닫아보십시오.

측면띠에서 마우스로 한번 누르면 항목들이 열립니다. <파일열람기>창문의 오른쪽에서 마우스로 두번 누르면 항목들이 열립니다.

이때까지 진행한 동작들을 다시 거슬러올라가려면 <파일열람기>창문의 웃부분 왼쪽모서리에 있는 삼각형모양의 <뒤로>단추를 마우스로 누르십시오.
