첫페지

차림표의 사용

대화접속
대화접속조작과 관련한 차림표입니다.

새 대화접속[Ctrl + Alt + N]

새로운 대화접속을 창조합니다.

새 창문[Ctrl + Alt + W]

새로운 조작탁을 열기합니다.

대화접속 닫기

현재의 대화접속을 닫습니다.

편집
편집조작과 관련한 차림표입니다.

복사

편집창의 선택된 내용을 오려둠판에 보관합니다.

붙이기[Shift + Insert]

오려둠판에 보관된 내용을 붙이기합니다.

리력에서 탐색

대화접속창의 리력에서 탐색을 진행합니다.

다음 탐색

리력에서 다음의 탐색어와 같은 부분으로 이행합니다.

이전 탐색

리력에서 이전의 탐색어와 같은 부분으로 이행합니다.

보기
보기조작과 관련한 차림표입니다.

대화접속분리

현재의 대화접속을 새로운 조작탁창문으로 열기합니다.

대화접속 이름변경[Ctrl + Alt + S]

현재의 대화접속의 이름을 변경합니다.

대화접속상태감시 및 입력보내기

현재의 대화접속의 활동 및 정지상태를 감시하거나 모든 대화접속들이 같은 명령을 수행하도록 합니다.

대화접속이동

현재의 대화접속위치를 오른쪽 혹은 왼쪽으로 이동합니다.

설정
설정조작과 관련한 차림표입니다.

완전화면방식[Ctrl + Shift + F]

화면방식을 완전화면방식으로 변경시킵니다.

서체

현재대화접속의 서체를 설정합니다.

부호화

현재대화접속의 부호화를 설정합니다.

구도

현재대화접속의 구도를 설정합니다.

기정설정으로 보관

설정된 내용을 기정설정으로 보관합니다.

설정파일로 보관

설정된 내용을 파일로 보관합니다.
