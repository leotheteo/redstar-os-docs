도움말주제를 찾을수 없습니다.

탐색어와 일치하는 도움말주제를 찾을수 없거나 해당한 도움말페지를 열수 없습니다. 아래에 간단한 해결방도들을 첨부하였습니다.

다음과 같이 해보십시오:
■

탐색어입력칸에 입력한 단어를 다시 확인해보십시오.

■

다른 단어로 탐색해보십시오.

■

한개의 단어를 탐색하였다면 2~3개의 단어를 더 입력하고 탐색을 해보십시오. 여러개의 단어로 탐색결과들이 나타나면 입력된 단어들의 개수를 줄여서 탐색을 해보십시오.

■

탐색하려는 주제의 시작단어들을 입력하십시오.(실례로, 《망설정》 대신에 《망》을 입력하십시오 )

■

체계에서 사용하는 응용프로그람들의 도움말주제들에 대해서만 탐색을 진행합니다.

도움말들의 제목은 도움말열람기 창문의 제목띠에 나타납니다.
