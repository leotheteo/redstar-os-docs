Exploring RedStar OS

It's safe to explore your computer using the Finder, the Dock, and your RedStar OS applications.

To exploreRedStar OS:

■

Open the applications that come with RedStar OS and experiment with them.

Look at the commands in the menus and try each one. If you see tool icons or buttons, click them to try each one. If a button or menu item is dimmed, you may need to perform an action (such as select some text) before you can use it.

■

Try accomplishing specific tasks.

Create a document or open a new window. Type text or draw graphics. Save the document, then change it. Close it, then open it again.

■

Use the onscreen help.

Decide what you’re interested in knowing about, open the help (usually in the Help menu in the menu bar), and search for it.

■

Use shortcuts to help make your work easier.

Start by learning the keyboard shortcuts shown next to menu commands. You’ll find information about other shortcuts in other onscreen help topics.
