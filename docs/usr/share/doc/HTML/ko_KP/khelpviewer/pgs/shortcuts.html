Setting shortcuts for Spaces

You can create keyboard and mouse shortcuts to activate and switch between spaces. You can also put an icon for Spaces in the menu bar.

To create shortcuts for Spaces:

Choose RedStar menu > System Preferences, click Exposé & Spaces, and then click Spaces.

Use the pop-up menus to choose keyboard shortcuts, mouse shortcuts, or both.

For more information about the options, click the Help (question mark) button.
