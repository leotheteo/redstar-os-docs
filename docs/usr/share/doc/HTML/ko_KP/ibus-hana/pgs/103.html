첫페지

한자입력

한자입력은 문자단위 혹은 문절단위로 한자변환을 하는 방법으로 진행합니다.

문자단위 입력
한 글자를 입력하고 미확정상태에서 오른쪽[Ctrl]건을 누른 다음 다시 아래방향건을 누릅니다.
이때 입력한 글자에 해당한 한자가 있는 경우 한자후보창이 나타납니다.
우/아래방향건을 리용하여 필요한 한자를 선택하고 [Enter]건을 누르거나 후보단어의 앞에 있는 수자건을 눌러서 입력을 진행합니다.
문절단위 입력
먼저 <환경설정>에서 확정방식을 문절단위로 설정합니다.
미확정상태에서 오른쪽[Ctrl]건을 누르면 현재 입력된 조선어문절에 대한 한자변환을 진행합니다.
아래방향건을 누른 다음 한자후보창을 펼칩니다.
우/아래방향건을 리용하여 첫 문구의 한자를 선택합니다.
좌/우방향건을 리용하여 다음 문구를 선택하고 우와 같은 방법으로 필요한 한자를 선택합니다.
※참고
한자후보들이 9개를 넘는 경우에는 흐름띠를 리용하여 다음 혹은 이전 후보목록을 볼수 있습니다.
