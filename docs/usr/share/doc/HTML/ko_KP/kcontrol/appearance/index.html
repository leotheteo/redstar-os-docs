  일반설정하기

여러가지 방법으로 《붉은별》사용자용체계3.0판의 전체보기를 설정하여 작업환경을 더 편리하게 보이도록 합니다.

환경설정

설명

겉모양과 강조된 색

일반체계색을 변환하도록 하기 위하여 펼침차림표로부터 색들을 선택합니다.

흘림띠화살표 표시위치

어느한 항목을 선택하여 <파일열람기>나 다른 응용프로그람창문에 현시할 흘림띠화살표의 위치를 설정합니다.

흘림띠를 찰칵할 때

흘림띠에서 마우스를 찰칵할 때 페지이동방식을 설정합니다. <다음페지로 이동>은 흘림이동띠를 찰칵하여 한 페지씩 이동한다는것을 의미합니다. <선택 위치로 이동>은 마우스로 찰칵하는 곳으로 이동합니다. 실례로 흘림이동띠의 밑을 찰칵하면 문서의 마지막으로 이동합니다.

창문제목띠의 두번찰칵에 의한 최소화

제목띠를 두번 찰칵함으로써 창문을 도크로 최소화할수 있습니다.

최근 리용한 개수

《붉은별》차림표는 <최근 리용한 개수>라는 항목을 가지고있습니다. 이 펼침차림표를 사용하여 얼마나 많은 항목들을 그 차림표에 현시하여야 하는가를 선택합니다.

서체의 경계잡음처리 형태

본문을 화면에 현시하는 방법을 약간 조절하기 위해서는 펼침차림표로부터 내용을 선택합니다.
