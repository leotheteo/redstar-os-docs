  공통차림표에서 PPPoE상태보기

망환경설정을 열지 않고 공통차림표의 그림기호에서 PPPoE련결을 조종할수 있습니다.

공통차림표에서 PPPoE상태를 보려면

<공통차림표/체계환경설정>을 선택한 다음 <망>을 찰칵합니다.

망련결봉사목록에서

■

<PPPoE봉사>를 선택합니다.

■

목록에 <PPPoE봉사>가 없다면 목록의 아래에 있는 <추가(+)>단추를 찰칵합니다. <대면>내리펼침안내에서 <PPPoE>를 선택하고 <이써네트>내리펼침차림표의 이써네트대면(유선련결인 경우에는 이써네트, 무선련결인 경우에는 AirPort)을 선택하고 PPPoE봉사에 이름을 입력하고 <창조>단추를 찰칵합니다.

봉사제공자로부터 받은 사용자정보를 입력하고 <적용>단추를 찰칵합니다.

인터네트련결에 필요한 정보

<공통차림표에서 PPPoE상태보기>를 선택합니다.

PPPoE상태차림표를 사용하여 PPPoE봉사에 련결하거나 련결된 시간을 표시하며 련결되여있는동안 상태를 표시합니다.
