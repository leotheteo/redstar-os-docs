  마우스의 동작을 변경하기

마우스의 동작을 변경시켜 사용자는 더욱 편리하게 작업할수 있습니다.

마우스에 대한 설정을 진행하려면

<붉은별차림표/체계환경설정/건반과 마우스>를 선택합니다.

<마우스>태브를 선택합니다.

미끄럼띠들을 조절합니다. 미끄럼띠들을 조절하고 변경된 효과를 보려면 마우스를 이동 및 찰칵해보십시오.

■

추적속도: 마우스가 움직일 때의 지시자의 이동속도를 조절합니다.

■

두번찰칵속도: 콤퓨터가 두번찰칵을 인식하자면 얼마나 빨리 눌러야 하는가를 조절합니다.

■

굴개속도(사용하는 마우스에 굴개가 있는 경우): 굴개를 움직이는 경우 지시자가 얼마나 빨리 움직이는가를 조절합니다.

■

마우스주단추: 모든 선택과 찰칵에 리용하는 단추를 선택합니다.
