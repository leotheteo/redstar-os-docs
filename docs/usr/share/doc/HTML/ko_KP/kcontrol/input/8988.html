  Mighty마우스의 리용

Mighty마우스(Apple의 단추가 4개인 마우스)를 사용하는 경우 사용자는 단추들의 동작을 조절하는 방법으로 그것의 설정을 진행할수 있습니다.

Mighty마우스에 대한 설정을 진행하기 위해서는

<붉은별차림표/체계환경설정/건반과 마우스>를 선택합니다.

<마우스>태브를 선택합니다.

마우스에 대한 설정을 진행하기 위하여 안내들과 미끄럼띠들을 리용할수 있습니다.

■

기본단추: 모든 찰칵과 추적을 위한것입니다. 왼쪽단추, 오른쪽단추 또는 두개의 단추가 다 될수 있습니다.

■

보조단추: 지름안내를 표시해줍니다.

■

화면효과, 응용프로그람절환기: 해당 도구들을 실행시킵니다.

■

기타: 사용자가 선택하는 응용프로그람을 기동합니다.

■

없음: 단추를 비활성화합니다.

■

굴개속도: 창문과 목록에서 마우스굴개의 동작을 설정합니다. 마우스굴개를 돌릴 때 지시자의 이동속도를 설정하기 위하여 이 미끄럼띠를 리용합니다.

■

추적속도: 마우스를 끌기할 때 지시자의 이동속도를 조절합니다.

■

두번찰칵속도: 콤퓨터가 인식할수 있는 두번찰칵속도를 조절합니다.
