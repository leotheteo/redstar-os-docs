  수정건 바꾸기

다음의 수정건들의 동작을 바꿀수 있습니다. [CapsLock], [Ctrl], [Alt], [Win]. 이 기능은 사용자가 현재의 건반과 다른 건반배치에 익숙하였을 때 유용합니다.

례를 들어 UNIX와 Sun콤퓨터건반들은 Apple콤퓨터의 [CapsLock]건자리에 [Control]건이 있습니다. 그 건반에 숙련된 타자수들에게는 불편할수 있습니다. [Caps Lock]건을 [Control]건으로 바꾸는 기능은 이런 문제들을 해결합니다.

수정건들을 바꾸기 위해서는

<붉은별차림표/체계환경설정/건반과 마우스>를 선택합니다.

<건반>태브를 선택합니다.

<수정건>단추를 찰칵합니다.

바꾸려는 수정건옆의 내리펼침목록에서 동작을 선택하고 확인을 진행합니다.

본래의 설정으로 돌아가려면 <표준설정>단추를 찰칵합니다.
