  계정환경설정의 등록가입항목열기

콤퓨터에 등록가입할 때 응용프로그람, 문서 또는 봉사기련결을 자동으로 열리도록 할수 있습니다.

환경설정

설명

항목

항목은 자동으로 열리는 응용프로그람, 문서 또는 련결이름을 보여줍니다.

종류

종류는 자동으로 열리는 항목의 종류를 보여줍니다.

<추가(+)>단추 및 <삭제(-)>단추

새로운 항목이 등록가입때 자동으로 열리게 하려면 <추가(+)>단추를 찰칵하고 원하는 항목을 선택합니다.

특정한 항목이 자동으로 열리는것을 중단하려면 목록에서 해당 항목을 선택하고 <삭제(-)>단추를 찰칵합니다.
