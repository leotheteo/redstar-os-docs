  계정의 생성

계정을 추가하려면

새 계정내리펼침안내에서 계정형태를 선택합니다.

관리자: 관리자는 계정을 생성하고 삭제할수 있으며 체계설정을 변경할수 있습니다.

표준: 표준사용자는 자기고유의 설정을 진행할수 있으며 체계환경설정을 변경하거나 계정을 생성할수는 없습니다.

공유만 가능: 원격가입에 리용되며 콤퓨터상의 파일을 변경하거나 체계에 등록가입을 할수 없습니다.

그룹: 선택된 사용자들로 구성된 사용자들의 모임입니다.

계정의 이름을 입력합니다.

자동으로 생성된 ID이름을 사용하고싶지 않다면 새로운 ID이름을 입력합니다.

참고: 계정이 생성되면 ID이름을 변경할수 없습니다.

계정의 ID이름을 변경할수 없습니다.

<통과암호>입력칸에 계정에 대한 통과암호를 입력한 다음 확인입력칸에 다시 입력합니다.

<통과암호암시>입력칸에 통과암호에 대한 암시를 입력합니다.

<계정생성>을 찰칵합니다.
