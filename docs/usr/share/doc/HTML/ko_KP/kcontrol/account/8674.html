  사용자가 콤퓨터에 등록가입하도록 요청

콤퓨터에 여러명의 사용자가 있거나 정보를 안전하게 보호하기 위해 콤퓨터사용자가 통과암호를 사용하여 자신의 사용자에 등록가입하도록 요청할수 있습니다.

콤퓨터가 기동될 때 등록가입창문이 나타나지 않는다면 자동등록가입이 설정되여있는것입니다.

모든 사용자가 콤퓨터에 가입하게 하려면

<붉은별차림표/체계환경설정/계정>을 찰칵합니다.

일부 설정을 변경할수 없게 되여있다면 열쇠그림기호를 찰칵하고 관리자이름과 통과암호를 입력합니다.

<등록가입추가선택>을 찰칵합니다.

<자동등록가입>내리펼침안내에서 <금지>를 선택합니다.

<등록가입추가선택>을 선택합니다.

■

사용자가 등록가입창문안의 목록에 있는 사용자를 선택하게 하려면 <사용자목록>검사칸을 선택합니다.

■

사용자가 자신의 사용자계정과 이름을 입력하도록 요구하려면 <이름>과 <통과암호> 검사칸을 선택합니다.

■

계정의 통과암호암시를 표시하려면 <통과암호암시 보기>검사칸을 선택합니다.
