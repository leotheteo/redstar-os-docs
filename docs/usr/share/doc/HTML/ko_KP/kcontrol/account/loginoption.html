  계정환경설정의 등록가입추가선택을 사용

등록가입창문이 동작하는 방식을 보다 안전하게 변경하거나 사용자가 자신의 계정에 등록가입하는 방법을 설정할수 있습니다.

환경설정

설명

자동등록가입

콤퓨터가 기동할 때 자동으로 계정에 가입하게 하려면 내리펼침안내에서 해당 계정을 선택합니다. 이것은 콤퓨터를 켜기만 하면 누구나 등록가입할수 있으므로 안전하지 못합니다.

사용자가 등록가입창문에서 통과암호를 입력하도록 하려면 내리펼침안내에서 금지를 선택합니다.

등록가입창문을 다음과 같이 표시

<사용자목록>을 선택하여 사용자가 등록가입창문에서 원하는 계정을 선택하게 할수 있습니다.

<이름과 통과암호>를 선택하여 사용자가 콤퓨터를 사용할 때 등록가입창문에 자신의 이름과 통과암호를 입력하도록 요구할수 있습니다.

재기동, 잠자기 및 체계끄기단추 보기

<재기동, 잠자기 및 체계끄기단추 보기>를 선택하여 등록가입창문에 이 단추들을 표시할수 있습니다.

통과암호암시 보기

통과암호암시내용을 표시하려면 <통과암호암시 보기>검사칸을 선택합니다. 등록가입창문이나 사용자절환때 인증창문에서 통과암호를 세번이상 틀리게 입력하였을 때 통과암호암시가 자동으로 현시됩니다.

빠른 사용자절환 활성화

사용자가 《붉은별》차림표로부터 다른 계정을 빠르게 선택할수 있게 하려면 <빠른 사용자절환 활성화> 검사칸을 선택하고 내리펼침안내에서 계정을 어떻게 표시할것인가를 선택합니다.

환경설정의 아래부분에 있는 <추가(+)>단추 및 <삭제(-)>단추

새로운 계정을 생성하려면 <추가(+)>단추를 찰칵하고 새로운 계정에 대한 정보를 입력합니다.

계정을 삭제하려면 목록에서 해당 계정을 찰칵하고 <삭제(-)>단추를 찰칵합니다.

열쇠

관리자만이 환경설정을 변경할수 있습니다. 계정환경설정을 잠금 해제하려면 열쇠그림기호를 찰칵하고 관리자의 계정통과암호를 입력합니다.
