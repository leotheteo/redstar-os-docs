  계정설정

<계정환경설정>을 사용하여 사용자에 대한 등록가입정보의 설정과 관리, 사용자의 권한과 사용자가 콤퓨터에 등록가입하는 방법을 설정할수 있습니다.

계정의 관리
관리자이름과 통과암호를 가지고있다면 <계정환경설정>을 사용하여 계정을 추가, 삭제 및 수정할수 있습니다.
■
관리자에 대하여
새로운 계정을 생성
새로운 계정을 생성하기 위하여 <계정환경설정>을 사용할수 있습니다. 모든 사용자에 대하여 서로 다른 사용자를 창조하는것이 가장 좋으며 이 경우 매 사용자는 자신의 사용자서류철과 문서에 대한 접근권한만을 가지게 될것입니다. <추가(+)>단추를 찰칵하여 계정생성을 진행할수 있습니다.
■
계정의 생성
등록가입추가선택의 변경
등록가입창문에서 사용자가 콤퓨터에 가입하는 방식을 변경하며 빠른 사용자절환 활성화를 비롯한 등록가입추가선택을 변경할수 있습니다.
■
계정환경설정의 등록가입추가선택을 사용
등록가입때 자동으로 항목열기
항상 특정한 응용프로그람이나 문서를 사용한다면 등록가입항목에 추가함으로써 사용자가 가입할 때마다 자동으로 열리게 할수 있습니다.
■
등록가입시 자동으로 항목열기
계정통과암호의 변경
관리자이름과 통과암호를 가지고있다면 통과암호를 변경할수 있고 다른 계정의 통과암호를 관리할수 있습니다.
