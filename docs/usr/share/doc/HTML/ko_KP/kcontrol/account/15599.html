  다중사용자에 대하여

《붉은별》사용자용체계3.0판은 한 대의 콤퓨터에서 한명이상의 사용자에게 안전한 작업환경을 제공하도록 설계되였습니다. 콤퓨터를 사용하는 사용자가 한명이고 콤퓨터에 있는 정보의 안전을 걱정할 필요가 없다면 콤퓨터가 기동될 때마다 매번 사용자가입창문을 표시할 필요가 없을것입니다. 이런 경우 콤퓨터에 자동으로 등록가입되도록 설정할수 있습니다.

여러명이 콤퓨터를 사용하거나 콤퓨터가 다른 사람이 쉽게 사용할수 있는 공개된 곳에 있다면 매 사용자에 통과암호를 설정하고 사용자들이 콤퓨터를 사용할 때마다 등록가입 또는 등록가입탈퇴 하도록 해야 할것입니다.

사용자가 콤퓨터에서 가입탈퇴하면 열려있는 모든 문서들과 응용프로그람은 끝납니다. 사용자가 등록가입, 탈퇴하면서 응용프로그람을 계속 실행하도록 하거나 문서를 계속 열어 놓으려면 <빠른 사용자절환>을 사용할수 있습니다.

빠른 사용자절환이 켜져있다면 현재 사용자의 이름이 《붉은별》차림표의 오른쪽 웃부분 모서리에 나타납니다. 이 이름을 찰칵하여 절환하려는 다른 사용자를 선택할수 있습니다. 다른 사용자에 통과암호가 없으면 콤퓨터는 자동적으로 새로운 사용자의 사용자서류철로 절환해줍니다. 그렇지 않으면 사용자의 통과암호를 묻는 대화창문이 나타납니다. 다시 자신의 사용자로 절환하면 이전의 작업상태로 되돌아갑니다.

계정환경설정을 사용하여 사용자추가선택을 설정할수 있습니다. <사용자추가선택 및 사용자설정>에 관한 정보는 《붉은별》사용자용체계3.0판 도움말의 관련주제에서 찾을수 있습니다.
