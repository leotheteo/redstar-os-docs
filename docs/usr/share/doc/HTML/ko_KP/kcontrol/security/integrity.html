보안환경설정의 완전성항목에 대하여

완전성항목에서는 체계완전성검사도구의 동작방식을 설정하고 체계파일들의 완전성변경에 대한 기록을 열람할수 있습니다.

체계가 기동할 때 전체 체계파일들에 대한 완전성검사를 진행하려면 《체계가 기동할 때 완전성검사를 진행합니다.》를 선택합니다. 실시간감시기능을 활성화시키려면 《실시간검사를 진행합니다.》를 선택합니다. 설정된 내용은 보존되며 따라서 다음번 체계를 기동할 때에도 유효합니다.

기록관리에서는 체계파일들의 완전성변경에 대한 기록을 날자별로 열람할수 있습니다. 왼쪽의 목록에서 날자를 선택하면 오른쪽부분에 해당 날자의 기록내용이 현시됩니다.
