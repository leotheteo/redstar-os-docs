  자동적으로 가입탈퇴하도록 콤퓨터 설정하기

콤퓨터가 일정한 시간동안 비활성상태에 놓이면 자동적으로 가입탈퇴되도록 설정할수 있습니다.

주의: 변경한 문서를 저장하고 끄기전에 대화창이 나타나는 응용프로그람을 꺼야 합니다. 가입탈퇴중에 저장되지 않은 문서나 열려있는 응용프로그람에 대화창이 나타나면 콤퓨터는 가입탈퇴를 중지합니다.

자동적으로 가입탈퇴 하려면

<붉은별차림표/체계환경설정/보안>을 찰칵한 다음 <일반>태브를 찰칵합니다.

일부 항목이 설정할수 없도록 표시되여 있다면 열쇠그림기호를 찰칵하고 관리자이름과 암호를 입력합니다.

<···분동안 비활성상태이면 가입탈퇴>를 선택합니다.

비활성시간을 설정합니다.

보안을 추가하려면 <잠자기 또는 화면보호기로부터 콤퓨터를 깨울 때 암호요구>를 선택합니다.
