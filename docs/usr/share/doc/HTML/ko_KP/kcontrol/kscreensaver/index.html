  화면보호기환경설정의 리용

콤퓨터를 사용하지 않을 때 화면에 그림이 나타나게 할수 있습니다.

환경설정

설명

화면보호기

목록에서 화면보호기를 선택합니다. 일부 화면보호기는 추가항목들에 대한 설정을 진행할수 있습니다.

그림서류철: 그림 서류철에 그림이 있는 경우에만 동작합니다. 그림들은 JPEG, PNG 또는 TIFF와 같은 파일형식을 가지고있어야 합니다. 필요한 경우에는 화상가공프로그람을 리용하여 새로운 파일형식으로 그림을 저장할수 있습니다. 그림이 희미하게 표시된다면 큰 그림을 리용해보십시오. (1 024 x 768 화소 등)

서류철선택: 그림파일들이 있는 서류철을 추가할수 있습니다.

추가항목

화면보호기에서 화상들을 표시하는 방법을 구체적으로 설정할수 있습니다.

화면보호기 시작

미끄럼편을 마우스로 끌기하여 콤퓨터가 어느정도 비활성상태로 된 후에 화면보호기가 시작되게 할것인가를 지정할수 있습니다. 흐름띠의 값을 <금지>로 설정하면 화면보호기가 동작하지 않습니다.

임의의 화면보호기 사용

이 검사칸을 선택하면 화면보호기가 활성화될 때마다 다른 화면보호기가 실행됩니다.

시계 표시

이 검사칸을 선택하면 화면보호기가 활성화되여있는 동안 시간이 표시됩니다.
