  수동 혹은 DHCP로 IP주소 지정

ISP(인터네트 봉사 제공업체) 또는 IP(인터네트 규약) 망으로 련결을 설정할 때 《붉은별》사용자용체계3.0판에 인터네트 또는 망련결에 사용하는 정확한 IP주소를 제공하여야 합니다.

IP주소는 인터네트 또는 IP망에 있는 정보를 보낸 사람 또는 받는 사람을 식별하는 수자렬입니다. 현재 가장 널리 사용되는 IP규약은 IPv4(IP 판본 4)입니다. IPv4주소는 3개의 점으로 분리되는 수자렬이며 보통 다음과 같은 형태를 가집니다. 123.45.67.89.

다른 IP규약인 IPv6은 더 많은 콤퓨터들에서 IP주소를 필요로 함에 따라 사용률이 높아지고있습니다. IPv6주소는 7개의 두점으로 분리되는 8개의 4자리 16진수들로서 보통 다음과 같은 형태를 가집니다. fa80:0000:0000:0123:0203:93ee:ef5b:44a0.

ISP 또는 망에서 IP주소를 제공하는 방법에는 여러가지가 있습니다. 일반적으로 DHCP(Dynamic Host Configuration Protocol)설정이 있습니다. ISP 또는 망계정에서 DHCP를 사용한다면 콤퓨터는 IP주소를 자동으로 제공받습니다. ISP 또는 망계정에서 IP주소를 수동으로 제공한다면 《붉은별》사용자용체계3.0판에서는 체계환경설정의 망입력칸에 해당 주소를 입력하여야 합니다.

IP주소를 받는 방법을 선택하려면

<붉은별차림표/체계환경설정/망>을 찰칵합니다.

봉사목록에서 계정(내장이써네트 등)에 대한 망 또는 망포구구성을 선택합니다.

<구성>내리펼침안내에서 <수동> 또는 <DHCP사용>을 선택합니다. 수동을 선택한 경우 IP주소 입력칸에 주소를 입력합니다. 대부분사용자의 ISP는 부분망마스크경로기, DNS와 같이 다른 주소를 제공합니다. 해당 마당에 이에 대한 주소를 입력합니다.
