  영상표시장치 환경설정 사용하기

영상표시장치 환경설정을 사용하여 표시장치의 동작방식을 설정할수 있습니다.

환경설정

설명

해상도

표시장치가 표시할수 있는 세부도입니다. 해상도가 높으면 작은 크기로도 많은 내용이 표시됩니다. 해상도가 낮으면 큰 크기로도 적은 내용이 표시됩니다.

밝기

표시장치의 밝기를 변화시킬수 있습니다. 영상표시장치구동프로그람이 없는 경우 제대로 동작하지 않을수 있습니다.

공통차림표에 영상표시장치 표시

공통차림표에 최근에 사용된 해상도사이를 전환할수 있게 해주는 그림기호를 표시합니다.
