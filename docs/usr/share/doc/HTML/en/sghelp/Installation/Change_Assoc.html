Changing the Association of Microsoft Office Document Types

To change the association of Microsoft Office file name extensions to open the files either in Sogwang or in Microsoft Office, using Microsoft Windows:

  1. Exit Sogwang and the Sogwang Quickstarter.

  2. Run the Sogwang Setup program:

    Click the Windows Start button, choose Control Panel, click Add or Remove Programs, select the Sogwang 3.0 entry, click Change.

  3. In the Sogwang Setup, check the Modify option and click Next until you see the file types page.

  4. Select or deselect the file types. Click OK and complete the Sogwang Setup program.
