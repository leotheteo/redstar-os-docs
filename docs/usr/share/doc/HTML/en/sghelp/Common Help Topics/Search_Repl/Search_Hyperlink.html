Searching With the Hyperlink Bar

The Hyperlink Bar can be used to search for the selected text in the Internet.

  1. Choose View - Toolbars - Hyperlink Bar to open the Hyperlink Bar.

  2. Enter the text you want to find in the URL Name field.

    If you select text in your document, the text is automatically entered.

  3. Click the Find icon to open a submenu.

  4. Select your preferred search engine from the list.

Sogwang opens your Web Browser, which calls the selected Internet search engine. After a short time you see the result of your search on screen.

Choose Sogwang Office - Reference - Internet - Search to define the search options.
