Sogwang Draw Options

Defines the global settings for drawing documents, including the contents to be displayed, the scale to be used, the grid alignment and the contents to be printed by default.

To access this command...

Open a drawing document, choose Sogwang Office - Reference - Sogwang Draw



General

Defines the general options for drawing or presentation documents.

View

Specifies the available display modes. By selecting an alternative display, you can speed up the screen display while editing your presentation.

Grid

Defines the grid settings for creating and moving objects.

Print

Specifies print settings within a drawing or presentation document.

Back

Resets modified values back to the Sogwangdefault values.
