Sogwang Writer Options

These settings determine the way text documents that are created in Sogwang are handled. It is also possible to define settings for the current text document. The global settings are automatically saved.

To access this command...

Open a text document, choose Sogwang Office - Reference - Sogwang Writer



General

Specifies general settings for text documents.

View

Defines the default settings for displaying objects in your text documents and also the default settings for the window elements.

Formatting Aids

In Sogwang text and HTML documents, defines the display for certain characters and for the direct cursor.

Grid

Specifies the settings for the configurable grid on your document pages. This grid helps you determine the exact position of your objects. You can also set this grid in line with the "magnetic" snap grid.

Basic Fonts (Western)

Specifies the settings for the basic fonts.

Basic Fonts (Asian)

Specifies the settings for the basic Asian fonts if Asian language support has been activated under Sogwang Office - Reference - Language Settings - Languages.

Basic Fonts (CTL)

Specifies the settings for basic fonts for complex text layout languages if their support has been activated under Sogwang Office - Reference - Language Settings - Languages.

Print

Specifies print settings within a text or HTML document.

Table

Defines the attributes of tables in text documents.

Changes

Defines the appearance of changes in the document.

Compatibility

Specifies compatibility settings for text documents. These options help in fine-tuning Sogwang when importing Microsoft Word documents.

AutoCaption

Specifies the settings for captions that are automatically added to inserted objects.

Mail Merge E-mail

Specifies the user information and server settings for when you send form letters as e-mail messages.
