Sending Documents as E-mail

Working in Sogwang , you can send the current document as an e-mail attachment.

  1. Choose File - Send - Document as E-mail.

    Sogwangopens your default e-mail program. If you want to send the current document with another e-mail program, you can select the program to use with Sogwang Office - Reference - Internet - E-mail.

  2. In your e-mail program, enter the recipient, subject and any text you want to add, then send the e-mail.
