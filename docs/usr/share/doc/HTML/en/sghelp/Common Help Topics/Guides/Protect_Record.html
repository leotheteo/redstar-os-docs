Protecting Records

The review function is available in Sogwang for text documents and spreadsheet documents.



To protect the changes made in a document during editing, choose Edit - Changes - Protect Records.

To turn off the function or to accept or reject changes it is necessary to enter the correct password first.

  1. Choose Protect Records. This opens the Password dialog.

  2. Enter a password consisting of at least 5 characters and confirm it. Click OK.
