Sogwang Math Options

Defines the print format and print options for all new formula documents. These options apply when you print a formula directly from Sogwang Math. You can also call the dialog by clicking the Options button in the Print dialog. The settings you define in the Sogwang Office - Reference dialog will be permanent settings, whereas the settings in the Print dialog are only valid for the current document.

To access this command...

Open a Math document, choose Sogwang Office - Reference - Sogwang Math



Options

Defines formula settings that will be valid for all documents.

Back

Resets modified values back to the Sogwangdefault values.
