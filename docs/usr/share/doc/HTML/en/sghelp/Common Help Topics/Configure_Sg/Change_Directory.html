Changing Your Working Directory

When you start a dialog to open or save a document, Sogwang initially displays your working directory.

To change this directory:

  1. Choose Sogwang Office - Reference - Sogwang Office- Paths.

  2. Click My Documents and click the Edit button, or double-click on My Documents.

  3. In the Select Path dialog, choose the working directory you want and click OK.

You also use this procedure to change the directory displayed by Sogwang when you want to insert a graphic.

Choose Sogwang Office - Reference - Sogwang Office- Paths - Graphics, then follow step 3.
