Paths

This section contains the default paths to important folders in Sogwang . These paths can be edited by the user.

To access this command...

Choose Sogwang Office - Reference - Sogwang Office- Paths

Choose Edit - AutoText - Path



Paths used by Sogwang

To modify an entry in this list, click the entry and click Edit. You can also double click the entry.

Default

The Default button resets the predefined paths for all selected entries.

Edit

Click to display the Select Path or Edit Paths dialog.

You can change the sequence of entries by clicking the bar in the Type column. The column width can be changed by moving the separator between the columns with the mouse.

In the following list of paths, the paths for the shared folders in the directory where Sogwang is installed, are not shown. The user data for each user is stored in the {user} directory, which is located in the user's home directory.

Type

Path

Description

AutoCorrect

{user}/share/autocorr

Contains the settings of the AutoCorrect dialog box.

AutoText

{user}/share/autotext/{language}

Your AutoTexts are stored in the specified folder.

My Documents

Default document folder of your system

You can see this folder when you first call the Open or Save dialog.

AutoCorrect

{user}/user/autocorr

This folder stores your own AutoCorrect texts.

AutoText

{user}/user/autotext

This folder stores your own AutoText texts.

Gallery

{user}/user/gallery

New Gallery themes are stored in this folder.

Graphics

{user}/user/gallery

This folder is displayed when you first call the dialog for opening or saving a graphic object.

Backups

{user}/user/backup

Automatic backup copies of documents are stored here.

Templates

{user}/user/template

In this folder you can store your own templates.

Temporary files

{user}/user/temp

This is where Sogwang puts its temporary files.



The Sogwang Directory Structure

In Sogwang , the following folders and files have special meaning.

Directory / File

Description

{user}/user/autotext

The AutoTexts that you define are stored in this folder.

{user}/user/backup

If automatic backups are enabled, this folder stores all automatically created backup copies. For more information, see Backup copy.

{user}/user/wordbook

This folder contains all custom dictionaries for the spellcheck.

{user}/user/plugin

This folder contains the plug-ins that you installed in Sogwang. Sogwang recognizes the plug-ins that are installed in Netscape, Mozilla, or Microsoft Internet Explorer, so you normally do not need to install plug-ins in this folder.
