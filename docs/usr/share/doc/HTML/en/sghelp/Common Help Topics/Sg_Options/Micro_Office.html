Microsoft Office

Specifies the settings for importing and exporting Microsoft Office OLE objects.

These settings are valid when no Microsoft OLE server exists (for example, in UNIX) or when there is no Sogwang OLE server ready for editing the OLE objects.

To access this command...

Choose Sogwang Office - Reference - Load/Save - Microsoft Office



List Box

The List Box field displays the entries for the pair of OLE objects that can be converted when loading into Sogwang (L) and/or when saving into a Microsoft format (S).

Mark the box in the [L] column in front of the entry if a Microsoft OLE object is to be converted into the specified Sogwang OLE object when a Microsoft document is loaded into Sogwang .

Mark the box in the [S] column in front of the entry if a Sogwang OLE object is to be converted into the specified Microsoft OLE object when a document is saved in a Microsoft file format.
