Presentation Wizard

Use the wizard to interactively create a presentation. With the wizard, you can modify the sample templates to suit your needs. The wizard takes you step by step through the design elements and offers various editing options.

To access this command...

Choose File - Wizards - Presentation


The Presentation Wizard starts automatically when you open a new presentation. You can deactivate this function if you choose Sogwang Office - Reference - Sogwang Office Impress- General and deselect the Start with Wizard check box.



Within each wizard page, you can undo, modify, or skip altogether the editing steps. If you decide to skip over one of the pages, the wizard uses the default settings.

Presentation Wizard Page 1

Specifies the presentation type and allows you to select a template.

Presentation Wizard Page 2

Selects the medium and the background of your presentation.

Presentation Wizard Page 3

Presentation Wizard Page 4

You can specify the name of your company, your presentation topic, and the basic ideas you want to cover.

Presentation Wizard Page 5

You can determine which pages to include in the created presentation.

<< Back

Returns to the previous step without deleting your current settings. You can only select this button after the second editing step.

Next >>

Accepts the new settings and moves to the next page. You will not be able to select this button in the last editing step.

Create

The wizard creates a new document based on the specified settings. You can later specify a name for the document and save it.

Sogwang saves the current wizard settings and uses them as default the next time you open the wizard.
