Data sources options

Defines the general settings for the data sources in Sogwang .

To access this command...

Choose Sogwang Office - Reference - Sogwang Office Base



Connections

Defines how the connections to data sources are pooled.

Databases

Add, modify, or remove entries to the list of registered databases. You must register a database within Sogwang in order to see it in the View - Data sources window.

Back

Resets modified values back to the Sogwangdefault values.
