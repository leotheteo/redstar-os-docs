Extension Manager

The Extension Manager adds, removes, disables, enables, exports and updates Sogwang extensions.

To access this command...

Choose Tools - Extension Manager

The following are examples of Sogwang extensions:

  • UNO components (compiled software modules)

  • Configuration data (for menu commands)

  • Sogwang Basic libraries

  • Sogwang dialog libraries

  • Extension files (*.oxt files containing one or more extensions of the above listed types)

Extension Scope

There are two categories of extensions available:

  • Extensions that you add to the "Sogwang Extensions" categories are shared extensions available to all users. You need write access to the Sogwang installation directory to modify shared extensions. Typically, shared extensions are maintained by the administrator.

  • Extensions that you add to the "My Extensions" category are user extensions and are only available to the user who installs them. You don't need write access to the Sogwang installation directory to maintain these extensions.

To install an extension

An extension is available as a file with the file extension *.oxt.

You can find a collection of extension on the Web. Click the "Get more extensions here" link in the Extension Manager to open your Web browser and see the http://extensions.services.Sogwang Office/ page.

To install a user extension

Do any of the following:

  • Double-click the *.oxt file in your system's file browser.

  • On a Web page, click a hyperlink to an *.oxt file (if your Web browser can be configured to start the Extension Manager for this file type).

  • Choose Tools - Extension Manager, select My Extensions and click Add.

To install a shared extension

You need write access to the Sogwang installation directory to be able to install a shared extension.            The extension manager will disable shared extension installation if you have no write access to the directory.


All running instances of Sogwang need to be terminated for a successful installation of a shared extension.



There are two ways of installing a shared extension:

From the Command Line

  1. Open a terminal or command shell.

  2. Change to the Sogwang /program directory.

  3. Terminate any running instances of Sogwang and the Quickstarter, if this happens to be running.

  4. Enter the following command:

    unopkg gui

    The Extension Manager starts with a graphical user interface.

  5. Click the Sogwang Extensions entry and click Add.

From Within Sogwang

  • Choose Tools - Extension Manager, select Sogwang Extensions and click Add.

To install a shared extension in text mode

  1. Open a terminal or command shell.

  2. Change to the Sogwang /program .

  3. Enter the following command, using the path and file name of your extension:

    unopkg add --shared path_filename.oxt

You need write access to the Sogwang installation directory to be able to install a shared extension.            The extension manager will disable shared extension installation if you have no write access to the directory.


All running instances of Sogwang need to be terminated for a successful installation of a shared extension.



Browse extensions

In this list box of Extension Manager, click where you want to add a new extension, or select the extensions that you want to remove, enable, disable, or export. To select multiple extensions, press the Command key when you click.

Add

Select a top-level node in the list box, and then click Add to add new extensions to that location.

A file dialog opens where you can select the extensions that you want to add. To copy and to register the selected extensions, click Open.

An extension can show a license dialog. Read the license. Click the Scroll Down button to scroll down if necessary. Click Accept to continue the installation of the extension.

Remove

Select the extensions that you want to remove, and then click Remove.

Enable

Select the extensions that you want to enable, and then click Enable.

Disable

Select the extensions that you want to disable, and then click Disable.

Export

Select the extensions that you want to export, and then click Export. When you export a single extension, a dialog opens where you can specify the path and the file name for the exported extension. If you export more than one extension, a dialog opens where you can select the folder where you want to save the exported extensions.

Updates

Click to check for online updates of all installed extensions. To check for updates of the selected extensions only, choose the Update command from the context menu. The check for availability of updates starts immediately. You will see the Extension Update dialog.

Options

Select an installed extension, then click to open the Options dialog for the extension.

You need write access to the Sogwang installation directory to be able to install a shared extension.            The extension manager will disable shared extension installation if you have no write access to the directory.


All running instances of Sogwang need to be terminated for a successful installation of a shared extension.
