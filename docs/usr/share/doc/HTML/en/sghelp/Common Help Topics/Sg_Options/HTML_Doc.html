Sogwang Writer/Web Options

Defines the basic settings for Sogwang documents in HTML format.

To access this command...

Open an HTML document, choose Sogwang Office - Reference - Sogwang Writer/Web



View

Defines the default settings for displaying objects in your text documents and also the default settings for the window elements.

Formatting Aids

In Sogwang text and HTML documents, defines the display for certain characters and for the direct cursor.

Grid

Specifies the settings for the configurable grid on your document pages. This grid helps you determine the exact position of your objects. You can also set this grid in line with the "magnetic" snap grid.

Print

Specifies print settings within a text or HTML document.

Table

Defines the attributes of tables in text documents.

Background

Specifies the background for HTML documents. The background is valid for both new HTML documents and for those that you load, as long as these have not defined their own background.

Back

Resets modified values back to the Sogwang default values.
