Selecting Measurement Units

You can select separate measurement units for Sogwang Writer, Sogwang Writer/Web, Sogwang Calc, Sogwang Impress and Sogwang Draw documents.

  1. Open a document of the type for which you want to change the measurement units.

  2. Choose Sogwang Office - Reference.

  3. In the left pane of the dialog, double-click the application for which you want to select the measurement unit.

    Double-click Sogwang Writer if you want to select the measurement units for text documents.

  4. Click on General.

  5. On the General tab page, select the measurement unit. Close the dialog with OK.
