Sogwang Basic Help

Sogwang 3.0 provides an Application Programming Interface (API) that allows controlling the Sogwang components with different programming languages by using the Sogwang Software Development Kit (SDK). For more information about the Sogwang API and the Software Development Kit, visit http://api.Sogwang Office

Due to changes to the API, any macros created with StarOffice 5.2 or before are no longer supported by later versions.

This help section explains the most common runtime functions of Sogwang Basic. For more in-depth information please refer to the Sogwang Programming Guide for Basic which is available separately.
