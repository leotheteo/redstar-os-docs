Databases

Add, modify, or remove entries to the list of registered databases. You must register a database within Sogwang in order to see it in the View - Data sources window.

To access this command...

Choose Sogwang Office - Reference - Sogwang Office Base - Databases

Registered Databases

Lists the registered name and database file of all registered databases. Double-click an entry to edit.

New

Opens the Database Link dialog to create a new entry.

Delete

Removes the selected entry from the list.

Edit

Opens the Database Linkdialog to edit the selected entry.
