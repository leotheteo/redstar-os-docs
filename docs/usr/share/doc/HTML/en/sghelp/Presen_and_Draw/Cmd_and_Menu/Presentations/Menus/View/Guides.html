Guides

Specifies the display options for guides.

To access this command...

Choose View - Guides(Impress or Draw)


Display Guides

Displays or hides guides that you can use to align objects on a page.

Snap to Guides

Automatically aligns objects to vertical and horizontal guides. To override this feature, hold down the Ctrl key when you drag an object.

Guides to Front

Displays the guides in front of the objects on the slide or page.
