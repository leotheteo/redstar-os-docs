Text Formatting Bar

To display the Text Formatting Bar, place the cursor inside a text object.

Font Name

Allows you to select a font name from the list or enter a font name directly.

You can enter several fonts, separated by semicolons. Sogwang uses each named font in succession if the previous fonts are not available.

Font Name



Font Size

Allows you to choose between different font sizes from the list, or to enter a size manually.

Font Size



Bold

Makes the selected text bold. If the cursor is in a word, the entire word is made bold. If the selection or word is already bold, the formatting is removed.

Bold



Italic

Makes the selected text italic. If the cursor is in a word, the entire word is made italic. If the selection or word is already italic, the formatting is removed.

Italic



Underline

Underlines or removes underlining from the selected text.

Underline



Font Color

Click to apply the current font color to the selected characters. You can also click here, and then drag a selection to change the text color. Click the arrow next to the icon to open the Font color toolbar.

Font Color



Left

Aligns the selected paragraph(s) to the left page margin.

Align Left



Center

Centers the selected paragraph(s) on the page.

Centered



Right

Aligns the selected paragraph(s) to the right page margin.

Align Right



Justify

Aligns the selected paragraph(s) to the left and the right page margins. If you want, you can also specify the alignment options for the last line of a paragraph by choosing Format - Paragraph - Alignment.

Justified



Increase Spacing

Click the Increase Spacing icon to increase the paragraph spacing above the selected paragraph.

Increase Spacing



Decrease Spacing

Click the Decrease Spacing icon to decrease the paragraph spacing above the selected paragraph.

Decrease Spacing



Bullets On/Off

Assigns bullet points to the selected paragraphs, or removes them from bulleted paragraphs.

Bullets On/Off



Promote

Moves the selected paragraph up one level in the numbering or bullets hierarchy.

Promote



Demote

Moves the selected paragraph down one level in a numbering or bullets hierarchy.

Demote



Move Up

Positions the selected paragraph before the one above it.

Move Up



Move Down

Positions the selected paragraph after the one below it.

Move Down



Character

Changes the font and the font formatting for the selected characters.

Character



Paragraph

Modifies the format of the current paragraph, such as indents and alignment.

Paragraph



Numbering Symbols

Adds numbering or bullets to the current paragraph, and lets you edit format of the numbering or bullets.

Bullets On/Off



Asian Language Support

These commands can only be accessed after you enable support for Asian languages in Sogwang Office - Reference - Language Settings - Languages.

Text running from left to right

Specifies the horizontal direction of the text.

Text direction from left to right



Text running from top to bottom

Specifies the vertical direction of the text.

Text direction from top to bottom
