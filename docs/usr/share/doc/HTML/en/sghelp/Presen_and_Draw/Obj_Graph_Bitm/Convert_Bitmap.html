Converting Bitmap Images into Vector Graphics

A vector graphic can be resized without losing the quality of the graphic. In Sogwang Draw and Impress, you can convert a bitmap image into a vector graphic.

  1. Select the bitmap image that you want to convert.

  2. Do one of the following:

    In Sogwang Draw, choose Modify - Convert - To Polygon.

    In Sogwang Impress, right-click the object, and then choose Convert - To Polygon.

  3. Set the conversion options for the image, and then click OK. See Convert to Polygon for a description of the conversion options.
