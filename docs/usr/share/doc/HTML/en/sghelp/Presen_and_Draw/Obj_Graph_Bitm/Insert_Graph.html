Inserting Pictures

  1. Choose Insert - Picture - From File.

  2. Locate the picture you want to insert. Select the Link check box to insert only a link to the picture. If you want to see the picture before you insert it, select Preview.

    After you insert a linked picture, do not change the name of the source picture or move the source picture to another directory.

  3. Click Open to insert the picture.
