Insert



Open the Insert toolbar, where you can add objects, including charts, spreadsheets, and images, to your document.

Slide

Inserts a slide after the currently selected slide.

Slide



Floating Frame

Inserts a floating frame into the current document. Floating frames are used in HTML documents to display the contents of another file. Floating frames are not supported by Netscape Navigator 4.x.

Floating Frame



File

Inserts a file into the active slide. You can insert Sogwang Draw or Impress files, or text from an HTML document or a text file.

File



Spreadsheet

Inserts a new table into the current slide or page.

Spreadsheet

From File

Inserts a picture into the current document.

From File

Movie and Sound

Inserts a video or sound file into your document.

Sound

Inserts a sound file into the current document.

Video

Inserts a video file into the current document.

Formula

Inserts a formula into the current document. For more information open the Sogwang Math Help.

Formula

Chart

OLE Object
