Assembling 3D Objects

You can combine two or more 3D objects into a single object.

To combine 3D objects:

  1. Insert a 3D object from the 3D Objects toolbar (for example, a cube).

  2. Insert a second slightly larger 3D object (for example, a sphere).

  3. Select the second 3D object (sphere) and choose Edit - Cut.

  4. Double-click the first object (cube) to enter its group.

  5. Choose Edit - Paste. Both objects are now part of the same group. If you want, you can edit the individual objects or change their position within the group.

  6. Double-click outside the group to exit the group.

You cannot intersect or subtract 3D objects.
