Object

Inserts an object into your document. For movies and sounds, use Insert - Movie and Sound instead.

To access this command...

Choose Insert - Object



OLE Object

Inserts an OLE object into the current document. The OLE object is inserted as a link or an embedded object.

Sound

Inserts a sound file into the current document.

Video

Inserts a video file into the current document.

Formula

Inserts a formula into the current document. For more information open the Sogwang Math Help.
