Rotating Text

  1. Select the cells whose text you want to rotate.

  2. Choose Format - Cells. You will see the Format Cells dialog.

  3. Click the Alignment tab.

  4. In the Text direction area use the mouse to select in the preview wheel the direction in which the text is to be rotated. Click OK.

In the Text direction area, if you press the ABCD button, the text is written vertically in the direction of the characters.
