Close

Closes the current document without exiting the program.

To access this command...

Choose File - Close



When you close the last open document window, a window with some icons to start new documents stays open. You can click some other icons to browse to featured web sites using your default web browser.

The Close command closes all of the open windows for the current document.

If you have made changes to the current document, you are prompted if you want to save your changes.

If you open a document for printing, and do not make any changes, you are still prompted to save your changes when you close the document. This is because Sogwang keeps track of when a document is printed.
