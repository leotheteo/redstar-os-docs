Alignment (Objects)

Aligns selected objects with respect to one another.

If one of the selected objects is anchored as a character, some of the alignment options do not work.


To access this command...

Choose Format - Alignment (SogwangWriter,SogwangCalc)

Choose Modify - Alignment (objects selected) (SogwangDraw)

Open context menu - choose Alignment (objects selected) (SogwangImpress, SogwangDraw)


Not all types of objects can be selected together. Not all modules (Writer, Calc, Impress, Draw) support all types of alignment.



Align Left

Aligns the left edges of the selected objects. If only one object is selected in Draw or Impress, the left edge of the object is aligned to the left page margin.

Center Horizontal

Horizontally centers the selected objects. If only one object is selected in Draw or Impress, the center of the object is aligned to the horizontal center of the page.

Align Right

Aligns the right edges of the selected objects.

Align Top

Horizontally aligns the top edges of the selected objects. If only one object is selected in Draw or Impress, the top edge of the object is aligned to the upper page margin.

Align Vertical Center

Vertically centers the selected objects. If only one object is selected in Draw or Impress, the center of the object is aligned to the vertical center of the page.

Align Bottom

Horizontally aligns the bottom edges of the selected objects. If only one object is selected in Draw or Impress, the bottom edge of the object is aligned to the lower page margin.
