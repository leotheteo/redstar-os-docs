Explorer On/Off

Turns on and off the view of the data source explorer. The Explorer On/Off icon is visible on the Table Data bar.

Database Overview

In the data source explorer you see the data sources registered in Sogwang with their links, queries and tables.

Establishing a connection - As soon as you select an individual table or query, a connection to the data source is established. Once the connection is opened, the name of the data source, the Queries or Tables entry, and the name of the query or table selected is shown in bold type.
