Find

Click and choose one of the Internet search engines from the submenu. The search term is entered in the URL Name box. The list of search engines in the Find submenu is defined in Sogwang Office - Reference - Internet - Search.

List of search engines

When you have selected a search engine, Sogwang transfers the search request to your standard web browser, which then establishes an Internet connection to the search engine and displays the result. See also URL Name.
