Tools Bar

Use the Tools bar to access commonly used commands.

Insert

Click the arrow next to the icon to open the Insert toolbar, where you can add graphics and special characters to the current sheet.

Insert



Insert Cells

Click the arrow next to the icon to open the Insert Cells toolbar, where you can insert cells, rows, and columns into the current sheet.

Insert Cells



Controls

The Form Controls icon opens a toolbar with the tools that you need to create an interactive form.

Form Controls



AutoFormat

Use this command to apply an AutoFormat to a selected sheet area or to define your own AutoFormats.

AutoFormat



Choose Themes

Applies a formatting style to the selected cells.

Choose Themes



AutoFilter

Automatically filters the selected cell range, and creates one-row list boxes where you can choose the items that you want to display.

AutoFilter



Standard Filter

Allows you to set the filtering options.

Standard Filter



Advanced Filter

Defines an advanced filter.

Start

Opens a dialog where you can select the source for your DataPilot table, and then create your table.

Euro Converter

Converts the currency amounts found in Sogwang Calc documents and in fields and tables of Sogwang Writer documents into euros.

Define

Opens a dialog where you can specify a name for a selected area.

Goal Seek

Opens a dialog where you can solve an equation with a variable.

Group

Defines the selected cell range as a group of rows or columns.

Group



Ungroup

Ungroups the selection. In a nested group, the last rows or columns that were added are removed from the group.

Ungroup
