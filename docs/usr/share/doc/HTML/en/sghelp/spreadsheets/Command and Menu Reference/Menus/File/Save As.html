Save As

Saves the current document in a different location, or with a different file name or file type.

To access this command...

Choose File - Save As



The following sections describe the Sogwang Save as dialog. To activate the Sogwang Open and Save dialogs, choose Sogwang Office - Reference - Sogwang Office- General, and then select the Use Sogwang dialogs in the Open/Save dialogs area.

To save a document as a template, use the command File - Templates - Save.

Save with password

Protects the file with a password that must be entered before a user can open the file.

Only documents using the Sogwang XML-based format can be saved with a password.



Edit filter settings

Allows you to set the spreadsheet saving options for some types of data files.

Selection

Exports only the selected graphic objects in Sogwang Draw and Impress to another format. If this box is not checked, the entire document is exported.

If you are exporting to any document file type, the entire document is exported.
