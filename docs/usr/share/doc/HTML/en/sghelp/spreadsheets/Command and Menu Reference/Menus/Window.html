Window

Contains commands for manipulating and displaying document windows.

New Window

Opens a new window that displays the contents of the current window. You can now view different parts of the same document at the same time.

Close

Closes the current window. Choose Window - Close, or press Command+F4. In the page preview of Sogwang Writer and Calc, you can close the current window by clicking the Close Preview button.

Split

Divides the current window at the top left corner of the active cell.

Freeze

Divides the sheet at the top left corner of the active cell and the area to the top left is no longer scrollable.

Document List

Lists the currently open documents. Select the name of a document in the list to switch to that document.
