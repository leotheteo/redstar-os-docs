New

Creates a new Sogwang document.

To access this command...

Choose File - New

New icon on the Standard Bar (the icon shows the type of the new document)

New


Key Command+N



If you want to create a document from a template, choose New - Templates and Documents.

A template is a file that contains the design elements for a document, including formatting styles, backgrounds, frames, graphics, fields, page layout, and text.

Creates a new formula document (Sogwang Math).

Labels

Opens the Labels dialog where you can set the options for your labels, and then creates a new text document for the labels (Sogwang Writer).

Business Cards

Opens the Business Cards dialog where you can set the options for your business cards, and then creates a new text document (Sogwang Writer).

Templates and Documents

Creates a new document using an existing template or opens a sample document.
