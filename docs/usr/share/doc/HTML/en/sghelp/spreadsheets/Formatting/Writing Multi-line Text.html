Writing Multi-line Text

  • Pressing the Command+Enter keys inserts a manual line break. This shortcut only works directly in the cell, not in the input line.

If you want the text to automatically break at the right border of the cell, proceed as follows:

  1. Select all the cells where you want the text to break at the right border.

  2. In Format - Cells - Alignment, mark the Automatic line break option and click OK.
