Customize

Customizes Sogwang menus, shortcut keys, toolbars, and macro assignments to events.

To access this command...

Choose Tools - Customize



You can customize shortcut keys and macro assignments for the current application, or for all Sogwang applications.

You can also save and load individual menu, shortcut key, and toolbar custom settings.

Menu

Customizes and saves current menu layouts as well as creates new menus. You cannot customize context menus.

Keyboard

Assigns or edits the shortcut keys for Sogwang commands, or Sogwang Basic macros.

Toolbars

Lets you customize Sogwang toolbars.

Events

Assigns macros to program events. The assigned macro runs automatically every time the selected event occurs.
