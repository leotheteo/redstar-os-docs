Hyperlink

Inserts a hyperlink from the current URL into your document. The URL address is taken from the entry in the Internet URLs combo box, and the name of the link is taken from the URL Name combo box.

You can insert the hyperlink as text or as a button. Click the arrow next to the Hyperlink icon, then select As text or As button from the menu. The hyperlink is then inserted at the current cursor location.
