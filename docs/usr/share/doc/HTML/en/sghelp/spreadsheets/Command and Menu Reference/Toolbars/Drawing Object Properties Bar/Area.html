Sets the fill properties of the selected drawing object.

To access this command...

Choose Format - Graphic - Area

On Line and Filling Bar, click

Area




Area

Set the fill options for the selected drawing object.

Shadow

Add a shadow to the selected drawing object, and define the properties of the shadow.

Transparency

Set the transparency options for the fill that you apply to the selected object.

Colors

Allows you to select a color from a color table, edit an existing color, or define new colors.

Gradients

Set the properties of a gradient, or save and load gradient lists.

Hatching

Set the properties of a hatching pattern, or save and load hatching lists.

Bitmap

Select a bitmap that you want to use as a fill pattern, or create your own pixel pattern. You can also import bitmaps, and save or load bitmap lists.

Back

Resets modified values back to the Sogwang default values.
