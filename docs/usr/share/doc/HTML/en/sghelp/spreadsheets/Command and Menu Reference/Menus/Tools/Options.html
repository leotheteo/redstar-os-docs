Options

This command opens a dialog for a customized program configuration.

All your settings are saved automatically. To expand an entry either double click this entry or click the plus sign.           To collapse the entry, click the minus sign or double click the entry.

You see only the entries that are applicable to the current document. If the current document is a text document, you see the Sogwang Writer entry, and so on for all modules of Sogwang . Sogwang Impress and Sogwang Draw are treated as the same in this dialog. The common entries are always visible.



To access this command...

Choose Sogwang Office - Reference



Sogwang

Use this dialog to create general settings for working with Sogwang . The information covers topics such as user data, saving, printing, paths to important files and directories, and color defaults.

Load/Save

Specifies general Load/Save settings.

Language Settings

Defines the properties for additional languages.

Internet

Specifies Internet settings.

Sogwang Writer

These settings determine the way text documents that are created in Sogwang are handled. It is also possible to define settings for the current text document.

Sogwang Writer/Web

Defines the basic settings for Sogwang documents in HTML format.

Sogwang Calc

Defines various settings for spreadsheets, contents to be displayed, and the cursor direction after a cell entry. You can also define sorting lists, determine the number of decimal places and the settings for recording and highlighting changes.

Sogwang Impress

Defines various settings for newly created presentation documents, such as the contents to be displayed, the measurement unit used, if and how grid alignment is carried out.

Sogwang Draw

Defines the global settings for drawing documents, including the contents to be displayed, the scale to be used, the grid alignment and the contents to be printed by default.

Sogwang Math

Defines the print format and print options for all new formula documents. These options apply when you print a formula directly from Sogwang Math.

Charts

Defines the general settings for charts.

Sogwang Database

Defines the general settings for the data sources in Sogwang .
