Toolbars

Opens a submenu to show and hide toolbars. A toolbar contains icons and options that let you quickly access Sogwang commands.

To access this command...

Choose View - Toolbars



Standard Bar

Shows or hides the Standard Bar.

Tools Bar

Shows or hides the Tools bar.

Hyperlink Bar

Shows or hides the Hyperlink Bar, where you can insert and edit URLs or search the Internet using keywords.

Formula Bar

Shows or hides the Formula Bar, which is used for entering and editing formulas. The Formula Bar is the most important tool when working with spreadsheets.

Customize Toolbar

Opens a dialog where you can add, edit, and remove icons.

Reset

Choose View - Toolbars - Reset to reset the toolbars to their default context sensitive behavior. Now some toolbars will be shown automatically, dependent on the context.
