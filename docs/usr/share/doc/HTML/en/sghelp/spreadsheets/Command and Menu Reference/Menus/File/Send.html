Send

Sends a copy of the current document to different applications.

To access this command...

Menu File - Send



Document as E-mail

Opens a new window in your default e-mail program with the current document as an attachment. The current file format is used. If the document is new and unsaved, the format specified in Sogwang Office - Reference - Load/Save - General is used.

E-mail as OpenDocument Spreadsheet

Opens a new window in your default e-mail program with the current document as an attachment. The OpenDocument file format is used.

E-mail as Microsoft Excel

Opens a new window in your default e-mail program with the current document as an attachment. The Microsoft Excel file format is used.

E-mail as PDF

Shows the Export as PDF dialog, exports the current document to Portable Document Format (PDF), and then opens an e-mail sending window with the PDF as an attachment.
