Insert

Click the arrow next to the icon to open the Insert toolbar, where you can add graphics and special characters to the current sheet.

Tools bar icon:

Insert



You can select the following icons:

Floating Frame

Inserts a floating frame into the current document. Floating frames are used in HTML documents to display the contents of another file. Floating frames are not supported by Netscape Navigator 4.x.

Floating Frame



Special Character

Inserts special characters from the installed fonts.

Special Character



From File

Inserts a picture into the current document.

From File



Movie and Sound

Inserts a video or sound file into your document.

Movie and Sound



Formula

Inserts a formula into the current document. For more information open the Sogwang Math Help.

Formula



Chart

Chart



OLE Object

Inserts an OLE object into the current document. The OLE object is inserted as a link or an embedded object.

OLE Object
