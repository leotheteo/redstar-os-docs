Format Cells

Allows you to specify a variety of formatting options and to apply attributes to the selected cells.

To access this command...

Choose Format - Cells



Numbers

Specify the formatting options for the selected cell(s).

Font

Specify the formatting and the font that you want to apply.

Font Effects

Specify the font effects that you want to use.

Alignment

Sets the alignment options for the contents of the current cell, or the selected cells.

Asian Typography

Set the typographic options for cells or paragraphs in Asian language files. To enable Asian language support, choose Sogwang Office - Reference - Language Settings - Languages, and then select the Enabled box in the Asian language support area. The Asian typography options are ignored in HTML documents.

Borders

Sets the border options for the selected objects in Writer or Calc.

Background

Set the background color or graphic.

Cell Protection

Defines protection options for selected cells.

Back

Resets modified values back to the Sogwang default values.
