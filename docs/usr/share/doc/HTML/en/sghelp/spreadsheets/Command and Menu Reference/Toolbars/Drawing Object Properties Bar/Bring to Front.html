Bring to Front

Moves the selected object to the top of the stacking order, so that it is in front of other objects.

To access this command...

Choose Format - Arrange - Bring to Front (Sogwang Writer, Sogwang Calc)

Choose Modify - Arrange - Bring to Front (Sogwang Draw)

Shift+Command+plus sign (Sogwang Impress, Sogwang Draw)

Open context menu - choose Arrange - Bring to Front (Sogwang Impress)
