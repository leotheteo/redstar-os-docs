Displaying Formulas or Values

If you want to display the formulas in the cells, for example in the form =SUM(A1:B5), proceed as follows:

  1. Choose Sogwang Office - Reference - Sogwang Office Calc - View.

  2. In the Display area mark the Formulas box. Click OK.

If you want to view the calculation results instead of the formula, do not mark the Formulasbox.
