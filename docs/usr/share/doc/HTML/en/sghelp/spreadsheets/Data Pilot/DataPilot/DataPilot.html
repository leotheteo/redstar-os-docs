DataPilot

A DataPilot table provides a summary of large amounts of data. You can then rearrange the DataPilot table to view different summaries of the data.

To access this command...

Choose Data - DataPilot



DataPilot

Start

Opens a dialog where you can select the source for your DataPilot table, and then create your table.

Refresh

Updates the DataPilot table.

Delete

Deletes the selected DataPilot table.
