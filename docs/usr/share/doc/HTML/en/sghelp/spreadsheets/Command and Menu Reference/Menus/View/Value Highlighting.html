Value Highlighting

Highlights numerical values in your sheet.

To remove the highlighting, unmark the menu entry.

To access this command...

Choose View - Value Highlighting



Text cells are formatted in black, number cells in blue, and all other types of cells, such as formulas, logical values, and dates, are formatted in green.

If this function is active, colors that you define in the document will not be displayed. When you deactivate the function, the user-defined colors are displayed again.
