Cell Contents

Opens a submenu with commands to calculate tables and activate AutoInput.

To access this command...

Choose Tools - Cell Contents



Recalculate

Recalculates the current sheet. Use Tools - Cell Contents - Recalculate or press F9 to recalculate all changed formulas in the current sheet. Press Shift+Command+F9 to recalculate all cells in all sheets.

AutoCalculate

Automatically recalculates all formulas in the document.

AutoInput

Switches the AutoInput function on and off, which automatically completes entries, based on other entries in the same column. The column is scanned up to a maximum of 2000 cells or 200 different strings.
