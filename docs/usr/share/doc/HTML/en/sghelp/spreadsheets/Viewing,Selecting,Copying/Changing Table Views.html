Changing Table Views

To permanently hide column and line headers in a table:

  • Under the menu item Sogwang Office - Reference - Sogwang Calc, go to the View tab page.                       Unmark Column/row headers. Confirm with OK.

To hide grid lines:

  • Under the menu item Sogwang Office - Reference - Sogwang Calc , go to the View tab page.                  Unmark Grid lines. Confirm with OK.
