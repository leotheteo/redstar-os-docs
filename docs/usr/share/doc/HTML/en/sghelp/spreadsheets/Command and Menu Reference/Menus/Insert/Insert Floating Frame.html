Insert Floating Frame

Inserts a floating frame into the current document. Floating frames are used in HTML documents to display the contents of another file. Floating frames are not supported by Netscape Navigator 4.x.

To access this command...

Choose Insert - Floating Frame

Open the Insert toolbar, click

Floating Frame



If you want to create HTML pages that use floating frames, choose Sogwang Office - Reference - Load/Save - HTML compatibility, and then select the "MS Internet Explorer" option. The floating frame is bounded by <IFRAME> and </IFRAME> tags.
