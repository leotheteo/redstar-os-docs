Filter

Contains filter commands.

Sogwang automatically recognizes predefined database ranges.

To access this command...

Choose Data - Filter



The following filtering options are available:

AutoFilter

Automatically filters the selected cell range, and creates one-row list boxes where you can choose the items that you want to display.

Standard filter

Allows you to set the filtering options.

Advanced filter

Defines an advanced filter.

Remove Filter

Removes the filter from the selected cell range.

Hide AutoFilter

Hides the AutoFilter buttons in the selected cell range.
