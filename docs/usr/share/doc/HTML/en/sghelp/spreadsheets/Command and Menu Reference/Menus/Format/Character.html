Character

Changes the font and the font formatting for the selected characters.

To access this command...

Choose Format - Character

On Text Formatting Bar (with cursor in object), click

Character




Font

Specify the formatting and the font that you want to apply.

Font Effects

Specify the font effects that you want to use.

Font Position

Specify the position, scaling, rotation, and spacing for characters.

Back

Resets modified values back to the Sogwang default values.
