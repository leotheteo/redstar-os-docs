Standard Bar

The Standard bar is available in every Sogwang application.

New

Creates a new Sogwang document.

New



Open File

Opens or imports a file.

Open File



Save

Saves the current document.

Save



Save As

Saves the current document in a different location, or with a different file name or file type.

Save As



Document as E-mail

Opens a new window in your default e-mail program with the current document as an attachment. The current file format is used. If the document is new and unsaved, the format specified in Sogwang Office - Reference - Load/Save - General is used.

Document as E-mail



Edit File

Use the Edit File icon to activate or deactivate the edit mode.

Edit File



Export as PDF

Saves the current file to Portable Document Format (PDF). A PDF file can be viewed and printed on any platform with the original formatting intact, provided that supporting software is installed.

Export Directly as PDF



Print File Directly

Click the Print File Directly icon to print the active document with the current default print settings. These can be found in the Printer Setup dialog, which you can call with the Printer Settings menu command.

Print File Directly



Spellcheck

Checks the document or the current selection for spelling errors.

Spellcheck



AutoSpellcheck On/Off

Automatically checks spelling as you type, and underlines errors.

AutoSpellcheck On/Off



Cut

Removes and copies the selection to the clipboard.

Cut



Copy

Copies the selection to the clipboard.

Copy



Paste

Inserts the contents of the clipboard at the location of the cursor, and replaces any selected text or objects. Click the arrow next to the icon to select the format.

Paste



Format Paintbrush

Copies the formatting of the selected text or object and applies the formatting to another text selection or object.

Click the Format Paintbrush icon on the Standard toolbar.

Format Paintbrush



Undo

Reverses the last command or the last entry you typed. To select the command that you want to reverse, click the arrow next to the Undo icon on the Standard bar.

Undo



Redo

Reverses the action of the last Undo command. To select the Undo step that you want to reverse, click the arrow next to the Redo icon on the Standard bar.

Redo



Hyperlink

Opens a dialog that enables you to create and edit hyperlinks.

Hyperlink Dialog



Navigator

Click the Navigator On/Off icon to hide or show the Navigator.

Navigator On/Off



Zoom & View Layout

Reduces or enlarges the screen display of Sogwang . The current zoom factor is displayed as a percentage value on the Status bar.

Zoom



Sogwang Help

Opens the main page of the Sogwang Help for the current application. You can scroll through the Help pages and you can search for index terms or any text.

Sogwang Help



What's this

Enables extended help tips under the mouse pointer till the next click.

What's this



Load URL

Loads a document specified by an entered URL. You can type a new URL or select one that is already registered. Sogwang automatically converts file paths into URL notation.

Enable Load URL with the Visible Buttons command (click the arrow at the end of the toolbar).
