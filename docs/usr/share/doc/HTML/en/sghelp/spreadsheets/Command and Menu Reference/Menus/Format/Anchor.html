Anchor

Sets the anchoring options for the selected object.

To access this command...

Choose Format - Anchor

Open Form Design toolbar, click

Change Anchor




Allows you to switch between anchoring options.

Open Form Design toolbar, click

Change Anchor



To Page

Anchors the selected item to the current page.

To Cell

Anchors the selected item to a cell. The anchor icon is displayed in the upper left corner of the cell.
