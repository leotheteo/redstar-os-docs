Wrapping Text Around Objects

Specify the format for bibliography entries.

    1. Select the object.

    2. Choose Format - Wrap, and then choose the wrapping style that you want to apply.

    The current wrapping style is indicated by a bullet.

Specifying the Wrapping Properties

    1. .Select the object.

    2. Choose Format - Graphics, and then click the Wrap tab.

    3. Set the options that you want.

    4. Click OK.

To change the wrapping contour of a graphic:

You can change the shape that the text wraps around.

    1. Select the graphic, right-click, and then choose Wrap - Edit Contour.

    2. Use the tools to draw a new contour, and then click the Apply icon (green check mark).

    3. Close the Contour Editor window.
