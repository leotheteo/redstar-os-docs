Page Preview

The Page Preview Bar appears when you view the current document in the page preview mode.

Previous Page

Moves back to the previous page in the document. This function is only active when you select the Page Preview function on the File menu.

Previous Page



Next Page

Moves forward to the next page in the document. This function is only active when you select the Page Preview function on the File menu.

Next Page



To Document Begin

Moves to the first page of the document. This function is only active when you select the Page Preview function on the File menu.

To Document Begin



To Document End

Moves to the last page of the document. This function is only active when you select the Page Preview function on the File menu.

To Document End



Page Preview: Two Pages

Displays two pages in the Page Preview window. Uneven numbers will always appear on the right side, even numbers on the left.

Page Preview: Two Pages



Page Preview: Multiple Pages

Defines the number of pages displayed on screen. Click the arrow next to the icon to open a grid to select the number of pages to be displayed as rows and columns in the preview.

Page Preview: Multiple Pages



Book preview

Select to display the first page on the right side in the page preview. If not selected, the first page is displayed on the left side of the preview.

Book Preview



Zoom In

Zooms in to get a close-up view of the document.

Zoom Out

Zooms out to see more of the document at a reduced size.

Preview Zoom

Determines the zoom level of the page preview.

Full Screen

Shows or hides the menus and toolbars in Writer or Calc. To exit the full screen mode, click the Full Screen On/Off button.

Full Screen On/Off (in Page Preview)



Print page view

Opens the Print dialog to print the page preview. Use the Print options page view icon to set the printing scale and other printing properties.

Print page view



Print Options

Opens a dialog where settings for the printout of your document can be made. The pages are proportionally reduced in size. When printing multiple document pages on one printed page, the whole sheet of paper may not be printed on and a margin may remain.

Print options page view



Close

Closes the current window. Choose Window - Close, or press Command+F4. In the page preview of Sogwang Writer and Calc, you can close the current window by clicking the Close Preview button.
