Align Bottom

Horizontally aligns the bottom edges of the selected objects.

If only one object is selected in Draw or Impress, the bottom edge of the object is aligned to the lower page margin.

To access this command...

Choose Format - Alignment - Bottom

Objects are aligned to the top edge of the topmost object in the selection.

To align the individual objects in a group, double-click to enter the group, select the objects, right-click, and then

choose an alignment option.
