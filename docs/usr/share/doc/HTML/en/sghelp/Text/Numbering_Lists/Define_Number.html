Defining Number Ranges

You can automatically number similar items, such as quotations, in your document.

  1. Type the text that you want to assign numbering to, for example, "Quotation Number ".

  2. Choose Insert - Fields - Other, and then click the Variables tab.

  1. Click "Number range" in the Type list.

  2. Type "Quotation" in the Name box.

  3. Do one of the following:

  • Type a number in the Value box, or leave the box empty to use automatic numbering.

  • Select the outline level where you want the numbering to restart in the Level box.

  1. Click Insert, and then click Close.
