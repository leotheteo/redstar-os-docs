Turning Number Recognition On or Off in Tables

Sogwang can automatically format dates that you have entered into a table, according to the regional settings specified in your operating system.

Do one of the following:

  • Right-click in a table cell and choose Number recognition. When this feature is on, a check mark is displayed in front of the Number recognition command.

  • Choose Sogwang Office - Reference - Sogwang Writer - Table, and select or clear the Number recognition check box.
