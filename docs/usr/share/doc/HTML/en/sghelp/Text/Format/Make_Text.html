Making Text Superscript or Subscript

  1. Select the text that you want to make superscript or subscript.

  2. Do one of the following:

  • Choose Format - Character - Position, and then select Superscript or Subscript.

  • Press Command+Shift+P to make the text superscript, and Command+Shift+B to make the text subscript.
