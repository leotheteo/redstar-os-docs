Resetting Font Attributes

  • You can quickly exit manual formatting by pressing the right-arrow key. For example, if you have pressed Command+B to apply the bold typeface to the text that you type, press the right arrow to return to the default character format of the paragraph.

  • To reset all direct formatting of existing text, select that text, then choose the menu command Format - Default Formatting.
