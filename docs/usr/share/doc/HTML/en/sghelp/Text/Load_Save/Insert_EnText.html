Inserting an Entire Text Document

  1. Place the cursor in the document where you want to insert the file.

  2. Choose Insert - File.

  3. Locate the text document that you want to insert, and then click OK.

The contents of the text document are embedded into the current document and are not updated if the source file is changed. If you want the contents to automatically update when you change the source document, insert the file as a link.

Inserting an Entire Text Document as a Link

  1. Place the cursor in the document where you want to insert the file.

  2. Choose Insert - Section.

  3. Type a name in the New Section box, and then select the Link check box.

  4. In the File Name box, type the name of the file that you want to insert, or click the browse button (...) and locate the file.

    If the target text document contains sections, you can select the section that you want to insert in the Sections box.

  5. If you want, set the formatting options for the section.

  6. Click Insert.

Sogwang automatically updates the contents of the inserted section whenever the source document is changed.              To manually update the contents of the section, choose Tools - Update - Update All.
