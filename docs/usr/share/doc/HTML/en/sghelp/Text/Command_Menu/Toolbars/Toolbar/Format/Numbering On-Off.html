Numbering On/Off

Adds or removes numbering from the selected paragraphs.

To define the numbering format, choose Format - Bullets and Numbering.

To display the Bullets and Numbering Bar, choose View - Toolbars - Bullets and Numbering.

Some of the bullets and numbering options are not available when working in the Web Layout.
