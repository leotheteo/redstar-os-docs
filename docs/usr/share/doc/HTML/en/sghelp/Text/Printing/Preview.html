Previewing a Page Before Printing

  1. Choose File - Page Preview.

  2. Use the zoom icons on the Page Preview bar to reduce or enlarge the view of the page.

    To print your document scaled down, print the zoomed preview. Click Print options page view icon to set the print options.

  3. Use the arrow keys or the arrow icons on the Page Preview bar to scroll through the document.
