Servers and shared computers

You can connect to the following types of servers and other computers:

  • Mac computers that have file sharing turned on
  • Windows computers with shared folders
  • SMB/CIFS, NFS, FTP, and WebDAV servers running on Mac OS X Server, UNIX, Linux, and Windows servers
  • FTP servers

    With read-only access you can copy files from the server, but to copy files to the server you may need another FTP application.
