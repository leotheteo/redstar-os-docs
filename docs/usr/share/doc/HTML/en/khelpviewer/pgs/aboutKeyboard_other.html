About keyboard and other shortcuts

Mac OS X provides extensive keyboard and other shortcuts, from shortcuts for system basics to using features such as the Dock. With keyboard shortcuts, you can quickly perform tasks on your computer by pressing keys on your keyboard.

Note: If you're working on a portable computer, you must press the Fn key before pressing the other keys of a shortcut; for example, press Fn-Control-F2.

Shortcuts for system basics
Use these shortcuts to start your computer, navigate, use Mouse Keys and windows, select controls and icons, use accessibility features, and handle computer freezes.
Shortcuts for system features
Use these shortcuts to use system features such as the Dock, Spotlight, Dashboard, Exposé, Front Row, and other tasks like taking pictures of the screen.
Shortcuts for files and folders
Use these shortcuts for actions such as copying and moving files, or opening folders in Finder.
Shortcuts for application features
Use these shortcuts for working with dialogs and menus in most applications.
