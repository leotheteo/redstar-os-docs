  Using the Login Options pane of Accounts preferences

You can change the way the login window behaves to be more secure or set up the way users will log in to their accounts.

Preference

Explanation

Automatic log in

To have the computer automatically log into an account on startup, choose the account in the pop-up menu. This is less secure than requiring users to log in, since anyone will be able to use the computer just by turning it on.

To require a user to select an account and enter a password, choose Disabled from the pop-up menu.

Display login window as

Select "List of users" to have the user choose an account in the login window .

Select "Name and password" to require the user to type their name and password in the login window to use the computer.

Show the Restart, Sleep, and Shut Down buttons

Choose "Show the Restart, Sleep, and Shut Down buttons" to show these buttons on the login window.

Show password hints

To display a user's password hint if they enter the wrong password three times, select the "Show password hints" checkbox.

Enable fast user switching

To allow users to quickly choose another account from the menubar, select the "Enable fast user switching" checkbox, and then choose how the accounts should be viewed from the pop-up menu.

Add (+) and Delete (-) buttons in the bottom section of the pane

To create a new account, click the Add (+) button and enter the information for the new account.

To delete an account, click on the account in the list and click the Delete (-) button.

Lock

Only an administrator can make changes to this preference. To unlock the Accounts preferences click the lock and enter an administrator's account password.
