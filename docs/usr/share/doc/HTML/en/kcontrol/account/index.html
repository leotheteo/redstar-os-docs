  Creating and modifying user accounts

Use Accounts preferences to set up and manage accounts for users, decide what types of privileges and access the user will have, and also to determine how users will log in to the computer.

Administrating accounts
If you have an administrator name and password, you can use the Accounts preferences to add, delete or modify accounts.
■
About administrator accounts
Creating new accounts:
You use the Accounts preferences to create new user accounts. Ideally it is best to create a unique account for each user, then they will have access to their own home folder and documents.
■
Creating a new user account
Changing Login Options
You can change the way users log in to the computer, modify the login window, enable fast user switching, and more in Login Options
■
Using the Login Options pane of Accounts preferences
Opening items automatically when you log in
If you always use certain applications or documents, you can have them open automatically whenever you log in by adding them to the Login Items.
■
Opening items automatically when you log in
Changing your account password
You can change your password, or if you have an administrator name and password, you can manage the passwords of other users.
