  Using an administrator name and password

The user account you created when you set up RedStar is also the computer’s administrator. Additional administrator accounts may have been created on the computer, depending on how it was set up.

To complete certain tasks, you need to authenticate by entering an administrator name and password. In some circumstances you may need to enter a smart card and personal identification number or use some other method of authentication. You should always be sure you know which application requests that you enter this information.

If you don’t know the user name and password for an administrator, ask the person who administers your computer for help.
