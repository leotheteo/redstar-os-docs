  Using the Login Items pane of Accounts preferences

You can have applications, documents, or server connections open automatically when you log in to your computer.

Preference

Explanation

List of items

This list shows the items that will open automatically.

Hide checkbox

If you want the windows for the item to remain closed, click the Hide checkbox next to it.

Item column

The item column shows the name of the application, document, or connection that will open automatically.

Kind column

The Kind column shows the kind of items that are opening automatically.

Add (+) and Delete (-) buttons

To have a new item open automatically on log in, click the Add (+) button and then select the item you want.

To stop an item from opening automatically, select the item from the list and click the Delete (-) button.
