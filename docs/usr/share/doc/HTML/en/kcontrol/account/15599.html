  About multiple user accounts

RedStar is designed to provide a secure working environment for more than one user on a computer. If you are the only person who uses your computer, and you have no reason to worry about the safety of the information you keep on your computer, you may not want to log in each time your computer starts up. You can set up your computer to log you in automatically.

If more than one person uses the computer, or if the computer is in an open area where others can easily access it, you may want to set up passwords for each user account and require users to log in and log out each time they use the computer.

When a user logs out of the computer, any open documents and applications close. If you want to leave applications running and documents open when users log out, you can set up the computer to allow “fast user switching.”

When fast user switching is turned on, the name of the current user is displayed in the upper-right corner of the menu bar. You can click the name to select another user to switch to. If the other user’s account doesn’t require a password, the computer switches automatically to the new user’s home folder. Otherwise, you see a dialog asking for the user’s password. When you switch back to your own account, you see the computer as you left it.
