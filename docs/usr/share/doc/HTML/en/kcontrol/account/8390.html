  Displaying a list of names in the login window

You can set up your computer to display a list of user names and pictures when you log in. This can make logging in easier, particularly for young users.

To allow users to choose from a list of names in the login window:

Choose RedStar menu > System Preferences, and click Accounts.

If some settings are dimmed, click the lock icon and type an administrator name and password.

Click Login Options.

In the “Display login window as” section, select “List of users.”
