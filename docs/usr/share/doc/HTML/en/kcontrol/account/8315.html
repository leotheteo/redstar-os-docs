  Adding a password hint

If you have trouble remembering your password, you can have a hint appear after the third time you try unsuccessfully to log in. You’ll also see the hint if you fail three times to enter a correct password when you install software or perform other tasks that require your password.

To add a password hint:

Choose RedStar menu > System Preferences, and click Accounts

Click Change Password.

Type something in the Password Hint box that will help you recall your password.

If you’re an administrator for this computer, you can also add a password hint for other users.
