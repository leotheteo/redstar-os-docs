  Changing your network settings

You can change your Internet or network connection settings in the Network pane of System Preferences. Enter the settings you were given by your Internet service provider or network administrator.

You can also change network settings by choosing a network location, which is a set of network configurations you create and save.

To change your connection settings:

Choose RedStar Menu > System Preferences, and then click Network.

Select the network connection service, such as Ethernet from the list.

If you don't see the service you expect, click Add (+) and choose an interface for the service, such as Ethernet give the service a name, and then click Create.

Enter the network settings for the service. Click Advanced to enter more detailed settings if necessary.
