  Setting advanced Ethernet options

You can configure advanced Ethernet settings if you have specific requirements for the network you are connected to.

In most cases, the settings that are configured automatically are correct. In some network environments you may need to set advanced options. Your network administrator or Internet service provider should be able to tell you if you need to adjust these settings.

To manually set advanced Ethernet options:

Choose RedStar Menu > System Preferences, and then click Network.

Select Ethernet from the network connection services list.

Click Advanced, click Ethernet, and then choose Manually from the Configure pop-up menu.

Choose a speed from the Speed pop-up menu, and “half-duplex” or “full-duplex” from the Duplex pop-up menu.

Select a Maximum Packet Size.

Check with your network administrator for the settings specific to the network.

If your computer and the device you are connecting to support Gigabit Ethernet but the Ethernet cable you are using does not, you may need to adjust the Ethernet speed. Alternatively, you can purchase a cable that supports Gigabit Ethernet.

These advanced settings affect the way your computer interacts with your network. Unless your network administrator has given you specific settings, use the automatic settings. Entering the wrong settings can affect network performance.
