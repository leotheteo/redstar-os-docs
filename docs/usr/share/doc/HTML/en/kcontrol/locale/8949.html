  About the Input Sources

If you use more than one input method to type on your computer, you can use the Input menu to switch between them. You can set preferences for the Input menu in the Input Sources pane of International preferences.

Click the Input menu icon to choose the input method you want to use.

You can also use a keyboard shortcut to switch input methods. The keyboard shortcut to select the next input method in the Input menu is Ctrl+Space bar. You can do this in the Keyboard Shortcuts pane of Keyboard & Mouse preferences.
