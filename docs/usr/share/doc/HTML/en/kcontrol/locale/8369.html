  If a menu doesn’t appear in the right language

You can change the language in which menus and dialogs appear. However, some applications can’t display their menus and dialogs in multiple languages.

If the language you selected in International preferences isn’t supported by the current application, menus will appear in the first language listed in the Language pane (in International preferences) that the application supports, so it may not be your first choice.
