  Changing the language shown in menus and dialogs

Depending on the application you’re using, you may be able to change the language shown in menus and dialogs. Some applications can’t display their menus and dialogs in all languages.

To change the language:

Choose Redstar Menu > System Preferences, click International, and then click Language.

Drag the language you most want to see in menus and dialogs to the top of the list, and choose options for sorted lists and word breaks.

Languages: Applications that support the first language in the list show menus and dialogs in that language. If the application does not support that language, it attempts to show the second language in the list, and so on. If you don’t see the language you want, click Edit List.

These language settings may also change the language used in other parts of an application or in the text you see on some websites.
