  Writing text in other languages

RedStar3.0 lets you write text in many languages. The language you write in can be different from the language that your menus and dialogs use, and even different from the characters on the keyboard you’re using.

To set language input preferences:

Choose RedStar Menu > System Preferences, and click International.

Click Input Sources, and click the checkbox next to the keyboard layout or input method you want to use.

Open the application that you want to use.

Click the Input menu (international symbol) and choose the keyboard layout or input method you want to use. Then start typing.

Not all applications support all languages. If the keyboard layout or input method is dimmed (not available) in the Input menu, the current application doesn’t support that language.

Some languages (for example, Hindi) may require you to install additional fonts before you can view the characters for those languages on the screen.
