  Viewing multilingual text documents

To view documents that contain text in more than one language, open the document in an application that supports multilingual text. If you use an application that supports Unicode, a worldwide standard for encoding multilingual text, you can view any language that system supports.

For example, TextEdit is a text-editing application that supports Unicode. Some applications that don’t support Unicode may also allow you to see text in multiple languages; others support only one language.

For more information about the languages that an application supports, see the documentation that came with the application.
