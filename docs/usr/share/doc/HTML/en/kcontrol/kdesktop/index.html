  Using Desktop preferences

You can change the desktop (the background area of your screen) to a different pattern, color, or picture.

Preference

Explanation

List of images and pictures

Choose a folder from the list on the left; then click a specific pattern or picture in the sample box on the right.

The "Pictures Folder" choice works only if you have pictures in your Pictures folder. The pictures should have the same file format—JPEG, PNG, or TIFF. Use Preview (in your Applications folder) to save your pictures in a new format if needed. If the pictures look fuzzy, try using larger pictures (such as 1024 x 768 pixels).

Plus (+) and minus (-) buttons

To use an image from a folder other than the Pictures folder, click the plus (+) button and select the folder you want. The folder is added to the list, and you can choose a picture from it. To remove a folder you have added, click the minus (-) button.

Change picture

If you can't settle on one choice, select this checkbox and choose a frequency from the pop-up menu. This option may affect the performance of some applications, such as games, that use a lot of graphics.

You can also change the background by pressing the Control key and clicking the desktop, and then choosing Change Desktop Background from the shortcut menu.

Random order

To display pictures randomly, select this checkbox.
