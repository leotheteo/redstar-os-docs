  Installing screen savers

You can install screen savers created by companies other than Apple and use them with Screen Saver preferences on your computer. Your screen saver may have its own instructions for installing or uninstalling the “.saver” file. If it does not, try using these instructions.

Important: Download screen savers only from trusted websites. If you have any doubt about the reliability of a website, don’t download screen savers (or anything else) from that site.

To install a screen saver:

Download or drag the screen saver installer to your hard disk.

If the screen saver is compressed (has “.sit” appended to its filename), double-click to expand it.

Double-click the screen saver’s icon.

■

If the screen saver has an installer, follow its instructions.

■

If the screen saver doesn’t have an installer, drag it to this folder: RedStar HD/usr/bin/*.ksscr. This makes the screen saver available to all users. If you want it available only to a specific user, drag it to the Library folder in that user’s home folder (the one with the user’s name).

To uninstall a screen saver, locate its “.saver” file inside the Screen Savers folder in the Library folder, and then delete the file. If the screen saver was available to all users of the computer, the file is in the Library folder at the top level of the hard disk. If the screen saver was for only one user, the file is in that user’s home folder.
