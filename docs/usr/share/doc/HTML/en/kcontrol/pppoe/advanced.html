  Setting advanced networking options

You can use Network preferences to set advanced options, such as TCP/IP, DNS, and Ethernet settings, depending on the network service you're using, and the services provided by your Internet service provider or network administrator.

Not all options are available for all services.

Advanced PPP options

You can control when your modem connects and disconnects from the Internet, how long your modem stays connected when it is inactive, how many time the modem will redial your service provider if the line is busy, and other PPP options.

A DNS (Domain Name System) server converts Internet names to IP addresses so you don't have to know the IP address of a server you are trying to connect to.
