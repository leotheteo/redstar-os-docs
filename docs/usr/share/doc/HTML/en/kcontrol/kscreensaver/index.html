  Using Screen Saver preferences

You can have images appear on your screen when you aren’t using your computer. You may want to do this to hide the items on your desktop while you’re away.

Preference

Explanation

Screen Savers

Choose a screen saver from the list. Some of the choices have special requirements:

Pictures Folder: Works only if you have pictures in your Pictures folder. The pictures should have the same file format—JPEG, PNG, or TIFF. Use Preview (in your Applications folder) to save your pictures in a new format if needed. If the pictures look fuzzy, try using larger pictures (such as 1024 x 768 pixels).

Choose Folder: This choice is available in case you keep your pictures in a folder other than the Pictures folder.

Options

Click to fine-tune how images are displayed by the screen saver.

Start screen saver

Drag the slider to specify how long the computer is inactive before the screen saver starts. If you don’t want a screen saver to start at all, set the slider to Never.

Use random screen saver

Select this checkbox to see a different screen saver each time the screen saver is activated. This option works only if your Pictures folder contains images.

Show with clock

Select this checkbox to have the time displayed while your screen saver is activated.

Hot Corners

Click to set a shortcut for starting or deactivating your screen saver. From Active Screen Corners, choose Start Screen Saver or Disable Screen Saver from the pop-up menu for a corner you want to use; then click OK.
