  Creating a sharing user account

You can create a user account in Sharing preferences to allow a user to share files and folders on your computer. This is known as a “sharing account,” and the account has access only to the folders and volumes you specify in Sharing preferences.

You can create a new sharing account and assign sharing privileges to them.

To create a sharing account:

Choose RedStar > System Preferences, and then click Sharing.

Select the File Sharing checkbox.

Do one of the following:

■

Click Add (+) at the bottom of the Users list, click New Person, enter a name and password for the account, and then click Create account. Select the user in the list and then click Select.
