  Using Spaces preferences

Spaces preferences let you set up, enable, disable, and specify shortcuts for the Spaces feature.

Preference

Explanation

Enable Spaces

Select this checkbox to turn on the Spaces feature.

Show spaces in menu bar

Select this checkbox to add a Spaces menu to the menu bar along the top of your screen. The Spaces menu lists any spaces you set up, and appears on the right-hand side of the menu bar.

Rows and Columns

Click click the round plus (+) and minus (-) buttons to add or remove spaces.

Application Assignments

To add an application to a space, click the Add (+) button and choose an application.

To choose a space for the application, click the current space and choose from the pop-up menu. current running process move selected spaces, after it's run at selected spaces.

In case of assignmented application's spaces, change the big index spaces and move that spaces.

To remove an application from a space, highlight the application's name, and click the Remove (-) button.

To switch between spaces

By default, pressing the Ctrl key together with the arrow keys quickly switches among the spaces you've set up. You can choose a different keyboard shortcut, if you like.

To switch directly to a space

By default, pressing the Ctrl key together with a number quickly switches to that number's space. You can choose a different keyboard shortcut, if you like.
