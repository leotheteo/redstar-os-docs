Using Dock preferences

You can change the size of icons in the Dock for better visibility, and reposition or hide the Dock to keep it out of the way.

Before you make changes, deselect "Automatically hide and show the Dock" so you can see the effect of any changes you make.

Preference

Explanation

Dock Size

Drag the slider to change the Dock size.

Magnification

Drag the slider toward "Max" to enlarge the icons when the pointer is over them.

Position on screen

Choose a location for the Dock.

Minimize using

Choose the effect used when you minimize a window. If you're unsure of the choices, try them out.

Animate opening applications

Select this checkbox to make icons bounce when you open applications.

Automatically hide and show the Dock

Select this checkbox to hide the Dock when you’re not using it. If you hide the Dock, move the pointer to the bottom or side of the screen to see it.
