  Changing modifier keys

You can change the behavior of the following modifier keys: CapsLock, Ctrl, Alt, and Win. This is useful if you’re familiar with a keyboard layout different from your current keyboard.

For example, UNIX and Sun computer keyboards have Control where Caps Lock is located on Apple keyboards. For experienced touch typists, this can be awkward. Changing the behavior of the Caps Lock key to Control solves this problem.

To change a modifier key:

Choose RedStar Menu > System Preferences, and then click Keyboard & Mouse.

Click Keyboard.

Click the Modifier Keys button.

Choose an action from the pop-up menu next to the modifier key you want to change, and then click OK.

To return the keys to their original settings, click Restore Defaults.
