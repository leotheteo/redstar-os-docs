  Changing how fast characters repeat

If you hold down a keyboard key when the insertion point is in a text area, the key’s character begins to repeat. You can set how long you must hold down the key before the character starts repeating and how fast it repeats once it starts.

To set character repetition speed:

Choose RedStar Menu > System Preferences, and then click Keyboard & Mouse.

Click Keyboard.

Drag the Delay Until Repeat slider to set how long to wait before the character begins repeating.

Drag the Key Repeat Rate slider to set how fast characters repeat.
