Use of Menus

Session Menu
This is menu about sessions operating.

New Session(Alt + Ctrl + N)

Create New Session.

New Window(Alt + Ctrl + W)

Open New Widnow(Konsole).

Close Session

Close the current session.

Quit

Quit Konsole, closing all sessions and any applications launched from them.

Edit Menu
This is menu abou Edit operating.

Copy

Copy the selected text to the clipboard.

Paste(Shift + Insert)

Paste text from the clipboard at the cursor location.

Clear Session

Clear all text from the session window.

Find in History...

Find a word or string of text in the current history.

Find Next

Move to the next instance of the text for which you are searching.

Find Previous

Move to the previous instance of the text which you are searching.

View Menu
This is menu about View operating.

Detach Session

Open the current session in a separate window. The name of the session is displayed on the titlebar of the new window.

Rename Session...(Alt + Ctrl + S)

Open a dialog box allowing you to change the name of the current session. The name is displayed on the session tab.

Monitor for Session Status & Send Input to All Sessions

Konsole is done to monitor current session's status or to send same command all sessions.

Move Session

Move the tab of the current session one tab to the left or right.

Settings Menu
This is menu about Setting operating.

Fullscreen(Ctrl + Shift + F)

Toggle window between full-screen and normal size.

Font

Set font family and size.

Encoding

Select character encoding.

Schema

Set colors of text and background.

Save as Default

Save the current settings as the new default.

Save Sessions Profile...

Save the current set of sessions under a name you choose. The profile can then be used by starting Konsole from the command-line with the --prifile and the name of the profile
