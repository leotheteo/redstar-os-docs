Setting KFinder preferences

KFinder preferences let you specify which folders should open automatically in new KFinder windows, how quickly KFinder windows spring open when the pointer hovers over them, and other options.

To set KFinder preferences:

To make sure you’re in the KFinder, click the desktop (the background area of your screen).

Choose KFinder > Preferences.

To determine which items appear on the desktop, and how new KFinder windows open, click General.

Show these items on the Desktop: Deselect items you don’t want to see on the desktop. You will still see them in KFinder windows.

New KFinder windows open: Choose which folder should open automatically when you open a new KFinder window.

Always open folders in a new window: To open a new window each time you open a folder, select this. If deselected, opening a folder replaces the current content of a window.

Spring-loaded folders: When a folder is “spring-loaded,” it opens automatically after a delay when you hover over it with the mouse. You can use the slider to specify how quickly it opens.

If you use colored labels to organize your files, click Labels and type a descriptive term for each color.

For example, if you use red to designate files that require immediate attention, you could type “Immediate” next to the red label.

To select which items should appear in the KFinder window sidebar, click Sidebar.

To remove or add warnings about changing filename extensions or emptying the Trash, click Advanced.

“Empty Trash securely” means that the deleted files are overwritten by meaningless data, so they can’t be recovered.
