Changing the default paper size

All new documents you create are automatically formatted to fit a specific paper size, which is the default paper size. You can choose a new paper size to be the default at any time, but it will affect only documents created after this change.

To change the default paper size:

Open System Preferences and click Printer.

Choose a paper size from the “Default Paper Size in Page Setup" pop-up menu.

You can print a document to any printer that supports that paper size.

You can format an individual document to print to a different paper size without changing your default setting by using the Paper Size pop-up menu in either the Page Setup or Print dialog.
