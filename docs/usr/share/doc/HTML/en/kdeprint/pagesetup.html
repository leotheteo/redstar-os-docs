Using the Page Setup dialog

When you create a new document, it has a default page setup that includes its paper size and orientation. Before printing a document, use the Page Setup dialog to choose a different paper size, or change the orientation of the printed pages.

To use the Page Setup dialog:

Open the document you want to print.

Choose File > Page Setup.

If the paper size you'll be using is a common one (such as US Letter or A4), choose Any Printer from the Format For pop-up menu. This ensures that your document can print on any printer that supports the paper size you select.

If the paper size is specific to a certain printer, choose the printer's name from the Format For pop-up menu.

Choose the paper size you are using from the Paper Size pop-up menu. To create a custom paper size, choose Manage Custom Sizes from the Paper Size pop-up menu.

Click to select portrait (vertical) or landscape (horizontal) orientation.

Click OK.

Note: The printer of setting here is for only paper setting.
