Deleting a print job

You can delete a print job if you accidentally print the wrong document or set the print options incorrectly.

To delete a print job:

While the document is printing, click the printer's icon in the Dock to open its Jobs window.

Select the document.

Click Delete.

If you want to pause or resume only the printing of an individual document, click Hold or Resume.

If you're printing to a shared printer, you can't pause or resume the printing of a document.
