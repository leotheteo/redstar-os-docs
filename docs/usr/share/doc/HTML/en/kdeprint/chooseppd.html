Choosing a printer's PPD file

A PostScript Printer Description (PPD) file specifies a printer's options and capabilities. When you add a printer, RedStar chooses a PPD file for the printer automatically. You can change the PPD file to one that you believe better describes your printer. You can use a PPD that came with RedStar or download a PPD from the Internet.

To change the PPD file for a printer you've already added:

Open System Preferences and click Print & Fax.

Select the printer in the Printers list, click Options & Supplies, and then click Driver.

If you want to choose a PPD file that came with RedStar, choose Other from the Print Using pop-up menu.

If you want to choose a PPD that you downloaded, choose “Select a driver to use” from the Print Using pop-up menu.

Choose the PPD file and click OK or Open.

Make sure the options under the Print Using pop-up menu match your printer's features, and then click OK.
