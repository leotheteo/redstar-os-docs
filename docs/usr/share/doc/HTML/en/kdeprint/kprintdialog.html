About printing

To print a document, choose File > Print. Use the Print dialog to select a printer and set print options. Then choose whether to print that document, preview it, or save it as a PDF.

If the Print dialog doesn't contain options you expected to see and instead contains two pop-up menus and buttons across the bottom, click the disclosure triangle beside the Printer pop-up menu.

Choosing a printer
You can choose which printer to use with the Printer pop-up menu. If you don't see the printer you want, choose Add Printer.

Setting print options
You can set print options, such as the number of copies to print, when to print them, how many pages to print to a piece of paper, and how the colors should appear.

Previewing a document
You can see what your printed document will look like with the print options you've chosen.

Printing to a file
You can save a document in PDF or PostScript format to share it with others. Or you can save a document to iPhoto and transfer it to an iPod. Just choose an option from the PDF pop-up menu.
