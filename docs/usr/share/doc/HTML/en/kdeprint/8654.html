Pausing or resuming all print jobs to a specific printer

When you pause a print job to a specific printer, all jobs on that printer are paused.

To pause or resume all of a printer's print jobs:

Open System Preferences and click Print.

Select the printer in the Printers list, and then click Open Print Queue.

Click Pause Printer or Resume Printer to stop or start all print jobs in the queue.

If you're using another user's shared printer, you can pause and resume only those print jobs on the computer that's sharing the printer.

If you want to pause or resume only the printing of an individual document, click Hold or Resume.

If you want to delete your print job, select it and click Delete.
