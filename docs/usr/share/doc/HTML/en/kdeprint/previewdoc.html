Previewing a document before you print

You can preview a document onscreen to see what it will look like when you print it.

You can also view a full-size preview.

To view a full-size preview:

Open the document and choose File > Print.

Choose “Preview”.

Click Print to print your document directly from the Preview window.

For more information about using Preview, see Preview Help, available in the Help menu when Preview is open.
