Saving a document in PostScript format

Using the Print dialog, you can save a document as a file in PostScript format.

To save a document in PostScript format:

Open the document you want to save in PostScript format.

Choose File > Print.

Choose “Save as Postscript” from the PDF pop-up menu.

To print the PostScript file, open the file in Preview and choose File > Print.
