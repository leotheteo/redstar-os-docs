Setting print options

The Print dialog lets you choose how a document is printed. You can choose the number of copies, print several pages on a sheet of paper, and more.

To print a document, choose File > Print. If the Print dialog doesn't contain options you expected to see and instead contains two pop-up menus and buttons across the bottom, click the disclosure triangle beside the Printer pop-up menu.

The Print dialog may contain options that are supplied by the printer or application you're using. Check the documentation that came with the application and printer for information on how to use them.

Saving paper
You can save paper by choosing Layout from the print options pop-up menu. You can print on both sides of a piece of paper or print several pages of a document to a single sheet of paper.
■

Changing a document's size
You can change the page size for a document. This reformats the document, which doesn’t change the size of its graphics or fonts but may change the locations of line breaks and page breaks. You can also change the default page size for new documents and create custom page sizes.

Saving commonly-used options
If you have a combination of options that you frequently use when printing a document, save it as a preset by choosing Save As from the Presets pop-up menu and entering a name. When you want to use that combination of options of again, choose its name from the Presets pop-up menu.
