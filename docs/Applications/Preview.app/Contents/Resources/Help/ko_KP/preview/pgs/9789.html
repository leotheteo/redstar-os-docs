첫페지

PDF문서에서 선택된 페지보기

여러페지의 PDF문서를 열면 첫페지가 보이면서 하나의 열람창문이 펼쳐집니다. 측면띠에서 화상이나 페지의 간략화상을 볼수있습니다.

보려는 페지를 선택할수 있는 방법:

■

측면띠가 열려져 있지 않다면 < 보기 / 측면띠 >을 선택합니다.

■

문서의 간략화상을 리용하여 탐색하려면 측면띠에서 간략화상을 선택하십시오.

■

다음 페지로 가려면 아래방향건이나 Page Down 건을 누르십시오. 이전 페지로 가려면 웃방향건이나 Page Up 건을 누르십시오.

■

수직흐름띠를 리용하여 여러페지의 문서를 보려면 < 보기 / PDF현시 / 한 페지련속 >, 혹은 < 보기 / PDF현시 / 두페지 련속 >을 선택합니다.

■

특정한 페지를 보려면 < 가기 / 페지로 가기 >를 선택하고 페지번호를 입력하십시오.

초기설정으로는 PDF파일을 열면 측면띠 펼쳐집니다.
