확대 및 축소

PDF파일의 페지나 화상에서 보기를 몇가지 방법으로 변경할수 있습니다. 실례로 화상을 확대하거나 더 큰 령역을 보기 위해 축소할수도 있습니다.

확대 및 축소방법:

■

확대하거나 축소하려면 < 보기 / 확대 > 혹은 < 보기 / 축소 >를 선택합니다.

■

원래의 크기로 화상이나 페지를 보려면 < 보기 / 실지 크기 >를 선택하십시오.

■

사용자가 지정한 크기로 화상이나 페지를 보려면 바라는 크기로 측면띠의 크기를 조절한 다음 < 보기 / 자동크기조절 >을 선택하십시오. 화상의 크기가 창문의 크기에 맞게 조절됩니다.

■

PDF문서의 선택부분을 확대하려면 < 도구 / 선택도구 >를 선택하고 그 부분을 선택한 다음 < 보기 / 선택령역확대 >를 선택합니다.

화상이나 페지의 보는 방법에 대한 변경사항은 저장할수 없습니다.
