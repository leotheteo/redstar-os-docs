하나의 창문에서 여러개의 화상을 보기

하나의 창문에서 하나이상의 화상을 열수있습니다. 하나의 창문에 하나이상의 화상이 포함되면 측면띠에는 각 화상파일에 대한 간략화상이 포함됩니다. 간략화상을 선택하면 화상이 나타납니다.

하나의 창문에 하나이상의 화상을 자동적으로 현시하거나 화상을 이미 있던 창문에 추가할수 있습니다.

하나의 창문에서 하나이상의 화상을 표시하려면:

< PDF 및 화상열람기 / 환경설정 >을 선택하고 화상을 누른다.

<화상을 열때:>에서 바라는 옵션을 선택하십시오.

한개 창문에 모든 화상열기: 모든 화상파일에 대하여 하나의 창문을 사용합니다.

한번에 열기한 화상들을 같은 창문에 열기: 한번에 열기한 화상파일들의 모임에 대하여 개별적인 창문을 사용합니다.

한개 창문에 한개 화상열기: 매 화상파일에 대하여 하나의 창문을 사용합니다.
