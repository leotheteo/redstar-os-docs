Bookmarking pages in a PDF document

You can bookmark an image file or a page in a PDF document so you can quickly return to it.

Here’s what you can do with bookmarks:

■

To add a bookmark, choose Bookmarks > Add Bookmark >

■

To delete a bookmark, choose Bookmarks > Edit Bookmarks , select it, and click Remove.

■

To go to a bookmark, choose its name from the Bookmarks menu.
