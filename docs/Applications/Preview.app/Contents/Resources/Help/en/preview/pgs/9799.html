Displaying several images in one window

You can display more than one image file in a window. When a window contains more than one image, its sidebar contains a thumbnail image for each image file. Selecting the thumbnail displays its image.

Preview can automatically display more than one image in a window, or you can add images to an existing window.

To display more than one image in a window:

Choose Preview > Preferences, and click "Images"

Select an option under “When opening images”:

Open all images in one window: Uses one window for all image files you open in Preview.

Open groups of images in the same window: Uses a separate window for each group of image files you open in Preview.

Open each image in its own window: Uses one window for each image file.
