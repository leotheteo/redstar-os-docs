Setting the default size for an image

You can choose the size at which Preview displays images: either large enough to fit the entire window or at its actual size.

To set the default size for an image:

Choose Preview > Preferences and then click "Images"

Select one of the options under “Default Image Size:”

■

To shrink large images so you can see them without scrolling, select “Scale large images to fit window.”

■

To open images at their actual size, select “Actual size.”
