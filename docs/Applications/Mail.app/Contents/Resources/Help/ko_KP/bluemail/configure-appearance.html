현시페지

서체

서체의 계렬, 격식과 크기를 변경할수 있습니다.

배치

여기서는 기본창문의 배치를 변경할수 있습니다.

우편프로그람은 서류철목록을 두가지 형식으로 보여줄수 있습니다. 《긴 서류철목록》을 선택하면 서류철목록이 왼쪽옆에 길게 놓이게 됩니다. 《짧은 서류철목록》을 선택하면 왼쪽의 일부만을 차지하게 됩니다.

《우편을 미리보기판에 표시하지 않습니다.》를 선택하면 우편미리보기판을 보여주지 않습니다. 《우편아래에 우편미리보기를 보여줍니다.》를 선택하면 우편목록의 아래에 우편미리보기창을 배치합니다. 《우편미리보기를 우편목록 다음에 보여줍니다.》를 선택하면 우편목록의 옆에 우편미리보기창이 현시됩니다.

우편프로그람은 우편의 구조도 보여줄수 있습니다. 《비표시》를 선택하면 우편의 구조를 보여주지 않습니다. 《비평문우편의 표시》를 선택하면 첨부파일을 가지고있는 우편에 대해서만 우편구조를 보여줍니다. 《항상 표시》를 선택하면 우편구조보기창이 항상 표시됩니다. 《우편령역의 우》를 선택하면 우편구조보기창이 우편미리보기창의 우에 표시됩니다. 《우편령역의 아래》를 선택하면 우편미리보기창의 아래에 표시됩니다.

우편목록

《우편크기현시》를 선택하면 우편의 크기가 우편목록의 정보마당에 현시됩니다.

《암호화그림기호를 표시》는 우편목록의 제목마당에 암호화상태를 보여줍니다.

《묶어진 우편목록》은 모든 우편들을 나무구조형식으로 묶어서 우편목록에 보여줍니다.

《묶음화된 우편목록선택》에서는 묶음들을 열려진것으로 표시하겠는가를 선택할수 있습니다.

《날자현시》에서는 여러가지 날자형식들을 선택할수 있습니다.

우편창문

우편에서 인용문을 작게 보이려고 한다면 《인용된 본문에 보다 작은 서체를 리용》을 선택하여야 합니다. 인용문이 계층을 이룰 때 나무구조형식으로 보여주려 한다면 《확장/축소된 인용표식을 표시》를 선택하면 됩니다.
