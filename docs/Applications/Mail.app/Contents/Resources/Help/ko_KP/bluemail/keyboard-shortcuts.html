지름건들

기본창문은 아래의 기본건들의 기능들을 지원합니다.

지름건들 동작
공백 현재우편을 아래로 흘리거나 마우스가 아래에 있으면 읽지 않은 다음우편으로 이동합니다.
오른쪽화살 또는 N 현재서류철에서 다음우편으로 이동합니다.
왼쪽화살 또는 P 현재서류철에서 이전우편으로 이동합니다.
+ 현재서류철에서 읽지 않은 다음우편으로 이동합니다.
- 현재서류철에서 읽지 않은 이전 우편으로 이동합니다.
웃화살 서류철목록에서 현재 선택된 서류철의 이전 서류철로 이동합니다.(서류철목록이 초점을 가진 경우)
아래화살 서류철목록에서 현재 선택된 서류철의 다음 서류철로 이동합니다.(서류철목록이 초점을 가진 경우)
Ctrl+왼쪽화살 현재 선택한 서류철의 웃준위서류철로 초점을 이동합니다.
Ctrl+오른쪽화살 현재 선택한 서류철의 자식서류철들을 펼쳐보입니다.
Shift+왼쪽화살건과 Shift+오른쪽화살건 현재우편으로부터 시작하여 우편목록에서 우편을 선택합니다.
