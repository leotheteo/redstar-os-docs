스마트그룹을 생성하기

스마트그룹은 해당한 그룹에 대해 지정한 기준에 맞을때 주소록에서 새로운 카드로 자동적으로 갱신해주는 그룹입니다.
  • 파일 / 새로운 스마트그룹을 선택하십시오.
  • 그룹이름을 입력하십시오.
  • 지름차림표 및 입력 마당을 사용하여 해당그룹에 대한 탐색기준을 지정하십시오. 추가(+) 단추를 눌러 추가기준으로 탐색을 재설정하십시오.

    • 스마트그룹을 편집하려면 그룹목록칸에서 항목을 선택하고 편집 / 스마트그룹편집을 선택하십시오.

    스마트그룹의 이름을 변경하려면 그룹목록칸에서 해당한 이름을 두번 누르기하고 새로운 이름을 입력하십시오.
