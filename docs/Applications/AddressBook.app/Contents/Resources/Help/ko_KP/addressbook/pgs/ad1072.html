목록을 인쇄하기

주소록에 있는 카드의 목록들을 인쇄할수 있습니다.

  1. 주소록의 창문에서, 그룹렬에서는 주소록 또는 그룹을 선택하거나 이름렬에서는 인쇄하려는 특정한 이름을 선택하십시오.
  2. 파일 / 인쇄를 선택하십시오.
  3. 지름차림표에서 목록을 선택하십시오.
  4. 요구하는대로 기타 인쇄항목을 구성한 다음, 인쇄를 누르십시오.

속성항목을 사용하여 주소록에서 모든 이름에 표시하려는 마당을 선택하십시오.

선택한 그룹의 카드들이 여러개의 주소나 전화 번호를 가지고 있다면, 모든 카드에 대해 사용할 주소 또는 전화 번호를 선택할수 있습니다. 취소를 눌러 인쇄 대화창를 닫으십시오. 그런 다음, 편집 / 전자우편의 분류목록편집을 선택하고 사용하려는 주소 및 전화 번호를 선택하십시오.

망서류철에서 직접 인쇄를 할수 없습니다. 망서류철에서 카드에 대한 주소록 정보를 인쇄하려면, 카드를 개별주소록으로 끌기하십시오.
