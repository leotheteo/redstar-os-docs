주소록에서 망서류철 사용하기

콤퓨터가 망에서 서류철봉사를 리용하도록 설정되여 있다면 주소록은 자동으로 서류철봉사를 탐색합니다.

또한 LDAP 봉사기를 탐색하도록 주소록을 설정할수 있습니다. LDAP는 봉사기에서 카드정보를 찾는데 사용되는 인터네트규약입니다.

  1. 주소록 / 환경설정을 선택한 다음 LDAP를 누르십시오.
  2. 추가(+)를 누르고 사용하려고 하는 LDAP 봉사기를 설정하십시오. 입력해야 하는 정보에 대해서는 봉사기관리자에게 문의하십시오. 일부 일반적인 설정은 다음과 같을수 있습니다. Server: ldap.mycompany.com Search Base: ou=people, o=mycompany
  3. 필요하다면 LDAP 봉사기상의 자신의 사용자 계정 암호 및 이름을 사용하여 "사용자 이름" 및 암호 마당을 채우십시오. 관리자의 지침에 따라 인증 류형 지름차림표에 없음 또는 일반을 선택하십시오.
  4. SSL을 사용하도록 구성된 LDAP 봉사기에 추가 보안을 설정하려면 SSL 사용 검사칸을 선택하십시오.

    SSL(Secure Sockets Layer)은 콤퓨터에서 인터네트에 걸쳐 암호화되고 인증된 정보를 보낼수 있도록 지원하는 인터네트규약입니다.

  5. 보관을 누르십시오.
  6. 자신의 개인 주소록에 끌기하는 LDAP 망서류철 카드에 대하여 자동으로 카드정보를 갱신되도록 하려면 "LDAP 카드 자동 갱신"를 선택하십시오.

망서류철의 정보는 탐색할때만 나타납니다. 망서류철을 탐색하려면 그룹목록칸에서 서류철을, 서류철목록칸에서 서류철을 선택하고 탐색마당에 본문를 입력하십시오. 망서류철에 있는 누군가를 자신의 개인 주소록에 추가하려면 카드를 서류철에서 그룹목록칸의 모두로 끌기하십시오.

망에서 서류철봉사를 리용하도록 콤퓨터를 설정하는 방법을 보려면 서류철리용을 열고 도움말 / 서류철리용 도움말을 선택하십시오.
