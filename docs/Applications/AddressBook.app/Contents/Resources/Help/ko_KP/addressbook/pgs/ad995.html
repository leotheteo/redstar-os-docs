vCards를 반입 및 반출하기

vCard는 응용프로그람간의 표준 자료교환방법입니다. 주소록은 vCard를 생성하고 읽을수 있습니다. vCard 형식을 인식할수 있는 다른 응용프로그람이 있다면 vCard를 반입하거나 반출할수도 있습니다.

또한 자신의 카드를 vCard 형식으로 다른 사람에게 전송할수 있습니다. vCard를 사용하여 자신의 정보를 자신의 주소록에 추가할수 있습니다.

vCard를 생성하려면 주소록 창문밖으로 주소 카드를 끌기하십시오.

다른 사람의 vCard를 주소록에 추가하려면 주소록 창문로 끌기하십시오.

여러개의 항목으로 단일vCard를 생성하려면 두개 이상의 카드를 주소록 창문밖으로 끌기하십시오.

동시에 여러 개의 vCard를 생성하려면 Alt 건을 누른 채로 여러 카드를 주소록 창문밖으로 끌기하십시오.

주소록은 또한 LDIF(Lightweight Directory Interchange Format)를 지원합니다. LDIF는 정보를 교환하는데 사용하는 ASCII 파일 형식으로 LDAP(Lightweight Directory Access Protocol) 봉사기사이 정보를 동기화할수 있습니다. 주소록의 정보를 LDIF 형식으로 반출할수 없습니다. 반입할수만 있습니다. 주소록은 vCard를 반입하거나 반출할수 있습니다.

다른 응용프로그람에서 기본 3.0 형식의 vCards를 리용하지 못한다면 주소록 환경설정의 vCard 부분에서 2.1 형식으로 변경한 다음 vCard를 다시 반출하십시오.
