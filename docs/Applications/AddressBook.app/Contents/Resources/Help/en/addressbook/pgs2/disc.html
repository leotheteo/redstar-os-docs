Discover Address Book

Address Book provides a flexible and convenient way to store your contact information online.

Setting up Address Book

It's easy to enter contact information in Address Book cards. Add as many address, telephone, and email fields as you need, and customize labels as you like. Create groups of contacts and access network directories. If you have existing contact information in other applications, you can import vCards, LDIF files, and tab-delimited and comma-separated values (CSV) text files to get that information into Address Book.
