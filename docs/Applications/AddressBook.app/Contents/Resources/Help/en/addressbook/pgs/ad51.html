I get an error when trying to add an image to a card

Address Book supports pictures in JPEG, GIF, TIFF, PNG, PDF, or just about any graphics format. If you can view the image with Preview (located in the Applications folder), Address Book can generally use the image as a picture for a card.

To choose an image for a contact:

  1. Select the contact to which you want to add an image and click Edit.
  2. Double-click the image if there is one. If there is no image, double-click the box to the left of the contact's name.
  3. Click Choose and locate the image you want to use.
  4. Drag the image in the box to select the portion you want to appear in the box.

You can also take a snapshot of yourself using a video camera. Attach an iSight or other compatible camera to your computer, then click the Video button. When the still video image appears, use the slider to zoom in or out and drag the picture to adjust its position.
