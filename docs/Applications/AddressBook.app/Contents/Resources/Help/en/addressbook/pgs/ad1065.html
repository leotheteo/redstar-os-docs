Why don't any contacts appear in my network directories?

The names of people in a network directory don’t appear in the Name column in the Address Book window until you enter text in the search field.

You must also be connected to the network on which the directories reside. If you've changed locations or lost your network connection, Address Book cannot look up contacts in directories on the network.

To see contacts in a network directory you’ve set up:

  1. Select Directories in the Group column.
  2. Select the directory you want to use in the Directories column.
  3. Enter text in the search field in the upper-right corner of the Address Book window.
