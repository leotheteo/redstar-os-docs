Using network directories with Address Book

If your computer is set up to access directory services on your network, Address Book automatically searches the directory services for addresses.

You can also set up Address Book to search LDAP servers for addresses. LDAP is an Internet protocol used for looking up contact information on servers.

  1. Choose Address Book / Preferences, then click LDAP.
  2. Click Add (+) to specify the settings for the LDAP server you want to use. Contact your server administrator for the information you need to enter. Some common settings may look like this: Server: ldap.mycompany.com Search Base: ou=people, o=mycompany
  3. If required, fill in the “User name” and Password fields, using the name and password of your user account on the LDAP server. Choose None or Simple from the Auth Type pop-up menu, as instructed by the administrator.
  4. For additional security on LDAP servers configured to use SSL, select the Use SSL checkbox.

    SSL (Secure Sockets Layer) is an Internet protocol that allows your computer to send encrypted, authenticated information across the Internet. Ask your system administrator if this option should be selected.

  5. Click Save.
  6. To have contact information automatically updated for LDAP network directory cards that you drag to your personal address book, select “Auto Update LDAP Cards.”

Information from network directories appear only when searching. To search a network directory, select Directories in the Group column and a directory in the Directory column, and then type text in the search field. To add someone from the network directory to your personal address book, drag the card from the directory to All in the Group column.

For instructions on setting up your computer to access directory services on your network, open Directory Access and choose Help / Directory Access Help.

For a list of public LDAP directories that you can add to Address Book, go to www.emailman.com/ldap/public.html or www.nd.edu/~eds/search/ldap_search.shtml.
