Printing lists

You can print lists of contacts from your address book.

  1. In the Address Book window, select your address book or a group in the Group column, or select the specific names in the Name column that you want to print.
  2. Choose File / Print.
  3. Choose Lists from the Style pop-up menu.
  4. Configure the other print options as you want, then click Print.

Use the Attributes options to select the fields you want to appear for each name in the address book.

If contacts in the group you selected have multiple addresses or phone numbers, you can choose which address or phone number to use for each contact. Click Cancel to close the Print dialog. Then choose Edit / Edit Distribution List and select the addresses and phone numbers you want to use.

You cannot print directly from network directories. To print address book information for contacts in network directories, drag the contacts to your personal address book.
