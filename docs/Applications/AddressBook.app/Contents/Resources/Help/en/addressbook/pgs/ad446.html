Adding a contact to your address book

Use Address Book to store contact information for people you correspond with.

  1. Open Address Book and choose File / New Card. A new card is created with empty fields for the person's information. If one of the fields doesn't apply, simply skip it, and it will not be shown in the completed card.
  2. Add the contact information you like to the fields. Press Tab to move from field to field.
  3. To add more fields, such as for additional phone or fax numbers, click the Add (+) button next to a field name. The Add button appears only after you have used fields that are already onscreen.

To add a virtual address card (vCard) that someone has sent you, drag it to the Address Book window. Or, double-click the vCard to open Address Book and automatically add the card.
