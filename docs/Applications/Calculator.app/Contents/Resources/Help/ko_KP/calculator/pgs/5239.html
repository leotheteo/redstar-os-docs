첫페지

값을 보관하여 후에 사용하기

전자수산기의 기억기능을 통해 값을 보관하여 후에 사용할수 있습니다. 값을 보관하면 동일한 값을 자주 사용해야 할 때 혹은 일부 연산의 합계를 실행해야 할 때 쓸모가 있습니다.

기억기에 0이 아닌 값이 포함되여있다면 전자수산기화면에 M이 나타납니다.

전자수산기의 기억기능을 사용하려면

■

화면에 나타난 값을 기억기의 값에 더하려면 [M+]를 누릅니다.

■

기억기에 있는 값에서 화면에 나타난 값을 덜려면 [M-]를 누릅니다.

■

기억기에 있는 값을 호출하여 연산에 사용하려면 [MR]를 누릅니다.

■

기억기에 있는 값을 지우려면 [MC]를 누릅니다.

■

기억기값을 표시된 값으로 바꾸려면 [MC]를 누른 다음 [M+]를 누릅니다.

프로그람개발자용전자수산기에서는 기억기능을 사용할수 없습니다.
