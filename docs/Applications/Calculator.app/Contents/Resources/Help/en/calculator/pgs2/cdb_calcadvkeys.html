Using the scientific calculator keys

This table describes the keys available only in the scientific calculator. You can also use the keys in the basic calculator, which you can learn about by clicking the link below.

NOTICE: When performing calculations, Calculator uses the fundamental "order of operations" to evaluate expressions. For example, multiplication operations are completed before addition and subtraction.

Key

Function

2nd (labeled with an Up Arrow)

Changes the trigonometric buttons (sin, cos, tan, sinh, cosh, and tanh) to their inverse functions (sin-1, cos-1, tan-1, sinh-1, cosh-1, and tanh-1). Click 2nd again to return the trigonometric buttons to their original functions.

(

Opens a parenthetical expression.

)

Closes a parenthetical expression.

%

Calculates percentages, adds markups, and subtracts discounts. To calculate a percentage, use it with the multiplication (x) key. For example, to calculate 8% of 500, enter

500 x 8 % =

which returns 40.

To add a markup or subtract a discount, use it with the plus (+) or minus (-) key. For example, to compute the total cost of a $500 item with an 8% sales tax, enter

500 + 8 % =

which returns 540.

1/x

Returns the reciprocal of a value in decimal format.

x2

Squares a value.

x3

Cubes a value.

yx

Click between values to raise the first value to the power of the second value. For example, to compute 34, enter

3 yx 4 =

which returns 81.

x!

Calculates the factorial of a value. (The factorial of a negative number can not be calculated.)

√

Calculates the square root of a value.

x√y

Click between values to calculate the x root of y. For example to compute 4√81, enter

81 x√y 4 =

which returns 3.

ln

Calculates the natural log of a value.

sin

Calculates the sine of a value.

sin-1

Calculates the arc sine of a value. (Available when the 2nd button is clicked.)

cos

Calculates the cosine of a value.

cos-1

Calculates the arc cosine of a value. (Available when the 2nd button is clicked.)

tan

Calculates the tangent of a value.

tan-1

Calculates the arc tangent of a value. (Available when the 2nd button is clicked.)

log

Calculates the log base 10 of a value.

sinh

Calculates the hyperbolic sine of a value.

sinh-1

Calculates the inverse hyperbolic sine of a value. (Available when the 2nd button is clicked.)

cosh

alculates the hyperbolic cosine of a value.

cosh-1

Calculates the inverse hyperbolic cosine of a value. (Available when the 2nd button is clicked.)

tanh

Calculates the hyperbolic tangent of a value.

tanh-1

Calculates the inverse hyperbolic tangent of a value. (Available when the 2nd button is clicked.)

ex

Click after entering a value to raise the constant "e" (2.718281828459045) to the power of that value.

Rad

Changes mode to express trigonometric functions in radians.

Deg

Changes mode to express trigonometric functions in degrees.

π

Enters the value of π (3.141592653589793).

RN

Returns a random number between 0 and 1.

EE

You enter the first number, press this button, and enter the second number, then you will have the first number multiplied by 10 raised to the second number. For example, the result of

3 EE 5 =

is 300 000.
