Storing a value to use later

Calculator's memory functions lets you store a value so you can use it later in a calculation. Storing values is useful when you need to use the same value frequently, or keep a running total of several calculations.

When the memory contains a value other than zero, an M appears in the calculator's display.

To use Calculator's memory function:

■

To add the displayed value to the value in memory, click M+.

■

To subtract the displayed value from the value in memory, click M-.

■

To recall the value in memory and use it in a calculation, click MR.

■

To clear the memory, click MC.

■

To replace the value in memory with the displayed value, click MC and then M+.

The memory functions are not available in the programmer's calculator.
