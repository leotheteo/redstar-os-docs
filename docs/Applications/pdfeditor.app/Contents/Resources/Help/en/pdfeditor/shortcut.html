Short keys

The following short keys will make it easier for you to use.

Ctrl + N : New

Ctrl + O : Open

Ctrl + S : Save

Ctrl + Shift + S : Save As

Ctrl + P : Print

Ctrl + W : Close

Ctrl + X : Cut

Ctrl + C : Copy

Ctrl + V : Paste

Ctrl + Z : Undo

Ctrl + Shift + Z : Redo

Ctrl + F : Search

Ctrl + A : Select All

Ctrl + G : Paging

Del : Delete

PgUp : Page Up

PgDn : Page Down

Home : Go to first page

End : Go to last page

↑ : Scroll Up

↓ : Scroll Down

← : Next page

→ : Previous page
