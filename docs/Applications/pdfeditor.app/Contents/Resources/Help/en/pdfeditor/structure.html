User Interface

It consists of main window, toolbars and bookmark window.

- Bookmark window

It shows the bookmark information of PDF file, and you can easily find/select the topics from it.

- Toolbars

These are for you to manipulate PDF file or edit it.

- Main Window

You can navigate PDF file, and work with it on this window.

You can easily open PDF file through Open Dialog.

You can also make some drawings and edit the documents.
