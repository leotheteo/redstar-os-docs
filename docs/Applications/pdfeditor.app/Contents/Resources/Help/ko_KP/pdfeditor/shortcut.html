프로그람에서 리용하는 지름건들

프로그람에서 리용하는 지름건들은 다음과 같습니다.

Ctrl + N : 새로운 창

Ctrl + O : 열기

Ctrl + S : 보관

Ctrl + Shift + S : 다른 이름으로 보관

Ctrl + P : 인쇄

Ctrl + W: 닫기

Ctrl + X : 자르기

Ctrl + C : 복사

Ctrl + V : 붙이기

Ctrl + Z : 실행취소

Ctrl + Shift + Z : 다시실행

Ctrl + F : 탐색

Ctrl + A : 모두선택

Ctrl + G : 페지이행

Del : 삭제

PgUp : 화면우로 한페지 이동

PgDn : 화면아래로 한페지 이동

Home : 첫페지로 이행

End : 마지막페지로 이행

↑ : 화면우로 이동

↓ : 화면아래로 이동

← : 이전페지로 이행

→ : 다음페지로 이행
