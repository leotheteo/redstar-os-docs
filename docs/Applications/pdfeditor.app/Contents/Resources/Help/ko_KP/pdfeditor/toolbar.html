도구띠들

문서를 관리, 편집하기 위한 도구띠들이 있습니다.

- 기본도구띠

파일을 열고 보관하며 파일의 인쇄와 각종 도형들을 편집하기 위한 도구띠입니다.





: 문서를 엽니다.

: 문서를 보관합니다.

: 인쇄를 진행합니다.

: 문자탐색을 합니다.

: 선택한 내용을 자르기합니다.

: 선택한 내용을 복사합니다.

: 복사한 내용을 붙이기합니다.

: 실행취소를 진행합니다.

: 다시실행을 진행합니다.

- 도형도구띠

각종 도형들을 삽입하고 도형들의 속성을 변경시키기 위한 도구띠입니다.





: 도형을 선택할수 있는 상태로 변경됩니다.

: 끌기방식으로 변경됩니다.

: 선그리기방식으로 됩니다.

: 화살그리기방식으로 됩니다.

: 4각형그리기방식으로 됩니다.

: 원그리기방식으로 됩니다.

: 본문칸그리기방식으로 됩니다.

: 검사칸그리기방식으로 됩니다.

: 삽입할 화상파일을 지정합니다.

: 채움색을 설정합니다.

: 선색을 설정합니다.

: 서체색을 설정합니다.

: 선두께를 설정합니다.

: 선류형을 설정합니다.

: 화살류형을 설정합니다.

- 서체도구띠

본문칸안에 있는 본문의 속성을 변경시키기 위한 도구띠입니다.





: 굵은체를 설정합니다.

: 경사체를 설정합니다.

: 밑선체를 설정합니다.

: 왼쪽맞추기

: 가운데맞추기

: 오른쪽맞추기

- 보기도구띠

문서의 확대축소와 지정하는 페지로 이행하고 문서의 확대축소를 조종하기 위한 도구띠입니다.





: 여러페지방식

: 문서확대

: 문서축소
