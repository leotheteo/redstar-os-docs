Introduction

This program is "kPhoto" used by our operating system "Red Star" Desktop 3.0.
With this program, you can import pictures, make the source images library, group and manage them in various albums, view thumbnails, process the selected image and print them.

kPhoto Startup

Please run "Finder", select "Applications" → "kPhoto".

kPhoto Main Window

You can see as following on kPhoto startup.

Library

It includes source image files used by kPhoto. You can import pictures into this library or delete pictures.

Album

It includes albums made by user. No albums, nothing is displayed.

Information Window

It shows informations of selected photos.

Photo Edit Toolbar

It contains toolbar buttons for edition and print.

kPhoto Main Menu

These are in kPhoto main menu.

File

make a new album, import new pictures, export and print ones.

Edit

cut, copy, paste pictures, select and deselect files, search files.

Photo

mark a picture with date and time, duplicate and delete the selected picture.

View

modifies view mode of pictures. With this, you can sort files by file name, path, size, time and view the pictures in full screen or slide show mode.

Window

minimize or zoom kPhoto window.

Help

browse kPhoto help.

File Menu

File menu includes as followings.

New Album

In menubar, Select "File" → "New Album".
In shown dialog, you could input the new album name and press "Create" button.
Then, the new album with input name is created.

Import to Library

In menu bar, select "File" → "Import to Library".
In shown dialog, you could select files for importion and press "OK" button.
Then, selected photos is imported as source images.

Export

Select files and click "File"→ "Export" in menu bar.
Then in the shown dialog, select a directory to export and click "Export" button.
Seleted files are to be exported to the directory.

Print

Select files and click "File"→ "Print" in menu bar.
Then, the print dialog is displayed as following.


In the dialog, you can set up and click "Print" button.
At this, in the print dialog, you can configure settings relative to print job.
At last, the print job is done.

Edit Menu

Edit menu includes as followings.

Cut

Select files and click "Edit"→ "Cut" in menu bar.
The selected files are to be cut.

Copy

Select files and click "Edit"→ "Copy" in menu bar.
The selected files are to be copied.

Paste

While the selected files are to bo cut or copied, click "Edit" → "Paste" in menu bar.
The files to be cut or copied are pasted to selected album or the library..

Select All

In menu bar, click "Edit" → "Select All".
All of files in the library or current album are selected.

Deselect

After some files are selected, click "Edit" → "Deselect" in menu bar.
It deselects the selected photos.

Search

In menu bar, click "Edit" → "Search".
You can see only files matched input character.

Photos Menu

Photos menu includes as followings.

Adjust Date and Time

Select files and click "Photo"→ "Adjust Date and Time" in menu bar.
In the dialog, select the date and time to be modified and click "OK" button.
Then, it appends the selected date and time to current photo.

Duplicate

Select files and click "Photo"→ "Duplicate" in menu bar.
It duplicates the selected photos.

Delete

Select files and click "Photo"→ "Delete" in menu bar.
It deletes the selected photos and moves it to the trash.

View Menu

View menu includes as followings.

Sort Photo

In menu bar, click "View" → "Sort".
In the submenu, please select the sort base.
It sorts the photos in the current album based on the selected specification.

Fullscreen

In menu bar, click "View" → "Fullscreen".
You can browse the photos in the current album with full screen mode as following.

Slide Show

In menu bar, click "View" → "Slide Show".
You can browse the photos in the current album with slide show mode.

Window Menu

Window menu includes as followings.

Minimize

In menu bar, click "Window" → "Minimize".
It minimizes the kPhoto window and keep it on the dock.

Zoom

In menu bar, click "Window" → "Zoom".
It zooms the kPhoto window.

Help Menu

Help menu includes as followings.

kPhoto Help

In menu bar, click "Help" → "kPhoto Help".
You can browse the kPhoto help.

kPhoto Edit Toolbar

Please double-click the selected photo to enter the edit station as following.


Using the toolbar, you can rotate, crop the photo and so on.

Rotate

rotate the image.

Crop

crop a region of the image.

Enhance

enhance the image.

Red Eye

process the image in red-eye mode.

Adjust

adjust color levels of the image.

Duplication and Deletion of an Album

Duplicate

Please select the album to be duplicated, right-click on it and click "Duplicate".
It duplicates the selected album. It also appends the serial number string within the bracket to the duplicated album name.

Delete

Please select the album to be deleted, right-click on it and click "Delete".
Then, selected album is deleted.
