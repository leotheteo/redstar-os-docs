Main Feature

In this chapter main feature is introduced.

File Menu

New(Ctrl + N)

Create a new document.

Open(Ctrl + O)

Open a document.

Close(Ctrl + W)

Close the current document.

Save(Ctrl + S)

Save th current document.

Save As

Save the current document as another name.

Setup Page...

Set the page of the current document for print.

Print(Ctrl + P)

Print the current document.

Edit Menu

Undo(Ctrl + Z)

Cancel the work just performed.

Cut(Ctrl + X)

Copy the selected text in clipboard and remove it.

Copy(Ctrl + C)

Copy the selected text in clipboard and keep it.

Paste(Ctrl + V)

Paste the text copied.

Click Show Clipboard to view the text copied in clipboard.

Clear

Remove selected text.

Select All(Ctrl + A)

Select all text.

Find(Ctrl + F), Find Again(Ctrl + G)

Find a text you specified.

Use Selection for Find(Ctrl + E)

Select the text to find.

Replace...(Ctrl + R), Replace Again(Ctrl + D)

Replace a text you specified.

Next Page, Previous Page

Go to next or previous page.

Font Menu

You can choose font.

Size Menu

You can choose font size.

Style Menu

Plain Text(Ctrl + T)

Change font style to plain.

Bold(Ctrl + B)

Change font style to bold.

Italic(Ctrl + I)

Change font style to italic.

Underline(Ctrl + U)

Change font style to underline.

Sound Menu

Play/Pause

Start and Pause reading text.

Stop

Stop reading text.

Window Menu

Minimize(Ctrl + M)

Minimize window.

Zoom

Zoom out window to maximize size or zoom in window to original size.

Cycle Through Windows

Cycle through opened windows

Bring All to Front

Bring all windows to front.

Help Menu

Help

Display Help.
