첫페지

기본 기능

본문편집기 응용프로그람이 가지고있는 기본기능에 대하여 소개합니다.

파일차림표
파일조작과 관련한 차림표입니다.

새 문서[Ctrl + N]

새로운 문서를 창조합니다.

열기[Ctrl + O]

존재하는 문서를 열기합니다.

닫기[Ctrl + W]

현재의 편집창을 닫습니다.

보관[Ctrl + S]

작성한 문서를 보관합니다.

새로 보관

보관된 문서를 다른 파일로 보관합니다.

페지설정

문서를 인쇄하기 위한 페지를 설정합니다.

인쇄[Ctrl + P]

문서를 인쇄합니다.

편집차림표
문서편집과 관련한 차림표입니다.

실행취소[Ctrl + Z]

최근의 조작을 취소합니다.

자르기[Ctrl + X]

선택한 본문을 오림판에 복사하고 원래 위치에서 삭제합니다.

복사[Ctrl + C]

선택한 본문을 오림판에 복사합니다.

붙이기[Ctrl + V]

오림판에 복사된 본문을 붙이기합니다.

<오림판내용 보기>를 눌러서 오림판에 복사된 본문을 볼수 있습니다.

지우기

선택한 본문을 삭제합니다.

전체 선택[Ctrl + A]

전체 본문을 선택합니다.

탐색[Ctrl + F], 다시 탐색[Ctrl + G]

탐색창이 현시되고 지정한 본문으로 탐색을 진행합니다.

탐색문자렬 선택[Ctrl + E]

선택된 문자렬을 탐색문자렬로 지정합니다.

교체[Ctrl + R], 계속 교체[Ctrl + D]

지정한 본문을 교체합니다.

다음 페지로 이동[Ctrl + =], 이전 페지로 이동[Ctrl + -]

다음 페지 혹은 이전 페지로 이동합니다.

서체차림표
서체설정과 관련한 차림표입니다.

선택된 본문의 서체를 선택한 서체로 변경시켜 보여줍니다.

크기차림표
문자의 크기와 관련한 차림표입니다.

선택된 본문을 지정한 크기로 설정하여 보여줍니다.

문자형태차림표
문자형태와 관련한 차림표입니다.

평문[Ctrl + T]

문자형태를 평문으로 변경합니다.

강조체[Ctrl + B]

문자형태를 강조체로 변경합니다.

경사체[Ctrl + I]

문자형태를 경사체로 변경합니다.

밑줄체[Ctrl + U]

문자형태를 밑줄체로 변경합니다.

소리차림표
소리조작과 관련한 차림표입니다.

시작/정지

본문읽기를 시작하거나 시작된 본문읽기를 정지합니다.

중지

본문읽기를 중지합니다.

창문차림표
창문조종과 관련한 차림표입니다.

최소화[Ctrl + M]

창문을 최소화합니다.

확대/축소

창문크기를 최대크기로 확대하거나 이전의 크기로 축소시킵니다.

창문들사이로 이동[Ctrl + `]

여러개의 편집창들이 펼쳐져있는 경우 다른 편집창으로 이행합니다.

모든 창문들 앞으로 내오기

현재의 편집기를 제일 앞으로 내옵니다.

도움말차림표
본문편집기의 도움말과 관련한 차림표입니다.

도움말

본문편집기의 도움말이 현시됩니다.
