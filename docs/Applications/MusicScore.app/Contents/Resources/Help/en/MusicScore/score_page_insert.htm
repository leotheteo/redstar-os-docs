악보차림표\페지삽입...

악보에 새로운 페지를 삽입합니다.
<악보\페지삽입...>차림표를 선택하면 <페지삽입>대화창이 표시됩니다.

  • 페지삽입수 : 새로 삽입하는 페지수를 설정합니다.
  • 빈페지삽입 : 이 항목을 체크하면 악보표가 없는 빈페지를 삽입합니다. 본문, 도형을 편집할 때에 리용합니다.
  • 삽입위치 : 새로 삽입하는 페지의 위치를 설정합니다. 지정한 페지의 앞 또는 뒤에 새로운 페지를 삽입합니다. 새로 삽입되는 페지의 배치는 지정한 페지와 같습니다.
  • 확인 : 이 단추를 누르면 지정된 위치에 새로운 페지를 삽입합니다.
  • 취소 : 이 단추를 누르면 페지를 삽입하지 않고 원래 화면으로 돌아옵니다.
