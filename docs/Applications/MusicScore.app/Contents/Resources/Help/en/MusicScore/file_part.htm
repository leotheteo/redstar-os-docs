파일차림표\파트보작성...

이 지령을 리용하여 악보파일에서 필요한 악보표만을 뽑아서 새로운 악보를 작성합니다.
<파일\파트보작성...>차림표를 선택하면 <파트보작성>대화창이 표시됩니다. 이 대화창을 리용하여 선택한 악보표로 구성되는 악보(파트보)를 작성할수 있습니다.

  • 악보표 : 이 목록에서 새로운 악보로 하려는 악보표를 마우스로 선택합니다. 이때 악보표이름앞에 체크표식이 붙습니다.
  • 소절소속본문 : 이 항목을 체크하면 선택된 악보표에 표시되여있는 본문이 새로 작성되는 악보에 표시됩니다.
  • 가사 : 이 항목을 체크하면 선택된 악보표에 표시되여있는 가사가 새로 작성되는 악보에 표시됩니다.
  • 페지에 한개 악보단씩 표시 : 이 항목을 체크하면 새로 작성되는 악보에 한 페지당 한 악보단씩 표시합니다.
  • 페지소속본문 : 이 항목을 체크하면 새로 작성되는 악보에 원래 악보의 페지소속본문이 표시됩니다.
  • <확인> : 이 단추를 누르면 선택한 악보표에 의한 새로운 악보가 작성됩니다.
  • <취소> : 이 단추를 누르면 우의 설정을 무시하고 원래의 악보화면으로 돌아옵니다.
