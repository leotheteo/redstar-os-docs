새로 추가하려는 화음기호뒤붙이이름을 입력합니다. <화음기호의 편집>대화창에서 <추가...>단추를 누르면 <새로운 화음기호뒤붙이의 추가>대화창이 표시됩니다.

 

화음기호뒤붙이이름의 입력규칙

  • ~:이 기호로부터 시작되는 단락은 우에 표시합니다.
  • _:이 기호로부터 시작되는 단락은 아래에 표시합니다.
  • b:이 기호는 내림표를 표시합니다.
  • $:이 기호는 제자리표를 표시합니다.
  • #:이 기호는 올림표를 표시합니다.
