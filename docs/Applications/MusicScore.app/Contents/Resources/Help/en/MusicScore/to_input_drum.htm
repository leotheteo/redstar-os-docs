물음과 대답\드람보에 악보를 입력하려면

  • 먼저 <설정\파일설정...>차림표를 찰칵하여 <성부>판을 표시합니다.

  • 성부1은 <아래로>, 성부2는 <우로>로 설정하고 <확인>단추를 누릅니다.
  • 입력도구띠에서 <음고기호>단추를 찰칵하여 <음고기호>입력도구띠를 표시합니다.
  • 여기서 <드람보기호>단추를 선택하고 드람보로 하려는 악보표의 제일 첫번째 음고기호에 마우스를 맞추고 찰칵하면 <드람배치표>대화창이 표시됩니다.
  • <Acoustic Bass Drum>의 표기방식을 설정합니다.

  • 마찬가지로 <Snare Drum>, <Closed Hi-Hat>의 표기방식을 설정합니다.
  • <Closed Hi-Hat>의 경우 <소리표의 종류]를 <x>로 한 다음 <확인>단추를 찰칵합니다.
  • 그림의 악보와 같이 성부1, 성부2의 소리표를 입력합니다. 이 입력방법에 대하여서는 <서로 다른 성부의 소리표를 편집하려면>을 참고하십시오.
