파일차림표\서고의 편집\드람배치표...

드람보로 되는 악보표에서 어떤 드람목록을 사용하며 드람목록의 매 드람을 어느 음정에 대응시키고 어떤 소리표로 표기하겠는가를 설정합니다. <음고기호>입력도구띠의 드람음고기호단추를 선택하고 해당 악보표의 첫소절의 음고기호위치에서 마우스를 찰칵해도 <드람배치표>대화창이 표시됩니다.

  • 드람배치표명 : 드람정보가 들어있는 드람표를 선택합니다.
  • 드람목록 : 사용하려는 드람을 선택하기 위한 목록입니다.
  • 마우스입력시에 사용 : 같은 위치에 설정되여있는 여러개의 체크된 드람중에서 이 항목이 체크된 드람이 마우스입력시에 작용합니다.
  • 소리표의 종류 : 드람목록에서 체크한 드람의 기보를 어떤 소리표로 하겠는가를 설정합니다.
  • 위치 : 드람목록에서 체크한 드람의 기보를 오선의 어느 위치에서 표시하겠는가를 설정합니다.
  • 우의 항목들을 설정하고 <확인>단추를 누르면 드람배치표가 변경되고 <취소>단추를 누르면 드람배치표의 표기변경은 취소됩니다.
