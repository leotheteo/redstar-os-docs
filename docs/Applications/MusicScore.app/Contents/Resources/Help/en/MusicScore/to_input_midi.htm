물음과 대답\MIDI사건을 입력하려면


우와 같은 악보의 1번악보표, 2번째 소절에 MIDI사건(례하면 modulation효과와 Harpsichord악기를 설정)을 입력해봅시다.

  • 먼저 입력도구띠에서 <묶음기호>단추를 선택하여 <묶음기호>입력도구띠를 표시합니다.
  • 여기서 <MIDI사건>단추를 선택하고 입력하려는 소절(여기서는 1번악보표, 2번째 소절)을 찰칵하면 <연주효과삽입>대화창이 표시됩니다.

  • 우와 같이 설정하면 <연주효과목록>대화창이 표시됩니다.

  • 그림과 같이 <Modulation>항목을 선택하고 <확인>단추를 누르면 연주효과가 설정됩니다.

  • 이번에는 악기음색을 설정합시다. 1번악보표, 2번째 소절에서 마우스를 찰칵하여 <연주효과삽입>대화창을 표시합니다.

  • 우와 같이 설정하면 <악기설정>대화창이 표시됩니다. 여기서 <Harpischord>를 선택하고 <확인>단추를 누르면 악기음색이 설정됩니다.

  • 설정후 연주해보면 1번악보표는 연주중에 2번째 소절에서부터 악기가 <Harpischord>로 바꾸고 <Modulation>연주효과를 냅니다.
