차림표\편집차림표

취소, 다시하기, 복사, 붙이기 등 악보파일을 편집하는데 필요한 지령들을 묶은 차림표입니다.

취소

편집중에 진행한 조작을 되돌이합니다. <편집\취소>차림표를 선택하거나 [Ctrl+Z]건을 누르면 직전의 조작을 취소합니다.

다시 하기

편집중에 취소한 조작을 되돌이합니다. <편집\다시 하기>차림표를 선택하거나 [Ctrl+Y]건을 누르면 그전의 취소조작을 실행하기 전상태로 돌립니다.

자르기

이 지령을 리용하여 선택범위를 잘라서 임의의 장소에 붙일수 있습니다. <편집\자르기>차림표를 마우스로 선택하거나 [Ctrl+X]건을 누르면 선택범위를 잘라서 오림판에 보관합니다.

복사

선택한 범위의 기호를 복사하는 지령입니다. <편집\복사>차림표를 마우스로 선택하거나 [Ctrl+C]건을 누르면 선택범위를 복사하여 오림판에 보관합니다.

붙이기

오림판의 내용을 악보의 임의의 소절에 붙이는 지령입니다.

  • 붙이려는 위치에서 마우스를 찰칵하여 붙이려는 위치에로 유표를 이동합니다.
  • <편집\붙이기>차림표를 마우스로 선택하거나 [Ctrl+V]건을 누르면 유표가 있는 위치에 오림판의 내용을 붙이기합니다.

<설정\자동간격조정>이 체크되여있는 경우는 유표가 놓인 소절에 입력되며 체크되여있지 않는 경우는 카레트가 놓인 위치에 그대로 입력됩니다. 박자기호, 조성기호, 음고기호 등의 일부기호들은 삽입되지 않습니다.

지우기

선택한 범위의 내용을 삭제하는 지령입니다.

  • 지우려는 범위를 마우스로 선택합니다.
  • <편집\지우기>차림표를 마우스로 선택하거나 [지우기]건을 누르면 선택범위를 삭제합니다. 삭제된 내용은 오림판에 보관되지 않기때문에<취소>는 가능하지만 붙이기는 할수 없습니다.

음고기호와 차례표는 선택하여 삭제할수 없고<삭제>단추를 리용해서만 삭제할수 있습니다.

소리표소속기호의 삭제

선택한 범위의 소리표에 소속되여있는 기호를 삭제하는 지령입니다. 이 지령은 여러개의 소속기호를 동시에 삭제하는 경우에 편리합니다.

페지선택

현재 페지를 선택하는 지령입니다. <편집\페지선택>차림표를 마우스로 선택하거나 [Ctrl+A]건을 누르면 작성중의 악보가운데서 현재 페지를 선택합니다.

세밀이동

선택한 범위의 소리표를 세밀이동하는 지령입니다.

  • 우로
    마우스로 소리표를 선택한 다음 <편집\세밀이동\우로>차림표를 선택하거나 [Ctrl+Up]건을 누르면 선택한 소리표를 반음 우로 올립니다.
  • 아래로
    마우스로 소리표를 선택한 다음 <편집\세밀이동\아래로>차림표를 선택하거나 [Ctrl+Down]건을 누르면 선택한 소리표를 반음 아래로 내립니다.
  • 왼쪽으로
    마우스로 소리표를 선택한 다음 <편집\세밀이동\왼쪽으로>차림표를 선택하거나 [Ctrl+Left]건을 누르면 선택한 소리표를 왼쪽으로 약간 이동합니다.
  • 오른쪽으로
    마우스로 소리표를 선택한 다음 <편집\세밀이동\오른쪽으로>차림표를 선택하거나 [Ctrl+Right]건을 누르면 선택한 소리표를 오른쪽으로 약간 이동합니다.
