물음과 대답\타브보에 악보를 입력하려면

이미 있는 악보에 타브악보를 입력하려면

  • 먼저 입력도구띠에서 <음고기호>단추를 찰칵합니다. <음고기호>입력도구띠가 표시됩니다.
  • <음고기호>입력도구띠에서 [타브]단추를 찰칵하면 마우스지시자는 TAB의 형으로 됩니다.
  • 타브보로 하려는 악보표의 제일 첫번째 음고기호에 마우스를 맞추고 찰칵하면 <타브보설정>대화창이 표시됩니다.
  • 여기서 타브보의 선수와 선사이간격을 설정하면 이미 있던 악보표는 타브보로 됩니다.
  • 타브악보를 입력하려면 먼저 <소리표>입력도구띠에서 필요한 길이의 소리표를 선택하여 타브보에 입력합니다. 이때 타브보에는 수자0의 타브악보가 입력됩니다.

  • 다음 입력도구띠에서 <타브보>단추를 찰칵하여 <타브보>입력도구띠를 표시합니다.
  • <타브보>입력도구띠에서 해당한 수자단추를 찰칵하고 이미 입력한 수자0에 마우스지시자를 맞추어 찰칵합니다.

타브보에서는 빈 소절에 수자기호를 직접 입력할수 없습니다.

새로운 타브악보를 입력하려면

  • 먼저 <악보>악보표삽입...>차림표를 찰칵하여 <악보표삽입>대화창을 표시합니다.

  • <악보표의 종류>항목에서 <타브보>를 선택합니다. <설정>단추를 찰칵하여 타브보의 설정을 진행합니다.

  • <확인>단추를 누르면 새로운 타브보가 삽입됩니다.
