악보차림표\정돈

악보표, 악보단사이의 간격을 일정하게 하여 악보화면을 보기좋게 정돈합니다. 이 지령에는 다음의 보조차림표가 있습니다.

  • 악보표를 기정간격으로 정돈 : 이 차림표를 선택하면 악보표사이 간격을 기정값으로 맞춥니다. 현재 페지에서 악보단사이 간격은 변화시키지 않고 악보표사이 간격만을 같은 간격으로 설정합니다. 이때 악보표사이 간격은 <설정\파일설정\간격>에서 <악보표사이 간격>에 설정한 값으로 됩니다. <파일설정\간격>에서는 악보전체 즉 모든 페지에 적용되지만 여기서는 현재 페지에만 적용됩니다.
  • 악보단을 기정간격으로 정돈 : 이 차림표를 선택하면 악보단사이 간격을 기정값으로 맞춥니다. 현재 페지에서 악보표사이 간격은 변화시키지 않고 악보단사이 간격만을 같은 간격으로 설정합니다. 이때 악보단사이 간격은 <설정\파일설정>간격]에서 <악보단사이 간격>에 설정한 값으로 됩니다. <파일설정\간격>에서는 악보전체 즉 모든 페지에 적용되지만 여기서는 현재 페지에만 적용됩니다.
  • 악보단을 왼쪽페지경계선에 맞추기 : 이 차림표를 선택하면 현재 페지에서 악보단들을 왼쪽페지경계선으로 줄맞추기합니다.
  • 소절너비를 같은 간격으로 정돈 : 이 차림표를 선택하면 현재 페지의 모든 소절의 폭을 같은 간격으로 변경합니다.
