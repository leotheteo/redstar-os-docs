소절차림표\소절삽입...

이 지령을 리용하여 선택한 소절을 삽입합니다.
<소절\소절삽입...>차림표를 선택하면 <소절삽입>대화창이 표시됩니다.

  • 삽입하는 소절수 : 삽입하는 소절수를 설정합니다.
  • 소절을 삽입하는 악보표 : 소절을 삽입하는 악보표를 체크하여 선택합니다.
  • 모든 악보표에 삽입 : 모든 악보표에 소절을 삽입하는 경우 이 항목을 체크합니다.
  • 삽입위치 : 삽입하려는 소절의 위치를 설정합니다.

소절을 삽입하려면

  • <소절\소절삽입...>차림표를 선택합니다. <소절삽입>대화창이 표시됩니다.
  • <삽입하는 소절수>를 설정합니다.
  • 개별적인 악보표에 소절을 삽입하는 경우<소절을 삽입하는 악보표>항목에서 악보표를 체크하여 선택합니다.
  • 모든 악보표에 소절을 삽입하는 경우<모든 악보표에 삽입>항목을 체크합니다.
  • 소절번호와<앞에>, <뒤에>항목으로 삽입하는 소절의 위치를 결정합니다.
  • <확인>단추를 누르면 소절이 삽입됩니다.
