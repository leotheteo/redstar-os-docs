물음과 대답\화음기호를 입력하려면

  • 입력도구띠에서 <화음기호의 선택>단추를 선택하든가 [Ctrl+Alt+C]건을 누르면 <화음기호의 선택>창문이 표시됩니다.

  • <뿌리음>항목에서 뿌리음을 선택합니다.
  • <기저음>항목에서 기저음을 선택합니다. 기저음이 없는 경우 <없음>을 선택합니다.
  • <뒤붙이>항목에서 뒤붙이를 선택합니다.
  • 이때 마우스지시자는 선택한 화음기호의 형으로 바뀝니다.
  • 화음기호를 입력하려는 소리표, 또는 소절에서 마우스를 찰칵합니다.
  • 그러면 화음기호가 입력됩니다. 이 경우 화음기호는 소리표 또는 소절에 소속됩니다.

화음기호의 입력시에 마우스를 소리표에 맞추어 찰칵하지 않으면 자동반주시에 연주가 정확하지 않는 경우가 있습니다.

화음기호의 위치를 변경하려면？

  • 하나의 화음기호만을 위치변경하려면 화음기호를 상하좌우로 끌기합니다.
