소리표차림표\련음부설정...

선택한 소리표를 해당한 종류, 형태의 련음부로 설정합니다. <소리표\련음부설정...>차림표를 선택하거나 <소리표입력도구띠>의 단추를 누르면 <련음부설정>대화창이 표시됩니다.

  • 련음부의 종류 : 련음부의 종류를 선택합니다.
  • 표준 : 표준의 련음부종류를 선택합니다.
  • 기타 : 사용자가 필요한 련음부를 설정합니다.
  • 형태 : 련음부의 접속형태를 선택합니다.
  • 2번째수자를 표시 : 련음부의 수자를 3:2와 같은 형으로 표시합니다.

련음부를 설정하려면

  • <선택>단추를 눌러 선택방식으로 한 다음 마우스를 끌기하여 련음부로 하려는 소리표들을 선택합니다.
  • <소리표\련음부설정...>차림표를 선택하면 <련음부설정]대화창이 표시됩니다.
  • <표준>항목에서 련음부를 선택합니다. 표준련음부가 아닌 경우는 <기타>항목에서 필요한 련음부를 선택합니다.
  • <형태>항목에서 련음부의 접속형태를 선택합니다.
  • <확인>단추를 누릅니다.

련음부를 입력하려면

  • 우에서와 같이 <련음부설정>대화창에서 입력하려고 하는 련음부를 설정합니다.
  • 소리표입력도구띠에서 련음부의 음길이에 해당한 소리표단추를 선택하고 련음부단추를 누릅니다.
  • 마우스지시자를 필요한 위치에로 이동하여 찰칵하면 련음소리표가 입력됩니다.
  • 또는 련음부로 하려는 소리표를 마우스끌기로 선택한 다음 <소리표\련음부설정...>차림표를 실행하여도 됩니다.
