달력이름의 변경

달력목록에서 임의의 달력의 이름을 변경할수 있습니다.

달력의 이름을 변경하려면 :

■

달력목록에서 달력을 선택하고 한번 더 누르면 달력이름이 편집상태로 됩니다. 달력이름을 변경하고 Enter건을 누르거나 마우스로 다른 부분을 누르면 변경된 이름이 반영됩니다.

■

달력을 선택하고 마우스의 오른쪽단추를 눌러 나오는 차림표에서 <정보얻기>를 선택하거나 달력을 두번 누르면 《정보보기》대화창이 현시됩니다. 대화창의 <이름:>마당을 변경하고 <확인>단추를 누르면 달력의 이름이 변경됩니다.
