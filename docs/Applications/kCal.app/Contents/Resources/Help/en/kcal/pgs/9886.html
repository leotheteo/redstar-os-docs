Creating an all-day or multiday event

You can create an all-day event that lasts one or more complete days (for example, for a vacation). All-day events are shown across the top of the day in Day or Week view.

A single event can also span multiple days and have specific start and end times. For example, you can enter specific times for a work shift that begins in the evening and ends the following morning.

To create an all-day or multiday event:

  • To create an all-day event, make sure you’re in Day or Week view, and then double-click in the “all-day” area near the top of the kCal window, just below the dates. If you want your all-day event to last multiple days, drag a corner of the event across the days in the main calendar view. You can also double-click the event. If necessary, click Edit to open the event editor. Then, type the start and end dates in the event editor.

    You can make any event into an all-day event by selecting the “all-day” checkbox in the event editor.

  • To create a multiday event, make sure you’re in Day or Week view, and then drag from the start time to the end time of the event. You can drag across multiple days. You can also double-click the event. If necessary, click Edit to open the event editor. Then, type the start and end dates and times in the event editor.
