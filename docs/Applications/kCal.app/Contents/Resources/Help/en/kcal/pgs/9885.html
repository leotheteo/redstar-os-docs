Organizing your calendars in groups

You can group similar calendars so that they appear together in the Calendars list. For example, if several family members use the same user account on your computer, you can create a group of calendars for each person. You can group calendars you’ve created on your computer, but not calendars you’ve subscribed to.

To group calendars:

  1. Choose File > New Calendar Group, or hold down the Shift key while clicking the Add (+) button in the lower-left corner of the kCal window, and then type a name for the group.

  2. Add existing calendars to the group by dragging them to the group name, or select the group name and choose File > New Calendar to create a new calendar within the group.

To remove calendars from the group, drag them out of the list.
