About calendar standards

kCal uses a format called “kCalendar” to display and exchange calendar information. kCal can exchange calendar information with several applications that support the kCalendar format. kCal can also import information stored in the older vCalendar format.

Calendar events that you export or drag to the desktop have a filename that ends in .ics, and vCalendar filenames end in .vcs. Both types of files can be viewed on Mac or Windows computers by applications that understand these extensions.
