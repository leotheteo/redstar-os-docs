Moving an event to another calendar

You can move events between any calendars that you’ve created or imported into kCal. You can’t move events on a calendar you’ve subscribed to.

Note:If you move an event from a calendar that’s not hosted on an Exchange server to a calendar that is, some information in your event may be saved to the note field. This is because some fields aren’t available in Exchange calendars.

To move an event to a different calendar:

  • Double-click the event. If necessary, click Edit to open the event editor. Choose a calendar from the “calendar” pop-up menu.

  • Drag the event from the main calendar view to a new calendar in the Calendars list.

  • Hold down the Shift key to select multiple events. Then Control-click a selected event and choose a calendar from the shortcut menu.
