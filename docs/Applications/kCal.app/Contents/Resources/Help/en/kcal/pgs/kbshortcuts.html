kCal keyboard shortcuts

You can use your keyboard to quickly accomplish many tasks in kCal. To find the shortcuts for common commands, look in the menus (or see the menu shortcuts below). To do an action, press the keys indicated below.

Option
Description

Calendar shortcuts

Command (⌘)-Right Arrow

Go to the next day, week, or month

Command (⌘)-Left Arrow

Go to the previous day, week, or month

Click the calendar’s checkbox

View the events on a calendar

Edit menu shortcuts

Shift-click the event

Select mutiple events

kCal menu shortcuts

Command (⌘)-comma

Open kCal preferences

Command (⌘)-H

Hide the kCal application

Option-Command (⌘)-H

Hide all other applications

Command (⌘)-Q

Quit the kCal application

File menu shortcuts

Command (⌘)-N

Create a new event

Command (⌘)-K

Create a new to-do item

Shift-Command (⌘)-N

Create a new calendar group

Command (⌘)-I

Show or hide the event editor for the selected calendar, event, or to-do item

Command (⌘)-W

Close the kCal window

Command (⌘)-P

Print calendars and to-do items

Edit menu shortcuts

Command (⌘)-Z

You can repeatedly press Command (⌘)-Z to undo each of your actions in reverse order. To see which action you can undo, open the Edit menu.

Undo your last action

Shift-Command (⌘)-Z

Redo your last action

Command (⌘)-X

Cut the selected text or event

Command (⌘)-C

Copy the selected text or event

Command (⌘)-V

Paste the cut or copied text or event

Command (⌘)-A

Select all text or all events in the current calendar

Command (⌘)-D

Duplicate the selected text or event

Command (⌘)-E

Edit the selected event

Command (⌘)-F

Make the kCal search field active

Calendar menu shortcuts

Option-Command (⌘)-S

Subscribe to a calendar

Command (⌘)-R

Refresh the selected calendar

Shift-Command (⌘)-R

Refresh all published or subscribed calendars

View menu shortcuts

Command (⌘)-T

Show today’s date in the main calendar view

Shift-Command (⌘)-T

Show a specific date in the main calendar view

Command (⌘)-1

Switch to Day view

Command (⌘)-2

Switch to Week view

Command (⌘)-3

Switch to Month view

Command (⌘)-Right Arrow

Go forward in the main calendar view

Command (⌘)-Left Arrow

Go backward in the main calendar view

Option-Command (⌘)-T

Show or Hide the To Do list
