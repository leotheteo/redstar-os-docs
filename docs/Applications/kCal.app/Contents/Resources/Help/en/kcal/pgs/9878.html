Deleting a calendar

You can delete any of the calendars or groups of calendars in your Calendars list. Deleting a calendar removes the calendar and all the events it contains from your computer.

To delete a calendar:

  1. Select the calendar (or calendar group) you want to delete.

  2. Choose Edit > Delete.

    Deleting a calendar group deletes all the calendars contained in the group.

If you delete a calendar that includes an event with invitees, kCal will notify them that the event has been canceled.
