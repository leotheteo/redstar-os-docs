If you’re not receiving alarms

If you set an alarm to occur before an event or to-do item but you’re not receiving the alarm, there are a few possible causes.

Try these suggestions:

  • Make sure alarms are not turned off in kCal preferences. Choose kCal > Preferences and click Advanced. Deselect the “Turn off all alarms” checkbox.

  • Make sure that your email information is correct in Address Book (in the Applications folder) and the card with your information is marked “me.” For more information about your card in Address Book, open Address Book and choose Help > Address Book.

  • Make sure you’ve set up the alarm properly.
