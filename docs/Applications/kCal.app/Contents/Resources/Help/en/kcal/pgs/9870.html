Exporting and importing events and to-do items

If you want to move a copy of all the events and to-do items from one calendar to a calendar on another computer, you can export the calendar’s events and to-do items, and then import them into kCal on the other computer. Do this if you want to archive a calendar or if you want to edit the calendar on another computer.

Note:If you export your Exchange Tasks calendar, only to-do items are exported because the calendar doesn’t contain events. If you export your Exchange calendar named Calendar, only events are exported.

To export events and to-do items from a calendar:

  1. From the Calendars list, select the calendar that contains the events and to-do items you want to export.

  2. Choose File > Export > Export.

    The events are exported as an kCalendar (.ics) file.

To import events and to-do items from a calendar:

  1. Choose File > Import > Import.

  2. Select the type of file you want to import, and then click Import.

  3. Locate the calendar file that contains the events and to-do items you want to import, and then click Import.

  4. Choose the calendar you want to add the events to.

To import events, you can also drag a .ics file from your desktop to kCal.
