Setting an alarm for an event

You can be notified of a pending event by setting one or more alarms for it. Alarms can be set to make a sound, flash a notice on the screen, or perform other actions.

Note:If your calendar is administered through a Microsoft Exchange Server 2007, you can set only one alarm per event.

To set alarms for an event:

  1. Double-click an event. If necessary, click Edit to open the event editor.

  2. Choose a type of alarm from the “alarm” pop-up menu.

    None: Sets no alarm.

    Message: Displays a notice on the screen.

    Message with Sound: Displays a notice on the screen and makes an alert sound. Choose the sound you want to hear from the accompanying pop-up menu.

    Email: Sends an email to your email address as specified in the Address Book application. If you have more than one email address, you can choose one from the accompanying pop-up menu.

    Open File: Opens the file you choose from the accompanying pop-up menu. If you don’t see the file you want in the pop-up menu, choose Other to select the file.

    Run Script: Runs the instructions given in an AppleScript file that you choose from the accompanying pop-up menu. If you don’t see the file you want in the pop-up menu, choose Other to select the file.

  3. Choose a time or date for the alarm from the accompanying “alarm” pop-up menu.

  4. To add another alarm, choose an alarm type from the next “alarm” pop-up menu, and set a time or date for it.

    Each time you set another alarm for the same event, a new “alarm” pop-up menu appears. You can set as many alarms as you want for each event. However, you can set only one alarm for events on an Exchange calendar.

  5. To remove an alarm, choose None from the “alarm” pop-up menu.
