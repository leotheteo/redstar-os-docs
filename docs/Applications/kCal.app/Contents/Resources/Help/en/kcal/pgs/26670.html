Advanced preferences

Use the Advanced pane of kCal preferences to set advanced preferences for time zone support, to-do items, events, alarms, and invitations.

Option
Description

Turn on time zone support

Select this checkbox to be able to see your calendars and events in different time zones. When the checkbox is selected, you can change the time zone of your calendars in the upper-right corner of kCal, and you can choose a time zone for each event in the event editor.

Hide to do items that are due after the dates visible in the calendar

Select this checkbox to hide to-do items with assigned due dates that are after the dates that are showing in kCal.

Hide to do items __ days after they have been completed

Select this checkbox and enter a value to hide to-do items a certain number of days after they’ve been completed.

Delete events __ days after they have passed

Select this checkbox and enter a value to delete events a certain number of days after they’ve passed.

Delete to do items __ days after they have been completed

Select this checkbox and enter a value to delete to-do items a certain number of days after they’ve been completed.

Turn off all alarms

Select this checkbox if you never want to receive alarms.

Open events in separate windows

Select this checkbox to see events in separate windows when you open them.

Ask before sending changes to events

Select this checkbox to get an alert message that asks whether you’re sure you want to send changes to events.

Automatically retrieve invitations from Mail

Select this checkbox to have kCal get invitations from Mail. Invitations appear in the Notifications box.
