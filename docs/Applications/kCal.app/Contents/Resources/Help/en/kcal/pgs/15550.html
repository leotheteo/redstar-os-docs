Setting an alarm for a to-do item

You can be notified of a pending to-do item by setting one or more alarms for it. Alarms can be set to make a sound, flash a notice on the screen, or perform other actions.

Note:If your calendar is administered through a Microsoft Exchange Server 2007, you can set only one alarm per to-do item.

To set alarms for a to-do item:

  1. Double-click the item in the To Do list.

  2. Make sure you’ve set a due date for the item by selecting the “due date” checkbox and then typing a month, day, and year in the date fields.

  3. Choose an alarm type from the “alarm” pop-up menu.

    None: Sets no alarm.

    Message: Displays a notice on the screen.

    Message with Sound: Displays a notice on the screen and makes an alert sound. Choose the sound you want to hear from the accompanying pop-up menu.

    Email: Sends a message to your email address as specified in Address Book. If you have more than one email address, you can choose one from the accompanying pop-up menu.

    Open File: Opens the file you choose from the accompanying pop-up menu. If you don’t see the file you want in the pop-up menu, choose Other and select the file.

    Run Script: Runs the instructions in the AppleScript file that you choose from the accompanying pop-up menu. If you don’t see the file you want in the pop-up menu, choose Other and select the file.

  4. Choose a time or date for the alarm from the accompanying “alarm” pop-up menu.

  5. To add another alarm, choose an alarm type from the next “alarm” pop-up menu, and set a time and or date for it.

    Each time you set another alarm for the same to-do item, a new “alarm” pop-up menu appears. You can set as many alarms as you want for each to-do item. However, you can set only one alarm for events on an Exchange calendar.

  6. To remove an alarm, choose None from the “alarm” pop-up menu.
