Adding events to a calendar

You can add any kind of event to your calendars, such as meetings, doctor appointments, and other activities. You can’t add events to a calendar you’ve subscribed to or to an Exchange Tasks calendar. The Exchange Tasks calendar is only for to-do items.

To add an event to a calendar:

  1. Select the name of the calendar you want to add an event to.

  2. In Day or Week view, drag from the event’s start time to its end time, and then type a name for the event.

    You can also quickly create a new one-hour event in Day, Week, or Month view by double-clicking within the day you want the event to appear, or choosing File > New Event, or pressing Command (⌘)-N.

  3. To make any other changes for the event (for example, how often it repeats or whether it has an alarm), double-click the event. If necessary, click Edit to open the event editor. Make your changes in the event editor.

    • If the selected event will take place in a different time zone (for example, if you will be traveling to another location for a meeting), choose kCal > Preferences and click Advanced. Make sure the “Turn on time zone support” checkbox is selected. Then choose a time zone for this event from the “time zone” pop-up menu in the event editor.
