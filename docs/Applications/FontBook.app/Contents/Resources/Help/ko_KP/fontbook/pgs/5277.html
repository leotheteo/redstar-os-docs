서체설치

<서체집>을 리용하여 새로운 서체를 쉽게 설치할수 있습니다. 서체가 서체집에 추가되면 응용프로그람과 사용가능한 서체목록에 서체가 자동으로 나타납니다.

서체집을 리용하여 서체를 설치하려면

새로운 서체가 존재하는 CD를 삽입하거나 다른 경로에 있는 서체를 하드디스크에 복사합니다.

<파일열람기>에서 서체파일을 두번찰칵합니다.

<서체집>이 기동하고 사용자가 서체의 모양을 볼수 있도록 서체를 표시합니다.

설치단추를 찰칵합니다.

서체는 사용자서류철에 자동적으로 설치되며 서체는 사용자만이 사용가능합니다. 모든 사용자들이 리용할수 있게 하려면 서체모임목록에 서체를 끌기하여 놓습니다.

콤퓨터의 모든 사용자들이 리용할수 있게 하려면 <서체집> 《환경설정》창문에서 기정설치경로를 《콤퓨터》서고로 선택하여 기정설치경로를 변경합니다.
