Exporting fonts to send with a document

You can export fonts to send them to another user. For example, you may need to send a document and the fonts it uses to another location for editing or printing.

To export fonts:

Open Font Book and select the fonts you want to export (to select fonts that are not adjacent to one another, press the Command key and click the fonts you want).

Choose File > Export Fonts.

Type a name for the folder and choose where you want to place it.

Click Save.
