Validating fonts

If fonts are not displayed as expected when you open documents or you cannot open documents, it’s possible fonts have been damaged. You can validate fonts to confirm they are still safe to use, and remove any damaged fonts you find.

To validate fonts:

Open Font Book and select one or more installed fonts to check.

Choose File > Validate Font.

In the Font Validation window, review the fonts listed for warnings or errors. Use the pop-up menu to display warnings and errors separately, if necessary.

■

For fonts with warnings or errors, click the disclosure triangle next to the font to see which validation rules show errors.

■

To remove a damaged font, click the checkbox next to the font to select it. Make sure fonts you want to keep are not selected. Then click the Remove Checked button.
