Turning fonts on and off

You can disable or turn off fonts so they don’t appear in the Fonts window or in the list of available fonts in an application. Disabled fonts display “Off” next to their names in the Font pane.

To make fonts available again, you can turn them on in Font Book.

To turn off a font:

In Font Book, select the font you want to turn off in the Font column, or select an entire font collection in the Collection column.

Choose Edit > Disable [font], or Edit > Disable [collection].

To turn on a font:

In Font Book, select the font you want to turn on in the Font column, or select an entire font collection in the Collection column.

Choose Edit > Enable [font], or Edit > Enable [collection].
