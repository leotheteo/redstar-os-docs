Previewing fonts in Font Book

You can use Font Book to preview the different typefaces and characters that are available in each of the fonts on your computer.

To preview fonts:

In Font Book, select a collection in the Collection pane, and then select the font family that you want to preview in the font pane.

Click the disclosure triangle next to the font name to see which typefaces are available for that font.

Select a typeface. A sample of the characters available in that typeface appear in the preview pane to the right. If you don’t see a preview pane, choose Preview > Show Preview.

To see how the selected typefaces appear at different font sizes, choose a font size from the Size pop-up menu in the upper-right corner of the preview pane, or drag the font size slider on the right edge of the window.
