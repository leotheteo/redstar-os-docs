Using Font Book preferences

To set Font Book preferences:

Open Font Book and choose Font Book > Preferences.

Choose from the following preferences:

Default Install Location: Fonts are automatically installed in the Library folder of your home folder so they are available only to you. If you want fonts you install to be available to all the computer’s users, you can change the default font location from the Default Install Location pop-up menu.

Validate fonts before installing: Select this checkbox to automatically validate all fonts before they are installed.
