Creating a new font collection

You can create your own font collections to help you manage and organize your font library. You can access font collections in the font panel of other applications, such as Text Edit or Mail.

To create a new font collection:

Open Font Book and choose File > New Collection.

Type a name for the collection.

Click the font library you want to use and drag fonts from the Font pane to the new collection.

Adding a font to a collection doesn’t move the font itself, but only places a pointer to the font in the collection. You can add the same font to as many collections as you want.
