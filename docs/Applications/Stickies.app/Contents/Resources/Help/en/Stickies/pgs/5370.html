Creating a default note template

If you typically use the same formatting options for your notes (such as a favorite note color, note size, and font), you can create a template that’s used each time you create a new note.

To create a note template:

Prepare a note that contains the formatting options you want to use as a standard part of the template.

To change the appearance of text in a note, choose different fonts and sizes from the Font menu.
