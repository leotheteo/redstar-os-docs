Exporting text from a note

You can export text from a note to create a text file.

To export text from a note:

Click the note that contains the text you want to export.

Choose File - Export Text.

Type a name and choose a destination for the text file you’re creating.

Choose a format from the Format pop-up menu:

Plain Text: Cannot include paragraph and font formatting.

RTF: Can include paragraph and font formatting. If you add graphics to a Rich Text Format (RTF) file, it is changed to a Rich Text Format (RTF) file.
