Checking if your system meets the requirements for a new product

When you’re considering buying a new hardware or software product, you may need to find out if your computer system meets its minimum requirements, such as a certain amount of memory, processor speed, or video card. System Profiler helps you get information about your system and check if it meets those requirements.

In general, if the configuration listed in System Profiler equals or exceeds the minimum requirements, you should be able to use the new product.
