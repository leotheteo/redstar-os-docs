Choosing a profile style

You can choose the amount of information your computer’s profile contains, so you can print or email it quicker.

To choose the style of profile:

Open the View menu and choose one of the following:

Mini Profile: This profile omits software information and, printer and power information in hardware.

Basic Profile: This profile contains the hardware information and leaves out software information.

Full Profile: This profile contains all the information System Profiler collects.
