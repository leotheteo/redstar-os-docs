Saving a profile

You can save a profile so you can send it to others or review it later.

To save a System Profiler report:

Choose a profile style from the View menu that contains the information you want.

Choosing a profile style

Choose File > Save.

Type a name and choose a destination for the profile.

Select the file format.

■

If you want to view the profile in a text editor such as TextEdit or Microsoft Word, choose Plain Text (UTF-16) format.

■

If you want to view the profile in System Profiler, choose System Profiler 1.0(SPML) format.
