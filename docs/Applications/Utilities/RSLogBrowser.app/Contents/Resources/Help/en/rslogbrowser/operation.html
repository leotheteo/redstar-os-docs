Main Features

Click to open the find dialog.

Figure1. Find dialog

Then type the key string in the “Find what:”box and click “Find”button. Check the “Match case” to use case sensitive. Check the “Search” box to search backward.

-     Filter Setting

Click to open the Filter dialog.

Figure 2. Filter dialog

Add some filter conditions and click “Ok” button.

·          Choosing log type : Choose log types to want to view.

·         Choosing record time : Choose the start time and end time to record log.

·         Adding filter condition : Select index, operator and value. And then click “Add” button.

·         Removing filter condition : Select the filter condition to remove from the condition list and remove “Remove” button. To remove all conditions, click “Remove All”.
