Testing whether you can contact another computer

Use Network Utility to see if your computer can communicate with a computer or other device at a specific network address.

This type of test is called "pinging" the other device. Pinging can help you find out if a communication problem you're experiencing is caused by your computer, the connection, or the remote device.

You can ping any device that uses Internet Protocol (IP), such a computer, network printer, or AirPort Base Station.

To ping another computer:

Open Network Utility, located in the Utilities folder in the Applications folder.

Click Ping.

Type the IP address or DNS name of the device you're trying to contact and click the Ping button.

If the other device responds to your ping, your basic connection is good.

If the other device does not respond, try pinging devices in other locations to determine if the problem is with your network connection or with the remote device.

For help interpreting the results, or to see how you can use the underlying ping command to fine-tune your troubleshooting, open the Terminal application and type:

man ping
