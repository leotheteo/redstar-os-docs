Looking up user or domain information

Use Network Utility to query Whois databases of user and domain information.

The type of information you can find depends on the purpose of the database. Some provide registration information for internet domain names. Some provide information about the members of an organization (students or faculty of a university, for example).

To look up domain or user information:

Open Network Utility, located in the Utilities folder in the Application folder.

Click Whois and type the user or domain name you are searching for.

Then type the name of the whois server you want to search (or choose it from the pop-up menu) and click the Whois button.
