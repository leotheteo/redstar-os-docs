Viewing network routing tables and statistics

Use Network Utility to examine your computer's network routing tables or view a detailed summary of packet types sent and recived using common network protocols.

Packet summaries are provided for TCP, UDP, IP, ICMP, IGMP, IPSEC, IP6, ICMP6, IPSEC6, and PFKEY.

To view network routing tables:

Open Network Utility and click NetStat.

Select the type of information you want to see, and click the Netstat button.

For Help interpreting the results, or for information about the underlying netstat command and how you can use it to produce other reports, open the Terminal application and type:

man netstat
