Tracks the route packets

Traceroute tracks the route packets take across a TCP/IP network on their way to a given host.

To trace the route:

Open Network Utility, located in the Utilities folder in the Application folder, and then click Traceroute.

Input the IP address and click the Trace button.

For more information about the traceroute command, open the Terminal application and type:

man traceroute
