Restoring a disk image to a disk

A disk image is a file that contains other files and folders. For example, it could contain a backup of a hard disk or data someone wants to share with you. To access its contents, double-click it. The Finder mounts a volume on your desktop with the image’s contents that you can access like any hard disk.

You can also restore a disk image to a hard disk if you prefer to access the data that way. You can choose to erase a disk’s data and replace it with the disk image’s contents, or you can leave the data on a disk and add the disk image’s contents to what’s on the disk.

To restore a disk image’s contents to a disk:

Select a disk in the list at left, and click the Restore tab.

Drag the disk image to the Source field.

You can drag the disk image from the list at left, the Finder, or a web browser.

Drag the disk that will hold the contents of the disk image to the Destination field.

If you want to erase the disk before copying to it, select “Erase destination.” If you want to use the disk to start up a computer, select “Erase destination.”

If you want to add the disk image’s contents to the destination disk without erasing it, deselect “Erase destination

Click the Restore button.
