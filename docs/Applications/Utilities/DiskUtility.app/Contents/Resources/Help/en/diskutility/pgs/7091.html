When you loged in system as a standard user

When you loged in system as a standard user,you have to authenticated as an administrator to use all functions of DiskUtility.

To be authenticated as an administrator

Enter administrator's name in name entry.

Enter administrator's password in password entry.

Then click OK button.

If name and password are valid, you can use DiskUtility with an administrator's privilege.

If click Cancel button,an error message is displayed and the operation fails.
