Converting a disk image

You can use Disk Utility to convert the image format of a disk image.

For example, if you create a read/write disk image but later want to prevent changes to the image, you can convert it to read-only format.

To convert a disk image:

Select the disk image if it appears in the list of disks and volumes, and then choose Convert.

Choose the new image format.

Type a new name for the image and click Create.
