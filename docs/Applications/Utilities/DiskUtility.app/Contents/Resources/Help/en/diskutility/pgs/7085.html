Unmounting a single volume

If you are using an external disk that contains several volumes and you unmount one of the volumes in the Finder, all the volumes not in use on that disk are ejected.

Use Disk Utility to unmount only a single volume of the disk.

To unmount a single volume:

Select the volume you want to unmount in the list, and click Unmount in the toolbar.

To mount the volume again, quit Disk Utility, and then reopen it. Select the volume in the list and click Mount. You can also unplug an external hard disk and plug it back in.

If you eject a volume on a removable disk, such as a CD, the disk is ejected. Insert the disk again to mount it.
