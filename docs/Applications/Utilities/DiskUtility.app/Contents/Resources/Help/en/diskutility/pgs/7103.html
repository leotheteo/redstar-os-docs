Partitioning a disk

Partitioning a disk divides it into sections, called volumes. Each volume works like a separate disk. You may need to create a new partition if you want to install multiple operating systems on your computer. Partitions can also help you organize your files.

Notice: Partitioning a disk erases all the files on the disk. If you want to save any files on the disk, be sure to copy them to another disk before you partition the disk.

You can specify the number of volumes and the size of each one. If you want to use one volume as your RedStar 3.0 startup disk, be sure it’s large enough to install the RedStar 3.0 software and any applications and files you’ll use. RedStar 3.0 requires at least 2 GB of disk space or 3.5 GB if you install the developer tools. Additional disk space is useful if you use many applications simultaneously.

To partition a disk:

If you’re partitioning an external hard disk, make sure it’s connected to your computer. If you’re partitioning the disk you are now using as a startup disk, you must start up using another disk.

Open Disk Utility. Double-click Disk Utility, located in the Utilities folder in your Applications folder.

Select the disk in the list that you want to partition, and click Partition.

Choose the number of partitions from the Volume Scheme pop-up menu.

If you can’t choose the number of partitions, you may be trying to partition your startup disk. Start up your computer with another disk.

Click each partition and type a name for it, choose a format, and type a size.

If you’ll be using a volume as a RedStar 3.0 startup disk, click Options, and choose the appropriate partition scheme. To use a volume to make GPT partition table, choose the GUID partition scheme.

Click Apply.

After you partition a disk, a disk icon for each volume appears in the list of disks and volumes. You’ll also see the volumes in the sidebar of Finder windows.
