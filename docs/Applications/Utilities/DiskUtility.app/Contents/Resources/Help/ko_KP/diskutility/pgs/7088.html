하드디스크나 구획 지우기

디스크편의프로그람을 사용하여 하드디스크와 구획을 지울수 있습니다. 하드디스크를 지우면 구획과 파일 모두가 삭제됩니다. 구획을 지우면 해당 구획의 모든 파일이 삭제되지만 다른 구획에는 영향이 없습니다.

주의: 저장할 파일이 있다면 디스크를 지우기전에 다른 디스크에 복사하여야 합니다.

디스크나 구획을 지우려면

외장하드디스크를 지우려면 디스크를 콤퓨터에 련결합니다.

디스크편의프로그람의 왼쪽목록에서 디스크나 구획을 선택합니다.

〈지우기〉태브를 찰칵합니다.

구획의 파일체계형식내리차림표를 선택합니다.

디스크나 구획의 이름을 입력합니다.

〈지우기〉를 찰칵합니다.

지우기추가선택에서 원하는 항목을 선택한 다음 〈확인〉을 찰칵합니다.

〈지우기〉를 찰칵합니다.
