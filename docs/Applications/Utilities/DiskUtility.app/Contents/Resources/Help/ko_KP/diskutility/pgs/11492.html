디스크에 새로운 구획 만들기

자료를 잃지 않고 디스크에 새로운 구획들을 만들수 있습니다. 콤퓨터에 여러 조작체계를 설치하려는 경우 새로운 구획을 만들어야 할수 있습니다. 또한 구획은 파일들을 분리하는데 도움이 됩니다.

주의: 디스크에 새로운 구획을 창조하기전에 부주의로 자료를 잃을수 있으므로 자료를 보관하여야 합니다.

디스크에 새로운 구획을 만들려면

왼쪽목록에서 해당 디스크를 선택하고 구획태브를 선택합니다.

구획구조모형칸에서 구획을 선택하고 〈추가(+)〉를 찰칵합니다.

디스크편의프로그람은 선택된 구획을 두개의 구획으로 나눕니다. 선택된 구획에 자료가 있는 경우 한개구획은 자료의 크기만한 용량을 가지고 자료들을 포함하며 다른 구획은 남은 크기로 설정합니다. 선택된 구획에 자료가 없으면 구획의 크기를 절반으로 나누어 두개의 구획을 만듭니다. 구획의 사용용량이 절반보다 작다면 디스크편의프로그람은 같은 크기로 두개의 구획을 만듭니다.

필요하다면 구획의 크기를 변경할수 있습니다.

구획구조모형칸에서 구획을 선택한 다음 크기 항목칸에 값을 입력할수 있습니다.

만들어질 구획의 파일체계를 선택합니다.

새로 만들어진 구획을 선택하고 이름을 입력한 다음 파일체계를 선택합니다.

〈적용〉을 찰칵합니다.
