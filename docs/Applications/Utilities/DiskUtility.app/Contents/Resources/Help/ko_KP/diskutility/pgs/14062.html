첫페지

디스크 복원하기

한 구획을 다른 구획에 복사할수 있습니다. 례를 들어 기동구획을 복사하여 사용할수 있습니다.

디스크를 복원하려면

복원할 구획을 선택하고 〈복원〉태브를 찰칵합니다.

복사할 구획을 원천입력칸에 끌기합니다.

왼쪽목록에서 끌기할수 있습니다.

복사될 구획을 목적입력칸에 끌기합니다.

특정한 구획이 끌기할수 없다면 복사할수 없습니다. 기동구획이라면 다른 디스크로 콤퓨터를 기동하여야 합니다. 그렇지 않으면 해당 디스크에 있거나 해당 디스크에서 사용되는 응용프로그람을 끝내야 합니다.

복사하기전에 목적구획을 지우려면 〈목적 지우기〉를 선택합니다. 기동디스크로 복사하려면 〈목적 지우기〉를 선택합니다.

원래 내용을 지우지 않고 대상에 추가하려면 〈목적 지우기〉를 선택 해제합니다.

〈복원〉을 찰칵합니다.
