Displaying information in the Dock

If you don’t want to take up screen space for the Activity Monitor window, you can use just the Activity Monitor icon in the Dock to display a graph of system activities.

The Dock icon can show a graph of processor (CPU) usage, CPU history, network usage, disk activity, or memory use.

To display Activity Monitor information in the Dock icon:

Choose View > Dock Icon, and then choose the type of activity you want to show.

The activity will be displayed in the Dock until you quit Activity Monitor.
