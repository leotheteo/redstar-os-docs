Viewing your processor usage while you work

Most of the time your computer’s processor, or CPU, is using only a small percentage of its processing power. When you use applications that require intensive calculations, or if you use multiple applications at one time, your processor may be working near its maximum capacity.

You can monitor the amount of activity on your computer’s processor while you work by displaying the processor activity in a floating window. These small windows remain in front of other applications you are running.

To see the processor usage:

Choose the type of processor window you want from the Window menu:

■

To display the current amount of processor usage, choose CPU Usage.

■

To display the processor usage in a tiny bar graph, choose Floating CPU Window. You can drag the bar wherever you want.

■

To display a graph of processor usage over time, choose CPU History.

The processor activity will be displayed as long as Activity Monitor is running.
