Adjusting how frequently information updates

You can adjust how frequently the data in Activity Monitor is updated. The default setting updates the information in Activity Monitor every two seconds. This interval can be increased for more precise monitoring or decreased to have less effect on your computer’s performance.

To change how frequently information is updated:

Choose View > Update Frequency, and then choose how often you want to update.

If you watch the % CPU column in the Activity Monitor window as you change the update frequency, you can see the percentage of processor time being used to update Activity Monitor information.
