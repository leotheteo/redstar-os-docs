Viewing processor activity

You can use Activity Monitor to see how the processor activity is being used. The processor activity is displayed in a scrolling graph that shows the level of activity over time. The distribution of the processor time is displayed in percentage and by color.

To see how the processor activity is being used:

Click CPU in the button bar.

The CPU Usage graph displayed at the bottom of the pane shows the amount of processor time being used. If you have more than one processor, the graph is split to display the usage of all the processors.

The types of processes using the processor time are shown by the use of different colors. The following types of processes are displayed:

System processes: Processes owned by the system

User-launched processes: Processes or applications that you have opened, or sub processes that are being run by them.

Nice processes: Processes that have altered scheduling priority.

To change the color of items in the graph, click the color box next to each item.

To view the CPU usage in a larger window, double-click the CPU usage graph.

For more information on nice processes, see the man page. Open the Terminal application, and enter “man nice”.
