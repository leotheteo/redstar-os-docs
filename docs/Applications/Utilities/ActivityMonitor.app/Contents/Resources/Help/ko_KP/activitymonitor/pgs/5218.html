정보갱신주기 조정하기

동태감시기에서 자료를 얼마나 자주 갱신할것인지 조정할수 있습니다. 기본설정은 동태감시기에 있는 정보를 2s마다 갱신합니다. 이 간격은 더 정확한 감시를 위해 늘일수도 있고 사용자의 콤퓨터성능에 영향을 덜 미치도록 줄일수도 있습니다.

정보를 갱신하는 주기를 변경하려면

<보기 / 갱신주기>를 선택한 다음 얼마나 자주 갱신할것인지 선택합니다.

갱신주기를 변경할 때 동태감시기 창문에 있는 % CPU 렬을 본다면 동태감시기정보를 갱신하기 위해 사용되고있는 프로쎄스비률을 볼수 있습니다.
