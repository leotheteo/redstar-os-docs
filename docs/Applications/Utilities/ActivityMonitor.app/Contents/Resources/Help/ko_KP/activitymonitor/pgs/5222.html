CPU활성상태보기

동태감시기를 사용하여 CPU가 어떻게 사용되고있는지 볼수 있습니다. CPU활성상태는 시간에 따른 활성도를 나타내는 도표로 표시됩니다. CPU시간분배는 비률 및 색으로 표시됩니다.

CPU가 어떻게 사용되고있는지 보려면

CPU태브를 찰칵합니다.

아래 태브에 나타나는 CPU사용도표는 사용되고있는 CPU의 시간을 나타냅니다. 한개이상의 CPU가 있다면 도표가 분리되여 모든 CPU의 사용상태를 표시합니다.

CPU시간을 사용하는 프로쎄스류형은 서로 다른 색으로 나타납니다. 다음 류형의 프로쎄스가 표시됩니다.

체계 프로쎄스: 체계에 의해 소유된 프로쎄스

사용자실행 프로쎄스: 사용자가 실행한 프로쎄스 또는 응용프로그람이나 이에 의해 실행되고있는 자식프로쎄스.

우선준위 프로쎄스: 우선 순위를 변경한 프로쎄스.

각 항목옆에 있는 색단추를 찰칵하여 도표의 항목색을 변경할수 있습니다.

더 큰 창문에서 CPU 사용량을 보려면 해당 CPU사용도표를 두번찰칵합니다.

우선준위프로쎄스에 관한 추가정보를 보려면 man페지를 참고하면 됩니다. 조작탁을 열고 《man nice》라고 입력합니다.
