프로쎄스그룹만들기

동태감시기는 콤퓨터에서 실행중인 모든 프로쎄스를 보여줍니다. 하나의 응용프로그람을 열었지만 많은 프로쎄스가 실행중일수 있습니다. 하나의 응용프로그람은 배경에서 실행되는 여러개의 프로쎄스를 가지고있을수 있습니다. 이 배경 프로쎄스들의 대부분은 눈에 보이지 않습니다.

또 어떤 프로쎄스는 조작체계에 의해 사용되면서 자기의 기능을 수행합니다.

그룹으로 프로쎄스를 보려면

프로쎄스려과내리펼침차림표에서 다음 프로쎄스류형중 하나를 선택합니다.

모든 프로쎄스: 체계에서 실행중인 모든 프로쎄스를 보여줍니다.

모든 프로쎄스, 계층: 프로쎄스에 속한 모든 프로쎄스를 보여줍니다. 프로쎄스가 계층으로 표시됩니다.

나의 프로쎄스: 현재 사용자가 소유하고있는 프로쎄스를 보여줍니다.

관리자 프로쎄스: 관리권한을 가진 사용자가 소유하고있는 프로쎄스를 보여줍니다.

다른 사용자프로쎄스: root 또는 현재 사용자가 소유하고있지 않은 프로쎄스를 보여줍니다.

활성프로쎄스: 실행중이고 잠자기상태가 아닌 프로쎄스를 보여줍니다.

비활성 프로쎄스: 실행중이지만 잠자기상태인 프로쎄스를 보여줍니다.

창문가진 프로쎄스: 창문을 생성하는 프로쎄스를 보여줍니다. 사용자가 볼수 없는 창문도 있습니다.

선택한 프로쎄스: 이 항목이 선택되여있을 때 선택된 프로쎄스만 보여줍니다.
