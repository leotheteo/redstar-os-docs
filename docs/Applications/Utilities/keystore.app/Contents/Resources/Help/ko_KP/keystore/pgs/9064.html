열쇠사슬 생성하기

계정환경설정창에서 사용자계정을 설정하면 해당 사용자가 콤퓨터에 처음 가입할 때 같은 암호를 가진 열쇠사슬이 자동적으로 생성됩니다. 이 열쇠사슬은 표준열쇠사슬 입니다. 사용자가 봉사기나 응용프로그람의 암호를 생성하면 암호가 이 열쇠사슬에 추가됩니다.

사용자 계정으로 가입할 때 자동으로 잠그지 않는 추가적인 개인용 열쇠사슬을 생성할수 있습니다.

열쇠사슬을 생성하려면

응용프로그람의 보조프로그람안에 있는 열쇠보관함을 실행시키십시오.

<파일 / 새 열쇠사슬>을 선택하십시오.

열쇠사슬의 이름을 입력하고 <보관>를 누르십시오.

열쇠사슬에 대한 암호를 입력한 다음 확인마당에 다시 입력하십시오.
