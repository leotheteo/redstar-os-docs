언제든지 열쇠사슬의 암호를 변경할수 있습니다. 하지만 가입할 때 표준열쇠사슬을 자동으로 잠금해제하려면 열쇠사슬암호를 체계가입암호와 일치시키십시오.

체계가입암호가 표준열쇠사슬암호와 동일하지 않다거나 응용프로그람이 열쇠사슬에 접근할 때 열쇠사슬이 잠겨있다면 암호를 요구할것입니다.
