열쇠사슬 잠금과 잠금해제

표준열쇠사슬은 체계를 설치할 때 생성되며 열쇠사슬잠금해제대화창에서 열쇠사슬암호를 입력하거나 가입하면 자동적으로 잠금해제됩니다. 열쇠보관함에서 다른 암호를 생성하지 않았거나 열쇠보관함을 사용하여 현재 열쇠사슬의 암호를 변경하지 않았다면 열쇠사슬암호는 항상 가입암호와 같습니다.

열쇠사슬을 잠그거나 잠금해제하려면

응용프로그람의 보조프로그람안에 있는 열쇠보관함을 실행시키십시오.

열쇠사슬목록이 숨겨져있다면 <보기 / 열쇠사슬목록 보이기>를 선택하십시오.

열쇠사슬목록에서 열쇠사슬을 선택하고 창문웃부분에 있는 자물쇠그림기호를 눌러 열쇠사슬을 잠그거나 잠금해제하십시오.

■

대화창에서 암호를 요구한다면 열쇠사슬암호를 입력하십시오.
