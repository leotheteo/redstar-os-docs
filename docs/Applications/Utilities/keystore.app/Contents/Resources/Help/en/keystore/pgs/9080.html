Adding an existing keychain file to your keychain list

If you have a keychain file from another computer, you can add the keychain to your keychain list.

To add a keychain to the keychain list:

If the file has an extension .keychain then you can just open the file.

Otherwise, open Key Store located in the Utilites folder in the Applications folder.

Choose File menu > Add Keychain.

Select the keychain file and click Open.
