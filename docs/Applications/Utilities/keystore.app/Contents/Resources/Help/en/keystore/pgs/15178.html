Getting information about a certificate

You can use the Key Store utility to view the information contained in a certificate.

To view the information contained in a certificate:

Open Key Store located in the Utilites folder in the Applications folder.

To reduce the number of items and show only certificates, select a certificate category in the Category list.

Select a certificate.

For more detailed information about the certificate, click the Info (i) button.
