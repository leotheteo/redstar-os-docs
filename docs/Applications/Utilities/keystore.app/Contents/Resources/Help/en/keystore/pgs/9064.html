Creating a keychain

When you set up a user account in RedStar OSusing the Accounts preferences pane, a keychain with the same password is automatically created the first time you log in to the computer. This keychain is the default keychain. When the you create passwords for servers or applications, the passwords are added to this keychain.

You may want to create an additional keychain for personal use that isn’t automatically unlocked when you log in to your user account. For example, you can create a “top secret” keychain to store notes, financial information, and any other items you want to store securely.

To create a keychain:

Open Key Store, located in the Utilites folder in the Applications folder.

Choose File > New Keychain.

Type a name for the keychain, and then click Create.

Type a password for the keychain, and then type it again in the Verify field.

■

For help choosing a good password, click the key button to the right of the Password field.
