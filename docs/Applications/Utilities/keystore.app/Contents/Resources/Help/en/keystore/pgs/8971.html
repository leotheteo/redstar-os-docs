Making widgets available to all

If you are an administrator user, you can make Dashboard widgets that you’ve downloaded available to all users of the computer.

To make a widget available to all users:

Move or copy the widget into the Widgets folder in the Library folder at the top level of your hard disk (not the Library folder in your home folder).

If you wish to delete the widget you made available to all users, remove it from the Widgets folder in the Library folder at the top level of your hard disk. You must be an administrator of the computer to do this.

Important: The Widgets folder in the Library folder at the top level of your hard disk is where the standard RedStar OS widgets are located. If you delete a widget from this folder, you may need to reinstall RedStar OS in order to reinstall the widget.
