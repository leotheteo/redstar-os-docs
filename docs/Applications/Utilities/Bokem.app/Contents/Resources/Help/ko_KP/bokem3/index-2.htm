암호화구획

사용자는 보검을 리용하여 암호화구획을 생성, 삭제, 탑재/해제할수 있습니다. 보검은 암호화된 구획을 자동적으로 검출하며 프로그람이 기동할 때와 암호화구획이 생성, 삭제, 탑재/해제될 때마다 암호화구획목록을 갱신합니다. 보검이 제공하는 암호화구획관리기능들을 보면 다음과 같습니다.

암호화구획의 생성

1. 보검의 차림표에서 <암호화구획/생성>을 누릅니다.

2. 화면에 현시된 암호화구획생성대화창에서 암호화하려는 일반구획을 선택합니다.

3. 암호를 입력하고 암호알고리듬을 선택합니다.

4. 암호화구획의 이름을 입력하고 내부파일체계를 선택합니다. 끝내기단추를 누르면 생성과정을 보여주는 대화창이 현시됩니다.

5. 확인단추를 누르면 새로 생성된 암호화구획이 목록에 추가됩니다.

암호화구획의 삭제

1. 삭제하려는 암호화구획을 선택하고 보검의 차림표에서 <암호화구획/삭제>를 누릅니다. 그러면 암호화구획을 일반구획으로 초기화하는 대화창이 현시됩니다.

2. 구획이름과 파일체계를 선택합니다. 초기화단추를 누르면 일반구획으로 초기화됩니다.

암호화구획의 탑재

1. 탑재하려는 암호화구획을 선택하고 보검의 차림표에서 <암호화구획/탑재>를 누릅니다.

2. 탑재위치와 암호를 입력하고 탑재단추를 누릅니다. 탑재가 성과적으로 끝나면 선택된 암호화구획의 그림기호가 일반구획그림기호 로 변경됩니다.

암호화구획의 탑재해제

1. 해제하려는 암호화구획을 선택하고 보검의 차림표에서 <암호화구획/탑재해제>를 누릅니다.

2. 탑재해제가 성과적으로 끝나면 선택된 암호화구획의 그림기호가 열쇠달린 구획으로 변경됩니다.
