가상디스크

사용자는 보검을 리용하여 가상디스크를 생성, 삭제, 탑재/해제할수 있습니다. 보검은 사용자가 리용하는 가상디스크의 목록을 관리하며 경로가 달라지거나 수동적으로 삭제된 가상디스크를 자동적으로 목록에서 제거합니다. 암호화구획과 마찬가지로 프로그람이 기동할 때와 가상디스크가 생성, 삭제, 탑재/해제될 때마다 가상디스크목록을 갱신합니다. 보검이 제공하는 가상디스크관리기능들을 보면 다음과 같습니다.

가상디스크의 생성

1. 보검의 차림표에서 <가상디스크/생성>을 누릅니다.

2. 화면에 현시된 가상디스크생성대화창에서 《새로운 가상디스크를 생성합니다.》를 선택하고 다음단추를 누릅니다.

3. 생성하려는 가상디스크의 경로와 크기를 입력합니다. 가상디스크의 경로는 편집칸옆의 《…》 단추를 눌러 선택할수도 있습니다. 가상디스크의 크기도 크기입력칸밑의 표쪽을 움직여 설정할수 있습니다.

4. 암호를 입력하고 암호알고리듬을 선택합니다.

5. 가상디스크의 이름을 입력하고 내부파일체계를 선택합니다. 끝내기단추를 누르면 생성과정을 보여주는 대화창이 현시됩니다.

6. 확인단추를 누르면 새로 생성된 암호화구획이 목록에 추가됩니다.

가상디스크의 추가

1. 이미 생성되여있던 가상디스크를 등록하려는 경우에는 가상디스크생성대화창의 첫 화면에서 《이미 만들어진 가상디스크를 추가합니다.》를 선택하고 다음 단추를 누릅니다.

2. 추가하려는 가상디스크의 경로를 입력합니다. 편집칸옆의 《…》단추를 눌러 가상디스크를 선택할수도 있습니다. 끝내기단추를 누르면 지정된 가상디스크가 목록에 추가됩니다.

가상디스크의 삭제

1. 삭제하려는 가상디스크를 선택하고 보검의 차림표에서 <가상디스크/삭제>를 누릅니다. 그러면 삭제여부를 묻는 대화창이 현시됩니다.

2. 삭제를 계속하려면 예를 누릅니다. 삭제가 성과적으로 진행되면 선택되였던 가상디스크가 목록에서 제거됩니다.

가상디스크 의 탑재

1. 탑재하려는 가상디스크를 선택하고 보검의 차림표에서 <가상디스크/탑재>를 누릅니다.

2. 탑재위치와 암호를 입력하고 탑재단추를 누릅니다. 탑재가 성과적으로 끝나면 선택된 가상디스크의 그림기호가 변경됩니다.

가상디스크의 탑재해제

1. 해제하려는 가상디스크를 선택하고 보검의 차림표에서 <가상디스크/탑재>해제를 누릅니다.

2. 탑재해제가 성과적으로 끝나면 선택된 암호화구획의 그림기호가 변경됩니다.
