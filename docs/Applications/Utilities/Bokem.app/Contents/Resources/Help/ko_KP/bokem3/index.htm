소 개

암호화파일체계 보검은 구획을 암호화하거나 암호화된 가상디스크를 제공하는 프로그람입니다.

보검은 사용자에게 투명한 암호화를 제공합니다. 투명한 암호화란 사용자가 암호화된 매체를 리용할 때 암호를 한번 입력한 다음에는 일반구획처럼 리용할수 있다는것을 의미합니다. 사용자가 입력한 암호는 콤퓨터에 접속된 그 어느 2차기억기에도 보관되지 않으며 오직 처음 암호를 입력할 때 기억기에 림시적으로 보관됩니다.

보검은 국가표준암호알고리듬 《필승》을 비롯한 여러가지 암호알고리듬을 지원하며 256bit의 열쇠길이를 리용합니다.

보검에서 제공하는 암호화매체에는 암호화구획과 가상디스크가 있습니다. 암호화구획은 하드디스크와 USB디스크와 같은 2차기억매체상의 구획을 암호화한것이며 가상디스크는 쓰기가능한 임의의 경로에 지정된 크기의 파일을 만들고 그 내용을 암호화구획처럼 형식화한것입니다.

보검매체안에 들어있는 모든 자료는 암호화됩니다. 즉 파일이름, 크기, 속성, 내용, 등록부구조와 같은 모든 자료가 암호화됩니다.

보검의 기동

- 도크에서 응용프로그람그림기호를 누르고 보조프로그람을 누른 다음 보검그림기호를 누릅니다.

* 보검그림기호를 도크에 끌어다놓고 리용할수도 있습니다.

- 일반사용자로 가입하여 보검을 리용하는 경우 사용자인증창문이 현시되는데 여기에 현재 가입한 사용자의 암호를 입력합니다.
